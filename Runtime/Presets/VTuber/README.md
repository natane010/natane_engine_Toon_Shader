# VTuber向けプリセット

高品質アニメ調のVTuberキャラクター向けに最適化されたマテリアルプリセット集です。

## プリセット一覧

### 1. VTuber - キャラクター肌
**用途**: キャラクターの肌
**特徴**:
- 柔らかいセルシェーディング
- SSSで透明感と血色感を表現
- リムライトで立体感
- 高品質なセルシェーディング

**推奨設定**:
- Shadow Steps: 2
- Shadow Sharpness: 0.08
- SSS Intensity: 0.4

---

### 2. VTuber - キャラクター髪
**用途**: キャラクターの髪
**特徴**:
- シャープなアニメ調ハイライト
- MatCapで光沢感を追加
- 両面描画でボリューム感
- 高品質なセルシェーディング

**推奨設定**:
- Shadow Sharpness: 0.05（よりシャープ）
- Specular Sharpness: 0.9
- Cull Mode: Off（両面描画）

---

### 3. VTuber - キャラクター服
**用途**: キャラクターの衣服
**特徴**:
- クリーンなセルシェーディング
- 明瞭なアウトライン
- シンプルで美しい表現
- 高品質なセルシェーディング

**推奨設定**:
- Shadow Steps: 2
- Shadow Sharpness: 0.1
- Outline Width: 0.005

---

### 4. VTuber - キャラクター目
**用途**: キャラクターの目・瞳
**特徴**:
- 明るくキラキラした表現
- エミッションで輝きを追加
- 強いスペキュラーハイライト
- 高品質なセルシェーディング

**推奨設定**:
- Shadow Steps: 3（柔らかく）
- Specular Intensity: 1.5
- Emission: 有効

---

### 5. VTuber - ライブパフォーマンス
**用途**: ライブ配信・パフォーマンス用の軽量設定
**特徴**:
- 高パフォーマンス設定
- 必要最小限の機能のみ有効
- クリーンで安定したレンダリング
- 軽量なアニメ調セルシェーディング

**推奨設定**:
- エフェクトは最小限
- アウトラインのみ有効
- VRChat/ライブ配信に最適

---

## 使用方法

### 1. プリセットの生成
Unity Editorで以下のメニューを実行：
```
Natane > Generate VTuber Presets
```

### 2. プリセットの適用
1. マテリアルを選択
2. インスペクターで「マテリアルプリセット＆共有」セクションを展開
3. 使用したいプリセットをドラッグ＆ドロップ
4. 「Apply Preset」ボタンをクリック

### 3. カスタマイズ
プリセットを適用後、以下の調整が可能です：
- 色の変更（Main Color、Shadow Color等）
- テクスチャの割り当て（Main Texture、Normal Map等）
- エフェクトの微調整（Specular、Rim Light等）

## シェーディングスタイルについて

高品質なアニメ調セルシェーディングを目指して設計されています：

- **高品質なセルシェーディング**: クリーンで明瞭な陰影境界
- **距離補正アウトライン**: カメラ距離に応じた一貫した太さ
- **パフォーマンス最適化**: VRChat、ライブ配信に適した設定
- **アニメ調レンダリング**: プロフェッショナルな品質

## カスタムプリセットの作成

独自のプリセットを作成する場合：

1. マテリアルで好みの設定を作成
2. `Assets > Create > Natane > Material Preset` で新規プリセット作成
3. 「Create From Material」ボタンで現在のマテリアル設定を保存

## 技術詳細

### 推奨パラメータ範囲

**セルシェーディング**:
- Shadow Steps: 2-3（アニメ調）
- Shadow Sharpness: 0.05-0.15（アニメ調推奨）
- Shadow Offset: -0.1 ~ 0.1

**アウトライン**:
- Outline Width: 0.002-0.006（キャラクター用）
- 距離補正が自動で適用されます

**パフォーマンス**:
- 基本機能のみ: ~50-60 FPS（VR）
- フル機能: ~30-40 FPS（VR）

## トラブルシューティング

### プリセットが見つからない
メニューから「Natane > Generate VTuber Presets」を実行してください。

### 色が変わらない
テクスチャが割り当てられている場合、Color設定が乗算されます。
白いテクスチャまたはテクスチャなしで色の変更が見やすくなります。

### パフォーマンスが悪い
「VTuber - ライブパフォーマンス」プリセットを使用するか、
不要なエフェクト（SSS、MatCap、Reflection等）を無効化してください。
