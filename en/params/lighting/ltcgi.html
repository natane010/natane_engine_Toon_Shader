LTCGI

Realistic lighting with real-time area lights

LTCGI (Linearly Transformed Cosines Global Illumination) is a real-time area light system. It automatically receives illumination from screens and area lights in supported worlds. To use it, you need to install the at.pimaker.ltcgi package from VCC.

LTCGI Intensity _LTCGIIntensity range

Controls the overall intensity of LTCGI lighting. 1 for full intensity, 0 to disable.

Default: 1

Range: 0 to 2

LTCGI Specular _LTCGISpecular range

Controls the intensity of specular (reflected light) from LTCGI. Used for area light reflections.

Default: 0.5

Range: 0 to 1

Blend _LTCGIBlend range

The blend intensity of the LTCGI effect.

Default: 1

Range: 0 to 1

Blend Mode _LTCGIBlendMode enum

Select the blending method for LTCGI.

  • Normal (0): Standard blending
  • Soft (1): Soft blending
  • Screen (2): Screen (additive brightening)
  • Overlay (3): Overlay (contrast enhancement)

Default: Normal (0)
