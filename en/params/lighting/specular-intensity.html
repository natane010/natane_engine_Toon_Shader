Specular Intensity

Control global brightness of specular highlights

Overview

Specular Intensity is a global multiplier that controls the overall brightness of specular highlights (glossy reflections). It is combined with the Specular Color (_SpecularColor), light color, and light attenuation to determine the final specular contribution.

The final specular output is computed as spec * _SpecularColor.rgb * _SpecularIntensity * lightColor * atten. Since the range extends from 0 to 5, you can boost specular beyond the normal 1x multiplier for HDR-style intense highlights.

Parameters

Specular Intensity _SpecularIntensity range

Global brightness multiplier for specular highlights. 0 completely removes specular contribution, 1 is standard intensity, and values above 1 boost the highlights (brighter gloss). Applied before the specular mask (_SpecularMask) and dithering stages.

Default: 1

Range: 0 to 5

For typical materials, 0.5-1.5 is recommended. For metals or jewelry that need strong highlights, values of 2.0-3.0 can be used.

Usage Tips

  • Quick adjustment: When you want to adjust overall specular brightness, changing this value is more intuitive than modifying the Specular Color RGB values. It preserves the hue while adjusting only the intensity.
  • HDR boost: Setting the value above 1 produces highlights that appear to glow when combined with bloom post-processing. Ideal for jewelry and metallic parts.
  • ForwardAdd pass behavior: In the ForwardAdd pass (additional lights), _AdditionalLightIntensity is also multiplied, allowing separate control of specular from point lights and spot lights.
  • Relationship with Specular Mask: _SpecularIntensity controls the overall brightness, while the _SpecularMask texture controls per-region specular presence. Combining both enables expressions like "generally subtle specular but shiny in specific areas."
  • Fully disabling specular: Setting the value to 0 zeros out the specular contribution, but the shader calculations still run. To fully disable and save performance, turn off the specular feature toggle itself.
