Shadow Color Texture

Control shadow color with textures

Shadow Color Texture is an advanced feature that lets you specify shadow colors via a texture. Use it when you want different shadow colors for different areas, such as bluish shadows for clothing and reddish shadows for skin. The texture colors are used directly as shadow colors.

Shadow Color Texture _ShadowColorTex texture

A texture that defines the shadow color. The color of each pixel in the texture is used as the shadow color for that area. Keyword: _SHADOW_COLOR_TEX

Default: "white" (enabled via toggle)

Paint warm colors (reddish) on skin areas and cool colors (bluish) on clothing areas for natural, beautiful shadow color separation. Uses the same UV mapping as the main texture.
Application Strength _ShadowColorTexStrength range

Controls the influence of the Shadow Color Texture. 0 to not use the texture shadow color (normal shadow color only), 1 to fully apply the texture shadow color.

Default: 1

Range: 0 to 1

Setting to 0.5-0.8 creates a natural blend between the texture shadow color and the normal shadow color.
