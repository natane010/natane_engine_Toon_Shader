Height Fog

Material-based height fog for atmospheric depth

Overview

Height Fog applies a height-based fog effect directly in the material shader. Unlike post-processing fog, this works per-material and does not require scene-level post-processing — making it ideal for VRChat environments where post-processing is unavailable or restricted.

The fog color is blended into the material output based on the fragment's world-space Y position, creating atmospheric depth effects such as ground-level mist, underground cavern haze, or elevated cloud layers.

Controlled by the keyword _HEIGHT_FOG. This feature is available in the Background shader variant.

Parameters

Fog Color _HeightFogColor color

The color of the height fog. This color is blended into the material output for fragments that fall within the fog zone.

Default: (0.7, 0.8, 0.9, 1.0) (light blue-gray)

Use dark blue for mysterious caves, white/light gray for morning mist, and warm orange for sunset atmospheres.
Fog Start Height _HeightFogStart float

The world-space Y position where fog begins to appear. Fragments above this height are unaffected by the fog.

Default: 10.0

Fog End Height _HeightFogEnd float

The world-space Y position below which the fog is at full density. Fragments at or below this height are fully fogged.

Default: 0.0

The fog transitions linearly (or exponentially) between Start and End heights. Set End lower than Start for bottom-up fog.
Fog Density _HeightFogDensity float

A multiplier controlling the overall fog density. Higher values produce thicker, more opaque fog; lower values create a subtler haze.

Default: 1.0

Fog Falloff Mode _HeightFogMode enum

Selects how the fog density transitions between the start and end heights.

  • 0 = Linear — Even, uniform falloff from start to end
  • 1 = Exponential — Concentrates fog density near the bottom, with rapid falloff upward

Default: 0 (Linear)

Linear mode is good for general-purpose fog. Exponential mode works better for ground-hugging mist effects.

Usage Tips

  • For a mysterious underground cave, use a dark blue fog color with a low start height to create a sense of depth.
  • For outdoor morning mist, use white or light gray fog with a moderate density.
  • Linear mode gives an even falloff across the height range; Exponential mode concentrates fog near the bottom for more realistic ground mist.
  • This feature is especially valuable in VRChat worlds where Unity's built-in post-processing fog cannot be used.
  • Multiple objects can share the same fog settings through a shared material, ensuring consistent atmospheric effects across an environment.
