Fur Rendering

Shell-based fur/hair rendering system

Overview

High-quality shell-based fur rendering using 16 shell passes. Creates realistic fur, wool, and hair effects. This feature is available only in the "Fur" rendering type variant. Default OFF due to high GPU cost — requires manual activation.

Controlled by the keyword _FUR (Fur shader variant only). When the _FUR keyword is OFF, all fur passes are discarded with zero GPU cost.

Basic Settings

Fur Length _FurLength float

Controls the length of the fur strands. Higher values produce longer fur.

Start with small values (0.01-0.05) and increase gradually. Very long fur may cause visual artifacts at extreme angles.
Fur Density _FurDensity float

Controls the density of fur strands. Higher values produce thicker, more packed fur.

Alpha Cutoff _FurAlphaCutoff float

Sets the alpha cutoff threshold for fur strand tips. Controls how sharp or tapered the strand ends appear.

Gravity _FurGravity float

Applies a gravity drooping effect to fur strands using quadratic falloff. Higher values make the fur droop more towards the ground.

Color Settings

Root Color _FurRootColor color

Sets the color at the base (root) of fur strands.

Darker root colors with lighter tips create a natural fur gradient. Match with the base material color for seamless blending at the surface.
Tip Color _FurTipColor color

Sets the color at the tip of fur strands.

Color Blend _FurColorBlend float

Controls the blend factor between root and tip colors along the fur strand length.

Shading

Ambient Occlusion _FurAO float

Controls the self-occlusion ambient darkening effect. Fur near the base appears darker, simulating light absorption within the fur volume.

Shadow Strength _FurShadowStrength float

Controls the intensity of shadows cast on the fur surface.

Specular _FurSpecular float

Controls the specular highlight intensity on fur strands.

Rim Light _FurRimLight float

Controls the rim lighting intensity on fur. Creates a backlit halo effect around the fur silhouette.

Wind Animation

Wind Direction _FurWindDirection vector

Sets the direction of the wind force applied to fur strands.

Wind Speed _FurWindSpeed float

Controls the animation speed of the wind effect on fur.

Wind Strength _FurWindStrength float

Sets the force strength of the wind animation.

LOD & Performance

LOD Distance _FurLODDistance float

Sets the distance at which LOD (Level of Detail) begins reducing shell layers. Beyond this distance, the number of shell passes decreases to save GPU performance.

Enable LOD for VRChat optimization. Set to a reasonable distance (5-10m) to maintain quality up close while saving performance at a distance.
LOD Minimum Layers _FurLODMinLayers float

Sets the minimum number of shell layers used at the LOD distance. The layer count interpolates between 16 (full quality) and this minimum based on camera distance.

Textures

Noise Texture _FurNoiseTex texture

A noise texture that defines the fur strand pattern. Controls the shape and distribution of individual fur strands across shells.

Use high-contrast noise for distinct fur strands, or soft noise for a woolly/plush appearance.
Fur Mask _FurMask texture

A mask texture that controls where fur is rendered. White areas produce fur, black areas remain fur-free.

Performance warning — 16 shell passes multiply draw calls significantly. Use _FurMask to restrict fur to specific areas (collar, tail, ears) to reduce rendering cost.
