Offset Rim Light

Freely position rim highlights with XY offset and light direction linking

Overview

Offset Rim Light differs from the standard rim light by allowing you to manually offset the rim highlight position in the XY direction. It works by adding an offset to the view-space normal before performing the Fresnel calculation, giving you full control over where the light appears. Additionally, it can optionally link to the scene's light direction for dynamic adaptation to changing lighting environments.

Controlled by the keyword _OFFSET_RIM_LIGHT. No shader instructions are generated when disabled.

Parameters

Offset Rim Color _OffsetRimColor color

Sets the color of the offset rim light. Adjust to match the scene's atmosphere or character design.

Default: (0.8, 0.9, 1, 1) (pale blue-white)

Warm colors work well for backlit scenes, and cool blue tones create a sleek impression.
Power _OffsetRimPower range

Controls the sharpness (falloff curve) of the rim. Higher values concentrate the effect on thin edge areas, while lower values spread it over a wider area.

Default: 3

Range: 0.01 - 10

Intensity _OffsetRimIntensity range

Controls the brightness of the rim light. Values exceeding 1.0 produce HDR-like glow effects.

Default: 1

Range: 0 - 10

Offset X _OffsetRimOffsetX range

Horizontal offset of the rim position in view space. Positive values shift the rim to the right, negative values to the left.

Default: 0.3

Range: -5 - 5

Offset Y _OffsetRimOffsetY range

Vertical offset of the rim position in view space. Positive values shift the rim upward, negative values downward.

Default: 0.1

Range: -5 - 5

Use Light Direction _OffsetRimUseLightDir toggle

When enabled, the rim position dynamically follows the scene's directional light direction. The light-based offset is added to the manual XY offset.

Default: 0 (disabled)

Enable this for dynamic lighting environments (such as VRChat world lights) for a more natural appearance.
Light Direction Strength _OffsetRimLightDirStrength range

Controls how strongly the rim follows the light direction. Higher values result in stronger tracking of the light direction.

Default: 0.5

Range: 0 - 1

Sharpness _OffsetRimSharpness range

Controls the sharpness of the toon (cel-shading) boundary of the rim. A smoothstep function is applied to create the toon boundary; higher values produce a crisper, more cel-shaded look.

Default: 0.5

Range: 0 - 1

Use 0.7-0.9 for a crisp anime-style rim, and 0.2-0.4 for a softer appearance.
Shadow Mask _OffsetRimShadowMask range

Controls how much the rim light is suppressed in shadowed areas. Higher values reduce rim intensity in shadows, producing a more natural lighting result.

Default: 0.5

Range: 0 - 1

Mask

Offset Rim Mask _OffsetRimMask texture

A mask texture that controls the display area of the offset rim light. The R channel is used.

Default: "white" (full display)

White = rim light visible, Black = rim light hidden. Useful for applying the rim to specific areas like hair or certain parts of clothing.

Blend Settings

Blend Mode _OffsetRimBlendMode enum

Selects the blend method for the offset rim light effect.

  • Normal (0) - Standard additive blending
  • Soft (1) - Soft additive. Prevents over-brightening
  • Screen (2) - Screen blending. Natural brightness addition
  • Overlay (3) - Overlay blending. Enhances contrast

Default: Normal (0)

Blend _OffsetRimBlend range

Controls the overall opacity of the offset rim light effect.

Default: 1

Range: 0 - 1

Blur _OffsetRimBlur range

Adjusts the blur amount of the rim. Internally attenuates the power value to produce a softer rim.

Default: 0

Range: 0 - 1

Distance Fade _OffsetRimDistFade range

When the distance fade feature (_DISTANCE_FADE) is active, controls how much the offset rim intensity fades based on camera distance.

Default: 0

Range: 0 - 1

Usage Tips

Backlighting Effect

Set Offset X to 0 and Offset Y to a positive value (e.g., 0.5) to create a backlit rim from above. Enable "Use Light Direction" to have the rim automatically adjust to match the world's light position.

Anime-Style Angel Ring

Set high sharpness (0.7-0.9) and a positive Offset Y to create an angel ring effect on hair. Use a mask texture to apply it only to hair meshes for the best result.

Performance Notes

This can be used simultaneously with the standard rim light (_RIM_LIGHT), but enabling both increases shader variant count. For VRChat Quest environments, using only one is recommended.
