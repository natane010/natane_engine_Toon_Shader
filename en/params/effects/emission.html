Emission

Self-illuminating glow effect

An effect that makes part or all of a material self-luminous. Used for glowing signs, neon expressions, magic effects, and luminous accessories. Scroll and pulse animations are also available.

Keywords: _EMISSION, _EMISSION_SCROLL, _EMISSION_PULSE

Basic Settings

Emission Color _EmissionColor color

Sets the emission (glow) color. Supports HDR color, and setting intensity above 1 enables strong glow when combined with bloom effects.

Default: (0, 0, 0, 1) (black, no emission)

Increasing HDR color intensity combined with post-processing bloom produces brilliant glow effects.
Emission Map _EmissionMap texture

A texture that defines the emission glow pattern. White areas glow, while black areas do not.

Default: "white" (entire surface glows)

Scroll Animation

Scroll Speed _EmissionScrollSpeed float

Sets the speed at which the emission texture scrolls. Enabled by the keyword _EMISSION_SCROLL.

Default: 1

Create animated effects like flowing light or circuit-like movement.

Pulse Animation

Pulse Speed _EmissionPulseSpeed float

Sets the speed at which the emission pulses (flickers). Enabled by the keyword _EMISSION_PULSE.

Default: 1

Pulse Amplitude _EmissionPulseAmplitude range

Sets the amplitude of the pulse's brightness variation. Higher values produce greater contrast between bright and dark.

Default: 0.5 (Range: 0 - 1)

Mask

Emission Mask _EmissionMask texture

Controls the application area of emission with a texture. Enabled by the keyword _EMISSION_MASK.

Default: "white" (apply to all)

White = emission applied, Black = emission hidden. Provides additional mask control separate from the emission map.

Glow (Bloom)

Emission Glow (Bloom) _EmissionGlow range

Bleeds and brightens the glowing areas, adding a soft luminous effect.

  • 0 = No glow (sharp emission)
  • 0.3 - 0.5 = Moderate glow (recommended)
  • 0.7 - 1.0 = Strong glow (intense radiance)

Default: 0 (Range: 0 - 1)

Combining with HDR color produces more vivid glow effects.

Blend Settings

Blend Mode _EmissionBlendMode enum

Selects how the emission is composited with the base color.

  • Normal (0) - Normal blending
  • Soft (1) - Soft light
  • Screen (2) - Screen
  • Overlay (3) - Overlay

Default: 0 (Normal)

Blend _EmissionBlend range

Sets the overall application amount of the emission effect.

Default: 1 (Range: 0 - 1)

Blur _EmissionBlur range

Blurs the boundaries of the emission.

Default: 0 (Range: 0 - 1)
