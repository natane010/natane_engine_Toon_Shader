Glitch

Digital noise and RGB split distortion effect

An effect that recreates digital video artifacts and glitches. Combines random UV distortion with RGB color splitting to create cyberpunk-style staging and transition effects. When used together with the hologram effect, even more intense sci-fi expressions are possible.

Keyword: _GLITCH

Glitch Settings

Glitch Intensity _GlitchIntensity range

Sets the strength of UV distortion caused by the glitch. Higher values produce more intense screen disruption.

Default: 0.5 (Range: 0 - 1)

Glitch Speed _GlitchSpeed float

Sets the animation speed of the glitch. Higher values switch glitch patterns more rapidly.

Default: 1

Block Size _GlitchBlockSize range

Sets the size of the distorted blocks in the glitch. Higher values create larger block distortions.

Default: 0.1 (Range: 0.01 - 1)

Small values produce fine noise-like glitch, while large values create a block-collapse style glitch.
RGB Split Intensity _GlitchRGBSplitIntensity range

Sets the strength of RGB chromatic aberration (color splitting). Offsets the red, green, and blue channels to produce a TV color-shift effect.

Default: 0.5 (Range: 0 - 1)

Glitch Frequency _GlitchFrequency range

Sets how frequently the glitch occurs. Higher values cause glitches to occur more often.

Default: 0.3 (Range: 0 - 1)

0.1-0.3 produces intermittent glitches, while 0.7 or higher causes nearly constant glitching.

Blend Settings

Blend Mode _GlitchBlendMode enum

Selects how the glitch effect is composited with the base color.

  • Normal (0) - Normal blending
  • Soft (1) - Soft light
  • Screen (2) - Screen
  • Overlay (3) - Overlay

Default: 0 (Normal)

Blend _GlitchBlend range

Sets the overall application amount of the glitch effect.

Default: 1 (Range: 0 - 1)

Blur _GlitchBlur range

Blurs the boundaries of the glitch effect.

Default: 0 (Range: 0 - 1)
