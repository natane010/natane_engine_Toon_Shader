X-Ray

Show only the part hidden behind walls and other objects, in a separate color, outline, or pattern. A dedicated variant for see-through silhouettes, target markers, and the "visible when hidden" ghost look. (v1.6.0)

PREVIEW X-Ray

Overview

X-Ray is a dedicated shader variant, Natane/Toon Shader (X-Ray), for occluded silhouettes. Because it needs an extra depth-test pass, it is not built into the normal shader and ships as a separate variant, generated from the Cutout variant.

The visible (non-occluded) part renders normally through the full toon feature set (ZTest LEqual). In addition, an X-RAY pass is drawn right after OUTLINE and before the forward passes. That pass uses ZTest Greater to draw only fragments behind the depth buffer — i.e. the occluded part.

It shares the standard vert, so vertex deformations such as VAT, Smear, Perspective Flat, and Face Ortho keep the see-through silhouette consistent with the visible surface. Stencil is declared at the SubShader level and applies to the X-RAY pass too.

Display modes (_XRayMode)

ValueModeDescription
0OutlineOnlyKeep only the Fresnel edge (thickness via _XRayOutlineWidth)
1SolidFillFlat fill by _XRayOccludedAlpha
2DitherFillBayer 4x4 dither halftone fill (screen-pixel based)
3ScanlineScanlines (screen space or world Y)
4FresnelRim-gradient fill + additive edge glow (default)
5PulseAlpha pulses via a time sine wave (_XRayPulseSpeed)
6DepthGradientFades with view depth (_XRayDepthFade)

Wireframe mode is intentionally omitted (it would need a geometry shader / barycentric coordinates). Use OutlineOnly / Scanline for line-based looks.

Masked by texture alpha (_MainTex.a × _Color.a) with a small clip threshold, so cutout holes do not glow through walls.

Main uses

  • World effects / self-occluding props: character outlines through walls, target markers, highlighting hidden performers or items
  • Cyber-scan effects (combine with Topographic for scan lines + see-through)
  • The "visible when hidden" look for ghosts and spirits

Behavior in VRChat

  • On avatars: it shows "you, seen through another player's world geometry (walls)". As long as another player's mesh writes depth, your X-Ray silhouette is visible behind it. The far side of your own mesh (self-occlusion) also shows.
  • Safety-blocked avatars fall back to a normal toon cutout via VRCFallback = "ToonCutout".

Known limitations

  • Draw order (transparent sorting): the X-RAY pass is LightMode = "Always", so it can show through transparent objects drawn later. This is a structural transparent-sorting limit, the same as Ghost and ordinary transparent shaders.
  • Wireframe mode is not supported (see above).
  • DepthGradient approximates using the fragment's own view depth to avoid extra depth sampling.
