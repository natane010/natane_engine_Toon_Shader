Color Bleeding

Simulates pigment diffusion where bright colors bleed into darker areas

Overview

Color Bleeding simulates the effect of color diffusion, similar to watercolor paint bleeding or ink spreading during printing. It samples 8 neighboring pixels (4 cardinal + 4 diagonal directions) and selectively blends brighter neighbors into darker areas, creating a natural color diffusion effect. Only brighter pixels bleed into darker ones, never the reverse.

Controlled by the keyword _COLOR_BLEEDING. No shader instructions are generated when disabled.

This is a screen-space effect that requires GrabPass. Not available in Lite variants.

Parameters

Bleeding Radius _BleedingRadius range

Controls the range of color bleeding in pixel units. Larger values spread the color over a wider area. The value is multiplied by the texel size, so the actual effect depends on screen resolution.

  • 0.5-1 - Subtle bleeding (recommended)
  • 1-3 - Moderate bleeding
  • 3-5 - Large bleeding (may appear blurry)

Default: 1

Range: 0 - 5

Blend _BleedingBlend range

Controls the intensity of the bleeding effect. 0 keeps the original image, 1 fully applies the bleeding effect.

Default: 0.3

Range: 0 - 1

The default value of 0.3 is a subtle setting. Increase to 0.5-0.7 for a stronger painterly expression.

Usage Tips

Watercolor-Style Rendering

Combine with the Watercolor effect for a more authentic watercolor look. The Watercolor effect handles edge darkening and paper texture in texture space, while Color Bleeding handles color diffusion in screen space, creating a complementary pairing.

Luminance-Based Selective Blending

Unlike a simple blur, this effect performs luminance-based selective blending. Only brighter neighboring pixels bleed into darker areas, creating a natural one-directional color flow. Dark colors never bleed into bright areas.

Performance Notes

With a fixed 8-direction sampling (8 texture fetches), this effect is relatively lightweight compared to the Kuwahara filter. It can be used in VRChat environments with moderate performance impact.
