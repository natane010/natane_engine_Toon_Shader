Decal

Apply stickers and marks in UV space

A decal system for applying textures onto mesh surfaces. Ideal for logos, marks, tattoos, patches, and other decorative expressions. Position, rotation, and scale can be freely adjusted in UV space.

Keyword: _DECAL

Decal Texture

Decal Texture _DecalTex texture

The texture to apply as a decal. By using the alpha channel, irregularly shaped decals can also be created.

Default: "white"

Using transparent PNGs, you can cleanly apply round stickers or complex-shaped logos.
Decal Color _DecalColor color

A color multiplied with the decal texture. Used to adjust the color tone of the texture or create solid-colored decals.

Default: (1, 1, 1, 1) (white, no change)

Position & Transform

Decal Position (XY) _DecalPosition vector

Sets the position of the decal in UV space. Adjust the placement using X and Y.

Default: (0, 0, 0, 0)

Since it uses the UV coordinate system, adjust the position while checking the mesh's UV layout.
Rotation _DecalRotation range

Sets the rotation angle of the decal in degrees.

Default: 0 (Range: 0 - 360)

Scale _DecalScale float

Sets the size of the decal. 1.0 is the base size; increasing the value enlarges the decal.

Default: 1

Blend Settings

Blend Mode _DecalBlendMode enum

Selects how the decal is composited with the base color.

  • Add (0) - Additive blending (brighten)
  • Multiply (1) - Multiply (darken)
  • Overlay (2) - Overlay
  • Replace (3) - Replace (overwrite with decal)

Default: 0 (Add)

Replace is recommended for logos and patches, while Add works well for glowing patterns.
Blend _DecalBlend range

Sets the overall application amount of the decal effect.

Default: 1 (Range: 0 - 1)

Blur _DecalBlur range

Blurs the boundaries of the decal.

Default: 0 (Range: 0 - 1)
