Dissolve

Transition effect where material melts and disappears

The Dissolve effect creates a transition where material gradually disappears or disintegrates. Ideal for VRChat avatar appear/disappear animations. By animating the dissolve amount parameter, you can make objects appear or vanish.

Keyword: _DISSOLVE

Dissolve Settings

Dissolve Amount _DissolveAmount range

Controls the dissolve progress. Operate this parameter via animation keys to achieve appear/disappear effects.

  • 0 = Fully visible (no dissolve)
  • 0.5 = Half dissolved
  • 1 = Fully disappeared

Default: 0 (Range: 0 - 1)

In VRChat, control this parameter from the Animator Controller to create appear/disappear effects.
Dissolve Texture (Noise) _DissolveTex texture

A noise texture that defines the dissolve pattern. The dissolve progresses based on the light and dark values of the texture.

Default: "white"

Various dissolve expressions are possible with different patterns such as Perlin noise or Voronoi noise.

Edge Settings

Edge Width _DissolveEdgeWidth range

Sets the width of the glowing edge at the dissolve boundary.

Default: 0.1 (Range: 0 - 0.5)

Edge Color _DissolveEdgeColor color

The color of the glowing edge displayed at the dissolve boundary. Supports HDR color; setting bright colors creates a luminous appearance.

Default: (1, 0.5, 0, 1) (orange)

Choose colors to match your setting: flame-like orange, magical blue, digital green, etc.
Edge Intensity _DissolveEdgeIntensity range

Sets the glow intensity of the dissolve edge. Higher values make the edge glow more intensely.

Default: 2 (Range: 0 - 10)

Mask

Dissolve Mask _DissolveMask texture

Controls the application area of dissolve with a texture. Enabled by the keyword _DISSOLVE_MASK.

Default: "white" (apply to all)

White = dissolve applied, Black = dissolve hidden. Use when you want to dissolve only specific parts.

Blend Settings

Blend Mode _DissolveBlendMode enum

Selects how the dissolve effect is composited.

  • Normal (0) - Normal blending
  • Soft (1) - Soft light
  • Screen (2) - Screen
  • Overlay (3) - Overlay

Default: 0 (Normal)

Blend _DissolveBlend range

Sets the overall application amount of the dissolve effect.

Default: 1 (Range: 0 - 1)

Blur _DissolveBlur range

Blurs the boundaries of the dissolve effect.

Default: 0 (Range: 0 - 1)
