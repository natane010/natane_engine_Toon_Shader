Color Quantize

Reduce color levels for posterization and illustration-style rendering

Overview

Color Quantize limits the number of discrete color levels in the output, creating posterization, retro game-style, or illustration-style color palettes. Two quantization modes are available: RGB mode (uniform levels per channel) and HSV mode (independent levels for hue, saturation, and value). Optional ordered dithering using a 4x4 Bayer matrix can be applied to reduce banding artifacts.

Controlled by the keyword _COLOR_QUANTIZE. No shader instructions are generated when disabled.

Applied only in the ForwardBase pass. No GrabPass required; available in all variants.

Parameters

Quantize Mode _QuantizeMode enum

Selects the color quantization method.

  • RGB (0) - Quantizes each R/G/B channel with uniform level count. Simple posterization
  • HSV (1) - Quantizes hue, saturation, and value independently. Allows more precise color control

Default: HSV (1)

HSV mode is recommended for illustration-style rendering. Independent control over hue and value enables anime cel-shading-like color palettes.
Quantize Levels (RGB) _QuantizeLevels range

Number of discrete levels per channel in RGB mode. Lower values produce stronger posterization.

  • 2-4 - Extreme retro/pixel art style
  • 6-12 - Illustration/anime style (recommended)
  • 16-32 - Subtle color reduction

Default: 8

Range: 2 - 32

Hue Levels _QuantizeHueLevels range

Number of discrete hue levels in HSV mode. Divides the hue wheel into this many segments.

Default: 12

Range: 2 - 36

12 divides the hue wheel at 30-degree intervals, preserving basic color variety. A value of 6 yields a primary-color-dominant look.
Saturation Levels _QuantizeSatLevels range

Number of discrete saturation levels in HSV mode.

Default: 8

Range: 2 - 16

Value Levels _QuantizeValLevels range

Number of discrete value (brightness) levels in HSV mode. For anime-style shadow rendering, setting this low (3-5) is effective.

Default: 8

Range: 2 - 16

Dither Amount _QuantizeDither range

Intensity of ordered dithering using a 4x4 Bayer matrix. Reduces banding (visible color steps) caused by quantization. Generates a stable dither pattern based on screen-space pixel coordinates.

  • 0 - No dithering (sharp color steps)
  • 0.3-0.5 - Moderate dithering (recommended)
  • 0.7-1.0 - Strong dithering (retro game style)

Default: 0.5

Range: 0 - 1

Dithering uses the StabilizeDitherCoord function for stable display in VR stereo rendering.
Blend _QuantizeBlend range

Controls the intensity of the quantization effect. Multiplied with the mask texture value.

Default: 1

Range: 0 - 1

Mask

Quantize Mask _QuantizeMask texture

A mask texture that controls the application area of the quantization effect. The R channel is used.

Default: "white" (full application)

White = quantization applied, Black = no quantization. Useful for keeping skin smooth while applying the illustration style to clothing only.

Usage Tips

Anime Cel-Shading Style

In HSV mode, set value levels to 3-4 and dithering to 0 for crisp, anime cel-shading-like color separation. Keep hue levels at 12-18 to maintain natural color variation.

Retro Game Style

In RGB mode, set levels to 4-6 and dithering to 0.5-0.8 for a retro game-style limited color palette with dithering patterns.

Combining with Kuwahara Filter

Limiting colors with Color Quantize and then smoothing details with the Kuwahara filter creates an impressionist oil-painting style. Color Quantize is processed in Stage A (color transform) and Kuwahara in Stage B (screen space), so they are automatically applied in this order.

Performance Notes

Color Quantize is a lightweight effect. HSV mode adds an RGB-to-HSV conversion, but since it requires no GrabPass and uses only arithmetic operations, it is suitable for mobile GPUs (VRChat Quest).
