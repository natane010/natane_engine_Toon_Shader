Shaped Highlight

Turn the specular into a star, heart, or cross instead of a round dot. Reproduce the symbolic highlights illustrators draw — star sparkles in the eyes, cross flares on a gem. (v1.6.0)

PREVIEW Shaped Highlight

Overview

Instead of a round specular, this adds a procedural shape — circle / ring / cross / star / heart / diamond / crescent / line (or a custom SDF texture) — as the highlight. It targets the symbolic highlights of anime and illustration rather than physical reflection.

The coordinates are built from the view-space deviation of the half vector and normal (the specular peak), so it aligns naturally with the existing specular. It toggles with _SHAPED_HIGHLIGHT and is zero cost when off. You can layer a second shape or make it sparkle over time.

What you can make

  • Star sparkles in the eyes, cross flares on gems
  • Long thin highlights in hair, sharp light streaks on metal
  • Heart-shaped light, glowing sigils on magic items
  • Comic-style flashes that appear for an instant (sparkle pulse)

Key parameters

Shape _ShapedHLShape enum (0–8)

Pick the highlight shape: Circle / Ring / Cross / Star / Heart / Diamond / Crescent / Line / Custom. Custom uses the SDF texture in _ShapedHLTex.

Default: 3 (Star)

Star / Heart for eyes, Cross / Diamond for gems.
Highlight Color _ShapedHLColor color (HDR)

The highlight color. HDR: values above 1 combine with Bloom for a strong glow.

Default: (1, 1, 1, 1)

Size _ShapedHLSize range (0.01–2)

Highlight size. Tune edge softness with _ShapedHLSoftness and non-uniform stretch with _ShapedHLStretch.

Default: 0.5

Light Follow / Camera Follow _ShapedHLLightFollow / _ShapedHLCameraFollow range (0–1)

How much the highlight rotation follows the light direction or the camera. 1 fully follows, 0 keeps a fixed rotation.

Default: LightFollow 1 / CameraFollow 0

Raise CameraFollow to keep an eye sparkle always facing the viewer.

Usage Tips

  • Tied to specular: it is added right after the Specular block using a highlight-safe blend (SafeAdditiveBlend), so it holds up even at high intensity.
  • Layer two: add a secondary shape with _ShapedHLShape2 / _ShapedHLIntensity2 (e.g. a small star inside a big star).
  • Sparkle: raise _ShapedHLSparkleSpeed for a twinkling eye glint.
  • Supports Distance Fade and fades out automatically at range.
