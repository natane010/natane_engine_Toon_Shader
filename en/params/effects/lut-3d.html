3D LUT

Color grading via look-up table

Overview

The 3D LUT (Look-Up Table) effect applies color grading to the final output color in a post-process-like fashion. It uses a strip-layout 2D texture (e.g., a 32x32x32 color cube packed into a 1024x32 image) to remap each input RGB value through the LUT. This is useful for cinematic or anime-style color correction, vintage color effects, and establishing a specific mood or tone.

Controlled by keyword _LUT_3D. When disabled, no shader instructions are generated. Applied only in the ForwardBase pass.

Parameters

Enable 3D LUT _UseLUT3D toggle

Enables or disables the 3D LUT color grading effect.

Default: 0 (Disabled)

LUT Texture _LUT3DTex texture

The strip-layout 3D LUT texture. The typical format is a 32x32x32 color cube arranged horizontally into a 1024x32 pixel image. LUT textures exported from Photoshop, DaVinci Resolve, LUT Generator, and similar tools can be used.

Default: "white" (white texture = no color transformation)

For accurate color reproduction, disable sRGB in the texture import settings and set the filter to Bilinear. Compression should be set to None.
LUT Intensity _LUT3DIntensity range

The strength of the LUT color grading. At 0, the original color is preserved. At 1, the color is fully replaced by the LUT output. Intermediate values linearly interpolate between the original and LUT colors.

Default: 1

Range: 0 - 1

Setting this to around 0.5-0.8 produces a natural-looking color grade.
LUT Grid Size _LUT3DSize float

The number of grid cells per axis in the LUT texture. This must match the LUT texture being used. For example, a 32x32x32 LUT requires a value of 32, while a 16x16x16 LUT requires 16.

Default: 32

If this value does not match the LUT texture size, colors will not be remapped correctly. You can calculate the grid size by dividing the texture width by its height (e.g., 1024 / 32 = 32).

Usage Tips

Obtaining LUT Textures

  • Create your own: Export from Photoshop's "Export Color Lookup" or DaVinci Resolve's color grading tools.
  • Free downloads: Many cinematic LUT packs are available online. Use tools like 3D LUT Creator to convert them to strip layout format.
  • Format note: .cube files cannot be used directly. They must be converted to strip-layout PNG/TGA textures.

Recommended Settings

  • Cinematic look: LUT Intensity at 0.6-0.8 for moderate color correction
  • Dramatic color shift: LUT Intensity at 1.0 for full LUT application
  • Retro style: Sepia or vintage LUT at intensity 0.5

Performance

Requires only two texture samples (for blue slice interpolation) and minimal arithmetic, so the performance cost is very low. Note that it is applied to the final color, so it processes after other effects such as Emission.
