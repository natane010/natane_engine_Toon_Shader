Smooth Normal

Smooth normals for better outlines and shading

Overview

Smooth Normal uses smoothed normals for outline extrusion direction, preventing outline breaks and unnatural protrusions on hard-edge meshes. It reads smooth normals from vertex colors or a baked texture and uses them as the outline normal. Additionally, the Shading Blend feature allows smooth normals to be applied to lighting calculations, softening shadow boundaries.

Controlled by the keyword _SMOOTH_NORMAL. When disabled, no shader instructions are generated. Implemented as a local keyword (shader_feature_local).

Parameters

Enable Smooth Normal _SmoothNormal toggle

Toggles the Smooth Normal feature on/off. Branches at compile time using the keyword _SMOOTH_NORMAL.

Default: OFF

Smooth Normal Mode _SmoothNormalMode enum

Selects the source of smooth normals.

  • 0 - Vertex Color ObjectSpace: Use when vertex color RGB stores object-space normals. Decodes from [0,1] vertex color to [-1,1] range.
  • 1 - Vertex Color TangentSpace: Use when vertex color RGB stores tangent-space normals. Transforms via the TBN matrix. Compatible with lilToon.
  • 2 - Baked Normal Texture: Uses normals baked into a texture. Samples from the texture and transforms from tangent space.

Default: 0 (Vertex Color ObjectSpace)

Smooth Normal Texture _SmoothNormalTex texture

The smooth normal texture used in Mode 2 (Baked Normal Texture). Specify a texture containing tangent-space normals.

Default: "bump"

Not used in Modes 0 and 1.
Smooth Normal Shading Blend _SmoothNormalShadingBlend range

Controls how much smooth normals are blended into the lighting normal. At 0, only the original normal is used for shading; at 1, smooth normals are used exclusively. Use this when you want to soften shadow boundaries in addition to outlines.

Default: 0

Range: 0 – 1

Values of 0.3–0.5 reduce shadow jaggedness while retaining the original surface shape.

Usage Tips

  • Most effective for improving outline quality. Significant improvements on hard-edge meshes (low-poly models or non-merged meshes)
  • Mode 1 (Vertex Color TangentSpace) is compatible with lilToon smooth normals, allowing seamless migration from lilToon
  • Mode 2 (Baked Normal Texture) is useful when vertex colors are already used for other purposes
  • Shading Blend affects lighting in addition to outlines, so start with conservative values and adjust gradually
  • Used in both the vertex shader (outline direction) and fragment shader (shading blend)
