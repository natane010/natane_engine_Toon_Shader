Rendering Settings

Rendering mode, culling, stencil, and other draw controls

Overview

Rendering Settings is the section that controls the fundamental drawing behavior of materials. It includes core shader settings such as opaque/cutout/transparent mode selection, polygon front/back face rendering control, depth buffer writing, and blend modes.

Rendering Mode

Rendering Type RenderingMode enum

Selects the material's rendering mode. The shader internally switches to the appropriate variant based on the mode. All properties are preserved.

  • Opaque - Standard opaque objects. Used for skin, clothes, and solid objects. The fastest and recommended mode.
  • Cutout - Alpha threshold transparency. Used for hair, leaves, and fences. Each pixel is either fully transparent or fully opaque.
  • Transparent - Smooth transparency. Used for glass, water, smoke, and effects. Provides gradual transparency based on alpha value, but is the most expensive mode.
  • Fur - Shell-based fur rendering. Extrudes the mesh along normals across 16 layers and applies noise texture cutoff to simulate fur. Very GPU-intensive; do not use on VRChat Quest.
  • Background - For background and environment objects. Supports lightmaps and PBR (Physically Based Rendering), ideal for static objects like buildings, terrain, and props. Allows blending toon shading with realistic GI lighting.

Default: Opaque

In terms of performance, efficiency ranks as Opaque > Cutout > Transparent. Use Opaque whenever possible.

Cutout-Specific Settings

Alpha Cutoff _Cutoff range

The alpha threshold for Cutout mode. Pixels with texture transparency at or below this value are hidden.

  • Lowering the value: More pixels become visible
  • Raising the value: More pixels become hidden

Default: 0.5 (recommended)

Advanced Settings

Culling Mode _Cull enum

Controls which side of polygons is rendered.

  • Back (2) - Hides backfaces (default; the most common setting)
  • Front (1) - Hides front faces (for special use cases)
  • Off (0) - Double-sided rendering (set when using the backface texture feature)

Default: Back (2)

Double-sided rendering (Off) doubles the drawing cost. Use only when necessary.
Z Write _ZWrite enum

Controls writing to the depth buffer. Normally keep this ON.

  • On (1) - Writes to depth buffer (standard for opaque objects)
  • Off (0) - Does not write to depth buffer (for transparent objects and effects)

Default: On (1)

Transparent-Specific Settings

Source Blend _SrcBlend enum

The blend factor for the source (foreground) during transparent rendering.

Default: SrcAlpha (5)

Destination Blend _DstBlend enum

The blend factor for the destination (background) during transparent rendering.

Default: OneMinusSrcAlpha (10)

Blend modes typically do not need to be changed. The default settings provide proper alpha blending.

Fur-Specific Settings

When the rendering type is set to "Fur", the following Fur-specific section is displayed.

Fur Length _FurLength range

Controls the length of fur strands.

Recommended: 0.01–0.05

Fur Density _FurDensity range

Controls the noise texture tiling, which determines fur density.

Alpha Cutoff _FurAlphaCutoff range

The alpha cutoff threshold for fur. Lower values produce dense fur, higher values produce sparse fur.

Noise Texture _FurNoiseTex texture

A noise texture that defines the fur distribution pattern. If no texture is assigned, procedural noise is used instead.

Fur Mask _FurMask texture

A mask texture that controls where fur grows. White areas grow fur, black areas do not.

Root Color / Tip Color _FurRootColor / _FurTipColor color

Set the color at the base and tip of fur strands independently. A darker root and lighter tip creates a natural look.

Gravity / Wind _FurGravity / _FurWindStrength range

Physics simulation settings. Gravity causes fur to droop downward, and wind adds a sway animation.

Self Occlusion / Self Shadow Intensity _FurAO / _FurShadowStrength range

Controls the darkening effect at the fur base (occlusion) and the shadow intensity inside fur.

LOD Start Distance / Minimum Layers _FurLODDistance / _FurLODMinLayers range

Performance optimization settings. Gradually reduces the number of shell layers starting from the specified distance.

Fur uses 16 shell passes and is very GPU-intensive. Use the LOD settings to reduce cost at a distance. Do not use on VRChat Quest.

Background-Specific Settings

When the rendering type is set to "Background", the following Background-specific sections are displayed.

Background Lightmap Settings

Lightmap Toon Influence _LightmapToonInfluence range

Controls the degree to which the lightmap affects toon shading.

  • 0 - Real GI (lightmap used as-is)
  • 0.5 - Hybrid (recommended; balances toon and GI)
  • 1 - Full Toon (fully driven by toon shading)
To use lightmaps, enable "Contribute GI" on the Mesh Renderer and bake your scene.
Lightmap Brightness _LightmapIntensity range

Adjusts the brightness of the lightmap.

PBR Material Settings

PBR Lighting _EnablePBR toggle

Enables PBR (Physically Based Rendering) lighting. Adds physically-based reflections using Cook-Torrance GGX BRDF on top of toon shading.

Metallic/Smoothness Map _PBR_MetallicGlossMap texture

A texture containing metallic and smoothness data. The R channel stores metallic, and the A channel stores smoothness.

Metallic _PBR_Metallic range

Controls the metalness of the surface. 0 for non-metals (plastic, wood, etc.), 1 for fully metallic.

Default: 0

Smoothness _PBR_Smoothness range

Controls the surface smoothness. 0 for rough surfaces (matte), 1 for perfectly smooth surfaces (mirror-like reflections).

Default: 0.5

Ambient Occlusion Map _PBR_OcclusionMap texture

An ambient occlusion texture that adds natural shadows to crevices and grooves.

AO Intensity _PBR_OcclusionStrength range

Controls the strength of the ambient occlusion effect.

Reflection Probe Intensity _PBR_ReflectionIntensity range

Adjusts the strength of environment reflections from reflection probes.

PBR adds physically-based reflections on top of toon shading. Express material quality using metallic/smoothness textures.

Usage Tips

  • Opaque is best for most VRChat avatar parts (skin, clothes, shoes)
  • Cutout mode is suitable for hair and eyebrows
  • Use Transparent for see-through materials like glass and gemstones
  • Use Fur mode for fur and animal characters (be mindful of GPU cost)
  • Background mode is ideal for static environment objects such as world buildings and terrain
  • Culling Off is required when using backface textures, but be mindful of the performance cost
  • Changing rendering mode involves switching shader variants, but all properties are preserved
