Backface Texture

Apply a different texture to polygon backfaces

Overview

The backface texture feature displays a different texture or color on the back side of polygons compared to the front. It enables different appearances for front and back faces in scenarios where both sides are visible, such as clothing linings, paper backs, and flag reverse sides.

Controlled by the keyword _BACKFACE_TEXTURE. To use this feature, the culling mode must be set to "Off" (double-sided rendering).

Properties

Enable Backface Texture _BackfaceTexture toggle

Toggles the backface texture feature on/off.

Default: OFF

Backface Texture _BackfaceTex texture

The texture displayed on the backface. Can be set independently from the front face main texture.

Default: "white"

Backface Color _BackfaceColor color

A color multiplied with the backface texture. Can be used to adjust the texture color tone or create a solid-color backface without a texture.

Default: (1, 1, 1, 1)

Backface Blend _BackfaceBlend range

The application intensity of the backface texture. 0 for no effect, 1 for full application.

Default: 1.0

Backface Blend Mode _BackfaceBlendMode enum

Selects the compositing method for the backface texture. Options include Replace, Multiply, Additive, and more.

Default: 0 (Replace)

Usage Tips

  • Set the culling mode to "Off" in Rendering Settings to show backfaces
  • Ideal for clothing linings and paper reverse side effects
  • Changing the blend mode adjusts how it composites with the front face texture
  • Backface texture resolution can often be lower than the front face without noticeable issues
