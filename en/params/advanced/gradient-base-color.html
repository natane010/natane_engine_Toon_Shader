Gradient Base Color

Vertical or horizontal gradient overlay on the base color

Overview

Gradient Base Color applies a two-color gradient across the model surface along a chosen axis. This allows you to create subtle color transitions — such as darker tones at the feet gradually shifting to lighter tones at the head — without requiring additional textures or complex UV painting.

The gradient can operate in local or world coordinate space and supports multiple blend modes for flexible integration with existing textures.

Controlled by the keyword _GRADIENT_BASE_COLOR.

Parameters

Top Color _GradientTopColor color

The gradient end color applied at the top (Y axis), right (X axis), or front (Z axis) of the model, depending on the selected axis.

Default: (1, 1, 1, 1) — White

Bottom Color _GradientBottomColor color

The gradient start color applied at the bottom (Y axis), left (X axis), or back (Z axis) of the model, depending on the selected axis.

Default: (0.5, 0.5, 0.5, 1) — Mid Gray

Gradient Axis _GradientAxis enum

Determines the direction of the gradient. Y produces a vertical gradient (bottom to top), X produces a horizontal gradient (left to right), and Z produces a front-to-back gradient.

Default: Y (Vertical)

Y axis (vertical) is the most commonly used option for natural character coloring.
Coordinate Space _GradientSpace enum

Selects whether the gradient is calculated in local object space or world space. Local space moves with the object, while world space remains fixed relative to the scene.

Default: Local

Use World space for consistent gradients across multiple objects at different positions. Local space is better for individual character coloring.
Gradient Start _GradientStart float

The position along the selected axis where the gradient begins (Bottom Color). Adjusting this value shifts where the gradient transition starts.

Default: 0

Gradient End _GradientEnd float

The position along the selected axis where the gradient ends (Top Color). The distance between Start and End controls the gradient sharpness — a narrow range creates a hard transition.

Default: 1

Blend Mode _GradientBlendMode enum

Controls how the gradient is composited with the base texture. Normal directly mixes, Soft applies a soft light blend, Screen lightens, and Overlay combines multiply and screen for contrast-preserving results.

Default: Normal (0)

Overlay blend mode is excellent for subtle color shifts that preserve underlying texture detail.
Blend Strength _GradientBlend range

Controls the overall intensity of the gradient effect. At 0, the gradient has no visible effect. At 1, the gradient is applied at full strength.

Default: 1

Range: 0 - 1

Usage Tips

  • For natural character coloring, use the Y axis (vertical) with World space. A gradient from white to a slightly warm tone simulates natural sunlight illumination from above.
  • Combine with Overlay blend mode for subtle color shifts that enhance without overpowering existing textures.
  • Narrow the Start/End range (e.g., 0.4 to 0.6) to create a sharp band of color transition, useful for stylized effects.
  • This feature is very lightweight — it adds minimal GPU cost since it only performs a simple interpolation and blend per pixel.
  • Try using complementary colors (e.g., warm orange bottom, cool blue top) for atmospheric environmental storytelling.
