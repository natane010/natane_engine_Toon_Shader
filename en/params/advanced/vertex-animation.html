Vertex Animation

Procedural vertex deformation animation

Overview

Vertex animation is a feature that procedurally deforms vertices within the shader. It enables simple animations such as swaying, waving, and expansion/contraction without scripts. Ideal for expressing movement in vegetation, cloth, water surfaces, and similar elements.

Controlled by the keyword _VERTEX_ANIMATION. By using a mask texture, animation can be applied partially as well.

Properties

Enable Vertex Animation _VertexAnimation toggle

Toggles the vertex animation feature on/off.

Default: OFF

Animation Speed _VertexAnimSpeed range

The playback speed of the animation. Higher values produce faster movement.

Default: 1.0

Animation Strength _VertexAnimStrength range

The magnitude (amplitude) of vertex deformation. Higher values produce larger deformations.

Default: 0.1

Animation Frequency _VertexAnimFrequency range

The fineness of the animation wave. Higher values produce finer waves.

Default: 1.0

Animation Type _VertexAnimType enum

Selects the animation pattern. Various deformation patterns are available, including swaying, waving, and expansion.

Default: 0

Animation Mask _VertexAnimMask texture

A mask texture that controls the animation application area. White areas receive animation, while black areas remain static. Enabled with the keyword _VERTEX_ANIM_MASK.

Default: "white" (applied everywhere)

A gradient mask is effective for keeping plant roots stationary while only swaying the tips.

Usage Tips

  • Ideal for natural swaying of vegetation, flags, cloth, and water surfaces
  • Use mask textures for partial animation (e.g., only swaying tree leaves)
  • Unlike VAT, it is procedural so no baked data is required
  • Keep the strength moderate and adjust for a natural-looking sway
  • Works without scripts in VRChat, making it convenient for avatar and accessory decorations
