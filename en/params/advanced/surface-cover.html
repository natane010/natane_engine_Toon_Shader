Surface Cover

Snow, sand, and dust accumulation on surfaces

Overview

Surface Cover simulates material accumulation — such as snow, sand, or dust — on surfaces based on world-space normals. Upward-facing (or any direction you specify) surfaces receive a cover layer with its own albedo texture, normal map, and color. The coverage amount, angle threshold, and blend sharpness are all configurable.

This feature works entirely within the shader, requiring no additional geometry or particle effects. It is especially effective for environment art in VRChat worlds.

Controlled by the keyword _SURFACE_COVER. This feature is available in the Background shader variant.

Parameters

Cover Color _CoverColor color

The base color of the cover material. This is multiplied with the cover texture if one is assigned.

Default: (1, 1, 1, 1) (white — ideal for snow)

White for snow, tan/beige for sand, dark green for moss, gray for dust.
Cover Amount _CoverAmount range

Controls how much of the surface is covered. At 0, no cover is applied; at 1, eligible surfaces are fully covered.

Default: 0.5

Range: 0 - 1

Cover Threshold _CoverThreshold range

The normal angle threshold that determines which surfaces receive cover. Surfaces whose normals align with the cover direction beyond this threshold will be covered.

Default: 0.5

Range: 0 - 1

Lower values cover more of the surface (including steeper slopes). Higher values restrict cover to only the most directly-facing surfaces.
Blend Sharpness _CoverBlendSharpness float

Controls how sharply the cover transitions at its edges. Low values produce soft, gradual blending; high values create hard, crisp boundaries.

Default: 4.0

Cover Tiling _CoverTiling float

Controls the texture tiling scale for the cover material. Adjust this to match the scale of your cover texture to the object size.

Default: 1.0

Cover Direction _CoverDirection vector

The world-space direction from which cover accumulates. The default (0, 1, 0) simulates top-down accumulation like falling snow. Change this to create cover from other directions.

Default: (0, 1, 0) (upward)

Use (0, 1, 0) for snow/rain. Use (0, 0, 1) for front-facing moss on walls. Use (-1, 0, 0) for wind-blown sand from the east.
Cover Texture _CoverTex texture

The albedo texture for the cover material. If no texture is assigned, the Cover Color is used as a flat color.

Default: "white"

Cover Normal Map _CoverNormalMap texture

A normal map for the cover material, adding surface detail such as snow grain, sand ripples, or moss texture to the cover layer.

Default: "bump" (flat normal)

Usage Tips

  • Snow: Use white CoverColor, Direction (0, 1, 0) for top-down accumulation, and a snow grain normal map.
  • Sand: Use tan/beige CoverColor, Direction (0, 1, 0), and a sand ripple texture for desert environments.
  • Wall moss: Use green CoverColor with Direction (0, 0, 1) for front-facing surfaces. Lower the threshold to extend coverage to angled surfaces.
  • Combine with Triplanar Mapping for UV-free environments that also feature surface cover — both features work together seamlessly.
  • CoverThreshold controls how steep a surface must be to receive cover. Experiment with values between 0.3 and 0.7 for natural-looking results.
