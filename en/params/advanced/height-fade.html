Height Fade

Height-based transparency fading for gradual appearance/disappearance

Overview

Height Fade gradually fades the material based on its world or local height position. This creates effects where objects appear to emerge from or dissolve into the ground, a fog boundary, or any spatial threshold.

Three fade modes are available: Alpha blending for smooth transparency, Clip for a hard binary cutoff, and Dithering which uses an ordered dithering pattern that works on opaque shaders without transparency sorting issues.

An optional glowing edge color adds a bright dissolve-like border at the fade boundary for dramatic visual effects.

Controlled by the keyword _HEIGHT_FADE.

Parameters

Fade Start _HeightFadeStart float

The height position where fading begins. Below this height (or above, if inverted), the material is fully transparent.

Default: 0

Fade End _HeightFadeEnd float

The height position where fading ends. Above this height, the material is fully opaque. The region between Start and End is the transition zone.

Default: 1

Animate this value over time to create teleport or spawn effects.
Fade Axis _HeightFadeAxis enum

Selects which axis the height fade operates along. Y is the most common (vertical fade), but X and Z are available for horizontal or depth-based effects.

Default: Y

Coordinate Space _HeightFadeSpace enum

Determines whether the height is measured in local object space or world space. Local space moves with the object, world space is fixed in the scene.

Default: Local

Invert Fade _HeightFadeInvert toggle

Reverses the fade direction. When enabled, the material fades out above the threshold instead of below it.

Default: OFF

Fade Mode _HeightFadeMode enum

Selects the fading method. Alpha uses smooth transparency blending. Clip uses a hard binary cutoff (fully visible or fully invisible). Dithering uses an ordered dithering pattern that simulates transparency on opaque shaders.

Default: Alpha

Dithering mode avoids transparency sorting artifacts and works on opaque shader variants.
Fade Intensity _HeightFadeBlend range

Controls the overall strength of the fade effect. At 0, the height fade has no effect. At 1, the fade is at full intensity.

Default: 1

Range: 0 - 1

Dither Scale _HeightFadeDitherScale range

Controls the scale of the dithering pattern when using Dithering mode. Lower values produce a coarser, more visible pattern. Higher values create a finer, less noticeable pattern.

Default: 4

Range: 1 - 200

Edge Width _HeightFadeEdgeWidth range

The width of the glowing edge effect at the fade boundary. Set to 0 to disable the edge glow entirely.

Default: 0

Range: 0 - 0.5

Edge Color _HeightFadeEdgeColor color

The HDR color of the glowing edge at the fade boundary. Using HDR values (intensity > 1) creates a bloom-compatible glow effect.

Default: (1, 0.5, 0, 1) — Orange

Bright HDR colors (intensity 2-5) combined with post-processing bloom create a striking sci-fi dissolve appearance.

Usage Tips

  • For teleport or spawn effects, animate the HeightFadeEnd value over time using an animation clip or script.
  • Dithering mode is recommended for opaque shader variants, as it avoids transparency sorting issues that can cause visual glitches in VRChat worlds.
  • The edge glow creates a sci-fi dissolve appearance when combined with bright HDR colors and post-processing bloom.
  • Use World space with the Y axis for consistent ground-level fading across all objects in a scene.
  • Combine with the Dissolve effect for layered disappearance animations — height fade for the overall direction and dissolve for texture-based detail.
