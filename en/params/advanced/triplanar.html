Triplanar Mapping

UV-free 3-axis texture projection for organic surfaces

Overview

Triplanar mapping projects textures from three world-space axes (X, Y, Z) simultaneously, blending them based on surface normals. This eliminates the need for UV unwrapping entirely — making it ideal for rocks, terrain, caves, and other organic environmental geometry where traditional UV layouts would produce visible seams or stretching.

Controlled by the keyword _TRIPLANAR. This feature is available in the Background shader variant.

Parameters

Texture Tiling Scale _TriplanarScale float

Controls the overall tiling scale for textures projected via triplanar mapping. Higher values shrink the texture pattern, creating finer detail; lower values enlarge it for broader coverage.

Default: 1.0

For large rock surfaces, try values around 0.5-2.0. For fine gravel or sand, values of 3.0-5.0 work well.
Blend Sharpness _TriplanarBlendSharpness float

Controls how sharply the textures from each axis blend into one another. Low values create soft, gradual transitions between projection planes; high values create hard, distinct boundaries.

Default: 2.0

For natural-looking rocks and caves, use values around 2-4. Higher values (8+) create sharper axis boundaries, which can be useful for stylized or geometric surfaces.
X-Axis Offset _TriplanarOffsetX float

Offsets the texture projection along the X axis. Use this to fine-tune the texture alignment on surfaces facing the X direction.

Default: 0.0

Y-Axis Offset _TriplanarOffsetY float

Offsets the texture projection along the Y axis. Useful for adjusting vertical alignment, particularly on terrain and cliffs.

Default: 0.0

Z-Axis Offset _TriplanarOffsetZ float

Offsets the texture projection along the Z axis. Adjusts texture position on surfaces facing the Z direction.

Default: 0.0

Usage Tips

  • Works best with tileable (seamless) textures — non-tileable textures will show visible repeats at projection boundaries.
  • BlendSharpness of 2-4 produces natural-looking blending for organic surfaces like rocks and caves.
  • Combine with the Surface Cover feature to create snow-on-rock or moss-on-stone effects without UV mapping.
  • For large environment pieces, use the axis offsets to align texture patterns across multiple objects that share the same material.
  • Performance impact is moderate — triplanar mapping samples the texture three times per pixel. Consider disabling on distant LODs.
