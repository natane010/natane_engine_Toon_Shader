Intersection Fade

Fade out geometry at intersection with other surfaces

Overview

Intersection Fade automatically fades out the material where it intersects with other geometry, creating a soft blending effect at contact points. This is achieved by comparing the fragment's depth against the scene depth buffer to detect proximity to other surfaces.

Common use cases include preventing ugly clipping on skirts touching the ground, hair passing through clothing, particle effects meeting surfaces, or water edges along shorelines.

Like Height Fade, this feature supports Alpha, Clip, and Dithering fade modes, plus an optional glowing edge effect at the intersection boundary.

Controlled by the keyword _INTERSECTION_FADE.

Parameters

Fade Distance _IntersectionFadeDistance float

The distance in world units from the intersection point over which the fade occurs. Larger values create a wider, more gradual fade zone. Smaller values produce a tighter transition.

Default: 0.5

Use 0.1-0.3 for subtle contact blending on clothing. Use 0.5-1.0 for dramatic fade effects on particles or environmental objects.
Fade Mode _IntersectionFadeMode enum

Selects the fading method. Alpha provides smooth transparency blending. Clip uses a hard cutoff for fully visible or invisible pixels. Dithering uses an ordered dithering pattern that works on opaque materials.

Default: Alpha

Fade Strength _IntersectionFadeBlend range

Controls the overall intensity of the intersection fade. At 0, the fade has no effect. At 1, the fade is at full strength.

Default: 1

Range: 0 - 1

Dither Scale _IntersectionFadeDitherScale range

Controls the scale of the dithering pattern when using Dithering mode. Lower values produce a coarser pattern, higher values produce a finer pattern.

Default: 4

Range: 1 - 200

Edge Glow Width _IntersectionFadeEdgeWidth float

The width of the glowing edge effect rendered at the intersection boundary. Set to 0 to disable the edge glow.

Default: 0

Edge Glow Color _IntersectionFadeEdgeColor color

The HDR color of the glowing edge at the intersection boundary. HDR values with intensity greater than 1 produce bloom-compatible glow.

Default: (0, 0.8, 1, 1) — Cyan

A cyan or blue edge glow creates an energy shield or force field aesthetic.

Usage Tips

  • Ideal for preventing ugly geometry clipping on long skirts, capes, or coattails that touch the floor.
  • Use Dithering mode on opaque materials for better performance and to avoid transparency sorting artifacts.
  • Small FadeDistance values (0.1-0.3) work best for subtle clothing blending where you just want to hide clipping.
  • Larger FadeDistance values (0.5-1.0) combined with edge glow create dramatic energy shield or hologram effects.
  • This feature requires access to the depth buffer (_CameraDepthTexture). It works automatically in most scenarios but may not function in certain VRChat mirror configurations.
  • Combine with the Hologram effect for a complete sci-fi force field material.
