Detail Map

Secondary UV texture for close-up surface detail enhancement

Overview

Detail Map adds a secondary texture layer using a second UV set to enhance surface detail at close viewing distances. This technique overlays fine-grained patterns — such as brick textures, concrete cracks, fabric weave, or metal scratches — on top of the main texture at a different tiling scale.

The system includes both an albedo detail map (for color detail) and a normal detail map (for surface relief detail), allowing you to add both visual and lighting-responsive fine detail to surfaces.

This feature is primarily designed for the Background shader variant, targeting environmental surfaces like walls, floors, and terrain where multi-scale detail is essential for visual quality.

Controlled by the keyword _DETAIL_MAP.

Parameters

Detail Albedo Map _DetailAlbedoMap texture

A secondary color texture that is blended with the main albedo texture. This adds fine color detail such as surface grain, stains, or micro-patterns that tile at the detail scale.

Default: None

Use a neutral gray (128, 128, 128) base for detail albedo maps that only darken or lighten the surface without shifting color.
Detail Normal Map _DetailNormalMap texture

A secondary normal map that is blended with the main normal map using the UDN (Unreal Developer Network) blending method. This adds fine surface relief that responds correctly to lighting.

Default: None

Detail Albedo Scale _DetailAlbedoScale float

Controls the intensity of the detail albedo texture blending. Higher values make the detail texture more visible, lower values make it more subtle.

Default: 1

Detail Normal Scale _DetailNormalScale float

Controls the intensity of the detail normal map. Higher values produce more pronounced surface relief from the detail layer. A value of 0 effectively disables the detail normal contribution.

Default: 1

UV Set _DetailUVSet float

Selects which UV channel to use for the detail textures. Use 0 for UV0 (same as the main texture) or 1 for UV1 (the second UV set, often used for lightmapping or detail).

Default: 0

UV1 is commonly set up with different tiling in 3D modeling software, making it ideal for detail textures that need independent UV control.
Detail Tiling _DetailTiling float

A multiplier applied to the detail texture UV coordinates. Higher values tile the detail texture more densely, creating finer patterns. Lower values stretch the detail across a larger area.

Default: 1

For environmental surfaces, a tiling value of 4-8 relative to the main texture often provides good multi-scale detail.

Usage Tips

  • Use detail maps to add fine surface texture (brick patterns, concrete cracks, fabric weave) that tiles at a different scale from the main texture.
  • Combining a main texture (low tiling, unique detail) with a detail texture (high tiling, repeating pattern) creates surfaces that look good both close up and far away.
  • For best results, ensure your mesh has a proper UV1 channel set up in your 3D modeling software if you plan to use UV Set 1.
  • Detail normal maps add significant visual quality at close range with minimal performance cost — they only add one extra texture sample per pixel.
  • This feature is designed for the Background shader variant. For character materials, consider using the Makeup layer system instead for layered detail.
  • Keep detail albedo maps neutral in color to avoid tinting issues when the detail pattern repeats visibly.
