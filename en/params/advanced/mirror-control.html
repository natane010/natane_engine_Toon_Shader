Mirror Control

VRChat mirror display control and emission multiplier

Overview

Mirror Control allows you to manage how materials appear in VRChat mirrors. The material can be configured to display in both the world and mirrors, only in mirrors, or only in the world. Additionally, an emission multiplier is provided specifically for mirror rendering, allowing signs, displays, and decorative elements to glow differently when viewed in reflections.

This is a VRChat-specific feature that detects whether the current rendering pass is a mirror reflection by checking the VRChat mirror flag. It has zero performance cost when no mirror is present in the scene.

Controlled by the keyword _MIRROR_CONTROL. This feature is available in the Background shader variant.

Parameters

Mirror Display Mode _MirrorMode enum

Controls the visibility of this material in relation to VRChat mirrors.

  • 0 = Both — Material is visible in the world and in mirror reflections (default behavior)
  • 1 = Mirror Only — Material is invisible in the world but visible in mirror reflections
  • 2 = World Only — Material is visible in the world but invisible in mirror reflections

Default: 0 (Both)

Use "Mirror Only" for hidden messages or easter eggs that only appear when looking in a mirror.
Mirror Emission Multiplier _MirrorEmissionMultiplier float

Multiplies the emission intensity of the material when rendered in a mirror reflection. A value of 1.0 keeps the emission unchanged; values above 1.0 make the material glow brighter in mirrors.

Default: 1.0

Set to 2.0-3.0 for neon signs that should appear extra vibrant in mirror reflections. Set to 0.0 to completely suppress emission in mirrors.

Usage Tips

  • Secret messages: Set Mirror Mode to "Mirror Only" (1) for objects that should only be visible when a player looks at a VRChat mirror — perfect for hidden text, easter eggs, or puzzle elements.
  • Performance optimization: Set Mirror Mode to "World Only" (2) for complex geometry that doesn't need to appear in mirror reflections. This reduces the rendering cost of mirror passes.
  • Neon signs: Use the emission multiplier (2.0-3.0) to make illuminated signs and displays look extra bright in mirror reflections, simulating how bright lights appear more intense in real mirrors.
  • Mirror Control detection is based on VRChat's built-in mirror rendering system. This feature has no effect outside of VRChat.
  • The emission multiplier only affects the emission component — base color, lighting, and other effects remain unchanged in mirror rendering.
