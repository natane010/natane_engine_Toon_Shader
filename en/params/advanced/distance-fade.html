Distance Fade

Automatic fade based on camera distance (LOD)

Overview

Distance fade is a feature that gradually fades out objects based on their distance from the camera. It achieves a LOD (Level of Detail) effect at the shader level, reducing the rendering load of distant objects. Particularly effective for performance optimization in VRChat.

Controlled by the keyword _DISTANCE_FADE.

Properties

Enable Distance Fade _DistanceFade toggle

Toggles the distance fade feature on/off.

Default: OFF

Fade Start Distance _DistanceFadeStart float

The distance from the camera (in meters) at which fading begins. The object is fully visible up to this distance.

Default: 10.0

Fade End Distance _DistanceFadeEnd float

The distance at which the object completely disappears. Gradually fades out from the start distance to the end distance.

Default: 20.0

Fade Mode _DistanceFadeMode enum

Selects the fading method.

  • Alpha - Fades using transparency. Results in semi-transparent rendering.
  • Simplify - Achieves the fade effect by simplifying effects.

Default: 0 (Alpha)

Fade Blend _DistanceFadeBlend range

The overall blend intensity of the distance fade effect.

Default: 1.0

Fade Blur _DistFadeBlur range

The blur amount at the fade boundary. Higher values produce smoother fade transitions.

Default: 0.0

Usage Tips

  • Effective for performance optimization by reducing the rendering load of distant objects
  • Ideal for reducing the cost of distant avatars and decorations in large VRChat worlds
  • A larger gap between start and end distances produces smoother fade transitions
  • Alpha mode looks more natural but incurs semi-transparent rendering overhead
