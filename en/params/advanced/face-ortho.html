Face Ortho Projection

Keep face proportions ideal at any camera distance or FOV (v1.6.0)

Overview

Face Ortho Projection keeps the face ideally proportioned regardless of camera distance, FOV, or camera type (desktop / VRChat camera / mirrors). It blends the screen-space projection of masked vertices from perspective toward orthographic around a pivot (the head).

Only NDC xy is transformed in the vertex stage; depth, world position, and lighting stay perspective-correct, so shadows, lights, and effects remain consistent. The outline pass applies the identical transform so outlines track the flattened face.

Controlled by the keyword _FACE_ORTHO.

Parameters

Enable Face Ortho _FaceOrtho toggle

Toggles the Face Ortho Projection feature. Sets the _FACE_ORTHO keyword when enabled.

Default: OFF

Enable it on the dedicated face material. For materials that include non-face geometry, use the mask texture.
Ortho Amount _FaceOrthoAmount range

Blend amount from perspective to orthographic projection. 0 = normal perspective, 1 = fully orthographic.

Default: 1.0

1.0 gives a face that never distorts at any distance. Start around 0.5 if you want a subtler effect.
VR Amount _FaceOrthoVRAmount range

Strength used instead of _FaceOrthoAmount in VR (stereo rendering). Fully orthographic faces fight stereo depth cues, so the default is conservative.

Default: 0.3

Set to 0 if it feels off in VR. Desktop, camera, and mirror rendering are unaffected.
Pivot (Object Space) _FaceOrthoPivot vector

Pivot position (object space) around which the projection is flattened, relative to the SkinnedMeshRenderer's root transform. Set it to the head position.

Default: (0, 1.4, 0)

Roughly Y=1.4 for humanoid avatars; adjust for avatar scale. The feature auto-disables when the pivot is not beyond the near plane.
Mask Texture _FaceOrthoMaskTex texture

Application mask. The R channel is the amount: white = apply, black = do not apply.

Default: white (applied everywhere)

Required for materials that include non-face geometry; feather the neck boundary with a gradient for a natural transition.

Usage Tips

  • Basic steps: enable on the face material, set the pivot to the head, and assign a mask if needed.
  • Close-up cameras: especially effective against face distortion from VRChat handheld cameras and close mirrors.
  • Lighting consistency: applied in both FORWARD_BASE and FORWARD_ADD, so additional lights stay depth-consistent.
  • Related: Perspective Flat (whole-object depth compression)
