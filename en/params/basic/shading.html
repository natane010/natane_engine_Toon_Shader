Shading

Toon shading style and shadow settings

Anime-style cel shading delivers clean, well-defined shadow boundaries for high-quality anime-style rendering. Choose from Toon mode, Gradient mode, or ramp textures.

Shading Mode

Mode _ShadingMode enum

Select the shading style.

  • Toon (0): Stepped cel shading. Classic anime-style expression.
  • Gradient (1): Smooth gradient shading. Gives a softer impression.

Default: Toon (0)

When a ramp texture is enabled, this mode setting is ignored and shading based on the ramp texture is applied instead.

Gradient Settings

Parameters displayed when Gradient mode is selected.

Gradient Width _ShadingGradientWidth range

Adjusts the smoothness of the shadow-to-light boundary. 0.1 for a narrow gradient (sharp boundary), 0.2-0.3 for a standard gradient, 0.5+ for a wide gradient (very soft).

Default: 0.2

Range: 0.001 to 1

Values of 0.2 or above are recommended for a softer impression.

Shadow Color Settings

Shadow Color (1st Level) _ShadowColor color

The primary shadow color. Used as the 1st level shadow color in Toon mode, and as the overall shadow color in Gradient mode.

Default: (0.5, 0.5, 0.5, 1)

Adding a slight reddish tint to skin shadows makes them look more natural. Example: (0.55, 0.45, 0.45)
Shadow Color (2nd Level) _Shadow2ndColor color

The 2nd level shadow color. Used when multi-step shadows are enabled. Set a darker color than the 1st level.

Default: (0.35, 0.35, 0.35, 1)

2nd Level Border _Shadow2ndBorder range

The darkness threshold where the 2nd level shadow is applied. The 2nd shadow color applies to areas darker than this value. 0.5 for half the darker area, 0.3 for slightly dark areas (recommended), 0.1 for only the darkest areas.

Default: 0.3

Range: 0 to 1

Shadow Color (3rd Level) _Shadow3rdColor color

The 3rd level shadow color (darkest shadow). Used when multi-step shadows are enabled.

Default: (0.2, 0.2, 0.2, 1)

3rd Level Border _Shadow3rdBorder range

The darkness threshold where the 3rd level shadow is applied. 0.15-0.2 for standard darkest areas (recommended), 0.05-0.1 for only the very darkest areas.

Default: 0.15

Range: 0 to 1

Set border values in descending order: 1st level > 2nd level > 3rd level.

Toon Mode Settings

Shadow Steps _ShadowSteps range

The number of cel shading steps. Fewer steps produce an anime look; more steps create a gradient-like effect.

Default: 2

Range: 1 to 10

Recommended: 2-3 (anime style). More steps produce a gradient effect.
Shadow Sharpness _ShadowSharpness range

Controls the sharpness of shadow boundaries. Low values for sharp boundaries (anime style), high values for soft boundaries (illustration style).

Default: 0.1

Range: 0.001 to 1

Recommended for anime style: 0.05-0.15

Common Settings

Shadow Offset _ShadowOffset range

Adjusts the shadow boundary position. Positive values make shadows brighter (smaller shadow area), negative values make shadows darker (larger shadow area).

Default: 0

Range: -1 to 1

Lit Softness _LitSoftness range

Blends the lit areas with their surroundings. 0 for sharp boundaries (default), 0.3-0.5 for moderate softness, 1.0 for maximum blending.

Default: 0

Range: 0 to 1

Adjust this when lighting is too harsh or when you want a smoother gradient.
Shadow Blending (Softness) _ShadowBlend range

Blends the shadow boundaries with their surroundings for a softer impression. 0 for sharp boundaries (default), 0.3-0.5 for moderate softness (recommended), 0.7-1.0 for very soft boundaries.

Default: 0

Range: 0 to 1

Adjust this when shadow boundaries are too sharp or when you want softer, illustration-style shadows. If setting above 0.7, it is recommended to also check other softness parameters in the "Advanced Lighting" tab.

Ramp Texture

Ramp Texture _RampTex texture

Shading using a ramp texture. Set a gradient texture from dark (left) to bright (right). When enabled, shading based on the ramp texture is applied instead of Toon/Gradient mode. Keyword: _USE_RAMP

Default: "white" (enabled via toggle)

Create custom shadow tones with custom gradients. Warm-colored gradients produce warm shadows, while cool-colored gradients produce cold-impression shadows.

SDF Shadow Map

SDF Map _SDFMap texture

An SDF (Signed Distance Field) Shadow Map texture. An advanced feature that enables precise texture-based control over shadow placement. White = lit, Black = shadow. Keyword: _SDF_MAP

Default: "white" (enabled via toggle)

Use this when you want fine control over face shadows or when you want shadows to always appear in specific areas.
SDF Intensity _SDFIntensity range

Controls the strength of the SDF shadow.

Default: 0.5

Range: 0 to 1

SDF Softness _SDFSoftness range

The softness of the SDF shadow boundary.

Default: 0.1

Range: 0 to 1

SDF Offset _SDFOffset range

Position adjustment for the SDF shadow.

Default: 0

Range: -1 to 1

Shading Grade Map

Shading Grade Map _ShadingGradeMap texture

A texture that allows partial adjustment of shadow intensity. White = brighter (thinner shadows), Black = darker (deeper shadows), Gray = neutral. Keyword: _SHADING_GRADE_MAP

Default: "white" (enabled via toggle)

Use this when you want different shadow intensities for different areas, such as brighter faces and darker clothing.
Grade Scale _ShadingGradeScale range

Adjusts the influence of the Shading Grade Map. -1 for darker, 0 for no change, 1 for brighter.

Default: 0

Range: -1 to 1
