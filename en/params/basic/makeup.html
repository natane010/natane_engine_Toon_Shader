Makeup

Up to 4 layers of makeup textures with HSV color adjustment

You can stack up to 4 layers of transparent PNG makeup textures. Each layer supports HSV color adjustment, intensity control, blend mode selection, and additional masking. The alpha channel controls the application area, and multiple blend modes enable natural makeup expression.

2nd Texture Layer

Use case: Highlights, eye shadow

Enable 2nd Texture _Use2ndTexture toggle

Enables the second makeup texture layer. Keyword: _2ND_TEXTURE

Default: OFF

2nd Texture _2ndTex texture

The second makeup texture. Supports transparent PNG, where the alpha channel is used as the application intensity.

Default: None

Hue Shift _2ndTexHueShift range

Shifts the hue of the texture. 0 for no change; positive/negative values shift the color along the hue wheel.

Default: 0

Range: -0.5 to 0.5

Saturation _2ndTexSaturation range

Adjusts the saturation of the texture. 1 for original saturation, 0 for grayscale, 2 for very vivid.

Default: 1

Range: 0 to 2

Brightness _2ndTexValue range

Adjusts the brightness of the texture. 1 for original brightness, 0 for completely dark, 2 for very bright.

Default: 1

Range: 0 to 2

Intensity _2ndTexIntensity range

The application intensity of the makeup texture. 0 for no effect, 1 for full application.

Default: 1

Range: 0 to 1

Blend Mode _2ndTexBlendMode enum

Select the blending method for the texture.

  • Add: Additive (best for highlights)
  • Multiply: Multiplicative (best for eye shadow)
  • Overlay: Overlay (natural makeup)
  • Screen: Screen (soft highlights)

Default: Add (0)

2nd Tex Mask _2ndTexMask texture

An additional mask texture. White = texture applied, Black = not applied. The mask is multiplied with the alpha channel. Keyword: _2ND_TEX_MASK

Default: None (enabled via toggle)
