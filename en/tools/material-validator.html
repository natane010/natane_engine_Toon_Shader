Material Validator

Automated VRChat optimization and performance checks

Menu: Tools > Natane > Material Validator Category: Material

Overview

The Material Validator automatically verifies VRChat optimization and performance for materials using Natane Toon Shader. It comprehensively checks texture sizes, the number of enabled features, performance ratings, and more, offering auto-fix suggestions when issues are found.

Key Features

  • VRChat optimization checks (Quest/PC compatible)
  • Texture size validation and recommended size suggestions
  • Performance rating (A/B/C/D rating)
  • Auto-fix suggestions and batch application
  • Batch validation of multiple materials

How to Use

  1. Drag and drop materials or click "Add Selected Materials" to add validation targets
  2. Enable or disable validation items as needed
  3. Click "Validate Materials" to start the validation
  4. Review issues by severity (Error / Warning / Info)
  5. Click "Auto Fix" to apply the suggested corrections

Validation Items

Performance

  • Rating based on the number of enabled features (A: 0-3, B: 4-6, C: 7-9, D: 10+)
  • Total texture memory usage
  • Shader keyword count

Textures

  • Maximum texture size check (VRChat recommended: 2048x2048 or less)
  • Compression format verification
  • Detection of unused texture slots

VRChat-Specific

  • Quest compatibility check (rating B or above recommended)
  • Fallback shader compatibility

Tips

  • Run validation before uploading to VRChat
  • Check "VRChat Optimization" for avatar compatibility
  • Fix errors before warnings for the best results
