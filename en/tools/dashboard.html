Dashboard

View an overview of your project status at a glance

Menu: Tools > Natane > Dashboard Category: General

Overview

The Dashboard is a comprehensive tool that provides a bird's-eye view of your project's status related to Natane Toon Shader. It displays the number of materials in use, a performance overview, statistics on enabled features, recent change history, and more — serving as the starting point for project management.

Key Features

  • List and count of materials using Natane Toon Shader
  • Performance rating overview per material (A/B/C/D)
  • Statistics on enabled features
  • Quick access links to each tool
  • Shader version information display

How to Use

  1. Open Tools > Natane > Dashboard from the Unity menu
  2. Natane Toon materials in the project are automatically scanned
  3. Check the status of materials in each section
  4. If issues are found, use the provided links to navigate directly to the relevant tools for fixes

Tips

  • Use this as a first step to get an overview of the overall project performance
  • Check the Dashboard performance overview before uploading to VRChat for peace of mind
  • Scanning may take a moment if the project has a large number of materials
