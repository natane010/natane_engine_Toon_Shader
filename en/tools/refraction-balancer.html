Refraction Quality Balancer

Optimally balance refraction effect quality and performance

Menu: Tools > Natane > Optimization > Refraction Balancer Category: Optimization

Overview

The Refraction Quality Balancer is a dedicated tool for adjusting the balance between refraction effect quality and performance. Refraction effects add beautiful expressions to transparent and semi-transparent materials like glass, water, and gemstones, but they use GrabPass and blur sampling, making them a relatively GPU-intensive effect.

This tool automatically optimizes sample counts per platform. For PC, it maintains high-quality (9 sample) refraction blur, while for Quest, it reduces to 5 samples to minimize mobile GPU load. With quality presets, you can set the appropriate balance with a single click.

It also centrally manages parameters such as refraction strength, blur radius, and chromatic aberration, displaying performance cost estimates in real time. You can find the optimal settings while visually comparing the trade-off between performance and appearance.

Key Features

  • Quality Presets — Four-tier presets: Low / Medium / High / Ultra. Instantly switch based on platform and use case
  • Sample Count Adjustment — Directly specify the blur sample count. More samples produce smoother blur but increase GPU cost
  • Per-Platform Settings — Maintain different quality settings for PC / Quest. Auto-switches based on build target
  • Performance Comparison — Compare estimated GPU costs side by side at each quality level. See at a glance how much performance impact each setting has
  • Real-time Preview — Quality setting changes are immediately reflected in the preview for checking blur appearance

How to Use

  1. Select Material

    Select a Natane Toon Shader material with the refraction feature (_REFRACTION) enabled. Transparent variant materials are the target.

  2. Select Platform

    Choose the target platform (PC / Quest). Recommended values are automatically displayed based on the platform.

  3. Adjust Quality Level

    Select a quality preset (Low to Ultra) or directly adjust the sample count. Performance cost estimates update in real time.

  4. Apply

    Apply the adjusted settings to the material. Batch application to multiple materials is also supported.

Tips

  • Always use Low or Medium quality for Quest. High or above may cause significant frame rate drops on mobile GPUs
  • Even for PC, Medium quality often provides sufficient visual quality. Consider Ultra quality for photography purposes only
  • Lowering refraction strength makes artifacts less noticeable even with fewer samples
  • If an avatar has multiple refraction materials, set only the most visible one to High quality and use Medium for others for a good balance
  • When blur radius is small, fewer samples are needed, so Low quality is sufficient for subtle refraction effects
