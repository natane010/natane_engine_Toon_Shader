Hierarchy Batch Editor

Batch-edit NataneToon materials under a hierarchy using the inspector UI

Menu: Tools > Natane > Material > Hierarchy Batch Editor Category: Material

Overview

The Hierarchy Material Batch Editor automatically detects all materials using Natane Toon Shader under a specified root GameObject and allows you to batch-edit them using the same full material inspector UI. You can select multiple materials simultaneously and have changes applied in real-time.

Access

Menu: Tools > Natane > Material > Hierarchy Batch Editor

Features

  • Hierarchy Scan - Automatically detects Natane Toon Shader materials from all Renderers under the root object
  • Deduplication - Shows each material only once even if used by multiple Renderers
  • Hierarchy Path Display - View the hierarchy path showing where each material is used
  • Selective Batch Editing - Use checkboxes to individually select or deselect materials for editing
  • Select All / Deselect All - Quickly toggle selection state of all materials with one click
  • Embedded Material Editor - Full NataneToonShaderGUI inspector embedded directly in the window
  • Real-time Updates - Changes are applied in real-time to all selected materials in the scene
  • Material Preview - Material preview sphere displayed in the embedded editor header

How to Use

  1. Drag and drop the root GameObject of your avatar or object into the "Root Object" field
  2. Press the "Scan" button to search for Natane Toon Shader materials under the hierarchy
  3. Select materials to edit using the checkboxes in the material list (all are selected by default)
  4. Edit properties in the Material Editor section using the same UI as the standard inspector
  5. Changes are applied simultaneously in real-time to all selected materials

Example Workflows

Unify shadow color across an entire avatar

  1. Set the avatar root object and scan
  2. With all materials selected, change the shadow color
  3. The same shadow color is applied to all materials at once

Edit only specific parts

  1. After scanning, click "Deselect All" to reset selection
  2. Check only the materials you want to edit
  3. Changes are applied only to the selected materials

Tips

  • Materials on inactive objects are also included in the scan
  • Changing the root object automatically clears previous scan results
  • Use the hierarchy path to identify which part a material belongs to
  • For VRChat avatars, set the avatar root object to adjust body, clothing, and hair materials all at once
