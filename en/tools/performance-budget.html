Performance Budget

Visualize material performance costs and manage within budget

Menu: Tools > Natane > Optimization > Performance Budget Category: Optimization

Overview

The Performance Budget tool visualizes the performance cost of materials and helps manage them within platform-specific budgets. It displays how much GPU load each shader feature incurs using a point system and provides optimization guidelines for both PC and Quest platforms.

Natane Toon Shader offers many features, but enabling all of them simultaneously can impact performance. With this tool, you can view the cost (points) of each enabled feature in a list and compare them against recommended budgets per platform. It allows you to make data-driven decisions about which features to enable or disable.

It is particularly useful when creating Quest-compatible VRChat avatars, helping you find material settings that fit within mobile GPU constraints. The performance rating (A/B/C/D) is displayed in real time, serving as a guideline for VRChat performance rank.

Key Features

  • Platform-Specific Budgets — Different performance budgets for PC and Quest. Evaluates based on criteria matched to each platform's GPU capabilities
  • Feature Cost Calculation — Displays the GPU load of each shader feature (rim light, MatCap, specular, refraction, etc.) as points
  • Real-time Tracking — Costs update in real time as you change material settings
  • Performance Rating — Four-tier rating: A (Light: 0-3 features), B (Standard: 4-6 features), C (Heavy: 7-9 features), D (High Load: 10+ features)
  • Optimization Suggestions — Automatically detects cost-inefficient features when over budget and suggests disabling them
  • Multi-Material Comparison — Compare costs of all materials in an avatar at a glance to identify the most expensive materials

How to Use

  1. Open the Tool

    Open the tool window from Tools > Natane > Optimization > Performance Budget.

  2. Select Materials

    Select the materials you want to analyze from the Project view or drag and drop them. To analyze an entire avatar, select the avatar object in the scene.

  3. Select Platform

    Choose the target platform (PC / Quest). Budget limits differ by platform.

  4. Review Cost Analysis

    Check the cost of each feature, total points, and performance rating. Features that exceed the budget are highlighted in red.

  5. Perform Optimization

    Refer to the suggested optimizations and disable unnecessary features to improve performance.

Tips

  • Aim for 40 points or less for Quest avatars. This corresponds to a performance rank of B
  • Actively disable unused features. Natane Toon Shader uses keyword-based branching, so disabled features incur zero GPU load
  • Refraction and screen effects are particularly costly, so use them carefully on Quest
  • Analyzing all materials of an avatar simultaneously makes it easier to grasp overall performance balance
  • Prioritize enabling features with the greatest visual impact while maintaining a performance rating of B
