lilToon Migration Tool

Automatic migration from lilToon shader to Natane Toon Shader

Menu: Tools > Natane > Migration > lilToon Migration Category: Migration

Overview

The lilToon Migration Tool is a migration utility that automatically converts materials configured with the lilToon shader to Natane Toon Shader. It has built-in property name mapping between lilToon and Natane Toon, automatically carrying over textures, colors, and numerical parameters.

lilToon is widely used as a toon shader for VRChat, but manually reconfiguring each parameter one by one when switching to Natane Toon Shader is extremely time-consuming. This tool automatically maps and converts most basic properties (main texture, shadow color, shadow boundary, rim light, MatCap, etc.).

It also auto-detects lilToon variants (Opaque, Cutout, Transparent, with Outline, etc.) and converts them to the corresponding Natane Toon Shader variants. You can preview before conversion and Undo is supported, so you can use it with confidence. Batch conversion is also supported, allowing you to migrate all materials for an entire avatar at once.

Key Features

  • Automatic Property Mapping — Automatically converts each lilToon property (_MainTex, _ShadowColor, _RimColor, etc.) to the corresponding Natane Toon Shader property
  • Variant Detection — Auto-detects lilToon variants in use (Opaque / Cutout / Transparent / TwoPass, etc.) and selects the appropriate Natane Toon variant
  • Batch Conversion — Convert lilToon materials in a folder or scene all at once. Ideal for migrating large avatar projects
  • Preview — Preview the mapping results before conversion. Check in advance how each property will be converted
  • Undo Support — All conversion operations can be undone. Press Ctrl+Z to revert immediately if issues arise
  • Custom Mapping — Properties that cannot be handled by automatic mapping can be manually added or modified

How to Use

  1. Select lilToon Materials

    Select the lilToon materials you want to convert in the Project view. If you specify a folder, lilToon materials within that folder are auto-detected.

  2. Review Property Mapping

    A list of auto-detected property mappings is displayed. Check the conversion target for each property and modify as needed.

  3. Preview

    Click "Preview" to check the converted material's appearance. It previews in real time in the Scene view.

  4. Execute Conversion

    Click "Execute Conversion" to convert the materials. The original material's shader switches to Natane Toon Shader, and mapped properties are automatically configured.

Tips

  • It's recommended to back up original materials before conversion. Using the Prefab Variant Converter lets you convert while preserving the original prefab
  • lilToon's 2nd/3rd Shadow maps to Natane Toon's multi-step shadows. Fine-tuning of color tones may be needed after conversion
  • MatCap and rim light intensity may need fine-tuning after conversion, as calculation methods differ between shaders
  • lilToon outline settings are also automatically converted, but check the width scale as it may differ
  • For batch conversion, it's safest to try one material first before converting the rest
