Outline Optimizer

Optimize outline rendering performance and quality

Menu: Tools > Natane > Optimization > Outline Optimizer Category: Optimization

Overview

The Outline Optimizer is a tool for adjusting the balance between outline rendering performance and visual quality. Outlines are an important element of toon shading, but since they require an additional rendering pass, their performance impact cannot be ignored.

This tool integrates management of outline width, distance fade, and LOD (Level of Detail)-based adjustments. The "distance fade" feature automatically adjusts outline width based on camera distance, allowing you to thin outlines on distant objects and reduce unnecessary rendering load.

Three presets — "Balanced," "Performance," and "Quality" — are provided, allowing you to quickly apply optimal settings for your use case. In VRChat, where many avatars are displayed simultaneously, properly configuring distance fade contributes significantly to stable frame rates.

Key Features

  • Width Optimization — Precise pixel-level control of outline width. Detects overly thick outlines and suggests appropriate values
  • LOD-Based Adjustment — Automatic outline adjustment based on camera distance. Crisp at close range, thinner at far range
  • Distance Fade — Gradually fades out outlines beyond a specified distance, reducing unnecessary rendering in the background
  • Performance Presets — One-click configuration with Balanced / Performance / Quality presets
  • Visual Quality Balance — Automatically calculates the optimal balance point between performance and appearance

How to Use

  1. Select Target

    Select the material or scene object to optimize. You can also select multiple materials for batch optimization.

  2. Analyze

    The current outline settings are analyzed, showing the current state of width, color, and distance fade settings. Performance impact is also displayed.

  3. Select Preset

    Choose the optimization level. "Balanced" is general-purpose, "Performance" is for Quest, and "Quality" is for screenshots and video production.

  4. Apply

    Apply the optimized settings to the material. Undo is supported, so you can always revert to the previous state.

Tips

  • The "Balanced" preset is recommended for general use. It achieves good performance and appearance in most environments
  • Enable distance fade for performance improvement. In VRChat, outlines become hard to see at a certain distance from other players, so fading has minimal visual impact
  • Thinner outlines perform better. A range of 0.5 to 1.0 still provides sufficient outline effect
  • For Quest avatars, set the distance fade start distance shorter to reduce rendering cost
  • Setting the outline color to a dark shade close to the material's base color creates a natural impression, reducing awkwardness even with thicker outlines
