Rim Light Direction Visualizer

Visually adjust rim light direction parameters with a 3D preview

Menu: Tools > Natane > Effects > Rimlight Visualizer Category: Effect

Overview

The Rim Light Direction Visualizer is a dedicated tool for visually adjusting rim light direction parameters. It allows you to interactively set the rim light direction in a 3D preview, which would otherwise only be adjustable via numeric sliders in the standard material inspector.

Rim lighting is an important effect for beautifully highlighting character outlines, but adjusting direction parameters (X, Y, Z vectors) with numbers alone is not intuitive. With this tool, you can pursue the ideal rim light expression while checking the direction and range in real time in 3D space.

It is especially useful for finding rim light settings that harmonize with stage lighting and world ambient light in VRChat avatars. Simply drag within the preview window to change the direction, and the result is reflected on the material in real time.

Key Features

  • 3D Direction Visualization — Visualizes the rim light direction vector as arrows and guides in 3D space. You can see at a glance which direction the rim light is coming from
  • Real-time Preview — When you change the direction parameters, the rim light effect on the preview object updates instantly
  • Direction Vector Editing — Supports intuitive direction editing via drag operations, as well as precise numerical input
  • Direct Material Reflection — Apply adjustment results to the material with one click. Undo support ensures safe operation
  • Rim Light Range Preview — The rim light width (Fresnel Power) can also be previewed simultaneously, allowing you to optimize both direction and range at the same time

How to Use

  1. Select a Material

    Select a material with Natane Toon Shader applied from the Project view or Inspector. Make sure the rim light feature (_RIMLIGHT) is enabled.

  2. Open the Visualizer

    Open the tool window from Tools > Natane > Effects > Rimlight Visualizer. The current rim light direction of the selected material is displayed in the 3D preview.

  3. Adjust the Direction

    Drag within the 3D preview to change the direction. Dragging up, down, left, and right updates the rim light direction vector in real time. Precise adjustments via numerical fields are also possible.

  4. Check in Preview

    Check the rim light effect on the preview object. Test the rim light appearance under various lighting environments by changing the light direction and intensity.

  5. Apply to Material

    Click the "Apply" button to reflect the settings on the material. You can Undo at any time with Ctrl+Z.

Tips

  • In VRChat worlds, light directions vary by location, so preview from multiple directions to find the most versatile setting
  • Setting the rim light direction to "diagonally upward" looks natural in many lighting environments
  • A larger Fresnel Power value creates a thinner rim; a smaller value creates a wider rim
  • Custom directional rim lighting is especially effective for avatars in specific worlds with fixed light sources
  • After adjusting in the direction visualizer, also check the avatar in Scene view for a final review
