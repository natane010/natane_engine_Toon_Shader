Dissolve Pattern Generator

Procedural dissolve texture generation

Menu: Tools > Natane > Dissolve Generator Category: Effect

Overview

The Dissolve Pattern Generator is a tool that procedurally generates noise textures for use with the dissolve effect. You can select from multiple noise algorithms, adjust parameters while viewing a real-time preview, and output the result as a texture.

Key Features

  • Multiple noise types (Perlin, Voronoi, Cellular, Random, Gradient)
  • Adjustable parameters for scale, contrast, octaves, etc.
  • Real-time preview
  • Output to texture file (PNG)
  • Preset patterns

How to Use

  1. Select a noise type: Perlin, Voronoi, Cellular, Random, or Gradient
  2. Adjust the scale, contrast, and other settings
  3. Check the generated pattern in real time in the preview window
  4. Click "Generate Texture" to save as an asset

Noise Types

  • Perlin - Smooth, natural noise. Ideal for general-purpose dissolve patterns
  • Voronoi - Cell-like patterns. Best for organic dissolve effects
  • Cellular - Grid-like patterns. Suited for digital expressions
  • Random - Fully random noise. For particle-like dissolve effects
  • Gradient - Directional gradients. For swipe-style dissolve effects

Parameters

  • Scale - Size of the noise pattern. Larger values produce finer patterns
  • Contrast - Black-white contrast. Higher values create sharper dissolve edges
  • Resolution - Output texture size (256 to 2048)
  • Seed - Random seed value. Generates different variations

Tips

  • Voronoi is ideal for creating organic dissolve patterns
  • High contrast settings produce sharp-edged dissolve effects
  • 512x512 is usually sufficient resolution for dissolve textures
  • Try different seed values to explore multiple variations
