Shader Prewarming

Pre-compile shader variants to prevent stuttering during gameplay

Menu: Tools > Natane > シェーダー Shader > シェーダープリウォーミング Shader Prewarming Category: Shader

Overview

Shader Prewarming is a tool that pre-compiles (warms up) shader variants to prevent stuttering caused by shader compilation during gameplay. It offers two modes: VRChat-safe editor-only prewarming and runtime prewarming for non-VRChat projects.

In Unity, compilation occurs when a shader variant is rendered for the first time, causing temporary frame rate drops (stutters). This tool eliminates this issue by pre-compiling shaders before build or within the editor.

The tool implements Unity's build pipeline API (IPreprocessBuildWithReport) to automatically execute prewarming before builds. It also features automatic variant collection from project materials when the ShaderVariantCollection is empty.

Key Features

  • Pre-Build Automatic Prewarming — Implements IPreprocessBuildWithReport to automatically prewarm shaders before builds. When the ShaderVariantCollection is empty, it also auto-collects variants from materials
  • ShaderVariantCollection Warmup — Detects existing ShaderVariantCollections and warms up all included variants. Supports both Assets layout and UPM package layout
  • Automatic Material Search and Warmup — Automatically finds all Natane Toon materials in the project, creates a temporary ShaderVariantCollection, and performs targeted warmup
  • Automatic Variant Collection from Materials — When the ShaderVariantCollection is empty, collects keyword combinations from project materials and auto-registers variants for ForwardBase/ForwardAdd/ShadowCaster/Meta pass types
  • 12 Shader Variants Supported — Targets all Natane Toon Shader variants: Toon Shader, Cutout, Transparent, Lite variants, Fur variants, Background, Wirelight, Eye, and Screen FX Overlay
  • Progress Bar Display — Shows warmup progress with a progress bar. Processing time and count are also shown in the final report
  • Runtime Prewarming Script Generation — For non-VRChat projects, can automatically generate and manage a MonoBehaviour script that warms up shaders at runtime
  • Full VRChat Compatibility — Editor-only mode uses no runtime scripts, making it fully compatible with VRChat's script restrictions

How to Access

Available through the following menus:

  • Tools > Natane > シェーダー Shader > シェーダープリウォーミング Shader Prewarming > すべてウォームアップ Prewarm All Shaders — Manually prewarm shaders
  • Tools > Natane > シェーダー Shader > シェーダープリウォーミング Shader Prewarming > バリアントコレクションをウォームアップ Prewarm Shader Variant Collection — Warm up only the ShaderVariantCollection
  • Tools > Natane > シェーダー Shader > シェーダープリウォーミング Shader Prewarming > 設定 Settings — Open settings window

How to Use

  1. Open Settings Window

    Select Tools > Natane > シェーダー Shader > シェーダープリウォーミング Shader Prewarming > 設定 Settings to open the settings window.

  2. Configure Editor-Only Prewarming (VRChat Safe)

    Adjust the following settings:

    • Prewarm on Build — Whether to automatically prewarm shaders before building. Enabled by default.
    • Auto-Find Materials — Whether to automatically find and prewarm all Natane Toon materials in the project. Enabled by default.
  3. Run Manual Prewarming

    Click "Prewarm Shaders Now" to immediately execute prewarming. Processing time and the number of warmed variants/materials are displayed in a dialog.

  4. Runtime Prewarming (Non-VRChat Only)

    For non-VRChat projects that need runtime prewarming, click "Generate Runtime Prewarming Script" to generate a MonoBehaviour script. Attach the generated script to a GameObject in your scene and assign the ShaderVariantCollection.

Runtime Prewarming Script

Features of the auto-generated runtime script for non-VRChat projects:

  • Prewarm on Awake — Warms up shaders immediately at game start (enabled by default)
  • Prewarm on Start — Delays warmup execution to after Awake
  • Debug Logs — Toggle logging of processing time and variant counts
  • Manual Invocation — Call the PrewarmShaders() method at any desired timing

Tips

  • For VRChat projects, always use editor-only mode. The runtime script does not work in VRChat
  • Pre-generating a ShaderVariantCollection with the Shader Variant Collector tool makes prewarming more efficient
  • Pre-build prewarming automatically collects from materials and warms up when the ShaderVariantCollection is empty
  • Prewarming processing time depends on the number of materials and variants in the project. Build time may slightly increase for large projects
  • Use in combination with Variant Stripping to achieve an optimal configuration that prewarms only necessary variants while removing unnecessary ones from the build
