Material Preview

Enhanced 3D preview with lighting controls

Menu: Tools > Natane > Material Preview Category: Material

Overview

Material Preview is an enhanced preview tool that allows you to inspect Natane Toon Shader materials in a high-quality 3D environment. You can freely control the lighting angle, color, and intensity, and check the material's appearance in real time under various lighting conditions.

Key Features

  • Real-time 3D preview
  • Multiple preview shapes (sphere, cube, cylinder, etc.)
  • Adjustable lighting (angle, color, intensity)
  • Camera rotation and zoom controls
  • HDR support

How to Use

  1. Drag a material into the preview field to set it
  2. Select the preview object shape (sphere, cube, etc.)
  3. Adjust the light color, intensity, and rotation angle
  4. Drag in the preview window to change the camera angle

Controls

Camera Controls

  • Left Drag - Rotate camera
  • Scroll - Zoom in/out

Lighting

  • Adjust the light angle with the light direction slider
  • Change the light color with the light color picker
  • Adjust the light brightness with the intensity slider

Tips

  • A sphere is ideal for general material previewing
  • Try various light angles to check how shadows appear
  • Use scroll to zoom in/out
  • To examine toon shading boundaries, slowly vary the light angle
