Default Preset Generator

Automatic generation of standard material presets

Menu: Tools > Natane > Generate Default Presets Category: Preset

Overview

The Default Preset Generator is a utility that automatically generates standard material presets for Natane Toon Shader. It provides a variety of presets utilizing the shader's features, and simultaneously generates thumbnail images for use in the Preset Browser.

Key Features

  • Batch generation of default presets by category
  • Automatic thumbnail preview image generation
  • Automatic performance rating calculation and assignment
  • Automatic preset description assignment
  • Overwrite confirmation for existing presets

How to Use

  1. Run Tools > Natane > Generate Default Presets from the Unity menu
  2. Select the preset categories to generate
  3. Confirm the output folder
  4. Click "Generate" to create the preset files
  5. Check the generated presets in the Preset Browser

Generated Preset Categories

  • Character - Skin (soft shadows), hair (glossy), clothing (multi-step shadows), etc.
  • Props - Material-based presets for metal, wood, cloth, plastic, etc.
  • Environment - Background materials such as buildings, rocks, vegetation
  • Effects - Effect-based presets like hologram, glitch, dissolve
  • Style_Toon - Style-based presets like sharp anime, soft toon
  • Style_NPR - NPR styles like watercolor, oil painting, pencil drawing

Tips

  • Run this during initial setup to build your preset library
  • Presets are saved as ScriptableObjects, so they can be customized
  • New presets may be added with version updates
