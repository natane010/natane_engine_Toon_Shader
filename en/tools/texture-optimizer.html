Texture Optimizer

Automatically optimize textures for performance

Menu: Tools > Natane > Optimization > Texture Optimizer Category: Optimization

Overview

The Texture Optimizer analyzes textures in your project and automatically applies performance-optimal settings. It manages texture size, compression format, and mipmap settings in batch, allowing you to significantly reduce VRAM usage.

In VRChat avatars, textures often account for the majority of memory usage, and without proper optimization, VRAM is consumed unnecessarily. This tool automatically detects textures used by materials and suggests optimal sizes and compression settings based on their purpose. It can optimize according to texture type — main textures, normal maps, mask textures, and more.

Memory usage comparison before and after optimization is also displayed, allowing you to verify the expected improvement in advance. Batch processing is supported, so you can optimize all textures for an entire avatar at once.

Key Features

  • Size Optimization — Automatically sets maximum resolution based on usage. Detects unnecessarily large textures and suggests resizing
  • Compression Settings — Automatically selects the optimal compression format per platform (BC7, ASTC, ETC2, etc.)
  • Mipmap Generation — Optimizes mipmap enable/disable based on usage. Saves memory by disabling for UI textures and similar cases where mipmaps are unnecessary
  • Memory Calculation — Calculates and displays VRAM usage for each texture and total in real time. Before/after comparison available
  • Batch Processing — Optimize textures in batch by material or by folder

How to Use

  1. Add Textures

    Select textures from the Project view or specify a material to auto-detect related textures. You can also drag and drop a folder to add all textures within it.

  2. Configure Settings

    Set the maximum size (recommended: 2048 for main textures, 1024 for masks/normals), compression format, and mipmap options. Per-platform settings are also available.

  3. Analyze

    Click the "Analyze" button to review the current texture state. Current size, compression format, and memory usage for each texture are displayed in a list.

  4. Optimize

    Click "Optimize All" to apply changes. A summary showing the difference in memory usage before and after optimization is displayed.

Tips

  • 2048x2048 is the recommended maximum size for VRChat avatars. Textures larger than this cause VRAM usage to spike, so keep them at 2048 or below unless there is a specific reason
  • Enable texture compression for performance improvement. The visual quality impact is minimal, and memory usage can be reduced by 1/4 to 1/8
  • Always check visual quality after optimization. Normal maps and gradient maps may show compression artifacts in some cases
  • Mask textures (shadow masks, emission masks, etc.) often achieve sufficient quality at 1024x1024
  • ASTC compression is recommended for Quest. BC7 offers the best quality/compression ratio balance for PC
