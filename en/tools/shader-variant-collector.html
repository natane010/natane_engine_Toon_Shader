Shader Variant Collector

Automatically collect shader variants in the project to significantly reduce build size

Menu: Tools > Natane > Shader > Shader Variant Collector Category: Shader

Overview

The Shader Variant Collector automatically scans shader variants (keyword combinations) actually in use within the project and generates a ShaderVariantCollection. This allows you to exclude unnecessary shader variants at build time, reducing build size by 50-80%.

Natane Toon Shader has many optional features, each controlled by shader_feature keywords. Including all keyword combinations (variants) in the build results in enormous size, but the combinations actually in use are limited. This tool surveys all materials in the project and collects only the keyword combinations that are actually enabled.

Collected variants are saved as a ShaderVariantCollection asset and utilized for shader stripping at build time. It is especially effective for reducing VRChat avatar upload size, and it also shortens shader compile time.

Key Features

  • Automatic Variant Detection — Scans all Natane Toon Shader materials in the project and auto-detects active keyword combinations
  • ShaderVariantCollection Generation — Automatically generates a ShaderVariantCollection asset from detected variants. Fully compatible with Unity's standard variant management system
  • Build Size Analysis — Displays size comparison of all variants vs. used variants. Verify reduction rates with concrete numbers
  • Unused Variant Removal — View unused variants in a list, with the option to manually add variants that may be needed in the future
  • Prewarming Support — Can also be used for shader prewarming in the editor environment (editor-only processing compatible with VRChat's runtime script restrictions)

How to Use

  1. Run Scan

    Open Tools > Natane > Shader > Shader Variant Collector and click the "Scan" button to scan materials in the project. All Natane Toon Shader materials are automatically detected.

  2. Review Variant List

    Detected shader variants (keyword combinations) are displayed in a list. You can also see which materials use each variant.

  3. Exclude Unnecessary Variants

    If there are variants you don't plan to use in the future, you can manually exclude them. Normally, using the auto-detection results as-is works fine.

  4. Generate Collection

    Click "Generate Collection" to save the ShaderVariantCollection asset. The ShaderVariants folder is recommended as the save location.

Tips

  • After adding new materials or changing feature settings on existing materials, run the scan again to update the collection
  • Running this tool before uploading a VRChat avatar can significantly reduce upload size
  • If the variant count is extremely high, disabling unused features in materials can further reduce it
  • It's recommended to include the ShaderVariantCollection in version control (Git, etc.) and share it with the entire team
  • If shader compilation feels slow, start by checking the variant count with this tool
