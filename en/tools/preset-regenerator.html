Regenerate All Presets

Batch regenerate all presets with current settings

Menu: Tools > Natane > Regenerate All Presets Category: Preset

Overview

The Regenerate All Presets tool is a utility that regenerates all existing material presets with the current shader settings. Use it to update presets to the latest state after a shader update, or to regenerate thumbnail previews.

Key Features

  • Batch regeneration of all presets
  • Batch regeneration of thumbnail images
  • Recalculation of performance ratings
  • Update for new shader feature compatibility
  • Batch processing with progress bar

How to Use

  1. Run Tools > Natane > Regenerate All Presets from the Unity menu
  2. A regeneration confirmation dialog appears
  3. Click "OK" to start regenerating all presets
  4. Monitor the progress with the progress bar
  5. After completion, verify the updates in the Preset Browser

Tips

  • Recommended to run after major shader updates
  • Processing may take several minutes if there are many presets
  • Custom presets are also regenerated, so creating a backup beforehand is recommended
  • This tool can also fix incorrectly displayed thumbnails
