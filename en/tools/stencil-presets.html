Stencil Presets

One-click stencil setups for peepholes, hidden patterns, and more (v1.6.0)

Location: Material Inspector > Advanced tab > Rendering Settings > Stencil > Presets Category: Shader

Overview

Stencil Presets apply the stencil-buffer settings needed for "visible only through a mask" effects with one click from the material inspector. You can build peepholes, hidden patterns, and vanishing-body effects without memorizing Ref / Comp / Pass combinations.

Access

Material inspector: Advanced tab > Rendering Settings > Stencil > Presets

Presets

  • Default — Ref=0, Comp=Always, Pass=Keep. Stencil unused (default)
  • Writer — Ref=1, Comp=Always, Pass=Replace. The material that writes the mask region (lens, window, magic circle)
  • Reader (Equal) — Ref=1, Comp=Equal, Pass=Keep. Visible only through the mask
  • Reader (NotEqual) — Ref=1, Comp=NotEqual, Pass=Keep. Disappears within the mask region

Usage

  1. Apply the "Writer" preset to the masking material (e.g. a glasses lens, window, or magic circle)
  2. Give the writer a lower Render Queue than the reader so it draws first
  3. Apply "Reader (Equal)" to the material that should only appear through the mask (or "Reader (NotEqual)" to hide it there)
  4. When using multiple mask groups, use a different Reference value (1-255) per group

Effect Ideas

  • Peephole: lens = Writer; the "true form" visible only through the lens = Reader (Equal)
  • Hidden pattern: a tattoo or crest that appears only when a specific item is held up
  • Vanishing body: parts of the body disappear over a magic circle (Reader (NotEqual))

Tips

  • In VRChat, other people's shaders share the stencil buffer; picking uncommon Ref values reduces accidents
  • Ref / Comp / Pass can still be fine-tuned manually after applying a preset
  • Combines well with the Mirror/Camera Alt Texture for mirror/camera trick effects
