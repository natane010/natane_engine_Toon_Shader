Color Palette

Create and manage color palettes

Menu: Tools > Natane > Color Palette Category: Preset

Overview

The Color Palette tool allows you to create, save, and manage color sets for use in materials. It's useful for character color scheme design and theme color unification, and you can directly apply palette colors to material color properties.

Key Features

  • Create and save new color palettes
  • Add, remove, and reorder colors
  • Extract colors from existing materials
  • Directly apply palette colors to materials
  • Color harmony generation (complementary, analogous, triadic, etc.)
  • Palette export/import

How to Use

  1. Open the Color Palette tool
  2. Create a new palette or load an existing one
  3. Add colors using the color picker or extract colors from a material
  4. Drag and drop to reorder colors within the palette
  5. Click a palette color to apply it to a material's color property

Tips

  • Creating a theme color palette first is efficient for unifying character color schemes
  • Shadow colors look natural when created by adjusting the saturation and brightness of the main color
  • Palettes are saved in the project and can be shared with the team
  • The harmony generation feature can automatically suggest well-balanced color schemes
