Batch Material Converter

A general-purpose tool for batch converting multiple materials to Natane Toon Shader

Menu: Tools > Natane > Migration > Batch Converter Category: Migration

Overview

The Batch Material Converter is a general-purpose migration tool for batch converting materials from any shader to Natane Toon Shader. It also handles migrations from shaders that don't have a dedicated migration tool like lilToon.

This tool detects materials using the specified shader from across the entire project and displays them in a list. Properties with the same name between the source and target shaders are automatically mapped; those with different names can be manually configured. Common texture property names such as _MainTex and _BumpMap are automatically recognized.

It can be used for a wide range of purposes: unifying shaders across a large project, migrating from basic shaders like Standard Shader or Unlit Shader, or migrating from third-party shaders. The backup feature safely protects materials before conversion, and conversion results support Undo.

Key Features

  • Multi-Material Batch Processing — Convert all selected materials at once. Streamlines migration of large projects
  • Folder Selection — Specify a particular folder to target only materials within that folder for conversion
  • Property Preservation — Properties with the same name between source and target are automatically carried over. Supports textures, colors, and numerical parameters
  • Backup — Automatically creates material backups before conversion. Used for restoration if issues occur
  • Filtering — Filter conversion targets by shader name or material name
  • Conversion Report — Displays a detailed report of successful, failed, and skipped materials after conversion

How to Use

  1. Select Source Shader

    Select the shader currently used by the materials you want to convert. A dropdown lists all shaders in use within the project.

  2. Review Material List

    A list of materials using the selected shader is displayed. Materials you don't want to convert can be excluded via checkboxes.

  3. Configure Settings

    Set the target variant (Opaque / Cutout / Transparent), property mapping, and backup options.

  4. Batch Convert

    Click "Batch Convert" to execute the conversion. A progress bar shows the progress, and a report is displayed upon completion.

Tips

  • Always keep the backup feature enabled. It allows restoration in case of unexpected conversion results
  • Texture mapping from Standard Shader is mostly automatic (_MainTex, _BumpMap, _MetallicGlossMap, etc.)
  • Always check the appearance in Scene view after conversion and add toon shader-specific settings like shadow colors and rim light as needed
  • When converting a large number of materials at once, proceeding folder by folder makes management easier
  • Materials showing "Skipped" in the conversion report may have had property incompatibilities — verify them manually
