Screen FX Setup

Auto-setup fullscreen post effects on camera for VRChat

Menu: Tools > Natane > Effects > Screen FX Setup Category: Effect

Overview

Screen FX Setup is a tool that automatically sets up fullscreen post effects on a camera for VRChat. Using a GrabPass-based overlay approach, it achieves screen effects such as Posterize, Edge Detection, Vignette, Chromatic Aberration, and more — all without runtime scripts.

Since VRChat restricts the use of runtime scripts, the standard post-processing stack cannot be used. This tool takes a shader-based approach: it automatically places an overlay mesh in front of the camera, captures the screen via GrabPass, and applies various effects. Settings are saved as material properties, so it works simply by building it into an avatar and uploading.

It can be used for photography, video production, VRChat event staging, and any scenario where you want to apply effects to the entire screen. Combined with Natane Toon Shader's shading expressions, you can achieve a unified visual style.

Key Features

  • GrabPass-Based — No runtime scripts required. Works entirely through shaders, fully compatible with VRChat restrictions
  • Automatic Camera Placement — Automatically generates and places an overlay object directly under the camera. No tedious manual setup needed
  • Recommended Defaults — Each effect comes with recommended initial values. They function as ready-to-use presets
  • Posterize — Limits color gradation to create retro or anime-style expressions
  • Edge Detection — Adds outlines across the entire screen. Great for manga or illustration-style staging
  • Vignette — Darkens screen edges to guide focus to the center for a cinematic effect
  • Chromatic Aberration — Adds RGB color shift for a lens-like effect
  • Scanline — CRT monitor-style scanline effect

How to Use

  1. Select a Camera

    Select a camera object in the scene. If none is selected, the MainCamera is used automatically. For VRChat avatars, select the camera inside the Head.

  2. Run Setup

    Run Tools > Natane > Effects > Screen FX Setup. An overlay object and material are automatically generated directly under the camera.

  3. Adjust the Material

    Adjust each effect in the Inspector of the generated material. Set the parameters for Posterize, Edge Detection, Vignette, and Chromatic Aberration to your preferred values.

  4. Check in Preview

    Verify the effect in the Game view or Scene view. Parameter changes are reflected in real time.

Tips

  • For Quest, keep Chromatic Aberration and Scanline low to minimize performance impact
  • Keep the Overlay directly under the camera to prevent position misalignment. Moving it manually may cause effects to display incorrectly
  • When utilizing Natane Toon's shading, start adjusting Edge intensity from around 0.2
  • Setting Posterize gradation levels to 3-5 produces an anime-style flat color look
  • Use Vignette modestly at around 0.3-0.5 for a natural cinematic atmosphere
  • When using multiple effects simultaneously, keep each intensity low to maintain overall balance
