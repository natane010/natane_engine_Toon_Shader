Variant Stripping Settings

Automatically strip unused shader variants at build time to significantly reduce build size

Menu: Tools > Natane > シェーダー Shader > バリアントストリッピング設定 Variant Stripping Settings Category: Shader

Overview

Variant Stripping Settings is a configuration tool for the automatic removal of unused shader variants at build time. It implements Unity's build pipeline API IPreprocessShaders and is fully integrated into the build process.

Natane Toon Shader has many optional features (outline, specular, rim light, SSS, etc.), each controlled by shader_feature keywords. Including all keyword combinations (variants) in the build results in enormous size, but this tool scans all materials in the project, whitelists only the keyword combinations actually in use, and removes all other variants from the build.

This feature runs after Unity's standard stripping process (callbackOrder = 100) and only targets Natane Toon Shader variants (Opaque/Cutout/Transparent/Lite/Fur/Background/Wirelight/Eye/Screen FX Overlay), so it does not affect other shaders.

Key Features

  • Automatic Build-Time Stripping — Implements IPreprocessShaders and runs automatically during builds. No manual action required — simply press the build button and unused variants are removed
  • Material-Based Whitelist — Scans all materials in the project and automatically whitelists keyword combinations actually in use. The base variant (no keywords) is always included in the whitelist
  • ShaderVariantCollection Support — Recognizes variants in existing ShaderVariantCollections, ensuring manually added variants are not stripped
  • 12 Shader Variants Supported — Targets all Natane Toon Shader variants: Toon Shader, Cutout, Transparent, Lite variants, Fur variants, Background, Wirelight, Eye, and Screen FX Overlay
  • Detailed Log Output — Outputs kept and stripped counts per shader to the Console. Log output can be toggled on/off
  • Material Keyword Scan — Built-in scan feature to check the number of Natane Toon materials and unique keyword sets in the project. Includes a progress bar for large projects
  • Enable/Disable Toggle — One-click toggle to enable or disable stripping from the settings window. Disabled by default

How to Access

Menu: Tools > Natane > シェーダー Shader > バリアントストリッピング設定 Variant Stripping Settings

How to Use

  1. Open Settings Window

    Select Tools > Natane > シェーダー Shader > バリアントストリッピング設定 Variant Stripping Settings to open the settings window.

  2. Enable Stripping

    Turn on the "Enable Variant Stripping" toggle. Stripping will automatically run on the next build.

  3. Configure Log Output (Optional)

    Toggle "Enable Log Output" to control Console logging. Enabled by default. Keep it on if you want to see detailed stripping results.

  4. Scan Material Keywords (Optional)

    Click "Scan Material Keywords" to check the number of Natane Toon materials and unique keyword sets in the project. Detailed scan results are output to the Console.

  5. Run Build

    Run the build as usual. When stripping is enabled, kept and stripped counts are output to the Console during the build process.

Tips

  • Before enabling stripping, it is recommended to first run "Scan Material Keywords" to understand the current state of your project
  • New keyword sets from newly added materials are automatically whitelisted on subsequent builds
  • Especially effective for reducing VRChat avatar upload size
  • Stripping only targets Natane Toon Shaders and does not affect other shaders
  • If issues occur, disable stripping and rebuild to revert to the original state
  • Use in combination with the Shader Variant Collector tool for even more effective build size reduction
