Reflection

Environment reflection using cubemaps

An effect that simulates environment reflections using cubemaps. Ideal for expressing reflective materials such as metal, glass, and glossy plastic. Fresnel settings allow natural reflections that vary based on viewing angle.

Keyword: _REFLECTION

Basic Settings

Reflection Cubemap _ReflectionCube texture

The cubemap texture used for environment reflection. Displays surrounding scenery as reflections on the surface.

Default: "black" (no reflection)

You can generate a cubemap from the Skybox or use a custom HDRI for realistic reflections.
Reflection Color _ReflectionColor color

Adjusts the color tint of reflections. White preserves the original cubemap colors; a tinted color adds color to the reflections.

Default: (1, 1, 1, 1) (white, no change)

Reflection Intensity _ReflectionIntensity range

Sets the intensity of environment reflection. Higher values produce stronger reflections.

Default: 1 (Range: 0 - 2)

Surface Settings

Smoothness (Glossiness) _Smoothness range

Sets the surface smoothness (glossiness). Higher values produce mirror-like reflections, while lower values create blurred reflections.

Default: 0.5 (Range: 0 - 1)

Metal: 0.7-1.0, Plastic: 0.3-0.6, Matte materials: 0-0.2 as a guideline.
Metallic _Metallic range

Sets the metalness of the material. Metallic materials have stronger reflections, while non-metallic materials emphasize the Fresnel effect.

Default: 0 (Range: 0 - 1)

Fresnel Settings

Fresnel Power _FresnelPower range

Sets the strength of the Fresnel effect. Higher values limit reflections to edge areas (viewed at oblique angles).

Default: 5 (Range: 0 - 10)

Fresnel Softness _FresnelSoftness range

Softens the reflection boundary for more natural and artistic reflections.

  • 0 = Sharp boundary (realistic)
  • 0.5 - 0.7 = Soft boundary (recommended)
  • 1.0 = Very soft boundary (artistic)

Default: 0 (Range: 0 - 1)

Blend Settings

Blend Mode _ReflectionBlendMode range

Sets how the reflection is composited with the base color.

  • 0 = Additive (brightens)
  • 1 = Overlay (natural integration)

Default: 0 (Additive)

Blend _ReflectionBlend range

Sets the overall application intensity of the reflection effect.

Default: 1 (Range: 0 - 1)

Mask

Reflection Mask _ReflectionMask texture

Controls the reflection application area using a texture. Enabled with the keyword _REFLECTION_MASK.

Default: "white" (applied everywhere)

White = reflection visible, Black = no reflection. Useful for applying reflections only to metallic parts.
