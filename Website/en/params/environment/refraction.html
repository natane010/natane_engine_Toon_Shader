Refraction

Refraction and distortion effect using GrabPass

Simulates the refraction effect of light bending through transparent materials such as glass and water using GrabPass. Produces realistic refraction with visible background distortion. Ideal for transparent materials.

Keyword: _REFRACTION

Refraction Settings

Index of Refraction (IOR) _RefractionIndex range

Sets the Index of Refraction (IOR) for the material. Can be set based on physical IOR values of real materials.

  • 1.0 = Air (no refraction)
  • 1.33 = Water
  • 1.5 = Glass (default)
  • 2.42 = Diamond

Default: 1.5 (Range: 1 - 3)

Higher values produce stronger background distortion. Glass works well at 1.5, gemstones at 1.8-2.4.
Refraction Intensity _RefractionIntensity range

Sets the overall intensity of the refraction distortion.

Default: 1 (Range: 0 - 1)

Refraction Blur _RefractionBlur range

Applies blur to the refracted background. Creates frosted glass-like effects.

Default: 0 (Range: 0 - 1)

A blur of 0.3-0.5 is recommended for frosted glass effects. On VRChat Quest, samples are reduced to 5 for performance optimization.

Mask

Refraction Mask _RefractionMask texture

Controls the refraction application area using a texture. Enabled with the keyword _REFRACTION_MASK.

Default: "white" (applied everywhere)

White = refraction visible, Black = no refraction. Useful for preventing refraction on window frames while keeping it on the glass.

Blend Settings

Blend Mode _RefractionBlendMode enum

Selects how the refraction effect is composited.

  • Normal (0) - Normal blending
  • Soft (1) - Soft Light
  • Screen (2) - Screen
  • Overlay (3) - Overlay

Default: 0 (Normal)

Blend _RefractionBlend range

Sets the overall application intensity of the refraction effect.

Default: 1 (Range: 0 - 1)
