Iridescence

Rainbow-like iridescent sheen effect

Adds an iridescence effect where colors shift depending on viewing angle. Reproduces rainbow-like effects caused by light interference, enabling expression of beautiful color changes found in nature such as soap bubbles, oil slicks, insect wings, and fish scales.

Keyword: _IRIDESCENCE

Iridescence Settings

Iridescence Color _IridescenceColor color

Sets the base color tone for the iridescence effect. This serves as the reference color for the rainbow color shifts.

Default: (1, 1, 1, 1) (white)

Intensity _IridescenceIntensity range

Sets the brightness (intensity) of the iridescence effect. Higher values produce a stronger rainbow effect.

Default: 0.5 (Range: 0 - 2)

Hue Shift _IridescenceHueShift range

Offsets the starting position of color changes on the hue wheel. Shifts the overall rainbow color tones.

Default: 0.5 (Range: 0 - 1)

Size (Frequency) _IridescenceSize range

Sets the frequency (fineness) of color changes. Higher values cause colors to shift more rapidly with changes in viewing angle.

Default: 1 (Range: 0 - 10)

Low values produce delicate changes like soap bubbles; high values create dynamic shifts like oil slicks.

Mask

Iridescence Mask _IridescenceMask texture

Controls the iridescence display area using the R (red) channel. Enabled with the keyword _IRIDESCENCE_MASK.

  • White (1.0): Fully displays iridescence
  • Black (0.0): Hides iridescence
  • Gray: Partially displays

Default: "white" (applied everywhere)

Blend Settings

Blend Mode _IridescenceBlendMode enum

Selects how iridescence is composited with the base color.

  • Normal (0) - Normal blending
  • Soft (1) - Soft Light
  • Screen (2) - Screen
  • Overlay (3) - Overlay

Default: 0 (Normal)

Blend _IridescenceBlend range

Sets the overall application intensity of the iridescence effect.

Default: 1 (Range: 0 - 1)

Blur _IridescenceBlur range

Blurs the boundaries of the iridescence effect.

Default: 0 (Range: 0 - 1)
