Environmental Rim

Rim light effect using environment maps

Creates a rim light effect based on the environment using a cubemap. Unlike standard rim lighting which uses a single color, environmental rim uses color information from a cubemap, enabling natural rim lighting that reflects the surrounding environment colors.

Keyword: _ENV_RIM

Environmental Rim Settings

Environment Cubemap _EnvRimCube texture

The cubemap texture used for the environmental rim. The rim light color varies based on the environment.

Default: "black" (no reflection)

Using the same cubemap as for Reflection creates a unified environmental appearance.
Environmental Rim Color _EnvRimColor color

Adjusts the color tint of the environmental rim. Multiplied with the cubemap colors.

Default: (1, 1, 1, 1) (white, no change)

Environmental Rim Power _EnvRimPower range

Sets the Fresnel effect strength for the environmental rim. Higher values concentrate the rim at edges, while lower values spread it wider.

Default: 3 (Range: 0.1 - 10)

Environmental Rim Intensity _EnvRimIntensity range

Sets the overall brightness of the environmental rim.

Default: 1 (Range: 0 - 5)

Mask

Environmental Rim Mask _EnvRimMask texture

Controls the environmental rim application area using a texture. Enabled with the keyword _ENV_RIM_MASK.

Default: "white" (applied everywhere)

White = environmental rim visible, Black = no environmental rim. Useful for masking areas like the face where environmental rim is not desired.

Blend Settings

Blend Mode _EnvRimBlendMode enum

Selects how the environmental rim is composited with the base color.

  • Normal (0) - Normal blending
  • Soft (1) - Soft Light
  • Screen (2) - Screen
  • Overlay (3) - Overlay

Default: 0 (Normal)

Blend _EnvRimBlend range

Sets the overall application intensity of the environmental rim effect.

Default: 1 (Range: 0 - 1)

Blur _EnvRimBlur range

Blurs the boundaries of the environmental rim effect.

Default: 0 (Range: 0 - 1)
