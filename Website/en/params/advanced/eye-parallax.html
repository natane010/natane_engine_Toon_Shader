Eye Parallax

Gaze-tracking depth for eye pupils

Overview

Eye Parallax is a lightweight parallax effect that offsets the pupil texture coordinates based on the camera's viewing direction, giving the eyes a sense of depth. Unlike full parallax mapping (_PARALLAX), it does not require a height map or ray marching. Instead, it uses only the XY components of the view direction, achieving a natural eye depth effect at very low cost.

Controlled by the keyword _EYE_PARALLAX. When disabled, no shader instructions are generated. If full parallax (_PARALLAX) is also enabled, it takes priority and Eye Parallax is automatically skipped.

Parameters

Enable Eye Parallax _EyeParallax toggle

Toggles the Eye Parallax feature on/off. Branches at compile time using the keyword _EYE_PARALLAX.

Default: OFF

Eye Depth _EyeParallaxDepth range

Controls the parallax offset amount for the pupil. Higher values make the pupil appear deeper, increasing the sense of depth. Values too high may cause unnatural texture shifting.

Default: 0.1

Range: 0 – 0.5

Values between 0.05 and 0.15 produce the most natural results.

Usage Tips

  • Designed for use on character eye materials
  • Significantly lighter than full parallax mapping (height map based), making it ideal for VRChat avatars
  • Works best when the pupil texture is centered within the UV space
  • Uses the view direction XY components directly as UV offset, so mesh orientation may require adjustment
  • If _PARALLAX (full parallax mapping) is also enabled, it takes priority and this feature is ignored
