Perspective Flat

Reduce foreshortening for a 2D illustration look

Overview

Perspective Flat compresses the clip-space Z depth to reduce foreshortening, making 3D models appear more 2D and illustration-like. In the vertex shader, the Z value is interpolated using lerp(z, w * 0.5, amount), compressing the object's depth extent.

Controlled by the keyword _PERSPECTIVE_FLAT. When disabled, no shader instructions are generated. Implemented as a local keyword (shader_feature_local), so it does not affect other materials' variants.

Parameters

Enable Perspective Flatten _PerspectiveFlat toggle

Toggles the Perspective Flat feature on/off. Branches at compile time using the keyword _PERSPECTIVE_FLAT.

Default: OFF

Flatten Amount _PerspectiveFlatAmount range

Controls the depth compression strength. At 0 perspective is normal, at 1 the depth is fully flattened. Intermediate values retain partial foreshortening for a natural illustration-style depth.

Default: 0.5

Range: 0 – 1

Values between 0.3 and 0.6 retain some depth while giving a flat impression.

Usage Tips

  • Ideal for anime and illustration-style rendering. Applying to character faces can reduce perspective-induced distortion
  • Processed in the vertex shader, so there is no additional fragment shader cost
  • Since Z depth is modified, Z-fighting or sorting issues may occur. Exercise caution with multiple materials on the same object
  • Setting the flatten amount to 1 makes the object nearly flat. Values around 0.3–0.7 are generally recommended
  • Also applies to the outline pass, so outline depth is flattened together
