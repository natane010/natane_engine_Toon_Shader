Quest Lite Mode

Automatic feature stripping for mobile GPU optimization

Overview

Quest Lite Mode is a compile-time optimization switch that automatically strips GPU-intensive features from the shader when targeting mobile GPUs such as the Meta Quest. When the _QUEST_LITE keyword is enabled, the following expensive features are disabled at the shader compilation stage, meaning they generate zero GPU instructions:

  • MatCap 2nd & 3rd (_MATCAP_2, _MATCAP_3)
  • Glitter (_GLITTER)
  • Water Drip (_WATER_DRIP)
  • Hologram (_HOLOGRAM)
  • Glitch (_GLITCH)
  • Intersection Fade (_INTERSECTION_FADE)

This results in an expected performance improvement of 30-50% on mobile GPUs compared to the full-feature shader. PC users can keep Quest Lite disabled for full visual quality.

Controlled by the keyword _QUEST_LITE. This feature is available in the Background shader variant.

Parameters

Quest Lite Mode _QUEST_LITE toggle

Enables or disables Quest Lite Mode. This is a shader keyword with no additional float or texture properties — it acts purely as a compile-time switch.

When enabled, the listed GPU-intensive features are excluded from shader compilation entirely, reducing instruction count and texture sampling overhead to zero for those features.

Default: OFF

This keyword controls compile-time stripping. Toggling it triggers shader recompilation.

Stripped Features Detail

MatCap 2nd & 3rd _MATCAP_2, _MATCAP_3 stripped

The second and third MatCap layers are disabled. The primary MatCap (_MATCAP) remains available. MatCaps require texture lookups and blending operations that are expensive on mobile.

Glitter _GLITTER stripped

The sparkle/glitter effect is disabled. Glitter involves random sampling and per-pixel noise generation, which is GPU-intensive on mobile hardware.

Water Drip _WATER_DRIP stripped

The animated water drip effect is disabled. This effect uses multiple texture samples and time-based animation that impacts mobile performance.

Hologram _HOLOGRAM stripped

The hologram scanline effect is disabled. Hologram rendering involves screen-space calculations and alpha manipulation.

Glitch _GLITCH stripped

The digital glitch effect is disabled. Glitch effects use noise functions and UV distortion that add computational overhead.

Intersection Fade _INTERSECTION_FADE stripped

The depth-based intersection fade effect is disabled. This feature requires depth texture sampling, which is particularly expensive on mobile GPUs.

Usage Tips

  • Enable Quest Lite for any material intended for use in VRChat Quest worlds. The compile-time stripping means zero runtime overhead — disabled features simply do not exist in the compiled shader.
  • PC users should keep Quest Lite disabled to enjoy full visual quality with all effects available.
  • The primary MatCap (1st) is not stripped — only the 2nd and 3rd MatCap layers are removed. You can still use a single MatCap for material definition on Quest.
  • Combine with the Material Validator tool (Tools > Natane > Material Validator) to check whether your material meets Quest performance guidelines.
  • When creating cross-platform content, consider using two material variants: one with Quest Lite enabled (for Quest builds) and one without (for PC builds).
