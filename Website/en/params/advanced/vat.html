VAT (Vertex Animation Texture)

Mesh animation using vertex animation textures

Overview

VAT (Vertex Animation Texture) is a technique where vertex animations created in tools like Houdini are baked into textures and played back in the shader. It allows lightweight playback of physics simulations that would be too heavy for real-time processing, such as fluid simulations, cloth simulations, and complex deformation animations, by baking them into textures.

Controlled by the keyword _VAT. Compatible with Houdini-compatible formats.

Basic Settings

Enable VAT Animation _VAT toggle

Toggles the VAT feature on/off. Branches at compile time using the keyword _VAT.

Default: OFF

VAT Position Map _VATPositionMap texture

A texture containing vertex position information. Use the Position Map (.exr) generated by Houdini's VAT export.

Default: "black"

Set compression to "None" and sRGB to OFF in the texture import settings.
Number of Frames _VATNumOfFrames float

The total number of frames in the VAT animation. Must match the Houdini export settings.

Default: 30

Animation Speed _VATSpeed range

Playback speed multiplier for the animation. 1.0 is normal speed, 2.0 is double speed.

Default: 1.0

Animation Intensity _VATIntensity range

The strength of the animation effect. 0 for no effect, 1 for normal, 2 for exaggerated motion.

Default: 1.0

Range: 0 - 2

Position Parameters

Position Minimum _VATPositionMin float

The minimum value of the position range from the Houdini export. Used when converting texture values to world coordinates.

Default: -1.0

Position Maximum _VATPositionMax float

The maximum value of the position range from the Houdini export.

Default: 1.0

VAT Normal Map (Optional)

Use VAT Normal Map _VATNormal toggle

Enables the use of a VAT normal map. Used when you want to animate normals in addition to positions. Controlled by the keyword _VAT_NORMAL.

Default: OFF

VAT Normal Map _VATNormalMap texture

A VAT texture containing normal information. Use Houdini's Normal Map (.exr).

Default: "bump"

Normal Minimum _VATNormalMin float

The minimum value of the normal texture value range.

Default: -1.0

Normal Maximum _VATNormalMax float

The maximum value of the normal texture value range.

Default: 1.0

Advanced Settings

Packing Mode _VATPackingMode enum

Selects how position data in the VAT texture is interpreted.

  • Absolute (0) - Absolute position mode. Directly replaces vertex positions.
  • Offset (1) - Offset mode. Adds an offset to the original positions (recommended).

Default: 0 (Absolute)

Offset mode is generally recommended. It allows adding animation on top of the original mesh shape.

Setup Guide

  1. Export using VAT (ROP Output Driver) in Houdini
  2. Import the Position Map (.exr) into Unity and assign it as the VAT Position Map
  3. Optionally assign the Normal Map (.exr) as the VAT Normal Map
  4. Match the number of frames to the Houdini export settings
  5. Adjust the position min/max to match the Houdini export range

Important Notes

  • VAT textures use more memory than standard textures
  • Choose appropriate resolution and frame count for VRChat
  • Set texture compression to None. Compression will cause animation artifacts
  • Set sRGB color space to OFF
