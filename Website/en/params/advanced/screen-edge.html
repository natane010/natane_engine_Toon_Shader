Screen Edge

Screen-space edge detection outlines

Overview

Screen Edge is a screen-space edge detection feature that uses the camera's depth buffer and normal buffer. It employs a Sobel filter to detect edges from both depth and normal discontinuities, outputting the maximum of both as the final edge strength. This produces illustration-style, post-process-like outlines.

Controlled by the keyword _SCREEN_EDGE. When disabled, no shader instructions are generated.

Parameters

Enable Screen Edge _UseScreenEdge toggle

Toggles the Screen Edge feature on/off. Branches at compile time using the keyword _SCREEN_EDGE.

Default: OFF

Edge Color _EdgeColor color

Specifies the color used to draw detected edges. Edge areas are blended with this color.

Default: (0, 0, 0, 1) (black)

Edge Width _EdgeWidth range

Controls the Sobel filter sampling interval, affecting the thickness of the edge lines. Higher values produce thicker edges.

Default: 1

Range: 0.1 – 5

Depth Sensitivity _EdgeDepthSensitivity range

Sensitivity of edge detection to depth differences. Higher values detect edges even with slight depth variations.

Default: 10

Range: 0 – 50

Normal Sensitivity _EdgeNormalSensitivity range

Sensitivity of edge detection to normal differences. Higher values detect edges even with subtle normal changes on smooth surfaces.

Default: 2

Range: 0 – 10

Edge Blend _EdgeBlend range

Controls how strongly the detected edges are blended over the original color. 0 means no effect, 1 applies full edge blending.

Default: 1

Range: 0 – 1

Usage Tips

  • Ideal for illustration and manga-style rendering. Combine with geometry-based outlines for richer line art
  • Depth edges detect object silhouettes, while normal edges detect surface creases. Adjust both sensitivities for the best balance
  • Requires DepthTextureMode.DepthNormals on the camera. VRChat enables this automatically
  • As a screen-space effect, it only operates in the forward base pass
  • Excessively large edge width may cause artifacts. Keeping values within 1–2 is recommended
