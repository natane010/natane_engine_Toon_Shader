Rendering Settings

Rendering mode, culling, stencil, and other draw controls

Overview

Rendering Settings is the section that controls the fundamental drawing behavior of materials. It includes core shader settings such as opaque/cutout/transparent mode selection, polygon front/back face rendering control, depth buffer writing, and blend modes.

Rendering Mode

Rendering Type RenderingMode enum

Selects the material's rendering mode. The shader internally switches to the appropriate variant based on the mode. All properties are preserved.

  • Opaque - Standard opaque objects. Used for skin, clothes, and solid objects. The fastest and recommended mode.
  • Cutout - Alpha threshold transparency. Used for hair, leaves, and fences. Each pixel is either fully transparent or fully opaque.
  • Transparent - Smooth transparency. Used for glass, water, smoke, and effects. Provides gradual transparency based on alpha value, but is the most expensive mode.

Default: Opaque

In terms of performance, efficiency ranks as Opaque > Cutout > Transparent. Use Opaque whenever possible.

Cutout-Specific Settings

Alpha Cutoff _Cutoff range

The alpha threshold for Cutout mode. Pixels with texture transparency at or below this value are hidden.

  • Lowering the value: More pixels become visible
  • Raising the value: More pixels become hidden

Default: 0.5 (recommended)

Advanced Settings

Culling Mode _Cull enum

Controls which side of polygons is rendered.

  • Back (2) - Hides backfaces (default; the most common setting)
  • Front (1) - Hides front faces (for special use cases)
  • Off (0) - Double-sided rendering (set when using the backface texture feature)

Default: Back (2)

Double-sided rendering (Off) doubles the drawing cost. Use only when necessary.
Z Write _ZWrite enum

Controls writing to the depth buffer. Normally keep this ON.

  • On (1) - Writes to depth buffer (standard for opaque objects)
  • Off (0) - Does not write to depth buffer (for transparent objects and effects)

Default: On (1)

Transparent-Specific Settings

Source Blend _SrcBlend enum

The blend factor for the source (foreground) during transparent rendering.

Default: SrcAlpha (5)

Destination Blend _DstBlend enum

The blend factor for the destination (background) during transparent rendering.

Default: OneMinusSrcAlpha (10)

Blend modes typically do not need to be changed. The default settings provide proper alpha blending.

Usage Tips

  • Opaque is best for most VRChat avatar parts (skin, clothes, shoes)
  • Cutout mode is suitable for hair and eyebrows
  • Use Transparent for see-through materials like glass and gemstones
  • Culling Off is required when using backface textures, but be mindful of the performance cost
  • Changing rendering mode involves switching shader variants, but all properties are preserved
