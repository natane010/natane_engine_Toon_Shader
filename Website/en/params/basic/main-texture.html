Main Texture

Basic settings for the main texture and color

Main Texture _MainTex texture

The primary texture of the material. Used as the albedo (diffuse reflectance color) map, defining the surface color of the object.

Default: "white" (white texture)

You can adjust the tiling and offset of the UV to change the texture's repetition and position.
Color _Color color

A color multiplied with the main texture. Use it to adjust the overall color tone of the texture, or to create a solid-color material without a texture.

Default: (1, 1, 1, 1) (white, fully opaque)

To adjust only the brightness without changing the texture's color, change the RGB values uniformly.
