Cast Shadow Color

Apply custom color tinting to cast shadows

Overview

Cast Shadow Color applies a custom color tint specifically to cast shadows (shadows projected by other objects). Unlike the general shadow color, this feature targets only the areas where external objects cast their shadow onto a surface, allowing for expressive anime-style shadow coloring such as purple-tinted hair shadows on a character's face.

Internally, a "cast shadow mask" is computed by combining the light attenuation value with NdotL. This detects regions where the surface faces the light but is darkened by external occlusion (i.e., a shadow from another object).

Controlled by the keyword _CAST_SHADOW_COLOR. When disabled, no shader instructions are generated.

Parameters

Enable Cast Shadow Color _CastShadowColorEnable toggle

Toggles the Cast Shadow Color feature on or off. When enabled, the tint color is applied to detected cast shadow regions.

Default: 0 (disabled)

Shadow Tint _CastShadowTint color

The tint color applied to cast shadows. This is multiplied with the existing shadow color. Purple or blue tones produce an anime-style impression for cast shadows.

Default: (0.5, 0.4, 0.6, 1) — light purple

In warm lighting environments, setting a complementary cool tone (blue-purple to purple) as the tint creates color contrast for a painterly expression.
Shadow Intensity _CastShadowIntensity range

Controls the strength of the cast shadow tint effect. 0 disables the tint (original shadow color is preserved), while 1 applies the tint at full strength. This value is multiplied with the cast shadow mask.

Default: 0.5

Range: 0 to 1

Recommended: 0.3-0.7. Lower values produce a subtle color shift, while higher values create dramatic cast shadow coloring.

Usage Tips

  • Anime-style cast shadows: In Japanese animation, hair shadows falling on a character's face are often rendered with a purple tint. This feature recreates that aesthetic.
  • Distinguishing shadow types: By coloring cast shadows differently from NdotL-based self-shadows, you can create more informative and visually rich shadow rendering.
  • Scene atmosphere: Set warm orange tints for sunset scenes and blue-purple tints for nighttime to match the environmental mood.
  • Combining with Shadow Color: The Shadow Color (_ShadowColor) controls the overall shadow tone, while Cast Shadow Color targets only projected shadows. Combining both allows fine-tuned shadow expression.
