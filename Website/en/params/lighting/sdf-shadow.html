SDF Shadow Map

Signed Distance Field-based shadow mapping for precise shadow control

Overview

SDF Shadow Map uses Signed Distance Field textures to define precise shadow boundaries on your model. Unlike standard NdotL-based shading, SDF shadows give you full artistic control over exactly where shadow edges appear. This feature is particularly useful for face shadows — the Face SDF Rotation feature allows proper facial shadow casting based on head orientation, ensuring shadows always fall naturally regardless of the viewing angle. Keywords: _SDF_MAP, _FACE_SDF_ROTATION

Parameters

SDF Shadow Texture _SDFMap texture

The Signed Distance Field texture that defines shadow boundaries. White areas represent fully lit regions, black areas represent fully shadowed regions, and the gradient between them defines the shadow transition zone.

Default: "white"

For anime-style face shadows, paint an SDF texture where white = lit and black = shadow. The gradient between them controls where the shadow edge falls as the light direction changes.
SDF Shadow Intensity _SDFIntensity range

Controls the overall intensity of the SDF shadow effect. At 0, the SDF shadow has no effect. At 1, the SDF shadow is fully applied, completely replacing the standard NdotL shadow calculation.

Default: 0.5

Range: 0 to 1

Start at 0.5 and adjust upward for stronger SDF shadow influence. Values around 0.7-0.9 work well for face shadows where you want the SDF to dominate.
SDF Shadow Softness _SDFSoftness range

Controls the softness of the shadow edge defined by the SDF texture. Lower values produce a sharp, cel-shaded shadow edge. Higher values create a smoother, more gradual transition from light to shadow.

Default: 0.1

Range: 0 to 1

For a classic anime look, keep this low (0.05-0.15). For a softer, more painterly feel, try 0.3-0.5. Very high values may cause the shadow to lose definition.
SDF Shadow Offset _SDFOffset range

Shifts the shadow boundary threshold. Negative values push the shadow boundary inward (more lit area), while positive values push it outward (more shadowed area). Use this to fine-tune where the shadow edge falls without re-painting the SDF texture.

Default: 0

Range: -1 to 1

Useful for quick adjustments. If the shadow appears too early (too much shadow), decrease the offset. If it appears too late (too much light), increase it.
Face Forward Direction _FaceForwardDirection vector

Defines the forward direction of the face in object space. This vector is used by the Face SDF Rotation system to determine the head's facing direction, allowing the SDF shadow to rotate correctly with head movement.

Default: (0, 0, 1, 0)

For most humanoid models, the default (0, 0, 1, 0) works correctly. If your model faces a different axis, adjust this to match the direction the face points in object space.
Face Right Direction _FaceRightDirection vector

Defines the right direction of the face in object space. Together with the forward direction, this establishes the face's local coordinate system for proper SDF shadow rotation.

Default: (1, 0, 0, 0)

For most humanoid models, the default (1, 0, 0, 0) works correctly. Adjust only if your model uses a non-standard orientation.

Usage Tips

  • For anime-style face shadows, paint an SDF texture where white represents lit areas and black represents shadow areas. The gradient controls the shadow transition.
  • Face SDF Rotation automatically adjusts the SDF sampling based on head rotation, so shadows always fall naturally as the character turns their head.
  • This feature is essential for preventing ugly, unrealistic face shadows that commonly occur with standard NdotL cel-shading.
  • You can use image editing tools to generate SDF textures from hand-painted shadow masks, or use dedicated SDF generation tools.
  • Combine with Shadow Color Texture for even more artistic control over face shadow appearance.
