VRC Light Volumes

Integration with VRChat's voxel-based lighting system

VRC Light Volumes is a next-generation voxel-based lighting system. High-quality partial illumination is automatically applied in supported worlds. Both the world and avatar must support it; in unsupported environments, it automatically falls back to Unity's light probes.

Light Probe Proxy Volume (LPPV) is now automatic (v1.6.0). The Unity light-probe fallback now supports LPPV with no material settings at all — just set the renderer's Light Probes to “Use Proxy Volume” and per-pixel probe-volume lighting is evaluated automatically, so even large objects pick up smooth lighting gradients across their surface. When VRC Light Volumes is active it takes priority, so there is no double-counting.

Light Volume Intensity _LightVolumeIntensity range

Controls the intensity of Light Volume lighting. 1 for full intensity, 0 to disable.

Default: 1

Range: 0 to 1

Blend Mode _LightVolumeBlendMode enum

Select the blending method for Light Volumes.

  • Add (0): Integrates direct light as ambient and indirect light as rim light (default, most natural). Separates Light Volume direct and indirect light, with indirect light naturally integrated as a rim effect for a more three-dimensional appearance.
  • Multiply (1): Multiplied with existing lighting (darkening effect)
  • Replace (2): Replaced by Light Volume (full control)

Default: Add (0)

In Add mode, the Shadow Receive Mask can be used to control indirect light influence.
Blend _LightVolumeBlend range

The blend intensity of the Light Volume effect.

Default: 1

Range: 0 to 1

Specular

Enabling Light Volume Specular generates colored specular from Light Volumes. Keyword: _LIGHT_VOLUME_SPECULAR. The following parameters are shared with Reflection.

Smoothness _Smoothness range

Controls the surface smoothness (glossiness). A parameter shared by both Reflection and Light Volume Specular. Higher values produce sharper reflections, lower values produce blurrier reflections.

Default: 0.5

Range: 0 to 1

Metallic _Metallic range

Controls the metalness. A parameter shared by both Reflection and Light Volume Specular. Higher values produce metallic reflections, lower values produce non-metallic reflections.

Default: 0

Range: 0 to 1
