Backlight

Edge glow and dramatic lighting from backlighting

Backlight adds illumination when light is behind the object, creating a rim-light-like edge glow effect. Ideal for dramatic backlighting scenes.

Backlight Intensity _BacklightIntensity range

Controls the intensity of the backlight effect. 0 to disable; higher values produce a stronger backlight effect.

Default: 0

Range: 0 to 2

Setting a value greater than 0 reveals the detailed backlight settings below.
Backlight Color _BacklightColor color

The color of the backlight. White for natural backlighting, warm tones for sunset style, cool tones for moonlight style.

Default: (1, 1, 1, 1) (white)

Blend _BacklightBlend range

The blend intensity of the backlight effect. Controls how much the effect is mixed into the base color.

Default: 1

Range: 0 to 1

Blend Mode _BacklightBlendMode enum

Select the blending method for the backlight.

  • Normal (0): Standard blending
  • Soft (1): Soft blending
  • Screen (2): Screen (additive brightening)
  • Overlay (3): Overlay (contrast enhancement)

Default: Normal (0)

Blur _BacklightBlur range

The blur amount of the backlight effect. 0 for sharp, 1 for maximum blur.

Default: 0

Range: 0 to 1

Adding blur creates a softer, more natural-looking backlight edge.
