Dither Stabilize

Prevent dither pattern sliding when objects move

Overview

Dither Stabilize locks the dithering pattern relative to the object's pivot position, preventing the visually distracting sliding of dither patterns across the screen when characters or objects move in world space.

Normally, dithering is calculated based on screen pixel coordinates, which means the dither pattern appears to slide across the object's surface as it moves. This feature projects the object's pivot into screen space and subtracts that offset from the dither coordinates, effectively anchoring the pattern to the object.

This parameter is controlled by a float value rather than a keyword toggle. 0 uses conventional screen-fixed dithering, while 1 uses fully object-relative dithering.

Parameters

Dither Stabilize _DitherStabilize range

Controls the strength of object-relative dither stabilization. 0 uses screen-coordinate-based dithering (conventional behavior), while 1 uses fully object-pivot-relative dithering (fully stabilized). Intermediate values allow blending between both modes.

Internally, the StabilizeDitherCoord() function projects the object's world pivot position into screen space and subtracts it from the dither coordinates.

Default: 0

Range: 0 to 1

For VRChat characters that walk around, setting this to 1.0 is highly recommended. For static objects, leaving it at 0 is perfectly fine.

Technical Details

The StabilizeDitherCoord() function operates as follows:

  1. The object's world pivot position (unity_ObjectToWorld._m03_m13_m23) is transformed to clip space
  2. Converted to NDC (Normalized Device Coordinates) and then to screen pixel coordinates
  3. The pivot's screen coordinates are subtracted from the original screen pixel coordinates
  4. A large positive offset (100000.0) is added to prevent negative indices from fmod()
  5. The original and stabilized coordinates are blended using the _DitherStabilize value

Usage Tips

  • Affected features: This stabilization applies to all dithering operations in the shader, including quantization dithering, specular dithering, hair highlight dithering, hashed alpha, and dithering alpha.
  • VRChat characters: Dither pattern "swimming" is highly noticeable on moving avatars, so setting this to 1.0 for character materials is strongly recommended.
  • Performance: One additional matrix multiplication is performed, but no texture sampling is required. The performance impact is negligible.
  • Camera movement: When the camera moves, the dither pattern will still shift regardless of this setting. This feature only stabilizes against object movement.
