SSS LUT

LUT-based pre-integrated subsurface scattering

Overview

SSS LUT (Subsurface Scattering Look-Up Table) replaces the standard SSS computation with a LUT texture lookup to achieve physically-based pre-integrated subsurface scattering. It calculates 2D LUT UV coordinates from NdotL (dot product of light direction and normal) and surface curvature, then retrieves scattered light color and intensity via texture lookup. This is well suited for realistic translucent rendering of skin, wax, and similar materials.

Controlled by keyword _SSS_LUT. Only active when the SSS feature (_SSS) is also enabled. When disabled, no shader instructions are generated. When SSS LUT is enabled, the LUT-based computation (SubsurfaceScatteringLUT function) is used instead of the standard SSS computation (SubsurfaceScattering function).

Parameters

Use SSS LUT _SSSLUT toggle

Enables or disables the SSS LUT. Only takes effect when the SSS feature (Enable SSS) is enabled.

Default: 0 (Disabled)

SSS LUT Texture _SSSLUTTex texture

The pre-integrated SSS look-up table texture. The horizontal axis (U) corresponds to NdotL (remapped to 0-1: ndotl * 0.5 + 0.5), and the vertical axis (V) corresponds to curvature (curvature * (1 - thickness)). The RGB value at each pixel represents the scattered light color for those conditions.

Default: "white"

Pre-integrated skin LUT textures (such as those described in NVIDIA GPU Gems 3) can be used. It is recommended to create the texture in linear color space and import with sRGB disabled.
LUT Scale _SSSLUTScale range

Multiplied with the scattered light color retrieved from the LUT. Amplifies or attenuates the LUT output to adjust the overall intensity of the SSS effect. SSS Color (_SSSColor) is also multiplied into the final result.

Default: 1.0

Range: 0 - 2

Related Parameters (SSS Common)

SSS LUT works in conjunction with the following common SSS parameters:

  • SSS Color (_SSSColor) - Scattered light color. Multiplied with the LUT output.
  • Thickness Map (_ThicknessMap / _ThicknessScale) - Thickness map. Used in the LUT V coordinate calculation as curvature * (1 - thickness). Thicker areas reduce scattering.
  • SSS Mask (_SSSMask) - SSS application mask. Applied to the result after LUT computation.
  • SSS Blend (_SSSBlend) / SSS Blend Mode (_SSSBlendMode) - Blend settings.

Technical Details

Curvature Calculation

Curvature is computed by dividing the fwidth (screen-space rate of change) of the normal by the fwidth of the world position. This value is clamped to 0-1 and represents how curved the surface is. Areas with high curvature (nose tip, ears, etc.) exhibit stronger scattering.

LUT UV Coordinate Calculation

The LUT texture UV coordinates are computed as follows:

  • U coordinate: NdotL * 0.5 + 0.5 (remaps -1 to 1 into 0 to 1)
  • V coordinate: curvature * (1.0 - thickness) (curvature adjusted by thickness)

Usage Tips

Comparison with Standard SSS

Standard SSS simulates scattering in real time, while SSS LUT uses a pre-computed look-up table, yielding more physically accurate results at low cost. For skin rendering in particular, SSS LUT often produces a more natural appearance than standard SSS.

Recommended Use Cases

  • Realistic skin: Use a pre-integrated skin LUT for reddish scattered light that expresses skin translucency
  • Wax / Marble: Use a warm-toned scattering LUT to reproduce the texture of translucent materials
  • Plant leaves: Use a green-toned scattering LUT to express light transmission when backlit

Performance

Consists of one texture sample and an fwidth calculation. Since it replaces the standard SSS computation (pow functions, etc.), the performance impact is roughly equivalent or slightly better.
