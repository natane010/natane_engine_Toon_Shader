Outline

Draw outlines around objects

An outline effect that draws lines along the contours of objects. As a fundamental feature of toon shaders, it adds anime-style outlines to characters and props. Includes automatic compensation based on camera distance.

Keyword: _OUTLINE

Outline Settings

Rendering Method _OutlineMode enum

Selects the outline rendering method.

  • Inverted Hull (0) - Draws outlines by extruding vertices along normals. Generally produces stable results with automatic camera distance adjustment. May show artifacts on low-poly models or hard edges.
  • Back Face (1) - Draws outlines by scaling the mesh and rendering back faces. Produces smooth outlines suited for high-poly models. Internal structures may become visible.

Default: 0 (Inverted Hull)

Outline Width _OutlineWidth range

Sets the thickness of the outline. Automatic camera distance compensation is applied, maintaining consistent thickness at all distances.

Default: 0.1 (Range: 0 - 1)

Outline Color _OutlineColor color

Sets the color of the outline.

Default: (0, 0, 0, 1) (black)

For characters, slightly brown or dark navy tones blend better in anime style than pure black.

Outline Mask

Outline Mask (R) _OutlineMask texture

Uses the R (red) channel to control outline visibility. Enabled by the keyword _OUTLINE_MASK.

  • White (1.0): Outline fully visible
  • Black (0.0): Outline hidden
  • Gray: Partially visible

Default: "white" (visible everywhere)

Useful for hiding outlines around the eyes and mouth on the face.

Outline Width Map

Outline Width Map (R) _OutlineWidthMap texture

Uses the R (red) channel to control outline width per body part. Enabled by the keyword _OUTLINE_WIDTH_MAP.

  • White (1.0): Normal width
  • Black (0.0): Zero width (outline hidden)
  • Gray: Partial width

Default: "white" (uniform width)

You can adjust outline thickness per body part, such as thin on the face and thick on the body.

Multi-Color Outline

Outline Color 2 _OutlineColor2 color

The second color for a two-color gradient outline. Enabled by the keyword _OUTLINE_MULTI_COLOR.

Default: (0.5, 0, 0, 1) (dark red)

Color Mix _OutlineColorMix range

Sets the mix ratio between Outline Color 1 and Color 2. 0 uses only Color 1, and 1 uses only Color 2.

Default: 0.5 (Range: 0 - 1)

Use this to add gradient or animation effects to the outline.
