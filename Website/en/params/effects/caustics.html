Surface Caustics

Complex light patterns flow across the surface of characters and props. Make an underwater character, rippling reflected light, magic streaming across skin, or dappled sunlight. (v1.6.0)

PREVIEW Caustics

Overview

This draws flowing caustics (focused light patterns) over the surface. The Procedural mode combines Voronoi and sine waves for a lightweight result; the Texture mode scroll-multiplies two texture samples. It renders in ForwardBase only and toggles with _CAUSTICS, with zero cost when off.

Choose the coordinate space (UV / Object / World / Triplanar-lite) and the composite mode (EmissionAdd / BaseMultiply / LitOnly / ShadowOnly). On Quest (_QUEST_LITE) it automatically switches to a lightweight pattern.

What you can make

  • An underwater character; rippling light reflected off water
  • Magic flowing across skin and clothing; light moving inside a crystal
  • Colored light through stained glass; dappled sunlight through leaves
  • Shimmer from fire or aurora; projected stage lighting

Key parameters

Pattern Mode _CausticsPatternMode enum

Procedural (lightweight, no texture) or Texture (scroll-multiplies two samples of _CausticsTex).

Default: Procedural

Composite _CausticsComposite enum

How the pattern is combined. EmissionAdd (additive glow) / BaseMultiply (lit-area boost) / LitOnly (lit faces only) / ShadowOnly (shadowed faces only).

Default: EmissionAdd

EmissionAdd for an underwater feel; LitOnly for magic flowing across skin.
Space _CausticsSpace enum

The coordinate space for the pattern: UV / Object / World / TriplanarLite (major-axis plane). World keeps the light fixed in space as the character moves.

Default: World

Scale / Speed _CausticsScale / _CausticsSpeed range + float

The pattern size (Scale) and flow speed (Speed). Set the flow direction with _CausticsDirection and warping with _CausticsDistortion.

Default: Scale 4 / Speed 0.5

Usage Tips

  • Quest-ready: under Quest Lite Mode (_QUEST_LITE) it skips the heavy 3×3 cell scan and switches to a lightweight pattern automatically.
  • Make it glow: in EmissionAdd, push _CausticsColor above 1 in HDR to bloom.
  • Hologram card: combine with Lenticular, Iridescence, and Shaped Highlight so the artwork changes with angle while rainbow and light patterns run across the surface.
  • Mask: control the affected area with the R channel of _CausticsMask.
