Smear Effect

Motion smear and afterimage trail effect

Overview

The Smear effect creates motion blur/smear trails for dynamic movement expressions. It supports manual direction control and automatic motion detection, making it ideal for anime-style speed effects and dance animations.

Controlled by the keyword _SMEAR. No shader instructions are generated when disabled.

Stretch Settings

Smear Stretch _SmearStretch range

Controls the stretch amount of the smear effect. Higher values produce more pronounced stretching.

Default: 0

Range: 0 - 3

Start with low values (0.3-0.5) for subtle motion hints. Values above 1.5 create dramatic anime-style speed streaks.
Smear Direction _SmearDirection vector

Manually sets the smear direction vector. Used when you want precise control over the smear orientation.

Default: (0, 0, 0, 0)

For horizontal motion, use (1, 0, 0, 0). For vertical, use (0, 1, 0, 0). Animate this via VRChat parameters for directional control.

Noise Settings

Noise Scale _SmearNoiseScale range

Controls the scale of the noise pattern applied to the smear. Adds variation and organic quality to the effect.

Default: 1

Range: 0 - 5

Noise Strength _SmearNoiseStrength range

Sets the distortion strength of the noise applied to the smear trail.

Default: 0.3

Range: 0 - 1

Motion Detection

Auto Magnitude _SmearAutoMagnitude toggle

Enables automatic motion detection. When active, the smear reacts automatically to object movement.

Default: 0 (Off)

Enable this for VRChat dance animations to get automatic motion-reactive smear without manual animation setup.
Motion Sensitivity _SmearMotionSensitivity range

Adjusts the sensitivity of automatic motion detection. Higher values make the effect respond to smaller movements.

Default: 1

Range: 0.1 - 10

VAT Velocity _SmearVATVelocity toggle

Uses Vertex Animation Texture (VAT) velocity data as the smear source. Enable when using VAT-based animations.

Default: 0 (Off)

Trail Settings

Trail Length _SmearTrailLength range

Sets the length of the afterimage trail behind the smear.

Default: 0.1

Range: 0 - 0.5

Trail Fade _SmearTrailFade range

Controls the fade-out speed of the trail. Higher values make the trail disappear more quickly.

Default: 0.5

Range: 0 - 1

Glow & Emission

Glow Color _SmearGlowColor color

Sets the color of the glow applied to the smear trail.

Default: (1, 1, 1, 1) (white)

Glow Intensity _SmearGlowIntensity range

Controls the intensity of the glow effect on the smear.

Default: 1

Range: 0 - 3

Glow Power _SmearGlowPower range

Controls the falloff power of the glow. Higher values concentrate the glow more tightly.

Default: 3

Range: 0.5 - 10

Emission _SmearEmission range

Sets the emission strength of the smear effect. Creates a self-illuminated appearance.

Default: 0

Range: 0 - 3

Emission Color _SmearEmissionColor color

Sets the emission color of the smear trail.

Default: (1, 0.5, 0, 1) (orange)

Orange creates a flame-like trail, blue produces an energy/magic effect, and white gives a clean speed-line look.

Mask

Smear Mask _SmearMask texture

A mask texture that controls the display area of the smear effect.

Default: "white" (full display)

White = smear visible, Black = smear hidden. Use to restrict smear to specific limbs or areas.

Blend & Blur

Blend Mode _SmearBlendMode enum

Selects the blend method for the smear effect.

  • Normal (0) - Standard blending
  • Soft (1) - Soft blending. Prevents over-brightening
  • Screen (2) - Screen blending. Natural brightness addition
  • Overlay (3) - Overlay blending. Enhances contrast

Default: Normal (0)

Blend _SmearBlend range

Controls the intensity (opacity) of the smear effect.

Default: 1

Range: 0 - 1

Blur _SmearBlur range

Adjusts the blur amount of the smear effect.

Default: 0

Range: 0 - 1

Distance Fade _SmearDistFade range

Fades the smear effect based on camera distance. Higher values cause the effect to fade out at closer distances.

Default: 0

Range: 0 - 1

Use distance fade for VRChat optimization to reduce visual noise when the avatar is far from the camera.
