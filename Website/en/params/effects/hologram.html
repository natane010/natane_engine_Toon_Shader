Hologram

Sci-fi style hologram effect

An effect that recreates cyberpunk and sci-fi holographic projections. Combine scanlines, edge glow, flicker, and noise distortion to create realistic hologram expressions.

Keyword: _HOLOGRAM

Hologram Basic Settings

Hologram Color _HologramColor color

Sets the overall color of the hologram effect. Affects all hologram elements including scanlines and edge glow.

Default: (0, 1, 1, 1) (cyan)

Sci-fi cyan or green is recommended, but you can freely change it to match your character.
Monochrome _HologramMonochrome range

Unifies the original texture color to the hologram color. Increasing the value causes the texture's color to be lost, creating a monochrome expression in the hologram color.

Default: 0 (Range: 0 - 1)

Setting to 1.0 creates a fully monochrome hologram, enhancing the sci-fi atmosphere.

Scanlines

Scanline Speed _HologramScanlineSpeed float

Sets the speed at which scanlines move vertically. A 3-layer scanline effect animates.

Default: 1

Scanline Intensity _HologramScanlineIntensity range

Sets the contrast of scanline light and dark. Higher values make the scanlines more clearly visible.

Default: 0.5 (Range: 0 - 1)

Scanline Density _HologramScanlineDensity float

Sets the number (density) of scanlines. Higher values display finer, more densely packed scanlines.

Default: 100

Values around 50-200 are typical. Very large values may cause moire patterns.
Scanline Width _HologramScanlineWidth range

Sets the thickness of each scanline. Higher values produce thicker scanlines.

Default: 0.5 (Range: 0 - 1)

Edge Glow (Fresnel)

Edge Glow Range _HologramEdgeGlowPower range

Sets the range of the Fresnel-based edge glow effect. Lower values spread the glow wider, while higher values concentrate it on edges only.

Default: 3 (Range: 0.1 - 10)

Edge Glow Intensity _HologramEdgeGlowIntensity range

Sets the brightness of the edge glow. Higher values make the edges glow more intensely.

Default: 1 (Range: 0 - 5)

Transparency & Flicker

Hologram Alpha _HologramAlpha range

Automatically controls the overall transparency of the hologram linked to Fresnel. Increasing the value makes the hologram semi-transparent.

Default: 0 (Range: 0 - 1)

Combining with the Transparent variant achieves more realistic holographic projections.
Flicker Speed _HologramFlickerSpeed float

Sets the speed at which the hologram flickers.

Default: 5

Flicker Amount _HologramFlickerAmount range

Sets the amplitude of the flicker. Higher values produce more intense flickering.

Default: 0.3 (Range: 0 - 1)

Noise Distortion

Noise Intensity _HologramNoiseIntensity range

Sets the strength of noise distortion applied to the hologram.

Default: 0 (Range: 0 - 1)

Noise Speed _HologramNoiseSpeed float

Sets the animation speed of the noise distortion.

Default: 1

Mask & Texture

Hologram Mask _HologramMask texture

Controls the application area of the hologram effect with a texture. Enabled by the keyword _HOLOGRAM_MASK.

Default: "white" (apply to all)

White = hologram applied, Black = hologram hidden. You can control the presence of hologram per body part.
Noise Texture _HologramNoiseTex texture

Uses a custom noise texture to control the hologram distortion pattern. Enabled by the keyword _HOLOGRAM_NOISE.

Default: "white"

Blend Settings

Blend Mode _HologramBlendMode enum

Selects how the hologram effect is composited with the base color.

  • Normal (0) - Normal blending
  • Soft (1) - Soft light
  • Screen (2) - Screen (brighten)
  • Overlay (3) - Overlay

Default: 0 (Normal)

Blend _HologramBlend range

Sets the overall application amount of the hologram effect. 0 disables it, 1 applies fully.

Default: 1 (Range: 0 - 1)

Blur _HologramBlur range

Blurs the boundaries of the hologram effect. Higher values produce softer compositing.

Default: 0 (Range: 0 - 1)
