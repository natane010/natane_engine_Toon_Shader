Fake Reflection

Cubemap-free fake environment reflection

Overview

Fake Environment Reflection simulates environment reflections without requiring a cubemap texture. It reflects the view direction around the surface normal and interpolates between sky and ground colors based on the Y component of the reflection vector. A Fresnel effect makes reflections stronger at grazing angles, enabling metallic luster and water-surface-like appearances.

Controlled by keyword _FAKE_REFLECTION. When disabled, no shader instructions are generated. Applied only in the ForwardBase pass.

Parameters

Enable Fake Reflection _FakeReflection toggle

Enables or disables the fake environment reflection.

Default: 0 (Disabled)

Sky Color _FakeReflSkyColor color

The color used for the upper (sky) portion of the reflection. This color is applied when the reflection vector points upward.

Default: (0.5, 0.7, 1.0, 1) Light blue

Ground Color _FakeReflGroundColor color

The color used for the lower (ground) portion of the reflection. This color is applied when the reflection vector points downward.

Default: (0.3, 0.25, 0.2, 1) Warm brown

Intensity _FakeReflIntensity range

Controls the overall brightness of the reflection effect. Higher values make the reflection brighter and more prominent.

Default: 1.0

Range: 0 - 3

Fresnel Power _FakeReflFresnelPower range

Controls the sharpness of the Fresnel effect. Higher values cause the reflection to appear only at grazing angles (near edges), while the reflection is barely visible from the front. Lower values show reflection more uniformly across the surface.

Default: 3.0

Range: 0.1 - 10

Use 1.0-2.0 for metallic reflections, 3.0-5.0 for glass or water-like surfaces.
Smoothness _FakeReflSmoothness range

Controls the sharpness of the gradient between sky and ground colors. Higher values create a sharper boundary between sky and ground, while lower values produce a smoother blend. Internally, this value is multiplied by 5 and applied to the Y component of the reflection vector.

Default: 0.5

Range: 0 - 1

Blend Settings

Blend _FakeReflBlend range

Sets the overall application amount of the fake reflection. When Distance Fade is enabled, this value is automatically attenuated based on distance.

Default: 1

Range: 0 - 1

Blend Mode _FakeReflBlendMode enum

Selects how the reflection effect is composited with the base color.

  • Add (0) - Additive blending. Adds the reflection color on top.
  • Multiply (1) - Multiply blending
  • Screen (2) - Screen blending
  • Overlay (3) - Overlay blending

Default: 0 (Add)

Usage Tips

Difference from Cubemap Reflection

Standard cubemap reflection (the Reflection feature) requires a cubemap texture and provides more realistic environment reflections. Fake Reflection achieves a sense of reflectivity without any textures, making it ideal for lightweight VRChat Quest avatars.

Recommended Combinations

  • Gems / Minerals: Sky color as cyan, ground color as purple, Fresnel 2.0, Intensity 1.5
  • Metal Armor: Sky color as white, ground color as gray, Fresnel 1.5, Intensity 1.0
  • Water / Ice: Sky color as light blue, ground color as dark blue, Fresnel 4.0, Intensity 0.8

Performance

No texture sampling is required -- only vector arithmetic is used, so the performance cost is very low.
