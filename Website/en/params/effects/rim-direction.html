Rim Light Direction Control

Restrict rim light direction for enhanced staging effects

Overview

Rim Light Direction Control is a feature that restricts rim light, which normally applies evenly to all edges, to a specific direction. By specifying a direction such as light from above or from the side, you can achieve more realistic and dramatic rim light expressions.

Controlled by the keyword _RIM_DIRECTION_CONTROL. This setting applies commonly to both Rim Light 1 and Rim Light 2.

Scope of This Setting

When Rim Light Direction Control is enabled, the same directional restriction is applied to both Rim Light 1 and Rim Light 2. Individual direction control is not available.

Parameters

Rim Light Direction _RimLightDirection vector

Specifies the direction to apply rim light as a world-space vector. Rim light is only applied to normals facing the specified direction.

Default: (0, 1, 0, 0) (upward)

The vector is automatically normalized. (0,1,0) = from above, (1,0,0) = from the right, (0,0,1) = from the front.
Direction Range _RimDirectionRange range

Controls the looseness of the directional restriction. Higher values apply rim light to areas further from the specified direction, while lower values strictly limit it to areas aligned with the direction.

Default: 0.5

Range: 0 - 1

Values close to 0 produce rim in a very narrow range only. Around 0.5 is a well-balanced setting.

Direction Presets

Use Tools > Natane > Effects > Rim Light Direction Visualizer to visually adjust the direction. The following preset directions can be set with one click:

  • Top: (0, 1, 0) - Rim from above. Ideal for backlight staging
  • Bottom: (0, -1, 0) - Rim from below. For eerie staging
  • Left: (-1, 0, 0) - Rim from the left
  • Right: (1, 0, 0) - Rim from the right
  • Front: (0, 0, 1) - Rim from the front
  • Back: (0, 0, -1) - Rim from behind

Fine angle adjustments are also possible using the Azimuth and Elevation sliders.
