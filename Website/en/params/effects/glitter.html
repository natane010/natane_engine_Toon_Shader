Glitter

Sparkling glitter highlight effect

Overview

Glitter is an effect that adds sparkling highlight effects. Use it to add glamour to costumes and accessories. Noise-based animation achieves realistic sparkling expressions.

Controlled by the keyword _GLITTER. No shader instructions are generated when disabled.

Parameters

Glitter Color _GlitterColor color

Sets the color of the glitter sparkle. Alpha channel is also available.

Default: (1, 1, 1, 1) (white)

For gold glitter, use (1, 0.85, 0.5). For rainbow effects, combining with emission is also effective.
Glitter Size _GlitterSize range

Controls the particle size of the glitter. Larger values produce larger particles.

Default: 0.1

Range: 0 - 1

Glitter Density _GlitterDensity range

Controls the frequency of glitter appearance. Higher values display more glitter.

Default: 0.5

Range: 0 - 1

0 = sparse, 1 = dense. High density (0.7-1.0) suits gem-like effects, while low density (0.2-0.4) works for subtle sparkle.
Glitter Speed _GlitterSpeed float

Controls the blinking speed of the glitter. Higher values produce faster blinking.

Default: 1

Setting to 0 stops the animation, creating static glitter.
Glitter Intensity _GlitterIntensity range

Controls the brightness of the glitter. Values exceeding 1.0 produce HDR-like strong sparkle effects.

Default: 1

Range: 0 - 2

Mask

Glitter Mask _GlitterMask texture

A mask texture that controls the display area of the glitter. Enabled by the keyword _GLITTER_MASK. Uses the R (red) channel to control the glitter display area.

Default: "white" (full display)

White (1.0) = fully visible, Black (0.0) = hidden, Gray = partially visible. Use to apply glitter only to decorative parts of accessories or clothing.

Blend & Blur

Blend Mode _GlitterBlendMode enum

Selects the blend method for the glitter effect.

  • Normal (0) - Standard additive blending
  • Soft (1) - Soft additive. Prevents over-brightening
  • Screen (2) - Screen blending. Natural brightness addition
  • Overlay (3) - Overlay blending. Enhances contrast

Default: Normal (0)

Blend _GlitterBlend range

Controls the intensity (opacity) of the glitter effect.

Default: 1

Range: 0 - 1

Blur _GlitterBlur range

Adjusts the blur amount of the glitter effect.

Default: 0

Range: 0 - 1

Usage Tips

Adding Glamour to Costumes and Accessories

  • Size: Glitter particle size
  • Density: Glitter appearance frequency (0=sparse, 1=dense)
  • Speed: Glitter blinking speed
  • Intensity: Glitter brightness

It is recommended to use mask textures to apply glitter only to specific decorative parts, like gems or sequins.
