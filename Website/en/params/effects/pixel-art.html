Pixel Art

Make a 3D model look like pixel art. Snap textures to a pixel grid and quantize lighting and color for a retro-game or PS1-era look. (v1.6.0)

PREVIEW Pixel Art

Overview

This implements UV pixelation, lighting/color quantization, a palette LUT, and dithering. Where Color Quantize reduces only the number of colors, this also lowers the spatial resolution. It toggles with _PIXEL_ART and is zero cost when off.

Mirror-safe by design: Screen Pixelation and Object-Stable Pixelation are intentionally omitted. Screen-space snapping is unsafe in VR (pixel seams appear between the two eyes) and object-stable reprojection is costly. This feature provides a mirror-safe subset in texture space and color space.

What you can make

  • Pixel-art versions of 3D characters; PS1 / retro-3D looks
  • 2D-game sprite style; voxel-game style
  • Low-resolution horror; a "digitize just one area" effect
  • Pixel-collapse on damage; switching between real and virtual space

Key parameters

Virtual Resolution _PixelArtSize range (4–512)

The virtual resolution the UVs snap to. Lower gives coarser (bigger) pixels and a stronger retro feel.

Default: 64

Around 32–64 for an 8-bit console feel; near 128 for finer pixels.
Quantization Steps _PixelLightSteps range (2–32)

How many steps lighting/color is rounded to. Fewer steps read as flat-filled pixel art.

Default: 6

Palette LUT _PixelPalette / _PixelPaletteTex toggle + 2D

When on, it samples a horizontal palette LUT (_PixelPaletteTex) by luminance to restrict the colors used — a Game Boy-style limited palette, for example.

Default: off

Palette replacement happens in ForwardBase only (additional passes must not recolor the base).
Dither _PixelDither range (0–1)

Bayer dither amount. Added before quantization to ease banding even with few color steps.

Default: 0

Usage Tips

  • Where it applies: UV pixelation snaps only mainUV right after UV animation resolves; other UV-driven features keep native resolution. Color/light quantization posterizes after lighting.
  • Cohesive retro look: combine Perspective Flat, Color Quantize, dither, and a pixel outline to push a 3D model toward a low-res 2D sprite.
  • Mask: use the R channel of _PixelArtMask to digitize just one area.
