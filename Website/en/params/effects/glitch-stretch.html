Glitch Stretch

Block-based horizontal stretch glitch

Overview

Glitch Stretch (Stretch Glitch) recreates digital data corruption by horizontally stretching UV coordinates on a per-block basis. Unlike the standard Glitch (UV distortion + RGB split), this effect specializes in horizontal texture stretching. A mask texture can limit where the effect is applied, and since the UV is deformed before the main texture is sampled, the stretch affects the entire rendered surface.

Controlled by keyword _GLITCH_STRETCH. When disabled, no shader instructions are generated. Applied only in the ForwardBase pass.

Parameters

Enable Stretch Glitch _GlitchStretch toggle

Enables or disables the stretch glitch effect.

Default: 0 (Disabled)

Stretch Intensity _GlitchStretchIntensity range

Sets the strength of horizontal UV stretching. Higher values cause greater UV displacement. The mask value is multiplied into this, allowing partial intensity control via the mask. Internally, the stretch amount is scaled by a factor of 3.

Default: 0.5

Range: 0 - 5

0.1-0.5 produces subtle distortion, while 1.0 and above creates intense stretching.
Stretch Speed _GlitchStretchSpeed float

Sets the animation speed of the stretch effect. Affects the time-based pseudo-random seed; higher values change patterns faster. Internally, _Time.y is multiplied by this value, scaled by 10, and floored for quantization.

Default: 1

Block Size _GlitchStretchBlockSize range

Sets the height of each stretch block (band). The UV.y coordinate is divided by this value to create blocks, and each block receives a different stretch amount. Smaller values create thinner bands, while larger values produce wider blocks.

Default: 0.1

Range: 0.01 - 1

0.02-0.05 gives a scanline look, while 0.1-0.3 creates a block-collapse effect.
Stretch Frequency _GlitchStretchFrequency range

Sets how frequently the stretch occurs. Stretching is applied only when each block's random value exceeds this threshold. Additionally, a global trigger prevents the effect from firing unless a time-based random exceeds (1 - frequency).

Default: 0.3

Range: 0 - 1

0.1-0.3 for occasional glitches, 0.5+ for frequent, 0.9+ for nearly constant stretching.

Mask Settings

Stretch Glitch Mask _GlitchStretchMask texture

A mask texture that limits where the stretch is applied. The R channel is used. White (1.0) areas receive the stretch effect, while black (0.0) areas are unaffected. The mask value is multiplied into the stretch intensity.

Default: "white" (applied everywhere)

Mask Scale _GlitchStretchMaskScale range

Amplification factor for the mask value. The R channel of the mask texture is multiplied by this value and clamped via saturate. 1.0 is unity, 5.0 boosts the mask value by 5x. Useful for strengthening the effect of faint masks.

Default: 1

Range: 1 - 5

Usage Tips

Combining with Standard Glitch

Use alongside the standard Glitch (_GLITCH) to create a compound effect with UV distortion + RGB split + horizontal stretch. Glitch Stretch deforms the UV before the main texture is sampled, so it operates independently of the standard Glitch.

Recommended Use Cases

  • Cyberpunk aesthetics: Combine with Hologram and Glitch to express instability of a digital avatar
  • Transitions: Animate intensity over time for appear/disappear transition effects
  • VJ visuals: Adjust mask and block size for music-synchronized visual effects

Performance

Requires only one mask texture sample and UV computation, so the performance cost is low. Note that since UVs are deformed before the main texture sample, the effect has a broad impact on the final rendering.
