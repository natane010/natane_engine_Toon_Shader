Lenticular

The picture itself changes with the viewing angle. Make expressions shift left to right, a different face appear from the side, or angle-dependent effects like a hologram card. (v1.6.0)

PREVIEW Lenticular

Overview

Store several images in one atlas (horizontal strip or grid) and switch the displayed frame by viewing angle. Where Iridescence shifts color with angle, Lenticular swaps the artwork itself.

The angle is measured from the object-space view vector, so it stays stable regardless of VRChat mirrors or camera position. The chosen frame is mixed in right after makeup texture compositing (base color modification). It toggles with _LENTICULAR and is zero cost when off.

What you can make

  • Expressions that change left to right; a different face from the side
  • A logo that switches to text; card artwork that animates
  • Eyes that morph between Normal / Heart / Star
  • Scars, magic sigils, or glowing marks that appear at an angle — a hologram-card material

Modes (_LenticularMode)

ModeDescription
SmoothBlendBlends adjacent frames with frac + Softness
HardStepSnaps instantly with round
ScanBlendMixes adjacent frames via UV stripes (_LenticularScanScale)
FrontRevealReveals a different frame near the front (linked to Emission boost)
SideRevealReveals a different frame at an angle (linked to Emission boost)
FlipSwitches A/B by view side (cross-fades the center via Softness)

Key parameters

Atlas / Frame Count _LenticularAtlas / _LenticularFrames 2D + range

The atlas image holding multiple frames and how many it contains. _LenticularDirection selects Horizontal or Grid layout.

Default: Frames 4 / Direction Horizontal

View Axis / Angle Range _LenticularViewAxis / _LenticularAngleRange enum + range

Whether to switch on horizontal (X) or vertical (Y) head movement, and over how many degrees the full frame set is mapped.

Default: ViewAxis X / AngleRange 90

Stereo Mode _LenticularStereoMode enum

How the angle is computed in VR. StereoCenter (default) averages both eyes so they pick the same frame, preventing flicker.

Default: StereoCenter

Keep StereoCenter for VR and give _LenticularSoftness enough room for extra stability.

Usage Tips

  • VR anti-flicker: use StereoCenter (default) and give Softness enough room so the two eyes never land on different frames.
  • Building the atlas: Horizontal lays frames left to right; Grid uses ceil(√n) columns in row-major order.
  • Make it glow: in FrontReveal / SideReveal the revealed frame is boosted by _LenticularEmission.
  • Mask: control the affected area with the R channel of _LenticularMask.
