Ghost

Artifact-free translucent ghost look — Natane/Toon Shader (Ghost) variant (v1.6.0)

Overview

Ghost is a shader variant, Natane/Toon Shader (Ghost), dedicated to translucent "ghost" looks. It structurally avoids the self-overlap artifacts of ordinary transparent shaders: double-blend where body parts overlap in depth, and backfaces bleeding through.

It works via a depth prepass: the first pass writes depth only (ColorMask 0 + ZWrite On), and the forward passes render with ZTest Equal, so exactly one (the nearest) surface layer is shaded and blended per pixel. The prepass shares the same vertex path, so vertex deformations such as VAT, Smear, and Perspective Flat stay depth-consistent with the visible surface.

The look is a Fresnel-shaped alpha (transparent toward the center, opaque at the silhouette) plus an additive spectral rim glow. Overall opacity is controlled by the _Color alpha; the Fresnel alpha multiplies on top of it.

Parameters

Rim Color _GhostRimColor color (HDR)

Color added along the silhouette. HDR: values above 1 combine with Bloom for a strong glow.

Default: (0.4, 0.8, 1.2, 1)

Pale blue spectral colors are the classic ghost look; with world Bloom the rim glows ethereally.
Fresnel Alpha _GhostFresnelAlpha range

Center fade amount. 0 = no Fresnel alpha change, 1 = the center (surfaces facing the viewer) fades out fully.

Default: 0.7

This is the key to the "see-through inside, visible edges" spectral quality.
Fresnel Power _GhostFresnelPower float

Exponent of the Fresnel curve. Higher values leave only a thin visible edge.

Default: 2.5

Raise for a sharper, thinner edge; lower for a softer falloff.
Rim Strength _GhostRimStrength float

Intensity of the additive rim glow. 0 disables the glow.

Default: 1.0

This variant has no outline pass, so use the rim glow as the outline substitute.
Depth Cutoff _GhostDepthCutoff range

Minimum alpha rendered by the depth prepass. Texels below this alpha are excluded from depth so fully invisible regions do not occlude other transparents.

Default: 0.02

If thin-alpha areas like hair tips act as an "invisible wall", raise this value slightly.

Usage Tips

  • Fading feet: for "the lower body dissolves into air", combine with Height Fade in alpha mode along the Y axis; it stays consistent with the depth prepass.
  • Overall opacity: adjust via the _Color alpha. Even at high transparency the silhouette always reads as one clean glass-like layer.
  • No outline: the outline pass is intentionally removed for this single-layer variant.
  • No shadows: there is no ShadowCaster pass, avoiding opaque shadows from a translucent object.
  • Renders in the Transparent queue and declares VRCFallback = ToonTransparent.
