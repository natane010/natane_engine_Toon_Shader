FX Modulator

A controller that drives other features automatically from time, audio, distance, or view angle. Make Emission pulse like a heartbeat, "awaken" as the camera approaches, or flow contour lines to the bass. (v1.6.0)

PREVIEW FX Modulator

Overview

This feature draws no color or pattern itself. It is a control system that takes a value from a Source and multiplies or adds it to a Target parameter, so it "moves" other features. It has two slots (0 / 1) that you can combine.

Slot values are computed once at the top of the fragment shader and applied at each target site. It toggles with _FX_MODULATOR and is zero cost when off. AudioLink sources are active only when _AUDIOLINK is in use.

What you can make

  • Patterns that switch to music; contour lines that rise with the bass
  • Emission that pulses like a heartbeat
  • "Awakening" as the camera approaches (CameraDistance)
  • Glitch that only triggers when viewed from the side (ViewAngle)

Usage Tips

  • Start with one slot: pick a Source, choose a Target, and raise Amount from 0. Nothing happens while Amount is 0 (neutral).
  • React to music: AudioLink sources need AudioLink (_AUDIOLINK). In unsupported worlds they read neutral, so nothing breaks.
  • Shape the output: adjust the output range with Min/Max, the response with Curve, and flip it with Invert.
  • Mask: the R channel of _FXModMaskTex maps to slot 0 and the G channel to slot 1.
