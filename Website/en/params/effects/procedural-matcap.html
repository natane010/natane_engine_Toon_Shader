Procedural MatCap

Texture-free mathematical MatCap lighting

Overview

Procedural MatCap generates MatCap-style lighting using only mathematical calculations, without requiring a MatCap texture. It computes MatCap UVs from view-space normals, then combines a spherical gradient based on distance from center with a Fresnel rim effect to produce metallic luster and glossy appearances without any textures.

Controlled by keyword _PROCEDURAL_MATCAP. When disabled, no shader instructions are generated. Applied only in the ForwardBase pass.

Parameters

Enable Procedural MatCap _ProceduralMatCap toggle

Enables or disables the procedural MatCap effect.

Default: 0 (Disabled)

MatCap Color _ProcMatCapColor color

The color of the procedural MatCap. This color is applied to both the spherical gradient and Fresnel effect.

Default: (0.8, 0.85, 1.0, 1) Light bluish white

Power _ProcMatCapPower range

Controls the falloff curve of the spherical gradient. The normalized distance from center in MatCap UV space is raised to this power. Higher values concentrate the gradient toward the center, creating a sharper highlight. Lower values produce a gentler gradient.

Default: 2.0

Range: 0.5 - 10

1.0-2.0 gives a soft highlight, 4.0 and above creates a sharp spotlight effect.
Intensity _ProcMatCapIntensity range

Controls the overall brightness of the procedural MatCap. The combined gradient and Fresnel value is multiplied by this. It also indirectly affects the SafeAdditiveBlend saturation prevention parameter (at 0.5x of intensity).

Default: 1.0

Range: 0 - 3

Fresnel Power _ProcMatCapFresnelPower range

Controls the sharpness of the Fresnel rim effect. (1 - NdotV) is raised to this power to adjust rim light width. Higher values narrow the rim light to the edges, while lower values spread it wider.

Default: 3.0

Range: 0.1 - 10

Blend Settings

Blend _ProcMatCapBlend range

Sets the overall application amount of the procedural MatCap. When Distance Fade is enabled, this value is automatically attenuated based on distance.

Default: 1

Range: 0 - 1

Blend Mode _ProcMatCapBlendMode enum

Selects how the procedural MatCap is composited with the base color.

  • Add (0) - Additive blending
  • Multiply (1) - Multiply blending
  • Screen (2) - Screen blending
  • Overlay (3) - Overlay blending

Default: 0 (Add)

Usage Tips

Difference from Texture-Based MatCap

Standard MatCap uses MatCap textures for rich lighting reproduction but requires texture preparation. Procedural MatCap requires no textures and adds lightweight glossy effects using only parameters. Ideal for adding simple metallic or glossy appearances.

Recommended Settings

  • Metallic gloss: Color (1.0, 1.0, 1.0), Power 2.0, Fresnel 2.0, Intensity 1.0
  • Cool blue sheen: Color (0.6, 0.7, 1.0), Power 3.0, Fresnel 4.0, Intensity 1.5
  • Soft spherical light: Color (1.0, 0.95, 0.9), Power 1.0, Fresnel 1.0, Intensity 0.5

Combining with Texture MatCap

Can be used simultaneously with texture-based MatCaps (up to 3 textures). Procedural MatCap is processed after the texture-based MatCaps, so it functions as an additional gloss layer.

Performance

No texture sampling is required -- only vector arithmetic is used, so the performance cost is very low. Ideal for lightweight optimization targeting VRChat Quest.
