Topographic / Slice Lines

Run evenly spaced lines or bands across the surface. Draw periodic lines like map contours, sci-fi scan lines rising up the body, or 3D-printer layer lines. (v1.6.0)

PREVIEW Topographic

Overview

This slices space at even intervals and overlays contour / slice bands in an Emission-capable color. Where Height Fade makes a single boundary, this generates repeating lines and bands. It needs no texture and pairs well with AudioLink and the FX Modulator.

It runs in ForwardBase only (pure additive color, so it does not affect additional lights) and toggles with _TOPOGRAPHIC, with zero cost when off. Choose the coordinate space (Object/World/View) and axis (X/Y/Z/Custom).

What you can make

  • Map contour lines, rock strata, and wood grain
  • Sci-fi scan lines and energy rising up the body
  • 3D-printer layer lines and hologram slices
  • Rings of light rising from a magic circle, top-to-bottom scan effects

Key parameters

Mode _TopoMode enum (0–5)

How the lines are drawn: Lines (thin) / Bands (thick) / GradientBands (stepped color) / DoubleLines / PulseRings (moving rings) / NoiseDistorted (noise-warped lines).

Default: 0 (Lines)

Space / Axis _TopoSpace / _TopoAxis enum

The coordinate space (Object / World / View) and axis (X / Y / Z / Custom). World + Y stacks the lines along "height" regardless of where the character stands.

Default: Space=World / Axis=Y

World + Y for scan lines rising up the body; Object space for stripes glued to the mesh.
Spacing / Line Width _TopoSpacing / _TopoLineWidth range

The gap between lines (Spacing) and the thickness of each line (LineWidth).

Default: Spacing 0.1 / LineWidth 0.1

Scroll Speed _TopoSpeed float

How fast the lines flow. 0 is static; higher values scroll the lines along the axis. Use _TopoOffset to shift their position.

Default: 0

Modulate TopographicOffset with the FX Modulator to move the lines to music or time.

Usage Tips

  • Make it glow: push _TopoColor above 1 in HDR and raise _TopoEmission so the lines bloom. It is added right after the Emission stage.
  • Cyber scan: combine with Glitch and X-Ray so scan lines rise up the body while wall-hidden parts read as analyzed.
  • Mask: control the affected area with the R channel of _TopoMask.
  • It renders in ForwardBase only, so additional lights (ForwardAdd) never double the line intensity.
