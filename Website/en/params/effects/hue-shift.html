Hue Shift

Real-time hue variation color effect

An effect that changes the hue of the entire material in real time. Ideal for color-changing effects in VRChat. By controlling the parameter from an Animator Controller, you can switch the color of costumes and accessories in real time.

Keyword: _HUE_SHIFT

Hue Shift Settings

Hue Shift _HueShift range

Changes the hue of the entire material. The color rotates along the hue wheel.

  • 0 = No change (original color)
  • 0.25 = 90 degree rotation
  • 0.5 = Complementary color (180 degree rotation)
  • 0.75 = 270 degree rotation
  • 1 = Full rotation (returns to original color)

Default: 0 (Range: 0 - 1)

Ideal for linking with VRChat's Expression Menu to change costume colors in real time during play.
Blend _HueShiftBlend range

Sets the overall application amount of the hue shift effect. 0 keeps the original color, 1 fully applies the hue shift.

Default: 1 (Range: 0 - 1)

Blur _HueShiftBlur range

Blurs the boundaries of the hue shift.

Default: 0 (Range: 0 - 1)
