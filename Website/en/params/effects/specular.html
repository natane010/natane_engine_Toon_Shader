Specular

Control highlight reflections from light sources

Overview

Specular is an effect that renders direct highlight reflections from light sources. It draws metallic luster and mirror-like reflections such as angel rings on hair in a toon style.

Controlled by the keyword _SPECULAR. No shader instructions are generated when disabled.

Parameters

Specular Color _SpecularColor color

Sets the color of the specular highlight. Alpha channel is also available.

Default: (1, 1, 1, 1) (white)

White tones close to the light source color produce natural results. Colored specular can create gem-like or metallic expressions.
Specular Size _SpecularSize range

Adjusts the size of the specular highlight. Larger values spread the highlight over a wider area.

Default: 0.1

Range: 0 - 1

Small values (0.05-0.15) produce sharp metallic luster, while larger values (0.3-0.5) create soft plastic-like luster.
Specular Softness _SpecularSoftness range

Controls the edge softness of the specular highlight. Lower values produce sharper edges, while higher values create smoother gradients.

Default: 0.05

Range: 0.001 - 1

Sharp edges (0.01-0.1) are common in toon style. For a more realistic look, try values of 0.3 or higher.

Mask

Specular Mask _SpecularMask texture

A mask texture that controls the display area of the specular. Enabled by the keyword _SPECULAR_MASK.

Default: "white" (full display)

White = specular visible, Black = specular hidden. Useful for applying specular to skin while suppressing it on clothing.

Blend & Blur

Blend Mode _SpecularBlendMode enum

Selects the blend method for the specular effect.

  • Normal (0) - Standard additive blending
  • Soft (1) - Soft additive. Prevents over-brightening
  • Screen (2) - Screen blending. Natural brightness addition
  • Overlay (3) - Overlay blending. Enhances contrast

Default: Normal (0)

Blend _SpecularBlend range

Controls the intensity (opacity) of the specular effect.

Default: 1

Range: 0 - 1

Blur _SpecularBlur range

Adjusts the blur amount of the specular effect. Softens edges for a more natural appearance.

Default: 0

Range: 0 - 1
