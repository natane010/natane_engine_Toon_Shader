Kuwahara Filter

Screen-space filter for painterly, oil-painting-style rendering

Overview

The Kuwahara filter is a non-linear image processing filter that produces a painterly, oil-painting look. It divides the area around each pixel into four quadrants, calculates the mean color and variance for each, and selects the mean color of the quadrant with the lowest variance (the most uniform region). This preserves edges while creating smooth, painting-like surfaces.

Controlled by the keyword _KUWAHARA_FILTER. No shader instructions are generated when disabled.

This is a screen-space effect that requires GrabPass. Not available in Lite variants.

Parameters

Radius _KuwaharaRadius range

The kernel radius of the filter. Each quadrant samples this many pixels in each direction. Larger values produce a stronger oil-painting effect but at a higher performance cost (sample count scales with the square of the radius).

  • 1-2 - Subtle smoothing effect
  • 3-4 - Moderate oil-painting effect (recommended)
  • 5-6 - Strong oil-painting effect (heavy processing)

Default: 3

Range: 1 - 6

For VRChat environments, low values of 2-3 are recommended. A radius of 6 results in 144 texture samples per pixel.
Blend _KuwaharaBlend range

Controls the blend ratio between the filtered result and the original image. 0 keeps the original image, 1 applies the filter fully.

Default: 1

Range: 0 - 1

A value of 0.5-0.7 gives a well-balanced setting that maintains the painterly texture while preserving some detail.

Usage Tips

Oil Painting Style Illustration

Combine with Color Quantize for a more painterly result. The Kuwahara filter smooths out details while Color Quantize limits the color palette, together producing an impressionist oil-painting style.

Anime-Style Backgrounds

Use a small radius (around 2) with a blend of 0.3-0.5 to create a soft, hand-painted texture similar to anime background art.

Performance Notes

The Kuwahara filter heavily samples the GrabPass texture in nested loops, making it relatively GPU-intensive. With a radius of 3, it performs 4 quadrants x 9 samples = 36 texture fetches per pixel. Use with caution in VRChat Quest environments.

Combining with Other Screen-Space Effects

This effect can be used alongside Soft Filter, Color Bleeding, and Chromatic Aberration, all of which share the same GrabPass. Be aware of the processing order: the Kuwahara filter is applied after Soft Filter and before Screen Edge detection.
