Eye Setup Tool

Non-destructive eye material separation and UV relayout (v1.6.0)

Menu: Tools > Natane > Mesh > Eye Setup Tool Category: Mesh

Overview

The Eye Setup Tool separates eye polygons into their own material slot (material separation) and remaps the eye UVs to fill the texture (UV relayout). The separated eyes can directly use the dedicated "Natane/Eye" shader (parallax, pupil size, eye states, etc.).

Meshes are always saved as new assets; the imported FBX mesh is never modified. All renderer and material changes are undoable.

Access

Menu: Tools > Natane > Mesh > Eye Setup Tool

Features

  • Three eye selection methods
    • Existing Material Slot — when the eyes already have their own slot; the mesh is untouched and a new "Natane/Eye" material is assigned to that slot
    • UV Rect — drag a rectangle on the UV preview (or type min/max values); triangles whose UV centroid is inside are selected
    • Mask Texture — provide a mask (white = eye); triangles whose UV-centroid luminance exceeds the threshold are selected
  • Three UV layouts
    • Single block — scale the whole submesh's UVs into the target rect
    • Overlap left/right — detect the left/right eye islands and overlap them (both eyes share one texture region — the common VRChat pattern), with optional horizontal mirroring of one eye
    • Side by side — place the left and right eyes next to each other
  • UV preview — inspect the selection (green) and before (gray) / after (green) states
  • Non-destructive workflow — new meshes are saved as .asset files; imported meshes are duplicated automatically before writing
  • Material inheritance — the new "Natane/Eye" material inherits the main texture and base color from the source material
  • Target UV channel — write to uv0 or uv1; target rect and padding are configurable

Usage

  1. Set the target SkinnedMeshRenderer / MeshRenderer at the top of the window ("From Selection" picks it from the Hierarchy selection)
  2. In the "1. Material Separation" tab, choose how eye geometry is identified (existing slot / UV rect / mask)
  3. Check the selection (green) in the preview and review the summary of changes
  4. Press "Apply Material Separation" and choose where to save the new mesh asset (the selected triangles become a new last submesh with a new "Natane/Eye" material)
  5. In the "2. UV Relayout" tab, pick the target submesh (the eye submesh is preselected right after separation)
  6. Set the layout, target rect, padding, and UV channel
  7. Check before/after in the preview and press "Apply UV Relayout"

Tips

  • UV rect / mask selection requires uv0
  • Left/right grouping uses mesh-space X (the sides of the face), so it also works when the eye UVs already overlap
  • A warning is shown when vertices are shared with other submeshes (their UVs move as well)
  • "Overlap left/right" fits the common VRChat setup where both eyes share one texture region
  • After separation, eye-specific features such as Eye Parallax of the "Natane/Eye" shader work out of the box
