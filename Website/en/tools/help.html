Help

Comprehensive guide to documentation and guides

Menu: Tools > Natane > Help Category: General

Overview

The Help tool is a comprehensive help window that provides access to Natane Toon Shader's documentation, guides, and tutorials. You can reference detailed descriptions and usage instructions for each feature directly within the editor, allowing you to quickly find information while working.

Key Features

  • Detailed documentation for each shader feature
  • Access to the Quick Start guide
  • Usage reference for each tool
  • Frequently Asked Questions (FAQ)
  • Troubleshooting guide
  • Version information and changelog

How to Use

  1. Open Tools > Natane > Help from the Unity menu
  2. Select the topic you want to learn about from the category list on the left
  3. Detailed documentation is displayed in the right pane
  4. You can also use the search bar for keyword searches

Tips

  • Each section in the material inspector also has a help toggle that displays brief explanations
  • It's efficient to review the help overview for a feature before configuring it for the first time
  • Links to the online documentation are also included
