VRC Light Volumes Helper

Support tool for easily configuring VRC Light Volumes integration

Menu: Tools > Natane > Shader > Light Volumes Helper Category: Shader

Overview

The VRC Light Volumes Helper is a support tool for configuring integration with VRChat's Light Volumes (voxel-based lighting system). VRC Light Volumes is an advanced lighting system available since VRChat v1.0.1 that stores world lighting information as voxel data, providing more accurate and beautiful lighting for avatars.

Natane Toon Shader supports VRC Light Volumes and can receive a world's voxel lighting data to reflect it in toon shading. However, several parameters need to be properly configured for quality and performance tuning. This tool makes those settings easy with quality presets.

In Light Volumes-enabled worlds, avatar appearance improves dramatically, but performance cost also increases. Using this tool's quality presets, you can easily find the right balance from high-quality PC settings to lightweight Quest settings.

Key Features

  • Quality Presets — Three-tier presets: Low / Medium / High. Set the balance between Light Volumes quality and performance with one click
  • Automatic Configuration — Automatically configures Light Volumes-related keywords and parameters on materials. No manual shader keyword management needed
  • Performance Optimization — Visually compare and adjust the trade-off between sampling accuracy and performance
  • Compatibility Check — Verify whether the current scene or world supports Light Volumes
  • Batch Application — Batch apply the same Light Volumes settings to all Natane Toon Shader materials in an avatar

How to Use

  1. Open the Tool

    Open the tool window from Tools > Natane > Shader > Light Volumes Helper.

  2. Select Materials

    Select the Natane Toon Shader materials to apply Light Volumes settings to. Selecting the avatar's root object auto-detects all materials underneath.

  3. Select Quality Preset

    Choose a quality level from Low / Medium / High. The estimated performance cost for each preset is displayed, so choose according to your target platform.

  4. Apply Settings

    Click "Apply" to reflect the Light Volumes settings on the selected materials. Undo is supported.

Tips

  • Enable Light Volumes for the best lighting quality in VRChat worlds. The lighting quality improvement is dramatic in supported worlds
  • Medium quality provides sufficient visual quality in most cases. Consider High for photography or showcases
  • In worlds that don't support Light Volumes, automatic fallback processing occurs, so there is no downside to keeping it enabled
  • Low quality is recommended for Quest avatars. Light Volumes sampling on mobile GPUs tends to be expensive
  • Testing in a Light Volumes-compatible world is the most reliable way to verify the effect. The full effect may be difficult to confirm in the editor
