Shadow Adjustment Wizard

Guided shadow parameter setup

Menu: Tools > Natane > Shadow Wizard Category: Effect

Overview

The Shadow Adjustment Wizard is a wizard-style tool that guides you through setting up shadow parameters — the core of toon shading — in a step-by-step process. Starting from presets and fine-tuning from there, even beginners can achieve beautiful shadow expressions.

Key Features

  • Guided step-by-step setup
  • Shadow style presets (Sharp Anime, Soft Toon, etc.)
  • Multi-step shadow configuration (1 to 3 shadow levels)
  • Real-time preview
  • Preview with adjustable light angle
  • Shadow map settings

How to Use

  1. Select the material to configure
  2. Choose a shadow style: Sharp Anime, Soft Toon, Realistic, etc.
  3. Adjust the base shadow color, offset, and sharpness
  4. Optionally add 2nd and 3rd shadow levels as needed
  5. Verify the result while changing the preview light angle

Shadow Style Presets

  • Sharp Anime - Crisp cel-shading. Ideal for anime characters
  • Soft Toon - Soft gradient blending. Best for character skin
  • Realistic - More realistic shadow representation
  • Flat - Minimal shadows. Suited for deformed characters
  • Custom - Freely configure all parameters

Tips

  • "Sharp Anime" is recommended for crisp cel-shading
  • Try "Soft Toon" for character skin
  • Adjust the preview light angle to test the appearance under various lighting conditions
  • Even just 2 shadow levels provide sufficient expressive power for multi-step shadows
