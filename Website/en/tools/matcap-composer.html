MatCap Composer

Blend multiple MatCap layers with blend modes

Menu: Tools > Natane > MatCap Composer Category: Effect

Overview

The MatCap Composer is a visual tool that lets you stack up to 3 MatCap (Material Capture) layers and blend them using different blend modes. By combining different MatCap textures, you can create complex glossiness and surface qualities that cannot be achieved with a single MatCap alone.

Key Features

  • Up to 3 layers of MatCap compositing
  • Blend mode selection per layer
  • Individual intensity (opacity) adjustment
  • Real-time preview
  • Direct application to material

How to Use

  1. Select the target material and open the tool
  2. Drag and drop MatCap textures into each layer
  3. Select the blend mode for each layer (Additive, Multiply, Overlay, etc.)
  4. Adjust the effect amount of each layer with the intensity slider
  5. Check the result in the preview and apply to the material

Use Cases

  • Metallic Sheen - Add a highlight MatCap to a base MatCap in additive mode for complex metallic looks
  • Skin Texture - Overlay a Fresnel MatCap onto a soft MatCap for natural skin quality
  • Gemstones - Layer colorful MatCaps with multiply for deep, rich glossiness

Tips

  • Layer multiple MatCaps to create complex effects
  • Additive mode is the most common way to add glossy effects
  • Using all 3 layers increases processing load, so express effects with the minimum number of layers needed
  • MatCap 2/3 keywords are enabled, so check the performance impact
