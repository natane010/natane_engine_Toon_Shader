GPU Particle Mesh Generator

Generate quad-cloud meshes for the stateless GPU particle shader (v1.6.0)

Menu: Tools > Natane > Mesh > GPU Particle Mesh Category: Effect

Overview

The GPU Particle Mesh Generator creates and saves static "quad cloud" meshes for the Natane/Effects/GPU Particles (Stateless) shader. The GPU particles are fully stateless: no simulation, CustomRenderTexture, camera, GrabPass, or runtime scripts. All animation is computed as a pure function of _Time and per-particle random seeds baked into the mesh, so it is safe to put directly on VRChat avatars.

v1.6.0 also adds the equally stateless math-based liquid shader Natane/Effects/Fake Fluid (fake fluid: fill amount, wobble, foam, fresnel, toon shading). It is assigned directly to a container mesh and needs no generated mesh.

Access

Menu: Tools > Natane > Mesh > GPU Particle Mesh

Features

  • Particle count — default 256, up to 4096; one particle = one quad (4 vertices)
  • Spread — emission range (XYZ box)
  • Random seed — reproducible mesh generation
  • Base tint / variation — per-particle colors baked into vertex colors
  • .asset saving — saved into the project via SaveFilePanelInProject

Usage

  1. Open the tool and set the particle count, spread, seed, and tint
  2. Generate the quad-cloud mesh and save it as a .asset
  3. Assign the mesh to an empty GameObject's MeshFilter and add a MeshRenderer
  4. Assign a material using Natane/Effects/GPU Particles (Stateless)
  5. Tune the motion mode (Rise / Fall / Orbit / Burst), size, speed, and fades

Technical Details

Motion Modes (_MotionMode)

  • 0: Rise — embers / fireflies; rising with sine sway
  • 1: Fall — cherry blossoms / snow; falling with lateral drift and billboard rotation
  • 2: Orbit — sparkles orbiting the object origin
  • 3: Burst — radiating from the center on a per-seed cycle

Mesh Convention

  • All 4 vertices share the same center position; corner offsets are reconstructed in the vertex shader from UV0 and _ParticleSize
  • UV0: quad corner (each component 0 or 1); doubles as sprite UV
  • UV1.x: particle random seed [0,1) / UV1.y: normalized particle index [0,1]
  • Vertex color: per-particle tint

Tips

  • Particle position is the pure function _Time.y * _Speed + seed * _CyclePeriod, looping seamlessly via frac()
  • AudioLink modulation is supported for music-reactive effects at club events
  • Rendered with additive blending / ZWrite Off / Transparent queue / VRCFallback = Particle
  • For lightweight toon particles, the separate Natane/Toon Shader (Particle) variant is also available (blend mode switching, soft particles, flipbook, camera fade)
