Makeup Layer Manager

Control makeup textures with visual layer management

Menu: Tools > Natane > Makeup Layer Manager Category: Material

Overview

The Makeup Layer Manager is an editor window for visually managing the texture layers used in Natane Toon Shader's makeup feature. It allows you to intuitively manipulate makeup layers such as blush, eye shadow, and lip in a Photoshop-like layer panel.

Key Features

  • Visual layer management interface
  • Opacity and blend mode control for each layer
  • Layer visibility toggling
  • Layer reordering (drag and drop)
  • Layer editing with preview
  • Layer color adjustments

How to Use

  1. Select the target material and open the tool
  2. Makeup layers (blush, eye shadow, lip, etc.) are displayed in a list
  3. Adjust the texture, color, and opacity of each layer
  4. Drag and drop to change the layer stacking order
  5. Check the results in the preview while making adjustments

Tips

  • Lowering layer opacity creates a more natural finish
  • Changing blend modes allows for different makeup textures and finishes
  • Try combining multiple layers to enrich character expression for VRChat avatars
  • Hide unnecessary layers to check the material's processing load
