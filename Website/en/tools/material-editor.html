Material Editor

Batch processing for multiple materials

Menu: Tools > Natane > Batch Material Processor Category: Material

Overview

The Batch Material Processor is a powerful batch processing tool that can execute parameter adjustments, color changes, texture replacements, feature toggles, and more across multiple materials at once. It significantly improves workflow efficiency for projects dealing with a large number of materials.

Key Features

  • Batch parameter adjustment (Set / Multiply / Add modes)
  • Batch color changes
  • Batch texture replacement
  • Batch shader feature toggling (ON/OFF)
  • Batch shader variant conversion (Opaque/Cutout/Transparent)

How to Use

  1. Add target materials from the material list
  2. Select an operation tab: Parameter / Color / Texture / Feature / Variant
  3. Set the values for the selected operation
  4. Click "Preview" to review changes before applying
  5. Click "Apply to All" to batch process all materials

Operation Modes

Parameter Adjustment

  • Set - Directly sets the specified value
  • Multiply - Multiplies the current value by a factor (useful for relative adjustments)
  • Add - Adds a value to the current value

Texture Replacement

  • Batch replace textures for specific property slots
  • Texture tiling and offset can also be set in batch

Tips

  • Use "Set" mode to apply exact values
  • Use "Multiply" for relative adjustments (e.g., scale all materials' outline width by 1.5x)
  • Always create a backup before batch operations (Undo is supported, but just in case)
  • Use the preview feature to prevent unintended changes
