Map Generator

Automatically generate texture maps from Albedo textures and mesh geometry

Menu: Tools > MapGenerator > Map Generator Window Category: Texture Generation

Overview

The Map Generator automatically creates Normal, AO, Curvature, Roughness, Shadow, and Control Maps from Albedo textures and mesh geometry. It uses GPU Compute Shaders for fast processing with full CPU fallback for unsupported environments. Generated maps are automatically assigned to NataneToon Shader properties.

Access

  • NataneToon Material Inspector: "Generate All Maps" button in the AO section, or individual map generation buttons
  • Component: Attach MapGenerator component → use Inspector controls
  • Menu: Tools > MapGenerator > Map Generator Window
  • Right-click: Context menu on Renderer / MeshFilter / SkinnedMeshRenderer components

Generated Maps

Normal Map

  • Generates a height map from mesh curvature and vertex positions, then converts to normals via Sobel filter
  • Blends Albedo texture detail on top (70% mesh + 30% Albedo)
  • Assigns to: _BumpMap + enables _NORMALMAP keyword
  • Parameters: Strength, Blur Radius

AO Map (Ambient Occlusion)

  • Raycasts in hemisphere directions using Fibonacci distribution from each vertex
  • Uses a temporary collider on Layer 31 to avoid physics interference
  • Assigns to: _AOMap + enables _USE_AO keyword
  • Parameters: Ray Count, Max Distance, Intensity, Dilation

Curvature Map

  • Computes curvature from neighbor vertex normal differences (0.5 = flat, >0.5 = convex, <0.5 = concave)
  • Assigns to: _CavityMap
  • Parameters: Multiplier, Dilation

Roughness Map

  • Estimates roughness from Albedo texture luminance and saturation
  • Option to invert to smoothness
  • Assigns to: _RoughnessMap + enables _USE_ROUGHNESS_MAP keyword
  • Parameters: Baseline, Luminance Influence, Saturation Influence, Blur Radius

Shadow Map

  • Directional raycasting with spread angle for occlusion calculation
  • Light direction adjustable via yellow arrow handle in Scene view
  • Assigns to: _ShadowReceiveMask
  • Parameters: Light Direction, Ray Count, Spread Angle, Intensity, Dilation

Control Map

  • Packs R channels from generated maps into RGBA channels
  • Freely assign source for each channel (AO / Curvature / Roughness / Shadow / None)
  • Parameters: R / G / B / A Channel Source

How to Use

Method 1: From NataneToon Inspector (Easiest)

  1. Select a material using NataneToon Shader
  2. Expand the AO section
  3. Click the "Generate All Maps" button
  4. All maps are generated and assigned to the corresponding properties

Method 2: MapGenerator Component

  1. Attach the MapGenerator component to a GameObject with a Renderer
  2. Albedo texture and mesh are auto-detected
  3. Adjust parameters for each map
  4. Click "Generate All Maps" for batch generation, or use individual section buttons

Method 3: Detailed Window

  1. Open Tools > MapGenerator > Map Generator Window
  2. Select the target MapGenerator component
  3. Adjust settings in the left panel, preview results in the right panel
  4. Click "Generate All Maps" to execute

Technical Details

  • GPU Processing: 5 Compute Shaders (UVBake, GaussianBlur, NormalFromHeight, Dilation, ChannelPack)
  • CPU Fallback: All features work without Compute Shader support
  • UV Baking: Triangle rasterization to bake vertex data into UV space
  • Dilation: Automatically fills UV seam gaps from neighboring pixels
  • SkinnedMeshRenderer Support: Uses BakeMesh for posed mesh capture
  • Output Formats: PNG / TGA / EXR

Tips

  • AO and Shadow Maps require mesh raycasting, so the object must be placed in the scene
  • Large meshes (100k+ vertices) may take longer for AO/Shadow generation. Cancel via progress bar
  • Normal Map uses mesh curvature + Albedo detail blend, so it works with mesh only or Albedo only
  • Drag the yellow arrow handle in Scene view to adjust Shadow Map light direction
  • Use the language toggle button to switch between Japanese and English
  • Ctrl+Z for Undo support
