Asset Reference Checker

Detect missing and broken references in scenes, prefabs, and materials

Menu: Tools > Natane > Optimization > Asset Reference Checker Category: Optimization

Overview

The Asset Reference Checker comprehensively detects missing and broken references within scenes, prefabs, and materials. It identifies Missing Scripts, missing materials, unassigned textures, shader errors, and null references across three scan modes, classifying issues by severity (Error / Warning / Info).

Access

Menu: Tools > Natane > Optimization > Asset Reference Checker

Features

Three Scan Modes

  • Scene Mode - Scans all GameObjects in the currently open scene. Option to include or exclude inactive objects
  • Prefab Mode - Scans a specific prefab or all prefabs in the entire project
  • Material Mode - Scans materials in the project with an optional filter for Natane Toon Shader materials only

Detected Issue Types

  • Missing Script (Error) - A component's script cannot be found
  • Missing Material (Error) - A Renderer's material slot is null
  • Missing Shader (Error) - A material's shader is null or in error state (Hidden/InternalErrorShader)
  • Missing Texture (Warning/Info) - A material's texture property is unassigned (_MainTex triggers Warning; others trigger Info)
  • Null Reference (Warning) - An object reference on a component is broken

Results Display

  • Result Summary - Color-coded counts of errors, warnings, and info items
  • Filtering - Filter by Error, Warning, and Info independently
  • Detail Expansion - Expand each issue to view component name, property name, and asset path
  • Object Selection - Click "Select" to ping and select the problematic object in the editor
  • Console Export - Export all detected issues to the Unity Console

How to Use

  1. Select a scan mode (Scene / Prefab / Material) from the toolbar
  2. Configure mode-specific settings:
    • Scene: Toggle "Include Inactive Objects"
    • Prefab: Assign a target prefab, or use "Scan All Project Prefabs"
    • Material: Toggle the "Natane Toon Shader Only" filter
  3. Press the scan button to start detection (a progress bar will be displayed)
  4. Review the result summary for an overview of detected issues
  5. Use filters to narrow results by severity level
  6. Click the "Select" button on each issue to navigate to the affected object and fix it
  7. Optionally, click "Export to Console" to output results to the log

Tips

  • Run a Scene scan before uploading to VRChat to catch Missing Scripts and null references early
  • The "Scan All Project Prefabs" option in Prefab mode may take time in large projects
  • In Material mode, _MainTex being unassigned is reported as a Warning while other textures are Info level
  • Scans can be cancelled mid-way using the progress bar's cancel button
  • Use Console export to save and share detection results as text
