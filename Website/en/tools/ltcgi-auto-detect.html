LTCGI Auto-Detect

Automatic detection and shader configuration for LTCGI package integration

Menu: Tools > Natane > VRChat > LTCGI 再検出 Re-detect Category: VRChat Integration

Overview

LTCGI Auto-Detect automatically detects the presence of the LTCGI (Linearly Transformed Cosines Global Illumination) package used in VRChat worlds and configures the shader accordingly.

It runs automatically on Unity editor startup, package installation/uninstallation, and script recompilation. When the LTCGI package (at.pimaker.ltcgi) is detected, the shader uses real LTCGI.cginc functions. When not detected, it automatically falls back to Unity SH + Reflection Probes.

This mechanism ensures no compile errors occur in environments without the LTCGI package, while high-quality area lighting is automatically enabled when LTCGI is available. No manual configuration changes are required.

Key Features

  • Automatic Detection on Editor Load — Using [InitializeOnLoad], the tool automatically detects the LTCGI package on Unity editor startup, script recompilation, and package changes
  • Auto-Generated Shader Config File — Based on detection results, generates NataneToonLTCGIConfig.hlsl automatically. When the package is detected, #define NATANE_LTCGI_AVAILABLE is defined, controlling conditional includes in the shader
  • Automatic Shader Reimport — After configuration changes, related shader files (such as NataneToonLighting.hlsl) are automatically reimported to immediately reflect the changes
  • State Change Tracking — Uses EditorPrefs to remember the previous detection state and only regenerates the config file and recompiles shaders when the state changes. Prevents unnecessary recompilation
  • Manual Re-detection — Force re-detection via the menu and view the results in a confirmation dialog
  • Fallback Support — In environments without the LTCGI package, a fallback implementation using Unity's standard SH (Spherical Harmonics) and Reflection Probes is automatically selected

How to Access

Menu: Tools > Natane > VRChat > LTCGI 再検出 Re-detect

Normally runs automatically on editor startup, so manual execution is unnecessary. Use it when there are issues with package installation status or when you want to manually verify the state.

How to Use

  1. Automatic Detection (Normal Usage)

    No action required. Simply launching the Unity editor will automatically detect the LTCGI package and configure shader settings appropriately. Settings are also automatically updated when packages are installed or uninstalled.

  2. Manual Re-detection

    Select Tools > Natane > VRChat > LTCGI 再検出 Re-detect to force re-detection. The result is displayed in a dialog.

  3. Verify Results

    After detection, one of the following messages is displayed in the dialog:

    • Detected: "LTCGI package detected. Shaders will use real LTCGI functions."
    • Not Detected: "LTCGI package not found. Fallback implementation (Unity SH + Reflection Probes) will be used."

Technical Details

  • Detected package path: Packages/at.pimaker.ltcgi
  • Detected file: Packages/at.pimaker.ltcgi/Shaders/LTCGI.cginc
  • Generated config file: Shaders/NataneToon/Include/Config/NataneToonLTCGIConfig.hlsl
  • The config file is auto-generated — do not edit it manually
  • Detection results are output to the Console with the [NataneToon] prefix
