UV Texture Generator

Generate noise and mask textures from mesh UV islands

Menu: Tools > Natane > Shader > UV Texture Generator Category: Shader

Overview

The UV Texture Generator analyzes a mesh's UV layout and automatically generates noise and mask textures. It supports 5 noise types (Perlin, Voronoi, Cellular, FBM, Value) and features advanced texture generation capabilities including per-UV-island mask generation and combined noise + mask modes.

Toon shaders require mask textures for various purposes, including dissolve effects, emission masks, shadow masks, and more. With this tool, you can generate the necessary textures within the Unity editor without opening external paint software. Accurate UV island detection using the Union-Find algorithm allows you to assign different mask values to different parts of the mesh.

Generated textures can be saved as PNG and also directly assigned to material properties. It can be used in various scenarios such as creating dissolve noise textures, part-specific mask textures, and specifying emission areas.

Key Features

  • 5 Noise Types — Supports 5 procedural noise types: Perlin (smooth), Voronoi (cell-like), Cellular (organic), FBM (fractal), and Value (granular)
  • UV Island Detection via Union-Find — Automatically detects islands (groups of connected faces) from mesh UV coordinates. Accurate detection based on vertex connectivity
  • Per-Island Mask Generation — Assign different mask values to each UV island. Automatically generates part-specific masks for head, body, clothing, etc.
  • Erosion-Based Boundary Gradients — Generates smooth gradients at UV island boundaries. Used for natural transition effects
  • Noise + Mask Combined Mode — Combine noise and mask textures to generate island-specific noise patterns
  • Direct Assignment to Material Properties — Assign generated textures to any material texture slot with one click

How to Use

  1. Select Tab

    Choose the appropriate mode from the three tabs: "Noise," "UV Mask," or "Combined Mode." Use Noise for dissolve effects, UV Mask for per-part control, and Combined Mode to combine both.

  2. Configure Parameters

    In Noise mode, set the noise type and scale. In UV Mask mode, set the mesh source and UV channel. You can also specify the texture resolution (128 to 2048).

  3. Generate Preview

    Click "Generate Texture" to check the preview. Adjust the noise scale and mask boundary settings to pursue the ideal result.

  4. Save & Assign

    Save to the project as PNG and, if needed, directly assign to a material's texture property. Can be set to any slot such as dissolve map, emission mask, etc.

Tips

  • FBM (Fractal Brownian Motion) noise is ideal for natural dissolve patterns. It generates fractal patterns by layering multiple octaves
  • Voronoi noise is perfect for cellular masks (crack and crystal patterns). Using it for dissolve effects creates a glass-shattering look
  • Combined mode lets you create island-specific noise, enabling advanced effects like different dissolve speeds for each body part
  • 512x512 resolution is sufficient for most mask textures. Avoid unnecessarily large sizes to keep memory usage low
  • UV Mask mode assumes the mesh has proper UV unwrapping. Channels other than UV1 can also be used, so choose based on your needs
  • When creating emission masks, assigning white (1.0) to UV islands you want to glow and black (0.0) to others is effective
