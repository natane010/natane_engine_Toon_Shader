Preset Browser

Visual preset selection with thumbnail previews

Menu: Tools > Natane > Preset Browser Category: Preset

Overview

The Preset Browser is a visual tool for browsing and applying Natane Toon Shader material presets with thumbnail previews. You can quickly find the desired style from presets organized by category and apply them to a material with a single click.

Key Features

  • Preset list with thumbnail previews
  • Category filters (Character, Props, Environment, Effects, Toon Style, NPR Style)
  • Performance rating display (A/B/C/D)
  • Preset search functionality
  • One-click application to selected material
  • Detailed preset information display

How to Use

  1. Select the material you want to apply a preset to in the Project view
  2. Open the Preset Browser and select a category
  3. Browse thumbnails to find a preferred preset
  4. Click a preset to view its details
  5. Click "Apply" to apply the preset to the selected material

Preset Categories

  • Character - Presets for skin, hair, clothing, and other character elements
  • Props - For weapons, accessories, and small items
  • Environment - For backgrounds, buildings, and natural objects
  • Effects - For effects and special expressions
  • Style_Toon - Anime-style cel-shading styles
  • Style_NPR - NPR (Non-Photorealistic Rendering) styles

Tips

  • Presets work best as a starting point; fine-tune from there for efficiency
  • Check performance ratings to choose optimal presets for VRChat
  • Custom presets also appear in the same browser
  • Preset application supports Undo, so feel free to experiment
