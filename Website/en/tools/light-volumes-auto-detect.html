VRC Light Volumes Auto-Detect

Automatic detection and shader configuration for VRC Light Volumes package integration

Menu: Tools > Natane > VRChat > VRC Light Volumes 再検出 Re-detect Category: VRChat Integration

Overview

VRC Light Volumes Auto-Detect automatically detects the presence of the VRC Light Volumes (voxel-based lighting system) package and configures the shader accordingly.

It runs automatically on Unity editor startup, package installation/uninstallation, and script recompilation. When the VRC Light Volumes package (red.sim.lightvolumes) is detected, the shader uses real Light Volumes functions (LightVolumes.cginc). When not detected, it automatically falls back to the bundled version of LightVolumes.cginc.

VRC Light Volumes is a voxel-based lighting system that improves lighting quality in VRChat worlds, providing higher-quality indirect illumination than traditional light probes. This tool ensures the shader works correctly regardless of whether the package is present.

Key Features

  • Automatic Detection on Editor Load — Using [InitializeOnLoad], the tool automatically detects the VRC Light Volumes package on Unity editor startup, script recompilation, and package changes
  • Auto-Generated Shader Config File — Based on detection results, generates NataneToonLVConfig.hlsl automatically. When the package is detected, #define NATANE_VRCLV_AVAILABLE is defined, controlling conditional includes in the shader
  • Automatic Shader Reimport — After configuration changes, related shader files (such as NataneToonLighting.hlsl) are automatically reimported to immediately reflect the changes
  • State Change Tracking — Uses EditorPrefs to remember the previous detection state and only regenerates the config file and recompiles shaders when the state changes. Prevents unnecessary recompilation
  • Manual Re-detection — Force re-detection via the menu and view the results in a confirmation dialog
  • Bundled Fallback — In environments without the VRC Light Volumes package, the bundled LightVolumes.cginc included with Natane Toon Shader is automatically used

How to Access

Menu: Tools > Natane > VRChat > VRC Light Volumes 再検出 Re-detect

Normally runs automatically on editor startup, so manual execution is unnecessary. Use it when there are issues with package installation status or when you want to manually verify the state.

How to Use

  1. Automatic Detection (Normal Usage)

    No action required. Simply launching the Unity editor will automatically detect the VRC Light Volumes package and configure shader settings appropriately. Settings are also automatically updated when packages are installed or uninstalled.

  2. Manual Re-detection

    Select Tools > Natane > VRChat > VRC Light Volumes 再検出 Re-detect to force re-detection. The result is displayed in a dialog.

  3. Verify Results

    After detection, one of the following messages is displayed in the dialog:

    • Detected: "VRC Light Volumes package detected. Shaders will use real Light Volumes functions."
    • Not Detected: "VRC Light Volumes package not found. Shaders will use bundled LightVolumes.cginc."

Technical Details

  • Detected package path: Packages/red.sim.lightvolumes
  • Detected file: Packages/red.sim.lightvolumes/Shaders/LightVolumes.cginc
  • Generated config file: Shaders/NataneToon/Include/Config/NataneToonLVConfig.hlsl
  • The config file is auto-generated — do not edit it manually
  • Detection results are output to the Console with the [NataneToon] prefix
  • Operates independently from LTCGI auto-detection — both can be used simultaneously
