Build Optimization

Automatic shader and material optimization at build / VRChat upload time (v1.6.0)

Runs: automatically at build time (no manual action needed) Category: Optimization

Overview

Natane Toon Shader automatically optimizes shaders and materials at build time — especially when uploading VRChat avatars. No user action is required; several components cooperate at each stage of the build pipeline.

How It Works

  • Pre-build (NataneBuildFeatureOptimizer) — generates build settings that #define only the features in use and #undefs unused keywords at the source level
  • Scene processing (NataneBuildSceneKeywordSync) — syncs every material's keywords with its property values and saves to disk (covers VRChat's AssetBundle builds)
  • Shader compilation (NataneShaderVariantStripper) — via IPreprocessShaders, discards compiled variants containing keywords not used by any material
  • Post-build (NataneBuildOptimizationReport) — writes an optimization summary to the console and Logs/NataneBuildOptimizationReport.txt
  • Pre-VRChat-avatar-build (NataneVRChatBuildHook) — keyword sync plus Lite conversion suggestions (compiled only when the VRChat SDK is present)

Report Contents

  • Stripped variant count — totals from the variant stripper (before → after is also logged to the console)
  • Disabled features — known keywords unused by every material
  • Lite conversion candidates — full-version materials that use no GrabPass features (refraction, Kuwahara, color bleeding, etc.)
  • Texture suggestions — maxSize above 2048, uncompressed textures, etc. (suggestions only; nothing is changed automatically)

Safety

  • Variant stripping only considers known Natane keywords; built-in multi_compile keywords (DIRECTIONAL / SHADOWS_SCREEN / INSTANCING_ON, etc.) are never touched
  • A keyword counts as "in use" if either the keyword state or the toggle property value is enabled — a conservative rule

Tips

  • To temporarily disable variant stripping, set the EditorPrefs key NataneToon_DisableVariantStripping to true
  • VRChat avatar builds do not invoke the post-build report, so Lite suggestions are also emitted by the VRChat build hook
  • For manual up-front optimization, see Variant Stripping Settings and the Shader Variant Collector
