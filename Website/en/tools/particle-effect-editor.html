Particle Effect Editor

Preset-based visual particle effect creation tool

Menu: Tools > Natane > Particle Effect Editor Category: Effects

Overview

The Particle Effect Editor is an editor window for visually creating and editing particle effects using ScriptableObject-based presets. Quickly create effects from 7 built-in templates (Explosion, Fire, Smoke, Magic Sparkles, Electric, Water Splash, Heal Effect) and fine-tune parameters while previewing in real-time.

Access

Menu: Tools > Natane > Particle Effect Editor

Features

Preset Management

  • Create New Preset - Create a ScriptableObject saved as an .asset file
  • Load Template - Load settings from 7 built-in templates with one click
  • Edit Preset Info - Set name, description, category, and preview icon
  • Save - Save the edited preset as an asset

Editable Parameters

  • Main Settings - Duration, Looping, Start Lifetime, Start Speed, Start Size, Start Color, Gravity, Max Particles
  • Emission - Rate Over Time, Burst settings (Count, Time)
  • Shape - Shape Type (Sphere, Cone, etc.), Angle, Radius
  • Color Over Lifetime - Lifetime color variation using the gradient editor
  • Size Over Lifetime - Lifetime size variation using the curve editor
  • Velocity Over Lifetime - Lifetime velocity variation (Vector3)
  • Rotation - Rotation speed settings
  • Renderer - Render Mode and material assignment
  • Trails - Enable trails, Lifetime, Min Vertex Distance, Trail Material

Preview

  • Play / Stop / Restart - Real-time preview playback controls
  • Auto Play on Change - Automatically replays on parameter changes
  • Particle Count Display - View current particle count and playback state
  • Scene View Preview - Preview object is placed in front of the Scene view camera

Apply to Scene

  • Apply to Selected Object - Adds a ParticleSystem to the selected GameObject and applies the preset
  • Create New Object - When no object is selected, creates a new GameObject with the effect

Built-in Templates

  • Explosion - Burst of 100 particles, sphere emission, orange-to-black gradient
  • Fire - Looping, cone shape, yellow-to-red gradient, negative gravity
  • Smoke - Looping, gradually expanding, with rotation, semi-transparent gray
  • Magic Sparkles - Sphere emission, white-to-purple gradient, with rotation
  • Electric - High emission rate, short lifetime, blue-white color
  • Water Splash - Burst of 50 particles, cone shape, strong gravity
  • Heal Effect - Cone shape, green gradient, upward emission

How to Use

  1. Click "New Preset" in the toolbar to create a new preset, or drag an existing preset into the object field
  2. Select a template from "Load Template" to load base settings
  3. Adjust parameters in each section (changes are reflected in the preview in real-time)
  4. Use the preview controls to verify the effect's appearance
  5. Click "Save" to save the preset
  6. Click "Apply to Scene" to apply the effect to an object in the scene

Tips

  • Customizing from a template is the most efficient way to create effects
  • Enable Auto Play to see preview updates immediately when changing parameters
  • Presets are ScriptableObjects, so they can be shared across projects
  • The preview object is automatically cleaned up when the window is closed
  • Since VRChat does not allow runtime scripts, complete your effect design in the editor
