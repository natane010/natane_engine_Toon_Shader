Material Comparison

Compare two materials side by side and view differences

Menu: Tools > Natane > Material Comparison Category: Material

Overview

The Material Comparison tool displays two Natane Toon materials side by side and highlights property differences at a glance. It helps you quickly identify setting differences, making it useful for material unification and debugging.

Key Features

  • Side-by-side display of two materials
  • Property difference highlighting
  • Visual texture comparison
  • Enabled feature difference listing
  • Performance rating comparison
  • Filter to show only differing properties

How to Use

  1. Drag and drop the source material into the left slot
  2. Drag and drop the target material into the right slot
  3. Property differences are automatically highlighted
  4. Use the "Show Differences Only" filter to narrow down changes
  5. Copy and apply values as needed

Tips

  • Useful for debugging when subtle setting differences affect scene appearance
  • Can also be used to compare before and after applying presets
  • Use the "Differences Only" filter to quickly find changes among a large number of properties
  • Compare performance ratings to verify the effectiveness of optimizations
