Smooth Normal Baker

Bake smooth normals into vertex colors for better outlines on hard-edge models

Menu: Tools > Natane > Mesh > Smooth Normal Baker Category: Mesh

Overview

The Smooth Normal Baker improves outline rendering on hard-edge models by baking smooth normals into the RGB channels of vertex colors. It groups vertices at the same position, averages their normals to calculate smooth normals, then encodes and saves them to vertex colors. The original mesh remains unmodified, following a non-destructive workflow.

Access

Menu: Tools > Natane > Mesh > Smooth Normal Baker

Features

  • Two Bake Modes
    • Tangent Space (Recommended) - Encodes smooth normals in tangent space. Follows skinning and blend shape deformation
    • Object Space - Encodes smooth normals in object space. Simple and stable but does not follow mesh deformation
  • Mesh Information Display - Shows mesh name, vertex count, submesh count, and whether existing vertex colors are present
  • Auto Assign - Option to automatically replace the mesh after baking (with Undo support)
  • Non-destructive Workflow - The original mesh is not modified; a new mesh is saved as a .asset file
  • Automatic Tangent Detection - When a mesh lacks tangent data, the tool suggests switching to Object Space mode
  • Position-based Vertex Grouping - Groups vertices at the same position using quantization (precision: 1/10000) for floating-point tolerance
  • SkinnedMeshRenderer / MeshFilter Support - Works with both skinned meshes and static meshes

How to Use

  1. Drag a GameObject with a SkinnedMeshRenderer or MeshFilter into the "Target Object" field
  2. Review the mesh information (vertex count, submesh count, etc.)
  3. Select a bake mode (Tangent Space is recommended for most cases)
  4. Enable "Auto Assign" to have the mesh automatically replaced after baking
  5. Press the "Bake" button
  6. Choose a save location, and the baked mesh will be saved as a .asset file
  7. Enable the "Smooth Normal Outline" feature in the shader to see the result

Technical Details

Smooth Normal Calculation

Vertices at the same position (quantization precision of 1/10000) are grouped together, and the normal vectors within each group are averaged. This averaged normal becomes the smooth normal.

Encoding Methods

  • Tangent Space: Uses the inverse TBN matrix to transform smooth normals into tangent space, then remaps from [-1,1] to [0,1] and stores in vertex color RGB
  • Object Space: Directly remaps object-space smooth normals from [-1,1] to [0,1] and stores in vertex color RGB

Tips

  • Especially effective when avatar outlines break at hard edges
  • Be aware that existing vertex colors will be overwritten by the bake
  • Tangent Space mode maintains smooth outlines during skinning animations
  • The baked mesh is named with a "_SmoothNormal" suffix appended to the original mesh name
  • If an asset already exists at the same path, it will be updated in place
