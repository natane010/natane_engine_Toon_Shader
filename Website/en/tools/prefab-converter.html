Prefab Variant Converter

Generate prefab variants and batch convert lilToon materials to NataneToon

Menu: Tools > Natane > Migration > Prefab Variant Converter Category: Migration

Overview

The Prefab Variant Converter creates a variant from an existing prefab (such as an avatar) and batch converts the lilToon materials within that variant to Natane Toon Shader. The original prefab and materials are preserved, allowing you to safely try the shader migration.

In VRChat avatar production, directly modifying purchased body or accessory prefabs can cause issues during updates. This tool leverages Unity's prefab variant feature to replace only the materials with Natane Toon Shader versions while maintaining references to the original prefab. This way, when the original prefab is updated, basic changes are automatically reflected.

Material naming conventions can be customized (prefix/suffix settings), and you can preview before conversion, making it easier to organize materials within your project. While specialized for lilToon migration, the converted materials function fully as Natane Toon Shader materials, giving you access to all Natane Toon features.

Key Features

  • Automatic Prefab Variant Generation — Automatically creates a variant without modifying the original prefab. Can follow updates to the original prefab
  • Batch Material Conversion — Detects lilToon materials within the variant and batch converts them to Natane Toon Shader
  • lilToon to NataneToon Migration — Dedicated automatic property mapping for lilToon, carrying over textures, colors, and parameters automatically
  • Material Name Customization — Add prefixes or suffixes to converted material names. Example: set naming rules like "Natane_Body"
  • Pre-execution Preview — Preview the list of detected lilToon materials and post-conversion material names. Individual conversion targets can be selected

How to Use

  1. Select Prefab

    Select the avatar prefab in the Scene view or Project view. If an instance exists in the Hierarchy, you can select that instead.

  2. Configure Settings

    Set the material prefix/suffix and save location. Setting the prefix to "Natane_" results in converted material names like "Natane_Body" and "Natane_Hair".

  3. Preview Materials

    Review the list of detected lilToon materials and select which ones to convert. Uncheck any specific materials you don't want to convert.

  4. Execute Conversion

    Click "Generate Variant & Execute Conversion" to create the prefab variant and convert the selected materials to Natane Toon Shader.

Tips

  • The original prefab and materials are not modified at all. You can always revert to the original state, so feel free to experiment
  • Using a consistent prefix makes organization in the Project view easier. Recommended: "Natane_" or "NT_"
  • You can verify exact material names before conversion in the preview screen, so check for naming duplicates
  • Multiple materials can be batch converted, completing an entire avatar migration in a single operation
  • After conversion, add Natane Toon Shader-exclusive features (custom rim light, MatCap, dissolve, etc.) to further enhance expressiveness
