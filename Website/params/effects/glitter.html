グリッター

キラキラと輝くグリッターエフェクト

概要

グリッターは、キラキラと輝くハイライト効果を追加するエフェクトです。衣装やアクセサリーに華やかさを追加したい場合に使用します。ノイズベースのアニメーションにより、リアルなきらめき表現を実現します。

キーワード _GLITTER で制御され、無効時はシェーダー命令が生成されません。

パラメータ

グリッター色 _GlitterColor color

グリッターの輝きの色を設定します。アルファチャンネルも使用可能です。

デフォルト: (1, 1, 1, 1)（白）

金色のグリッターには (1, 0.85, 0.5)、虹色の効果にはエミッションと組み合わせるのも効果的です。
グリッターサイズ _GlitterSize range

グリッターの粒子サイズを制御します。値が大きいほど粒子が大きくなります。

デフォルト: 0.1

範囲: 0 〜 1

グリッター密度 _GlitterDensity range

グリッターの出現頻度を制御します。値が大きいほど多くのグリッターが表示されます。

デフォルト: 0.5

範囲: 0 〜 1

0 = 少ない、1 = 多い。宝石のような効果には高密度（0.7〜1.0）、控えめな輝きには低密度（0.2〜0.4）が適しています。
グリッター速度 _GlitterSpeed float

グリッターの点滅速度を制御します。値が大きいほど速く点滅します。

デフォルト: 1

0に設定するとアニメーションが停止し、静的なグリッターになります。
グリッター強度 _GlitterIntensity range

グリッターの明るさを制御します。1.0を超える値でHDR的な強い輝き効果が得られます。

デフォルト: 1

範囲: 0 〜 2

マスク

グリッターマスク _GlitterMask texture

グリッターの表示領域を制御するマスクテクスチャです。キーワード _GLITTER_MASK で有効化します。Rチャンネル（赤）を使用してグリッターの表示領域を制御します。

デフォルト: "white"（全面表示）

白 (1.0) = グリッターを完全に表示、黒 (0.0) = グリッターを非表示、グレー = 部分的に表示。アクセサリーや衣装の装飾部分にだけグリッターを適用するのに使います。

ブレンド＆ブラー

ブレンドモード _GlitterBlendMode enum

グリッターエフェクトのブレンド方法を選択します。

  • Normal (0) - 通常の加算合成
  • Soft (1) - ソフトな加算。明るくなりすぎを防ぐ
  • Screen (2) - スクリーン合成。自然な明るさ加算
  • Overlay (3) - オーバーレイ合成。コントラスト強調

デフォルト: Normal (0)

ブレンド _GlitterBlend range

グリッターエフェクトの強度（不透明度）を制御します。

デフォルト: 1

範囲: 0 〜 1

ブラー _GlitterBlur range

グリッターエフェクトのぼかし量を調整します。

デフォルト: 0

範囲: 0 〜 1

使い方のヒント

衣装やアクセサリーに華やかさを追加

  • サイズ: グリッターの粒子サイズ
  • 密度: グリッターの出現頻度（0=少ない、1=多い）
  • 速度: グリッターの点滅速度
  • 強度: グリッターの明るさ

マスクテクスチャを活用して、宝石やスパンコールのように特定の装飾部分にだけグリッターを適用するのがおすすめです。
