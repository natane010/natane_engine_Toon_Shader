レンチキュラー

見る角度によって絵柄そのものが切り替わります。左右から見ると表情が変わる、正面と横で別の顔が現れる、ホログラムカードのような角度依存の演出を作れます。(v1.6.0)

PREVIEW Lenticular

概要

複数の絵柄を 1 枚のアトラス (横並び / グリッド) に格納し、視線角度に応じて表示フレームを切り替える機能です。イリデッセンスが角度で色を変えるのに対し、レンチキュラーは絵柄そのものを差し替えます。

角度判定はオブジェクト空間の視線ベクトルで行うため、VRChat のミラーやカメラ位置に依存しにくく安定します。選択したフレームはメイクアップテクスチャ合成の直後 (ベースカラー修飾) に混合されます。キーワード _LENTICULAR で切り替わり、OFF 時はゼロコストです。

作れる表現

  • 左右から見ると表情が変わる、正面と横で別の顔が現れる
  • ロゴと文字が切り替わる、カードのイラストが動く
  • 瞳が Normal / Heart / Star へ変わる
  • 角度によって傷・魔法紋・発光模様が現れる、ホログラムカード風の素材

動作モード (_LenticularMode)

モード内容
SmoothBlend隣接フレームを frac + Softness で滑らかに補間
HardStepround で瞬時に切り替え
ScanBlendUV 縞 (_LenticularScanScale) で隣接フレームを混在
FrontReveal正面付近のみ別フレームを出現 (Emission ブースト連動)
SideReveal斜め付近のみ別フレームを出現 (Emission ブースト連動)
Flip視線の左右で A/B を切り替え (Softness で中央をクロスフェード)

主なパラメータ

アトラス / フレーム数 _LenticularAtlas / _LenticularFrames 2D + range

複数フレームを格納したアトラス画像と、その枚数です。_LenticularDirection で横並び (Horizontal) かグリッド (Grid) を選びます。

デフォルト: Frames 4 / Direction Horizontal

角度判定軸 / 角度幅 _LenticularViewAxis / _LenticularAngleRange enum + range

横振り (X) か縦振り (Y) のどちらで切り替えるか、そしてフレーム全体を何度の範囲にマップするかです。

デフォルト: ViewAxis X / AngleRange 90

ステレオモード _LenticularStereoMode enum

VR での角度計算方法です。StereoCenter (既定) は左右の目の視点を平均し、両眼で同じフレームを選ぶことでちらつきを防ぎます。

デフォルト: StereoCenter

VR で使う場合は StereoCenter を維持し、_LenticularSoftness を十分に持たせるとより安定します。

使い方のヒント

  • VR でのちらつき対策: StereoCenter (既定) を使い、Softness を十分に持たせると、左右の目で別フレームが選ばれることによるちらつきを抑えられます。
  • アトラスの作り方: Horizontal は左から順にフレームを並べます。Grid は ceil(√n) 列の行優先で配置します。
  • 光らせる: FrontReveal / SideReveal では、出現フレームに _LenticularEmission の発光ブーストが連動します。
  • マスク: _LenticularMask の R チャンネルで適用範囲を制御できます。
