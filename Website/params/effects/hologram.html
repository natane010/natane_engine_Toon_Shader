ホログラム

SFスタイルのホログラム効果

サイバーパンクやSF風のホログラム投影を再現するエフェクトです。スキャンライン、エッジグロウ、フリッカー、ノイズ歪みを組み合わせて、リアルなホログラム表現を作成できます。

キーワード: _HOLOGRAM

ホログラム基本設定

ホログラム色 _HologramColor color

ホログラムエフェクト全体の色を設定します。スキャンラインやエッジグロウなど、すべてのホログラム要素に影響します。

デフォルト: (0, 1, 1, 1)（シアン）

SF風のシアンや緑がおすすめですが、キャラクターに合わせて自由に変更できます。
モノクロ化 _HologramMonochrome range

元のテクスチャ色をホログラム色に統一します。値を上げるほど、テクスチャの色味が失われてホログラム色のモノクロ表現になります。

デフォルト: 0（範囲: 0 - 1）

1.0 にすると完全なモノクロホログラムになり、SF的な雰囲気が強くなります。

スキャンライン

スキャンライン速度 _HologramScanlineSpeed float

スキャンライン（走査線）が上下に移動する速度を設定します。3層構成の走査線エフェクトがアニメーションします。

デフォルト: 1

スキャンライン強度 _HologramScanlineIntensity range

スキャンラインの明暗のコントラストを設定します。値が大きいほど走査線がはっきりと見えます。

デフォルト: 0.5（範囲: 0 - 1）

スキャンライン密度 _HologramScanlineDensity float

スキャンラインの本数（密度）を設定します。値が大きいほど走査線が細かく密に表示されます。

デフォルト: 100

50-200 程度が一般的です。大きすぎるとモアレが発生する場合があります。
スキャンライン幅 _HologramScanlineWidth range

各スキャンラインの太さを設定します。値が大きいほどスキャンラインが太くなります。

デフォルト: 0.5（範囲: 0 - 1）

エッジグロウ（Fresnel）

エッジグロウ範囲 _HologramEdgeGlowPower range

Fresnelベースの縁光り効果の範囲を設定します。値が小さいほどグロウが広く、大きいほどエッジのみに集中します。

デフォルト: 3（範囲: 0.1 - 10）

エッジグロウ強度 _HologramEdgeGlowIntensity range

エッジグロウの明るさを設定します。値が大きいほどエッジが強く光ります。

デフォルト: 1（範囲: 0 - 5）

透明度・フリッカー

ホログラム透明度 _HologramAlpha range

ホログラム全体の透明度をFresnel連動で自動制御します。値を上げるとホログラムが半透明になります。

デフォルト: 0（範囲: 0 - 1）

Transparent バリアントとの組み合わせでよりリアルなホログラム投影を実現できます。
フリッカー速度 _HologramFlickerSpeed float

ホログラムが明滅（フリッカー）する速度を設定します。

デフォルト: 5

フリッカー量 _HologramFlickerAmount range

フリッカー（明滅）の振幅を設定します。値が大きいほど激しく明滅します。

デフォルト: 0.3（範囲: 0 - 1）

ノイズ歪み

ノイズ強度 _HologramNoiseIntensity range

ホログラムに加わるノイズ歪みの強さを設定します。

デフォルト: 0（範囲: 0 - 1）

ノイズ速度 _HologramNoiseSpeed float

ノイズ歪みがアニメーションする速度を設定します。

デフォルト: 1

マスク・テクスチャ

ホログラムマスク _HologramMask texture

ホログラムエフェクトの適用範囲をテクスチャで制御します。キーワード _HOLOGRAM_MASK で有効化します。

デフォルト: "white"（全体に適用）

白 = ホログラムあり、黒 = ホログラムなし。部位ごとにホログラムの有無を制御できます。
ノイズテクスチャ _HologramNoiseTex texture

カスタムノイズテクスチャを使用してホログラムの歪みパターンを制御します。キーワード _HOLOGRAM_NOISE で有効化します。

デフォルト: "white"

ブレンド設定

ブレンドモード _HologramBlendMode enum

ホログラムエフェクトとベースカラーの合成方法を選択します。

  • Normal (0) - 通常合成
  • Soft (1) - ソフトライト
  • Screen (2) - スクリーン（明るく追加）
  • Overlay (3) - オーバーレイ

デフォルト: 0（Normal）

ブレンド _HologramBlend range

ホログラムエフェクトの全体的な適用度を設定します。0 で無効、1 で完全適用です。

デフォルト: 1（範囲: 0 - 1）

ブラー _HologramBlur range

ホログラムエフェクトの境界をぼかします。値が大きいほど柔らかい合成になります。

デフォルト: 0（範囲: 0 - 1）
