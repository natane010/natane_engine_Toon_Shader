グリッチ

デジタルノイズとRGBスプリットの不具合効果

デジタル映像の乱れや不具合を再現するエフェクトです。ランダムなUV歪みとRGB色ずれを組み合わせて、サイバーパンク風の演出やトランジション効果を作成できます。ホログラムエフェクトと併用することで、より強烈なSF表現が可能です。

キーワード: _GLITCH

グリッチ設定

グリッチ強度 _GlitchIntensity range

グリッチによるUV歪みの強さを設定します。値が大きいほど画面の乱れが激しくなります。

デフォルト: 0.5（範囲: 0 - 1）

グリッチ速度 _GlitchSpeed float

グリッチのアニメーション速度を設定します。値が大きいほど高速にグリッチが切り替わります。

デフォルト: 1

ブロックサイズ _GlitchBlockSize range

グリッチで歪むブロックの大きさを設定します。値が大きいほど大きな塊で歪みます。

デフォルト: 0.1（範囲: 0.01 - 1）

小さい値で細かいノイズ風、大きい値でブロック崩壊風のグリッチになります。
RGBスプリット強度 _GlitchRGBSplitIntensity range

RGB色収差（色ずれ）の強さを設定します。赤・緑・青の各チャンネルをずらして、テレビの色ずれのような効果を出します。

デフォルト: 0.5（範囲: 0 - 1）

グリッチ発生頻度 _GlitchFrequency range

グリッチが発生する頻度を設定します。値が大きいほど頻繁にグリッチが発生します。

デフォルト: 0.3（範囲: 0 - 1）

0.1-0.3 で断続的、0.7 以上でほぼ常時グリッチが発生します。

ブレンド設定

ブレンドモード _GlitchBlendMode enum

グリッチエフェクトとベースカラーの合成方法を選択します。

  • Normal (0) - 通常合成
  • Soft (1) - ソフトライト
  • Screen (2) - スクリーン
  • Overlay (3) - オーバーレイ

デフォルト: 0（Normal）

ブレンド _GlitchBlend range

グリッチエフェクトの全体的な適用度を設定します。

デフォルト: 1（範囲: 0 - 1）

ブラー _GlitchBlur range

グリッチエフェクトの境界をぼかします。

デフォルト: 0（範囲: 0 - 1）
