サーフェス・コースティクス

キャラや小物の表面を、複雑な光模様が流れます。水中のキャラクター、水面の反射光、魔力が皮膚を流れる表現、木漏れ日のような揺らめく光を作れます。(v1.6.0)

PREVIEW Caustics

概要

表面を流れるコースティクス (集光模様) を描く機能です。Procedural モードは Voronoi と sin 波を組み合わせて軽量に生成し、Texture モードは 2 枚のテクスチャをスクロール乗算します。ForwardBase のみで描画され、キーワード _CAUSTICS で切り替わります。OFF 時はゼロコストです。

座標空間 (UV / Object / World / Triplanar-lite) と合成方式 (EmissionAdd / BaseMultiply / LitOnly / ShadowOnly) を選べます。Quest (_QUEST_LITE) では自動的に軽量パターンへ切り替わります。

作れる表現

  • 水中にいるキャラクター、水面から反射した揺れる光
  • 魔力が皮膚や衣装を流れる表現、結晶内部を移動する光
  • ステンドグラスから差し込む色光、木漏れ日
  • 炎やオーロラによる光の揺らぎ、ライブステージの投影ライト

主なパラメータ

パターン生成方式 _CausticsPatternMode enum

Procedural (軽量・テクスチャ不要) か Texture (_CausticsTex を 2 枚スクロール乗算) を選びます。

デフォルト: Procedural

合成方式 _CausticsComposite enum

模様の重ね方です。EmissionAdd (加算・発光) / BaseMultiply (明部ブースト) / LitOnly (光の当たる面のみ) / ShadowOnly (影の面のみ)。

デフォルト: EmissionAdd

水中感は EmissionAdd、皮膚を流れる魔力は LitOnly が向いています。
座標空間 _CausticsSpace enum

模様を貼る座標空間です。UV / Object / World / TriplanarLite (主要軸平面) から選びます。World にするとキャラが動いても光が空間に固定されます。

デフォルト: World

スケール / 速度 _CausticsScale / _CausticsSpeed range + float

模様の大きさ (Scale) と流れる速度 (Speed) です。_CausticsDirection で移動方向を、_CausticsDistortion で歪みを調整できます。

デフォルト: Scale 4 / Speed 0.5

使い方のヒント

  • Quest 対応: Quest 軽量モード (_QUEST_LITE) 時は、重い 3×3 セル走査を行わず軽量パターンへ自動で切り替わります。
  • 光らせる: EmissionAdd では _CausticsColor を HDR で 1 以上にすると Bloom で発光します。
  • ホログラムカード: レンチキュラー・イリデッセンス・形状付きハイライトと組み合わせると、角度で絵柄が変わり表面に虹色と光模様が走る素材になります。
  • マスク: _CausticsMask の R チャンネルで適用範囲を制御できます。
