ヘアスペキュラー

Kajiya-Kay方式の異方性ヘアハイライト

概要

ヘアスペキュラーは、リアルなアニメ風ヘアハイライトのために2つのスペキュラーローブを持つKajiya-Kayヘアシェーディングモデルを実装しています。プライマリローブはシャープなハイライトを提供し、セカンダリローブはよりソフトなフィルを追加します。これにより、アニメやCGレンダリングで見られる特徴的なデュアルバンドの髪の輝きが生まれます。

キーワード _HAIR_SPECULAR で制御され、無効時はシェーダー命令が生成されません。

プライマリローブ

プライマリハイライト色 _HairSpecColor1 color

プライマリ（シャープ）ヘアハイライトの色を設定します。

デフォルト: (1, 1, 1, 1)（白）

白や髪色の明るいバージョンが最も自然な結果になります。カラーハイライトでファンタジーやスタイライズド表現も可能です。
プライマリタンジェントシフト _HairSpecShift1 range

プライマリハイライトを髪のタンジェント方向に沿ってシフトさせます。正の値はハイライトを毛先方向に、負の値は毛根方向に移動させます。

デフォルト: 0.1

範囲: -1 〜 1

わずかに正の値（0.05〜0.2）がアニメ髪で最も自然なハイライト配置になります。
プライマリシャープネス _HairSpecWidth1 range

プライマリハイライトのシャープネスを制御します。値が高いほどタイトでシャープなハイライトバンドになります。

デフォルト: 64

範囲: 1 〜 256

アニメ髪には高い値（96〜128）でくっきりしたハイライトバンドが最適です。低い値（16〜32）でより柔らかくリアルな見た目になります。

セカンダリローブ

セカンダリハイライト色 _HairSpecColor2 color

セカンダリ（ソフトフィル）ヘアハイライトの色を設定します。通常、プライマリより暗めに設定します。

デフォルト: (0.5, 0.5, 0.5, 1)（グレー）

セカンダリタンジェントシフト _HairSpecShift2 range

セカンダリハイライトを髪のタンジェント方向に沿ってシフトさせます。リアルなデュアルバンドの外観のため、通常プライマリと反対方向に設定します。

デフォルト: -0.1

範囲: -1 〜 1

セカンダリシャープネス _HairSpecWidth2 range

セカンダリハイライトのシャープネスを制御します。ソフトなフィルエフェクトのため、通常プライマリより低く設定します。

デフォルト: 32

範囲: 1 〜 256

一般設定

全体の強度 _HairSpecIntensity range

両方のヘアスペキュラーローブの全体的な強度を制御します。

デフォルト: 1

範囲: 0 〜 2

マスク＆シフトテクスチャ

ヘアスペキュラーマスク _HairSpecMask texture

ヘアスペキュラーエフェクトの表示領域を制御するマスクテクスチャです。

デフォルト: "white"（全面表示）

白 = ハイライトあり、黒 = ハイライトなし。ハイライトを髪のみに制限し、肌やアクセサリーに表示されないようにするために使用します。
シフトテクスチャ _HairSpecShiftTex texture

タンジェントシフトにピクセル単位のバリエーションを加えるテクスチャです。完全に均一なハイライトバンドを防ぎ、髪の毛に沿った自然な不規則性を生み出します。

デフォルト: "grey"（ニュートラル、シフト変化なし）

ノイズやグラデーションテクスチャを使ってハイライトバンドを崩してください。シフトテクスチャは髪に沿った自然な変化を加え、より説得力のある見た目にします。

ブレンド＆距離フェード

ブレンドモード _HairSpecBlendMode enum

ヘアスペキュラーエフェクトのブレンド方法を選択します。

  • Normal (0) - 通常の加算合成
  • Soft (1) - ソフトな加算。明るくなりすぎを防ぐ
  • Screen (2) - スクリーン合成。自然な明るさ加算
  • Overlay (3) - オーバーレイ合成。コントラスト強調

デフォルト: Normal (0)

ブレンド _HairSpecBlend range

ヘアスペキュラーエフェクトの強度（不透明度）を制御します。

デフォルト: 1

範囲: 0 〜 1

距離フェード _HairSpecDistFade range

カメラ距離に基づいてヘアスペキュラーエフェクトをフェードさせます。LOD最適化に便利です。

デフォルト: 0

範囲: 0 〜 1
