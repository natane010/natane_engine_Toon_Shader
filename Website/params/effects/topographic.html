等高線 / 断層スライス

表面に等間隔の線や帯を走らせます。地形図の等高線、身体を上昇する SF スキャンライン、3D プリンターの積層線のような、周期的なラインを描けます。(v1.6.0)

PREVIEW Topographic

概要

空間座標を等間隔でスライスし、等高線 / 断層バンドを Emission 対応色で重ねる機能です。ハイトフェードが 1 本の境界を作るのに対し、こちらは複数の線や帯を繰り返し生成できます。テクスチャ不要で、AudioLink や FX モジュレーターと組み合わせやすいのが特長です。

ForwardBase のみで動作し (純粋な加算色のため二重光源に影響しない)、キーワード _TOPOGRAPHIC で切り替わります。OFF 時はゼロコストです。座標空間 (Object/World/View) と軸 (X/Y/Z/Custom) を選べます。

作れる表現

  • 地形図の等高線、地層や木目
  • SF スキャンライン、身体を上昇するエネルギー
  • 3D プリンターの積層線、ホログラムの断層
  • 魔法陣から上昇する光のリング、上から下へ解析されるスキャン演出

主なパラメータ

モード _TopoMode enum (0〜5)

線の描き方を選びます: Lines (細い線) / Bands (太い帯) / GradientBands (段階的な色) / DoubleLines (二重線) / PulseRings (移動するリング) / NoiseDistorted (ノイズで歪んだ線)。

デフォルト: 0 (Lines)

座標空間 / 軸 _TopoSpace / _TopoAxis enum

線を並べる座標空間 (Object / World / View) と軸 (X / Y / Z / Custom) です。World + Y にすると、キャラの位置に関わらず「高さ方向」に線が並びます。

デフォルト: Space=World / Axis=Y

身体を上昇するスキャン線は World + Y、体に貼り付く縞は Object 空間が向いています。
間隔 / 太さ _TopoSpacing / _TopoLineWidth range

線と線の間隔 (Spacing) と、線そのものの太さ (LineWidth) です。

デフォルト: Spacing 0.1 / LineWidth 0.1

スクロール速度 _TopoSpeed float

線が流れる速度です。0 で静止、値を上げると線が軸方向へ流れます。_TopoOffset で位置をずらせます。

デフォルト: 0

FX モジュレーターで TopographicOffset を変調すると、音や時間に合わせて線を動かせます。

使い方のヒント

  • 光らせる: _TopoColor を HDR で 1 以上にし、_TopoEmission を上げると、線が Bloom で発光します。Emission ステージ直後に加算されます。
  • サイバースキャン: グリッチや X-Ray と組み合わせると、スキャン線が身体を上昇し壁に隠れた部分だけ解析表示される演出が作れます。
  • マスク: _TopoMask の R チャンネルで適用範囲を制御できます。
  • ForwardBase のみで描画されるため、追加光源 (ForwardAdd) で線が二重に濃くなることはありません。
