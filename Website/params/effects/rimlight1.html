リムライト1

オブジェクトの縁に光を追加して立体感を強調

概要

リムライトは、視線方向とオブジェクトの法線が垂直に近い部分（縁）に光を追加するエフェクトです。キャラクターの立体感を強調し、背景から浮き上がらせる効果があります。

キーワード _RIM_LIGHT で制御され、無効時はシェーダー命令が生成されません。

パラメータ

リムライトの色 _RimColor color

リムライトの色を設定します。環境光に合わせた色や、キャラクターの雰囲気に合った色を選択できます。

デフォルト: (1, 1, 1, 1)（白）

夕焼けシーンではオレンジ系、水中シーンでは青系の色がおすすめです。
リムライトのパワー _RimPower range

リムライトの鋭さを制御します。値が大きいほど縁の細い部分のみに集中し、小さいほど広範囲に広がります。

デフォルト: 3

範囲: 0.1 〜 10

繊細な輪郭線のような効果は5〜8、ふんわりしたオーラのような効果は1〜2がおすすめです。
リムライトの強さ _RimIntensity range

リムライトの明るさ（強度）を制御します。1.0を超える値を設定すると、HDR的な発光効果が得られます。

デフォルト: 1

範囲: 0 〜 5

リムの広がり（グロー） _RimSpread range

リムライトを滲ませて広げ、柔らかく発光しているような効果を追加します。

  • 0 - 広がりなし（シャープなリム）
  • 0.3〜0.5 - 適度な広がり（推奨）
  • 0.7〜1.0 - 大きな広がり（強いグロー）

デフォルト: 0

範囲: 0 〜 1

グロー効果は低いパワー値と組み合わせると、幻想的な発光演出に最適です。

マスク

リムマスク _RimMask texture

リムライトの表示領域を制御するマスクテクスチャです。キーワード _RIM_MASK で有効化します。

デフォルト: "white"（全面表示）

白 = リムライトあり、黒 = リムライトなし。顔だけにリムライトを集中させたり、衣装の一部を除外するのに便利です。

ブレンド＆ブラー

ブレンドモード _RimBlendMode enum

リムライトエフェクトのブレンド方法を選択します。

  • Normal (0) - 通常の加算合成
  • Soft (1) - ソフトな加算。明るくなりすぎを防ぐ
  • Screen (2) - スクリーン合成。自然な明るさ加算
  • Overlay (3) - オーバーレイ合成。コントラスト強調

デフォルト: Normal (0)

ブレンド _RimBlend range

リムライトエフェクトの強度（不透明度）を制御します。

デフォルト: 1

範囲: 0 〜 1

ブラー _RimBlur range

リムライトエフェクトのぼかし量を調整します。

デフォルト: 0

範囲: 0 〜 1
