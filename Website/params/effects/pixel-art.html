ピクセルアート

3D モデルをドット絵風に見せます。テクスチャをピクセル単位に丸め、ライティングと色を段階化して、レトロゲームや PS1 風のルックを作れます。(v1.6.0)

PREVIEW Pixel Art

概要

UV のピクセル化、ライティング / 色の量子化、パレット LUT、ディザを実装した機能です。カラー量子化が色数だけを減らすのに対し、こちらは空間的な解像度も落とします。キーワード _PIXEL_ART で切り替わり、OFF 時はゼロコストです。

ミラー安全な設計: Screen Pixelation と Object-Stable Pixelation は意図的に非対応です。スクリーン空間スナップは VR で両眼にピクセル継ぎ目が出て安全でなく、Object-Stable 再投影は高コストのためです。本機能はミラー安全なテクスチャ空間 + 色空間のサブセットを提供します。

作れる表現

  • 3D キャラクターのドット絵化、PS1 / レトロ 3D 風
  • 2D ゲームのスプライト風、ボクセルゲーム風
  • 低解像度ホラー、一部分だけデジタル化する演出
  • ダメージ時にピクセル崩壊する表現、現実と仮想空間を切り替える表現

主なパラメータ

仮想解像度 _PixelArtSize range (4〜512)

UV をスナップする仮想解像度です。小さいほど粗い (大きな) ドットになり、レトロ感が強まります。

デフォルト: 64

ファミコン風なら 32〜64、少し細かいドットなら 128 前後が目安です。
量子化段階数 _PixelLightSteps range (2〜32)

ライティング / 色を何段階に丸めるかです。少ないほどベタ塗りのドット絵らしくなります。

デフォルト: 6

パレット LUT _PixelPalette / _PixelPaletteTex toggle + 2D

有効にすると、輝度で横方向パレット LUT (_PixelPaletteTex) をサンプルし、使用色を制限します。ゲームボーイ風の限定色パレットなどが作れます。

デフォルト: OFF

パレット置換は ForwardBase のみで行われます (加算パスでベースの色を置き換えないため)。
ディザ量 _PixelDither range (0〜1)

Bayer ディザの量です。量子化前に加算され、段階の少ない色でもバンディング (縞) を緩和します。

デフォルト: 0

使い方のヒント

  • 適用箇所: UV ピクセル化は UV アニメーション確定直後に mainUV のみをスナップします。他の UV 駆動機能はネイティブ解像度を維持します。色 / ライト量子化はライティング後にポスタライズします。
  • レトロゲーム調のまとめ方: パースペクティブフラット・カラー量子化・ディザ・ピクセルアウトラインを組み合わせると、3D モデルが低解像度の 2D スプライトに近づきます。
  • マスク: _PixelArtMask の R チャンネルで、一部分だけデジタル化する演出ができます。
