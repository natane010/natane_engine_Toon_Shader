SSS（サブサーフェススキャッタリング）

表面下散乱（Subsurface Scattering）で肌のような半透明感

概要

SSS（サブサーフェススキャッタリング）は、オブジェクトを通過する光をシミュレートするエフェクトです。人の肌、葉、蝋燭、薄い布など、光が表面を透過して散乱する素材の表現に最適です。

キーワード _SSS で制御され、無効時はシェーダー命令が生成されません。

パラメータ

SSSの色 _SSSColor color

サブサーフェス散乱光の色を設定します。肌では赤みのある色が自然な印象になります。

デフォルト: (1, 0.5, 0.5, 1)（薄い赤）

肌には (1, 0.5, 0.5)〜(1, 0.7, 0.6) の暖色系、葉には (0.5, 1, 0.3) の緑系がおすすめです。
SSSの強さ _SSSIntensity range

サブサーフェス散乱エフェクトの全体的な強度を制御します。

デフォルト: 1.5

範囲: 0 〜 5

SSSのパワー _SSSPower range

散乱光の集中度を制御します。値が大きいほど散乱が狭い範囲に集中し、小さいほど広範囲に広がります。

デフォルト: 3

範囲: 0.1 〜 10

SSSの歪み _SSSDistortion range

散乱光の方向歪みを制御します。法線方向にどれだけ歪ませるかを設定し、より自然な散乱パターンを作ります。

デフォルト: 0.5

範囲: 0 〜 1

厚さマップ

厚さマップ _ThicknessMap texture

オブジェクトの厚さ情報を格納するテクスチャです。キーワード _THICKNESS_MAP で有効化します。薄い部分ほど光が透過しやすくなります。

デフォルト: "white"（均一な厚さ）

白 = 薄い（SSSが強い）、黒 = 厚い（SSSが弱い）。耳や鼻、指先などの薄い部分を白くペイントすると効果的です。
厚さのスケール _ThicknessScale range

厚さマップの影響度をスケーリングします。値が小さいほど厚さの差異が軽減されます。

デフォルト: 0.2

範囲: 0 〜 1

マスク

SSSマスク _SSSMask texture

SSSの適用領域を制御するマスクテクスチャです。キーワード _SSS_MASK で有効化します。

デフォルト: "white"（全面適用）

白 = SSSあり、黒 = SSSなし。肌部分のみにSSSを適用し、衣装や金属パーツは除外するのが一般的です。

ブレンド＆ブラー

ブレンドモード _SSSBlendMode enum

SSSエフェクトのブレンド方法を選択します。

  • Normal (0) - 通常の加算合成
  • Soft (1) - ソフトな加算。明るくなりすぎを防ぐ
  • Screen (2) - スクリーン合成。自然な明るさ加算
  • Overlay (3) - オーバーレイ合成。コントラスト強調

デフォルト: Normal (0)

ブレンド _SSSBlend range

SSSエフェクトの強度（不透明度）を制御します。

デフォルト: 1

範囲: 0 〜 1

ブラー _SSSBlur range

SSSエフェクトのぼかし量を調整します。

デフォルト: 0

範囲: 0 〜 1
