溶解

マテリアルが溶けて消えるトランジション効果

ディゾルブ（溶解）エフェクトは、マテリアルが徐々に消滅・分解するトランジション効果を作成します。VRChatアバターの出現・消滅アニメーションに最適で、ディゾルブ量パラメータをアニメーションさせることでオブジェクトを出現または消滅させることができます。

キーワード: _DISSOLVE

ディゾルブ設定

ディゾルブ量 _DissolveAmount range

ディゾルブの進行度を制御します。このパラメータをアニメーションキーで操作することで、出現・消滅エフェクトを実現できます。

  • 0 = 完全に表示（溶解なし）
  • 0.5 = 半分溶解
  • 1 = 完全に消滅

デフォルト: 0（範囲: 0 - 1）

VRChatでアニメーションコントローラーからこのパラメータを制御して、出現・消滅エフェクトを作成できます。
ディゾルブテクスチャ（ノイズ） _DissolveTex texture

ディゾルブのパターンを定義するノイズテクスチャです。テクスチャの明暗に基づいて溶解が進行します。

デフォルト: "white"

パーリンノイズやボロノイノイズなど、異なるパターンで多様な溶解表現が可能です。

エッジ設定

エッジの幅 _DissolveEdgeWidth range

溶解境界のエッジ（光る縁）の幅を設定します。

デフォルト: 0.1（範囲: 0 - 0.5）

エッジの色 _DissolveEdgeColor color

溶解境界に表示される光るエッジの色です。HDRカラー対応で、明るい色を設定すると発光して見えます。

デフォルト: (1, 0.5, 0, 1)（オレンジ）

炎のようなオレンジ、魔法的な青、デジタル的な緑など、世界観に合わせて選択してください。
エッジの強さ _DissolveEdgeIntensity range

溶解エッジの発光強度を設定します。値が大きいほどエッジが強く光ります。

デフォルト: 2（範囲: 0 - 10）

マスク

ディゾルブマスク _DissolveMask texture

ディゾルブの適用範囲をテクスチャで制御します。キーワード _DISSOLVE_MASK で有効化します。

デフォルト: "white"（全体に適用）

白 = ディゾルブあり、黒 = ディゾルブなし。特定の部位だけを溶解させたい場合に使用します。

ブレンド設定

ブレンドモード _DissolveBlendMode enum

ディゾルブエフェクトの合成方法を選択します。

  • Normal (0) - 通常合成
  • Soft (1) - ソフトライト
  • Screen (2) - スクリーン
  • Overlay (3) - オーバーレイ

デフォルト: 0（Normal）

ブレンド _DissolveBlend range

ディゾルブエフェクトの全体的な適用度を設定します。

デフォルト: 1（範囲: 0 - 1）

ブラー _DissolveBlur range

ディゾルブエフェクトの境界をぼかします。

デフォルト: 0（範囲: 0 - 1）
