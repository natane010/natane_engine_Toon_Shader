形状付きハイライト

反射光を丸ではなく星・ハート・十字などの形にできます。瞳の星形ハイライトや宝石の十字反射など、イラストで描き込まれる記号的な光をそのまま再現します。(v1.6.0)

PREVIEW Shaped Highlight

概要

通常の丸いスペキュラの代わりに、円 / リング / 十字 / 星 / ハート / ダイヤ / 三日月 / ライン等のプロシージャル形状 (またはカスタム SDF テクスチャ) をハイライトとして加算します。物理的な反射ではなく、アニメやイラストで描かれる記号的なハイライトを狙った機能です。

座標はハーフベクトルと法線のビュー空間偏差 (スペキュラのピーク中心) から作られるため、既存スペキュラと自然に整合します。キーワード _SHAPED_HIGHLIGHT で切り替わり、OFF 時はゼロコストです。2 つ目の形状を重ねたり、時間で明滅させることもできます。

作れる表現

  • 瞳の星形ハイライト、宝石の十字反射
  • 髪の細長いハイライト、金属の鋭い光条
  • ハート型の光、魔法アイテムの発光記号
  • 一瞬だけ現れる漫画的な光 (スパークル明滅)

主なパラメータ

形状 _ShapedHLShape enum (0〜8)

ハイライトの形を選びます: Circle / Ring / Cross / Star / Heart / Diamond / Crescent / Line / Custom。Custom を選ぶと _ShapedHLTex の SDF テクスチャを使います。

デフォルト: 3 (Star)

瞳なら Star / Heart、宝石なら Cross / Diamond が定番です。
ハイライト色 _ShapedHLColor color (HDR)

ハイライトの色です。HDR のため 1 を超える値で Bloom と組み合わせると強く発光します。

デフォルト: (1, 1, 1, 1)

サイズ _ShapedHLSize range (0.01〜2)

ハイライトの大きさです。_ShapedHLSoftness でエッジの柔らかさ、_ShapedHLStretch で縦横の伸縮を調整できます。

デフォルト: 0.5

ライト追従 / カメラ追従 _ShapedHLLightFollow / _ShapedHLCameraFollow range (0〜1)

ハイライトの回転を、ライト方向またはカメラ向きにどれだけ追従させるかです。1 で完全追従、0 で固定回転になります。

デフォルト: LightFollow 1 / CameraFollow 0

瞳のキラキラを常に正面に見せたいときは CameraFollow を上げてください。

使い方のヒント

  • スペキュラと連動: スペキュラーブロック直後に加算されます。白飛びしにくい合成 (SafeAdditiveBlend) を使うため、強度を上げても破綻しにくくなっています。
  • 2 つ重ねる: _ShapedHLShape2 / _ShapedHLIntensity2 でセカンダリ形状を追加できます (大きな星の中に小さな星、など)。
  • 明滅: _ShapedHLSparkleSpeed を上げると、瞳のキラッとした点滅を演出できます。
  • 距離フェードに対応し、遠距離では自動的にフェードします。
