水彩エフェクト

エッジの暗化・ウェットエッジ・粒状感・紙テクスチャで水彩画を再現

概要

水彩エフェクトは、4つの要素を組み合わせて水彩画の質感をシミュレーションするエフェクトです。(1) ddx/ddyの勾配に基づくエッジの暗化、(2) エッジでの彩度上昇によるウェットエッジ効果、(3) テクスチャベースの顔料粒状感、(4) スクリーンスペースの紙テクスチャオーバーレイの4段階で構成されます。

キーワード _WATERCOLOR で制御され、無効時はシェーダー命令が生成されません。

テクスチャスペースのエフェクトであり、GrabPassは不要です。全バリアント（Lite含む）で使用可能です。

パラメータ

エッジの暗化 _WCEdgeDarkening range

色の変化が激しいエッジ部分を暗くする強度を制御します。ddx/ddyによるグラデーション変化量で駆動され、水彩画でインクが溜まるエッジの表現を再現します。

デフォルト: 0.5

範囲: 0 〜 2

0.3〜0.7が自然な範囲です。1.0以上にすると強いエッジ効果が得られます。
ウェットエッジ _WCWetEdge range

エッジ付近で彩度を局所的に上昇させる効果の強度です。水彩画で水分が乾燥する際にエッジに顔料が集まる現象を再現します。smoothstepでエッジ強度に基づいて適用されます。

デフォルト: 0.3

範囲: 0 〜 1

粒状感 _WCGranulation range

顔料の粒状感（グラニュレーション）の強度を制御します。影になっている部分ほど粒状感が強調され、暗い領域にテクスチャの凹凸が目立つようになります。

デフォルト: 0.4

範囲: 0 〜 1

粒状感テクスチャ _WCGranulationTex texture

顔料の粒子感を表現するテクスチャです。Rチャンネルが参照され、UV空間でサンプリングされます。テクスチャのタイリングとオフセットが設定可能です。

デフォルト: "gray"

ノイズテクスチャや紙の繊維パターンなど、不規則な凹凸のあるテクスチャが効果的です。
紙テクスチャ _WCPaperTex texture

水彩紙の表面質感を再現するテクスチャです。Rチャンネルが参照され、スクリーンスペースでサンプリングされるため、カメラの動きに対して安定した表示になります。

デフォルト: "white"

紙テクスチャの強さ _WCPaperIntensity range

紙テクスチャの影響度を制御します。テクスチャ値は[-1,1]にリマップされて乗算されます。

デフォルト: 0.3

範囲: 0 〜 1

紙テクスチャのタイリング _WCPaperTiling float

紙テクスチャのスクリーンスペースでのタイリング倍率です。値を大きくすると紙の目が細かくなります。

デフォルト: 1

ブレンド _WCBlend range

水彩エフェクト全体の適用強度を制御します。マスクと乗算されて最終的なブレンド値になります。

デフォルト: 1

範囲: 0 〜 1

マスク

水彩マスク _WCMask texture

水彩エフェクトの適用領域を制御するマスクテクスチャです。Rチャンネルが参照されます。タイリングとオフセットが設定可能です。

デフォルト: "white"（全面適用）

白 = 水彩エフェクトあり、黒 = 水彩エフェクトなし。キャラクターの衣装は水彩風、肌はクリーンに保つといった使い分けができます。

使い方のヒント

基本的な水彩画セットアップ

エッジの暗化0.5、ウェットエッジ0.3、粒状感0.4がデフォルトのバランス設定です。紙テクスチャに実際の水彩紙のスキャン画像を使うとリアリティが向上します。

Color Bleedingとの連携

Color Bleeding（色にじみ）と組み合わせると、より本格的な水彩表現が可能です。水彩エフェクトがテクスチャスペースで質感を、Color Bleedingがスクリーンスペースで色の拡散を担当するため、相補的に機能します。

GrabPass不要の軽量設計

他のイラスト風エフェクト（Kuwahara、Color Bleeding等）と異なり、水彩エフェクトはddx/ddyとテクスチャサンプリングのみで動作するため、GrabPassが不要です。そのため、Liteバリアントでも使用可能で、パフォーマンスコストも比較的低いです。

粒状感テクスチャの選び方

粒状感の効果は影部分（shadingValue）に比例して強まります。そのため、影の濃い部分に顔料が沈殿する水彩画の物理特性を自然に再現できます。
