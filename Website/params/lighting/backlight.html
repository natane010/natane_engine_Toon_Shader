バックライト

逆光による縁の輝きとドラマチックなライティング

バックライト（逆光）はオブジェクトの背後に光がある時に照明を追加し、リムライトのような縁の輝き効果を作ります。ドラマチックな逆光演出に最適です。

逆光の強さ _BacklightIntensity range

バックライト効果の強度を制御します。0で無効、値が大きいほど逆光効果が強くなります。

デフォルト: 0

範囲: 0 〜 2

0より大きい値を設定すると、以下のバックライト詳細設定が表示されます。
逆光の色 _BacklightColor color

バックライトのカラーです。白で自然な逆光、暖色で夕焼け風、寒色で月光風の演出が可能です。

デフォルト: (1, 1, 1, 1)（白）

ブレンド _BacklightBlend range

バックライト効果のブレンド強度です。エフェクトがベースカラーにどの程度混合されるかを制御します。

デフォルト: 1

範囲: 0 〜 1

ブレンドモード _BacklightBlendMode enum

バックライトのブレンド方法を選択します。

  • Normal (0): 通常の合成
  • Soft (1): 柔らかい合成
  • Screen (2): スクリーン（明るく加算）
  • Overlay (3): オーバーレイ（コントラスト強調）

デフォルト: Normal (0)

ブラー _BacklightBlur range

バックライト効果のぼかし具合です。0でシャープ、1で最大ぼかしです。

デフォルト: 0

範囲: 0 〜 1

ぼかしを加えると、逆光の縁がより柔らかく自然な印象になります。
