アンビエントオクルージョン

接触面の影を強調してリアルな陰影を表現

アンビエントオクルージョン（AO）は、隙間や窪みなど環境光が届きにくい部分を暗くして、より立体的で柔らかい印象を与えます。衣服の折り目、髪の毛の重なり、耳の内側などの自然な陰影を表現するのに最適です。

AO マップ _AOMap texture

アンビエントオクルージョンのマップテクスチャです。白 = 影なし（明るい）、黒 = 完全な影（暗い）。キーワード: _USE_AO

デフォルト: "white"（トグルで有効化）

キャラクターの脇の下や首元などの影表現に最適です。AOマップは3Dモデリングソフトからベイクするか、手動でペイントして作成します。
AO強度 _AOIntensity range

AOの効果の強さを制御します。0で効果なし、1で最大効果です。

デフォルト: 1

範囲: 0 〜 1

推奨強度: 0.5〜0.8。強すぎると不自然な影が目立ちます。
ブレンド _AOBlend range

AO効果のブレンド強度です。エフェクトがベースカラーにどの程度混合されるかを制御します。

デフォルト: 1

範囲: 0 〜 1

ブレンドモード _AOBlendMode enum

AOのブレンド方法を選択します。

  • Normal (0): 通常の合成
  • Soft (1): 柔らかい合成
  • Screen (2): スクリーン
  • Overlay (3): オーバーレイ

デフォルト: Normal (0)

ブラー _AOBlur range

AO効果のぼかし具合です。0でシャープ、1で最大ぼかしです。

デフォルト: 0

範囲: 0 〜 1

ぼかしを加えると、AO の境界がより柔らかく自然な印象になります。テクスチャの解像度が低い場合にも有効です。
