イリデッセンス

玉虫色の虹色光沢エフェクト

見る角度によって色が変化する玉虫色（イリデッセンス）効果を追加します。光の干渉による虹色効果を再現し、シャボン玉、オイルスリック、昆虫の羽、魚の鱗など、自然界の美しい色彩変化を表現できます。

キーワード: _IRIDESCENCE

イリデッセンス設定

イリデッセンスの色 _IridescenceColor color

イリデッセンス効果のベースとなる色調を設定します。虹色の色彩変化の基準色になります。

デフォルト: (1, 1, 1, 1)（白）

強度 _IridescenceIntensity range

イリデッセンス効果の明るさ（強度）を設定します。値が大きいほど虹色効果が強くなります。

デフォルト: 0.5（範囲: 0 - 2）

色相シフト _IridescenceHueShift range

色の変化の開始位置を色相環上でオフセットします。虹色の色味を全体的にシフトさせます。

デフォルト: 0.5（範囲: 0 - 1）

サイズ（周波数） _IridescenceSize range

色の変化の周波数（細かさ）を設定します。値が大きいほど角度の変化に対して色が早く変化します。

デフォルト: 1（範囲: 0 - 10）

シャボン玉のような繊細な変化は低い値、オイルスリックのようなダイナミックな変化は高い値がおすすめです。

マスク

イリデッセンスマスク _IridescenceMask texture

R（赤）チャンネルを使用してイリデッセンスの表示領域を制御します。キーワード _IRIDESCENCE_MASK で有効化します。

  • 白 (1.0): イリデッセンスを完全に表示
  • 黒 (0.0): イリデッセンスを非表示
  • グレー: 部分的に表示

デフォルト: "white"（全体に適用）

ブレンド設定

ブレンドモード _IridescenceBlendMode enum

イリデッセンスとベースカラーの合成方法を選択します。

  • Normal (0) - 通常合成
  • Soft (1) - ソフトライト
  • Screen (2) - スクリーン
  • Overlay (3) - オーバーレイ

デフォルト: 0（Normal）

ブレンド _IridescenceBlend range

イリデッセンスエフェクトの全体的な適用度を設定します。

デフォルト: 1（範囲: 0 - 1）

ブラー _IridescenceBlur range

イリデッセンスエフェクトの境界をぼかします。

デフォルト: 0（範囲: 0 - 1）
