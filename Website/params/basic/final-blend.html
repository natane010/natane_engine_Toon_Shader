最終カラーブレンド

ハイライトの白飛び・シャドーの黒つぶれを防止するなじませ処理

ハイライトなじませ

ハイライトなじませ（白飛び防止） _FinalHighlightBlend range

明るすぎる部分（ハイライト）を自然になじませます。スムーズショルダートーンマッピングにより輝度60%以上の明るい部分を自然に圧縮し、色の鮮やかさを保ちながら白飛びを防止します。

処理フロー: (1) トーンマッピング圧縮 → (2) ハイライトブレンド（30%デサチュレーション） → (3) ジェントルクランプ（1.05まで許容）

デフォルト: 0

範囲: 0 〜 1

おすすめ設定: 通常は0.3〜0.5、強めは0.7〜0.9、最大は1.0。
ハイライト閾値 _HighlightThreshold range

この値より明るい部分に追加のハイライトブレンドが適用されます。低い値ほど広い範囲にブレンドが適用されます。

デフォルト: 0.75

範囲: 0 〜 1

推奨値は0.75。強めに効かせたい場合は0.6、最大効果の場合は0.5に設定してください。

シャドーなじませ

シャドーなじませ（黒つぶれ防止） _FinalShadowBlend range

暗すぎる部分（シャドー）を周囲となじませます。黒つぶれを防止し、ディテールを保持します。影の境界を柔らかくし、わずかにシャドーを持ち上げて自然な見た目にします。

デフォルト: 0

範囲: 0 〜 1

暗いワールドでディテールが潰れる場合に有効です。
シャドー閾値 _ShadowThreshold range

この値より暗い部分にシャドーブレンドが適用されます。高い値ほど広い範囲に効果が適用されます。

デフォルト: 0.25

範囲: 0 〜 1

推奨値は0.25。影が深い場合は0.3〜0.4に引き上げてください。
