シェーディング

トゥーンシェーディングのスタイルと影の設定

アニメ調のセルシェーディングにより、クリーンで明瞭な陰影境界を実現し、高品質なアニメ調レンダリングを提供します。ToonモードとGradientモード、またはランプテクスチャから選択できます。

シェーディングモード

モード _ShadingMode enum

シェーディングのスタイルを選択します。

  • Toon (0): 階段状のセルシェーディング。クラシックなアニメ調の表現です。
  • Gradient (1): 滑らかなグラデーションシェーディング。柔らかい印象を与えます。

デフォルト: Toon (0)

ランプテクスチャを有効にすると、このモード設定は無視されランプテクスチャに基づくシェーディングが適用されます。

グラデーション設定

Gradientモード選択時に表示されるパラメータです。

グラデーション幅 _ShadingGradientWidth range

影と光の境界の滑らかさを調整します。0.1で狭いグラデーション（シャープな境界）、0.2〜0.3で標準的なグラデーション、0.5以上で広いグラデーション（非常に柔らかい）になります。

デフォルト: 0.2

範囲: 0.001 〜 1

柔らかい印象を与えるために、0.2以上の値がおすすめです。

影の色設定

影の色（1段目） _ShadowColor color

メインの影色です。Toonモードでは1段目の影色として、Gradientモードでは影全体の色として使用されます。

デフォルト: (0.5, 0.5, 0.5, 1)

肌の影にはわずかに赤みを加えると自然に見えます。例: (0.55, 0.45, 0.45)
影の色（2段目） _Shadow2ndColor color

2段目の影色です。多段階影を有効にした場合に使用されます。1段目より濃い色を設定してください。

デフォルト: (0.35, 0.35, 0.35, 1)

2段目の境界 _Shadow2ndBorder range

2段目の影が適用される暗さの境界値です。この値より暗い部分に2段目の影色が適用されます。0.5で半分より暗い部分、0.3でやや暗い部分（推奨）、0.1で最も暗い部分のみです。

デフォルト: 0.3

範囲: 0 〜 1

影の色（3段目） _Shadow3rdColor color

3段目の影色（最も濃い影）です。多段階影を有効にした場合に使用されます。

デフォルト: (0.2, 0.2, 0.2, 1)

3段目の境界 _Shadow3rdBorder range

3段目の影が適用される暗さの境界値です。0.15〜0.2で標準的な最暗部（推奨）、0.05〜0.1で非常に暗い部分のみです。

デフォルト: 0.15

範囲: 0 〜 1

境界値は 1段目 > 2段目 > 3段目 の順に設定してください。

Toonモード設定

影のステップ数 _ShadowSteps range

セルシェーディングの段階数です。少ないステップでアニメ調、多いステップでグラデーション的な効果になります。

デフォルト: 2

範囲: 1 〜 10

推奨値: 2〜3（アニメ調）。より多いステップでグラデーション効果が得られます。
影のシャープネス _ShadowSharpness range

影の境界のシャープさを制御します。低い値でシャープな境界（アニメ調）、高い値で柔らかい境界（イラスト調）になります。

デフォルト: 0.1

範囲: 0.001 〜 1

アニメ調推奨: 0.05〜0.15

共通設定

影のオフセット _ShadowOffset range

影の境界位置を調整します。正の値で影を明るく（影領域を小さく）、負の値で影を暗く（影領域を大きく）します。

デフォルト: 0

範囲: -1 〜 1

ライト部分のソフトネス _LitSoftness range

光の当たっている部分を周囲となじませます。0でシャープな境界（デフォルト）、0.3〜0.5で適度な柔らかさ、1.0で最大のなじませ効果です。

デフォルト: 0

範囲: 0 〜 1

光の当たり方が強すぎる場合や、より滑らかなグラデーションが欲しい場合に調整してください。
影のなじませ（柔らかさ） _ShadowBlend range

影の境界を周囲となじませて、より柔らかい印象にします。0でシャープな境界（デフォルト）、0.3〜0.5で適度な柔らかさ（推奨）、0.7〜1.0で非常に柔らかい境界です。

デフォルト: 0

範囲: 0 〜 1

影の境界が鋭すぎる場合や、よりイラスト調の柔らかな影が欲しい場合に調整してください。0.7以上に設定する場合は「高度なライティング」タブの他のソフトネスパラメータも確認することを推奨します。

ランプテクスチャ

ランプテクスチャ _RampTex texture

ランプテクスチャを使用したシェーディングです。暗い色（左）から明るい色（右）へのグラデーションテクスチャを設定します。有効にするとToon/Gradientモードの代わりにランプテクスチャに基づくシェーディングが適用されます。キーワード: _USE_RAMP

デフォルト: "white"（トグルで有効化）

カスタムグラデーションで独自の影の色合いを作成できます。暖色系グラデーションで温かみのある影、寒色系で冷たい印象の影が作れます。

SDF Shadow Map

SDFマップ _SDFMap texture

SDF（距離場）Shadow Mapテクスチャです。テクスチャベースで影の位置を正確にコントロールできる高度な機能です。白 = 明るい、黒 = 影。キーワード: _SDF_MAP

デフォルト: "white"（トグルで有効化）

顔の影を細かく制御したい場合や、特定の場所に常に影を落としたい場合に使用します。
SDF強度 _SDFIntensity range

SDF影の強さを制御します。

デフォルト: 0.5

範囲: 0 〜 1

SDFソフトネス _SDFSoftness range

SDF影の境界の柔らかさです。

デフォルト: 0.1

範囲: 0 〜 1

SDFオフセット _SDFOffset range

SDF影の位置調整です。

デフォルト: 0

範囲: -1 〜 1

Shading Grade Map

Shading Grade Map _ShadingGradeMap texture

影の濃さを部分的に調整できるテクスチャです。白 = 明るく（影が薄くなる）、黒 = 暗く（影が濃くなる）、グレー = 中間。キーワード: _SHADING_GRADE_MAP

デフォルト: "white"（トグルで有効化）

顔は明るく、服は暗くなど、部位ごとに影の濃さを変えたい場合に使用します。
グレードスケール _ShadingGradeScale range

Shading Grade Mapの影響度を調整します。-1で暗く、0で変化なし、1で明るくなります。

デフォルト: 0

範囲: -1 〜 1
