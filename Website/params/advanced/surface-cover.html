サーフェスカバー

雪・砂・ほこりの表面堆積表現

概要

サーフェスカバーは、ワールド空間の法線方向に基づいて、雪・砂・ほこりなどの物質がサーフェス上に堆積する様子をシミュレートします。上向き（または指定した任意の方向）のサーフェスに、独自のアルベドテクスチャ、ノーマルマップ、カラーを持つカバーレイヤーが適用されます。カバー量、角度閾値、ブレンドシャープネスはすべて調整可能です。

この機能はシェーダー内で完結するため、追加のジオメトリやパーティクルエフェクトは不要です。VRChatワールドの環境アートに特に効果的です。

キーワード _SURFACE_COVER で制御されます。この機能はBackgroundシェーダーバリアントで使用可能です。

パラメータ

カバーカラー _CoverColor color

カバーマテリアルの基本色です。カバーテクスチャが設定されている場合、テクスチャと乗算されます。

デフォルト: (1, 1, 1, 1)（白 — 雪に最適）

雪には白、砂にはタン/ベージュ、苔にはダークグリーン、ほこりにはグレーがおすすめです。
カバー量 _CoverAmount range

サーフェスがどの程度カバーされるかを制御します。0ではカバーなし、1では対象サーフェスが完全にカバーされます。

デフォルト: 0.5

範囲: 0 - 1

カバー閾値 _CoverThreshold range

どのサーフェスにカバーが適用されるかを決定する法線角度の閾値です。カバー方向との法線の一致度がこの閾値を超えるサーフェスにカバーが適用されます。

デフォルト: 0.5

範囲: 0 - 1

低い値ではより多くのサーフェス（急な斜面を含む）がカバーされます。高い値では、最も直接的に向いているサーフェスのみにカバーが限定されます。
ブレンドシャープネス _CoverBlendSharpness float

カバーの端でどの程度鮮明に遷移するかを制御します。低い値では柔らかく緩やかなブレンディング、高い値ではくっきりとした境界が生まれます。

デフォルト: 4.0

カバータイリング _CoverTiling float

カバーマテリアルのテクスチャタイリングスケールを制御します。カバーテクスチャのスケールをオブジェクトサイズに合わせて調整してください。

デフォルト: 1.0

カバー方向 _CoverDirection vector

カバーが堆積するワールド空間の方向です。デフォルトの(0, 1, 0)は、降雪のような上から下への堆積をシミュレートします。方向を変更することで、他の方向からのカバーを作成できます。

デフォルト: (0, 1, 0)（上方向）

雪/雨には(0, 1, 0)を使用。壁の正面苔には(0, 0, 1)を使用。東からの風で吹き寄せられた砂には(-1, 0, 0)を使用。
カバーテクスチャ _CoverTex texture

カバーマテリアルのアルベドテクスチャです。テクスチャが未設定の場合、カバーカラーがフラットカラーとして使用されます。

デフォルト: "white"

カバーノーマルマップ _CoverNormalMap texture

カバーマテリアル用のノーマルマップです。雪の粒、砂の波紋、苔のテクスチャなど、カバーレイヤーに表面ディテールを追加します。

デフォルト: "bump"（フラットノーマル）

使い方のヒント

  • 雪: 白のCoverColor、Direction (0, 1, 0)で上からの堆積、雪粒のノーマルマップを使用します。
  • 砂: タン/ベージュのCoverColor、Direction (0, 1, 0)、砂漠環境には砂波のテクスチャを使用します。
  • 壁の苔: グリーンのCoverColorとDirection (0, 0, 1)で正面向きサーフェスに適用。閾値を下げると傾斜面にも広がります。
  • トライプレーナーマッピングと組み合わせることで、UV展開不要の環境にサーフェスカバーも追加できます。両機能はシームレスに連携します。
  • CoverThresholdはカバーを受けるのに必要なサーフェスの傾斜を制御します。自然な見た目には0.3〜0.7の値で試してみてください。
