スクリーンエフェクト設定

VRC向けフルスクリーンポストエフェクトをカメラに自動セットアップ

メニュー: Tools > Natane > Effects > Screen FX Setup カテゴリ: エフェクト

概要

スクリーンエフェクト設定は、VRChat向けのフルスクリーンポストエフェクトをカメラに自動セットアップするツールです。GrabPassを利用したオーバーレイ方式で、ランタイムスクリプトを使わずにPosterize（ポスタライズ）、Edge Detection（エッジ検出）、Vignette（ビネット）、Chromatic Aberration（色収差）などの画面効果を実現します。

VRChatではランタイムスクリプトの使用が制限されているため、通常のポストプロセッシングスタックが使えません。このツールはシェーダーベースのアプローチで、カメラ前面にオーバーレイメッシュを自動配置し、GrabPassで画面をキャプチャして各種エフェクトを適用します。設定はマテリアルのプロパティとして保存されるため、アバターに組み込んでアップロードするだけで機能します。

写真撮影、映像制作、VRChatイベントでの演出など、画面全体にエフェクトをかけたいシーンで活用できます。Natane Toon Shader本体の陰影表現と組み合わせることで、統一感のあるビジュアルスタイルを実現できます。

主な機能

  • GrabPassベース — ランタイムスクリプト不要。シェーダーだけで動作するため、VRChatの制限に完全対応しています
  • カメラ自動配置 — カメラ直下にオーバーレイオブジェクトを自動生成・配置。面倒な手動セットアップが不要です
  • 推奨初期値 — 各エフェクトに推奨初期値が設定済み。そのまま使えるプリセットとして機能します
  • Posterize（ポスタライズ） — 色の階調を制限してレトロ・アニメ調の表現を作成
  • Edge Detection（エッジ検出） — 画面全体にアウトラインを追加。漫画やイラスト風の演出に
  • Vignette（ビネット） — 画面周辺を暗くして視線を中央に誘導する映画的な効果
  • Chromatic Aberration（色収差） — RGB色ずれによるレンズ風の効果を追加
  • Scanline（スキャンライン） — CRTモニター風の走査線効果

使い方

  1. カメラを選択

    シーン内のカメラオブジェクトを選択します。未選択の場合はMainCameraが自動的に使用されます。VRChatアバターの場合は、Head内のカメラを選択してください。

  2. セットアップを実行

    Tools > Natane > Effects > Screen FX Setup を実行します。カメラ直下にオーバーレイオブジェクトとマテリアルが自動生成されます。

  3. マテリアルを調整

    生成されたマテリアルのInspectorで各エフェクトを調整します。Posterize、Edge Detection、Vignette、Chromatic Aberration の各パラメータをお好みの値に設定してください。

  4. プレビューで確認

    Game ビューまたは Scene ビューでエフェクトの効果を確認します。パラメータの変更はリアルタイムに反映されます。

Tips

  • Quest向けはChromatic AberrationとScanlineを低めに設定して、パフォーマンスへの影響を最小限に抑えましょう
  • Overlayはカメラ直下に維持して、位置ズレを防止してください。手動で移動するとエフェクトが正しく表示されない場合があります
  • Natane Toon本体の陰影表現を活かす場合は、Edgeの強度を0.2前後から調整を始めるのがおすすめです
  • Posterizeの階調数を3〜5に設定すると、アニメ風のフラットな色合いが得られます
  • Vignetteは0.3〜0.5程度で控えめに使うと、自然な映画的雰囲気を演出できます
  • 複数のエフェクトを同時に使う場合は、それぞれの強度を控えめにして全体のバランスを取りましょう
