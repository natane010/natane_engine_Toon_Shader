ビルド時最適化

ビルド・VRChatアップロード時にシェーダーとマテリアルを自動最適化 (v1.6.0)

実行タイミング: ビルド時に自動実行（手動操作不要） カテゴリ: 最適化

概要

Natane Toon Shader は、ビルド時（特に VRChat アバターのアップロード時）にシェーダーとマテリアルを自動的に最適化する仕組みを備えています。ユーザーの操作は不要で、複数のコンポーネントがビルドパイプラインの各段階で連携して動作します。

仕組み

  • ビルド前 (NataneBuildFeatureOptimizer) — 使用機能だけを #define したビルド設定を生成し、未使用キーワードをソースレベルで #undef します
  • シーン処理時 (NataneBuildSceneKeywordSync) — 全マテリアルのキーワードをプロパティ値と同期してディスク保存します（VRChat の AssetBundle ビルド対応）
  • シェーダーコンパイル時 (NataneShaderVariantStripper) — IPreprocessShaders により、どのマテリアルからも使われていないキーワードを含むコンパイル済みバリアントを破棄します
  • ビルド後 (NataneBuildOptimizationReport) — 最適化サマリをコンソールと Logs/NataneBuildOptimizationReport.txt に出力します
  • VRChatアバタービルド前 (NataneVRChatBuildHook) — キーワード同期と Lite 変換候補の提案を行います（VRChat SDK 導入時のみ有効）

最適化レポートの内容

  • 破棄されたバリアント数 — バリアントストリップの集計値（before → after はコンソールにもログ出力）
  • 無効化された機能 — 既知キーワードのうち、どのマテリアルでも未使用のもの一覧
  • Lite 変換候補 — GrabPass機能（屈折・Kuwahara・カラーブリーディングなど）を使っていないフル版マテリアル一覧
  • テクスチャ改善提案 — 2048超の maxSize、未圧縮テクスチャなど（提案のみ・自動変更なし）

安全性

  • バリアント破棄の判定対象は既知の Natane キーワードのみです。multi_compile 由来のビルトインキーワード（DIRECTIONAL / SHADOWS_SCREEN / INSTANCING_ON など）には一切触れません
  • キーワード状態と Toggle プロパティ値のどちらかが有効なら「使用中」とみなす安全側の判定です

Tips

  • バリアントストリップを一時的に無効化したい場合は EditorPrefs のキー NataneToon_DisableVariantStripping を true に設定します
  • VRChatのアバタービルドではビルド後レポートは呼ばれないため、Lite 提案は VRChat ビルドフック側でも出力されます
  • 手動での事前最適化にはバリアントストリッピングやシェーダーバリアント収集も利用できます
