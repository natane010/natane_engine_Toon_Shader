アセット参照チェッカー

シーン・プレハブ・マテリアルの欠損/破損参照を検出

メニュー: Tools > Natane > 最適化 Optimization > アセット参照チェック Asset Reference Checker カテゴリ: 最適化

概要

アセット参照チェッカーは、シーン、プレハブ、マテリアルに含まれる欠損・破損した参照を包括的に検出するツールです。Missing Script、欠損マテリアル、テクスチャ未設定、シェーダーエラー、null参照などを3つのスキャンモードで検出し、問題の重要度（エラー/警告/情報）別に分類して表示します。

アクセス方法

メニュー: Tools > Natane > 最適化 Optimization > アセット参照チェック Asset Reference Checker

機能

3つのスキャンモード

  • シーンモード - 現在開いているシーン内の全GameObjectをスキャン。非アクティブオブジェクトを含むかどうかを選択可能
  • プレハブモード - 指定したプレハブ、またはプロジェクト全体のプレハブをスキャン
  • マテリアルモード - プロジェクト内のマテリアルをスキャン。Natane Toon Shaderのみに絞り込むフィルター付き

検出する問題の種類

  • Missing Script（エラー）- コンポーネントに紐づくスクリプトが見つからない
  • Missing Material（エラー）- Rendererのマテリアルスロットがnull
  • Missing Shader（エラー）- マテリアルのシェーダーがnullまたはエラー状態（Hidden/InternalErrorShader）
  • Missing Texture（警告/情報）- マテリアルのテクスチャプロパティが未設定（_MainTexは警告、その他は情報）
  • Null Reference（警告）- コンポーネントのオブジェクト参照が破損している

結果表示

  • 結果サマリー - エラー/警告/情報の件数をカラー表示
  • フィルタリング - エラー・警告・情報を個別にフィルタリング
  • 詳細展開 - 各問題のコンポーネント名・プロパティ名・アセットパスを確認可能
  • オブジェクト選択 - 「Select」ボタンで問題のあるオブジェクトを直接選択・ハイライト
  • Console出力 - 検出結果をUnity Consoleにエクスポート

使い方

  1. ツールバーからスキャンモード（シーン/プレハブ/マテリアル）を選択します
  2. モード固有の設定を行います：
    • シーン: 「非アクティブオブジェクトを含む」の切り替え
    • プレハブ: ターゲットプレハブの指定、または「プロジェクト全体スキャン」
    • マテリアル: 「Natane Toon Shaderのみ」フィルターの切り替え
  3. スキャンボタンを押して検出を開始します（進捗バーが表示されます）
  4. 結果サマリーで問題の全体像を確認します
  5. フィルタを使って重要度別に問題を絞り込みます
  6. 各問題の「Select」ボタンで対象オブジェクトに移動して修正します
  7. 必要に応じて「Consoleに出力」で結果をログに書き出します

Tips

  • VRChatアップロード前にシーンモードでスキャンして、Missing Scriptやnull参照を事前に検出しましょう
  • プレハブモードの「プロジェクト全体スキャン」は大規模プロジェクトでは時間がかかる場合があります
  • マテリアルモードでは_MainTexが未設定の場合は警告、その他のテクスチャは情報レベルで報告されます
  • スキャンは途中でキャンセルできます（進捗バーのキャンセルボタン）
  • Console出力を使えば、検出結果をテキストとして保存・共有できます
