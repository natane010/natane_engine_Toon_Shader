GPUパーティクルメッシュ生成

ステートレスGPUパーティクル用のクアッドクラウドメッシュを生成 (v1.6.0)

メニュー: Tools > Natane > メッシュ Mesh > GPUパーティクルメッシュ生成 GPU Particle Mesh カテゴリ: エフェクト

概要

GPUパーティクルメッシュ生成は、シェーダー Natane/Effects/GPU Particles (Stateless) 用の静的な「クアッドクラウド」メッシュを生成・保存するツールです。GPUパーティクルは完全ステートレス設計で、シミュレーション・CustomRenderTexture・カメラ・GrabPass・実行時スクリプトを一切使用しません。すべてのアニメーションは _Time とメッシュに焼き込んだ乱数シードから計算されるため、VRChatアバターにそのまま乗せても安全です。

同じくステートレスな数式ベースの液体表現シェーダー Natane/Effects/Fake Fluid（疑似流体: 充填量・揺れ・泡・フレネル・トゥーン陰影）も v1.6.0 で追加されています。こちらは容器メッシュに割り当てるだけでメッシュ生成は不要です。

アクセス方法

メニュー: Tools > Natane > メッシュ Mesh > GPUパーティクルメッシュ生成 GPU Particle Mesh

機能

  • パーティクル数 — 既定 256、最大 4096。1パーティクル = 1クアッド（4頂点）
  • スプレッド — エミッション範囲（XYZボックス）の指定
  • 乱数シード — 再現可能な乱数でメッシュを生成
  • 基本ティント / ばらつき — パーティクル毎の色を頂点カラーへ焼き込み
  • .asset保存 — SaveFilePanelInProject でプロジェクト内にメッシュアセットとして保存

使い方

  1. ツールを開き、パーティクル数・スプレッド・シード・ティントを設定します
  2. クアッドクラウドメッシュを生成し、.asset として保存します
  3. 生成したメッシュを空の GameObject の MeshFilter に割り当て、MeshRenderer を付けます
  4. マテリアルに Natane/Effects/GPU Particles (Stateless) を割り当てます
  5. モーションモード（Rise / Fall / Orbit / Burst）とサイズ・速度・フェードなどを調整します

技術詳細

モーションモード (_MotionMode)

  • 0: Rise — 火の粉 / 蛍。上昇 + サイン揺らぎ
  • 1: Fall — 桜吹雪 / 雪。下降 + 横ドリフト + ビルボード回転
  • 2: Orbit — キラキラ。オブジェクト原点周りを周回
  • 3: Burst — シード周期で中心から放射

メッシュ規約

  • 4頂点すべてが同じ中心座標を持ち、角のオフセットは UV0 と _ParticleSize から頂点シェーダーで復元
  • UV0: クアッドの角（各成分 0 or 1）。スプライトUVも兼ねる
  • UV1.x: パーティクル乱数シード [0,1) / UV1.y: パーティクルインデックス正規化 [0,1]
  • 頂点カラー: パーティクル毎のティント

Tips

  • パーティクル位置は _Time.y * _Speed + seed * _CyclePeriod の純粋関数で、frac() によりシームレスにループします
  • AudioLink変調にも対応しており、クラブイベントでの音楽連動演出に使えます
  • Additiveブレンド / ZWrite Off / Queue Transparent / VRCFallback = Particle でレンダリングされます
  • 軽量トゥーンパーティクル用には別途シェーダーバリアント Natane/Toon Shader (Particle)（ブレンドモード切替・ソフトパーティクル・フリップブック・カメラフェード）も利用できます
