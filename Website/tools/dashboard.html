ダッシュボード

プロジェクトの状態を一覧で確認

メニュー: Tools > Natane > Dashboard カテゴリ: 全般

概要

ダッシュボードは、Natane Toon Shaderに関するプロジェクトの状態を俯瞰できる総合ツールです。使用中のマテリアル数、パフォーマンス概要、有効化されている機能の統計、最近の変更履歴などをひと目で確認でき、プロジェクト管理の起点となるウィンドウです。

主な機能

  • Natane Toon Shaderを使用しているマテリアルの一覧と数の表示
  • マテリアルごとのパフォーマンスレーティング（A/B/C/D）の概要
  • 有効化されている機能の統計情報
  • 各ツールへのクイックアクセスリンク
  • シェーダーバージョン情報の表示

使い方

  1. Unityメニューから Tools > Natane > Dashboard を開きます
  2. プロジェクト内のNatane Toonマテリアルが自動的にスキャンされます
  3. 各セクションでマテリアルの状態を確認します
  4. 問題がある場合は、対応するツールへのリンクから直接修正できます

Tips

  • プロジェクト全体のパフォーマンス状況を把握するための最初のステップとして活用してください
  • VRChatアップロード前にダッシュボードでパフォーマンス概要を確認すると安心です
  • マテリアル数が多い場合、スキャンに少し時間がかかることがあります
