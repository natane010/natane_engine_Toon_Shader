ヒエラルキー一括編集

ヒエラルキー配下のNataneToonマテリアルをインスペクターUIで一括編集

メニュー: Tools > Natane > マテリアル Material > ヒエラルキー一括編集 Hierarchy Batch Editor カテゴリ: マテリアル

概要

ヒエラルキー一括マテリアル編集ツールは、指定したルートGameObject配下にあるNatane Toon Shaderを使用した全マテリアルを自動検出し、Unityのマテリアルインスペクターと同一のUIで一括編集できるエディタウィンドウです。複数のマテリアルを同時に選択して、リアルタイムで変更を反映させることができます。

アクセス方法

メニュー: Tools > Natane > マテリアル Material > ヒエラルキー一括編集 Hierarchy Batch Editor

機能

  • ヒエラルキースキャン - ルートオブジェクト配下の全Rendererからnatane Toon Shaderマテリアルを自動検出
  • 重複排除 - 同一マテリアルが複数のRendererで使用されていても1つだけ表示
  • ヒエラルキーパス表示 - 各マテリアルがどのオブジェクトに使用されているかパスで確認可能
  • 選択式一括編集 - チェックボックスで編集対象のマテリアルを個別に選択/解除
  • 全選択/全解除 - ワンクリックでマテリアルの選択状態を一括変更
  • 埋め込みマテリアルエディタ - NataneToonShaderGUIのフルインスペクターをウィンドウ内に埋め込み表示
  • リアルタイム反映 - 変更はリアルタイムでシーン内の全対象マテリアルに適用
  • マテリアルプレビュー - 埋め込みエディタのヘッダーにマテリアルプレビュー球を表示

使い方

  1. ツールウィンドウの「ルートオブジェクト」フィールドに、編集したいアバターやオブジェクトのルートGameObjectをドラッグ&ドロップします
  2. 「スキャン」ボタンを押して、ヒエラルキー配下のNatane Toon Shaderマテリアルを検索します
  3. マテリアル一覧から編集対象のマテリアルをチェックボックスで選択します（デフォルトでは全て選択されています）
  4. マテリアルエディタセクションで、通常のインスペクターと同じUIでプロパティを編集します
  5. 変更はリアルタイムで全ての選択中マテリアルに同時適用されます

ワークフロー例

アバター全体のシャドウカラーを統一する

  1. アバターのルートオブジェクトを設定してスキャン
  2. 全マテリアルが選択された状態でシャドウカラーを変更
  3. 全マテリアルに一括で同じシャドウカラーが適用される

特定パーツのみ編集する

  1. スキャン後、「全て解除」ボタンで選択をリセット
  2. 編集したいマテリアルだけをチェック
  3. 選択したマテリアルのみに変更が適用される

Tips

  • 非アクティブなオブジェクトのマテリアルもスキャン対象に含まれます
  • ルートオブジェクトを変更すると、前回のスキャン結果は自動的にクリアされます
  • ヒエラルキーパスを確認して、どのパーツのマテリアルかを識別できます
  • VRChatアバターの場合、アバターのルートオブジェクトを指定するとボディ・衣装・髪のマテリアルを一括で調整できます
