全プリセット再生成

現在の設定で全プリセットを一括再生成

メニュー: Tools > Natane > Regenerate All Presets カテゴリ: プリセット

概要

全プリセット再生成ツールは、既存のすべてのマテリアルプリセットを現在のシェーダー設定で再生成するユーティリティです。シェーダーのアップデート後にプリセットを最新の状態に更新したり、サムネイルプレビューを再生成する場合に使用します。

主な機能

  • 全プリセットの一括再生成
  • サムネイル画像の一括再生成
  • パフォーマンスレーティングの再計算
  • 新しいシェーダー機能への対応更新
  • 進捗バー付きのバッチ処理

使い方

  1. Unityメニューから Tools > Natane > Regenerate All Presets を実行します
  2. 再生成の確認ダイアログが表示されます
  3. 「OK」をクリックすると全プリセットの再生成が開始されます
  4. 進捗バーで処理状況を確認します
  5. 完了後、プリセットブラウザで更新を確認します

Tips

  • シェーダーのメジャーアップデート後に実行することをおすすめします
  • プリセット数が多い場合、処理に数分かかることがあります
  • カスタムプリセットも含めて再生成されるため、事前にバックアップを取ることを推奨します
  • サムネイルが正しく表示されない場合にも、このツールで修復できます
