パフォーマンスバジェット

マテリアルのパフォーマンスコストを可視化し、予算内に収まるよう管理

メニュー: Tools > Natane > 最適化 Optimization > パフォーマンスバジェット Performance Budget Tool カテゴリ: 最適化

概要

パフォーマンスバジェットツールは、マテリアルのGPUコストと推定Samplerリスクをまとめて可視化し、プラットフォーム別の予算内に収まるよう管理するためのツールです。各シェーダー機能がどの程度のGPU負荷をかけるかをポイント制で表示しつつ、D3D11で詰まりやすいSampler組み合わせも同時に確認できます。

Natane Toon Shaderは多くの機能を備えていますが、GPUコストが低くてもSampler制限で詰まる場合があります。このツールを使えば、有効にしている各機能のGPUポイントとSampler寄与を一覧で確認でき、どの機能を優先的に見直すべきかを判断できます。

特にVRChatのPCアバターで Light Volume や LTCGI、髪のマスク、追加テクスチャを併用する場合に有用です。Quest向けには従来どおりGPUコストの軽量化指標としても使えます。

主な機能

  • プラットフォーム別GPU予算 — PC版とQuest版で異なるGPU予算を設定。各プラットフォームの負荷感に合わせた基準で評価します
  • 機能コスト計算 — 各シェーダー機能（リムライト、マットキャップ、スペキュラ、屈折など）のGPU負荷をポイント化して表示
  • Samplerリスク統合 — 推定Sampler数、危険な組み合わせ、上限付近かどうかを同じ画面で確認
  • 最適化提案 — GPUコスト超過時やSampler危険域で、優先的に見直す候補を表示
  • 機能の直接無効化 — 一覧から重い機能をその場で無効化して再確認できます

使い方

  1. ツールを開く

    Tools > Natane > 最適化 Optimization > パフォーマンスバジェット Performance Budget Tool からツールウィンドウを開きます。

  2. マテリアルを選択

    分析したいマテリアルをProjectビューから選択するか、ドラッグ&ドロップで追加します。アバター全体を分析する場合は、シーン上のアバターオブジェクトを選択します。

  3. プラットフォームを選択

    ターゲットプラットフォーム（PC / Quest）を選択します。プラットフォームによって予算の上限が変わります。

  4. コスト分析を確認

    各機能のGPUコスト、Sampler寄与、合計ポイント、Sampler警告を確認します。GPU負荷とSampler制限は別々に見て判断するのがコツです。

  5. 最適化を実施

    提案された最適化を参考に、不要な機能を無効化してパフォーマンスを改善します。

Tips

  • Quest向けアバターは40ポイント以下を目標にしましょう。これはGPU負荷の目安です
  • PC向けでも Light Volume + LTCGI + Hatching の組み合わせはSampler制限に注意してください
  • 不要な機能は積極的に無効化しましょう。Natane Toon Shaderはキーワードベースの分岐を使用しているため、無効化した機能のGPU負荷はゼロになります
  • 屈折（Refraction）や水彩、複数MatCapはGPUコストが高めです。Quest版では慎重に使用してください
  • 追加テクスチャや髪表現を盛る場合は、Inspector の「推定 Sampler 負荷」と併用して確認するのが安全です
