デフォルトプリセット生成

標準マテリアルプリセットの自動生成

メニュー: Tools > Natane > Generate Default Presets カテゴリ: プリセット

概要

デフォルトプリセット生成ツールは、Natane Toon Shaderの標準マテリアルプリセットを自動的に生成するユーティリティです。シェーダーの機能を活用した様々なスタイルのプリセットが用意されており、プリセットブラウザで使用するサムネイル画像も同時に生成されます。

主な機能

  • カテゴリ別のデフォルトプリセット一括生成
  • サムネイルプレビュー画像の自動生成
  • パフォーマンスレーティングの自動計算と設定
  • プリセット説明文の自動付与
  • 既存プリセットの上書き確認

使い方

  1. Unityメニューから Tools > Natane > Generate Default Presets を実行します
  2. 生成するプリセットカテゴリを選択します
  3. 出力先フォルダを確認します
  4. 「生成」をクリックしてプリセットファイルを作成します
  5. プリセットブラウザで生成されたプリセットを確認します

生成されるプリセットカテゴリ

  • Character - 肌（柔らかい影）、髪（光沢）、服（多階調シャドウ）など
  • Props - 金属、木材、布、プラスチックなど素材別プリセット
  • Environment - 建物、岩、草木など背景素材
  • Effects - ホログラム、グリッチ、ディゾルブなどエフェクト系
  • Style_Toon - シャープアニメ、ソフトトゥーンなどスタイル別
  • Style_NPR - 水彩、油絵、鉛筆画などNPRスタイル

Tips

  • 初回セットアップ時に実行して、プリセットライブラリを構築してください
  • プリセットはScriptableObjectとして保存されるので、カスタマイズも可能です
  • バージョンアップ時に新しいプリセットが追加される場合があります
