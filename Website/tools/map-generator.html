マップジェネレーター

Albedo テクスチャとメッシュから各種テクスチャマップを自動生成するツール

メニュー: Tools > MapGenerator > Map Generator Window カテゴリ: テクスチャ生成

概要

マップジェネレーターは、Albedo テクスチャとメッシュジオメトリから Normal / AO / Curvature / Roughness / Shadow / Control Map を自動生成するツールです。GPU Compute Shader による高速処理と、Compute 非対応環境向けの CPU フォールバックを備えています。生成したマップは NataneToon Shader のプロパティに自動割り当てされます。

アクセス方法

  • NataneToon マテリアルインスペクター: AO セクション内の「★ 全マップ一括生成」ボタン、または各マップの個別生成ボタン
  • コンポーネント: MapGenerator コンポーネントをアタッチ → インスペクターから操作
  • メニュー: Tools > MapGenerator > Map Generator Window
  • 右クリック: Renderer / MeshFilter / SkinnedMeshRenderer コンポーネントのコンテキストメニュー

生成可能なマップ

Normal Map（ノーマルマップ）

  • メッシュの曲率と頂点位置からハイトマップを生成し、Sobel フィルタで法線マップに変換
  • Albedo テクスチャのディテールもブレンド（メッシュ 70% + Albedo 30%）
  • 割り当て先: _BumpMap + _NORMALMAP キーワード有効化
  • パラメータ: 強度 (Strength)、ぼかし半径 (Blur Radius)

AO Map（アンビエントオクルージョンマップ）

  • 各頂点から半球方向に Fibonacci 分布でレイキャスト、遮蔽率を計算
  • レイヤー31に一時コライダーを配置して物理干渉を回避
  • 割り当て先: _AOMap + _USE_AO キーワード有効化
  • パラメータ: レイ数、最大距離、強度、ダイレーション

Curvature Map（カーブチャーマップ）

  • 隣接頂点の法線差分から曲率を計算（0.5 = 平面、>0.5 = 凸、<0.5 = 凹）
  • 割り当て先: _CavityMap
  • パラメータ: 倍率、ダイレーション

Roughness Map（ラフネスマップ）

  • Albedo テクスチャの輝度と彩度からラフネスを推定
  • スムーズネスへの反転オプション付き
  • 割り当て先: _RoughnessMap + _USE_ROUGHNESS_MAP キーワード有効化
  • パラメータ: ベースライン、輝度の影響、彩度の影響、ぼかし半径

Shadow Map（シャドウマップ）

  • 指定したライト方向から散布角付きレイキャストで遮蔽を計算
  • Scene ビューで黄色のハンドルをドラッグしてライト方向を調整可能
  • 割り当て先: _ShadowReceiveMask
  • パラメータ: ライト方向、レイ数、拡散角度、強度、ダイレーション

Control Map（コントロールマップ）

  • 生成した各マップの R チャンネルを RGBA にパッキング
  • 各チャンネルのソースを自由に選択（AO / Curvature / Roughness / Shadow / None）
  • パラメータ: R / G / B / A チャンネルソース

使い方

方法1: NataneToon インスペクターから（最も簡単）

  1. NataneToon シェーダーを使用しているマテリアルを選択
  2. AO セクションを展開
  3. 「★ 全マップ一括生成」ボタンをクリック
  4. 全マップが自動生成され、対応プロパティに割り当てられます

方法2: MapGenerator コンポーネント

  1. Renderer を持つ GameObject に MapGenerator コンポーネントをアタッチ
  2. Albedo テクスチャとメッシュが自動検出されます
  3. 各マップのパラメータを調整
  4. 「★ 全マップ生成」ボタンで一括生成、または各セクションの個別ボタンで生成

方法3: 詳細ウィンドウ

  1. Tools > MapGenerator > Map Generator Window を開く
  2. ターゲットの MapGenerator コンポーネントを選択
  3. 左パネルでパラメータ調整、右パネルでプレビュー確認
  4. 「★ 全マップ生成」で実行

技術仕様

  • GPU 処理: 5つの Compute Shader（UVBake, GaussianBlur, NormalFromHeight, Dilation, ChannelPack）
  • CPU フォールバック: Compute Shader 非対応環境でも全機能動作
  • UV ベイク: 三角形ラスタライゼーションで頂点データを UV 空間にベイク
  • ダイレーション: UV 継ぎ目の隙間を近傍ピクセルで自動塗りつぶし
  • SkinnedMeshRenderer 対応: BakeMesh でポーズ状態のメッシュを取得
  • 出力形式: PNG / TGA / EXR

Tips

  • AO と Shadow Map はメッシュのレイキャストを使用するため、シーンにオブジェクトが配置されている必要があります
  • 大規模メッシュ（10万頂点以上）では AO / Shadow の生成に時間がかかる場合があります。プログレスバーからキャンセル可能です
  • Normal Map はメッシュの曲率 + Albedo ディテールのブレンドで生成されるため、メッシュだけ or Albedo だけでも動作します
  • Scene ビューで Shadow Map のライト方向ハンドル（黄色矢印）をドラッグして方向を調整できます
  • 言語切り替えボタンで日本語 / English を切り替えられます
  • Ctrl+Z で Undo が効きます
