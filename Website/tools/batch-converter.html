一括マテリアル変換

複数のマテリアルを一括でNatane Toon Shaderに変換する汎用ツール

メニュー: Tools > Natane > Migration > Batch Converter カテゴリ: 移行

概要

一括マテリアル変換は、任意のシェーダーからNatane Toon Shaderへのマテリアル変換を一括で行う汎用マイグレーションツールです。lilToonのような専用移行ツールがないシェーダーからの移行にも対応しています。

このツールは、指定したシェーダーを使用しているマテリアルをプロジェクト全体から検出し、リスト表示します。変換元シェーダーのプロパティ名が同じであれば自動的にマッピングされ、異なる場合は手動でマッピングを設定できます。テクスチャプロパティについては、_MainTexや_BumpMapなどの一般的なプロパティ名は自動認識されます。

大規模プロジェクトでシェーダーを統一したい場合や、Standard ShaderやUnlit Shaderなどの基本シェーダーからの移行、サードパーティシェーダーからの移行など、幅広い用途で使えます。変換前にバックアップ機能でマテリアルを安全に保護でき、変換後の結果もUndo可能です。

主な機能

  • 複数マテリアル一括処理 — 選択したすべてのマテリアルを一度に変換。大規模プロジェクトの移行を効率化
  • フォルダ指定 — 特定のフォルダを指定して、そのフォルダ内のマテリアルのみを変換対象にできます
  • プロパティ保持 — 変換元と変換先で同名のプロパティは自動的に値を引き継ぎ。テクスチャ、色、数値パラメータに対応
  • バックアップ — 変換前にマテリアルのバックアップを自動作成。問題が発生した場合の復元に使用
  • フィルタリング — シェーダー名やマテリアル名でフィルタリングして、変換対象を絞り込み可能
  • 変換レポート — 変換完了後、成功/失敗/スキップされたマテリアルの詳細レポートを表示

使い方

  1. 変換元シェーダーを選択

    変換したいマテリアルが現在使用しているシェーダーを選択します。プロジェクト内で使用中のシェーダー一覧がドロップダウンで表示されます。

  2. マテリアルリストを確認

    選択したシェーダーを使用しているマテリアルの一覧が表示されます。変換したくないマテリアルはチェックボックスで除外できます。

  3. 設定

    変換先のバリアント（Opaque / Cutout / Transparent）、プロパティマッピング、バックアップの有無を設定します。

  4. 一括変換

    「一括変換」ボタンで変換を実行します。プログレスバーで進捗が表示され、完了後にレポートが表示されます。

Tips

  • バックアップ機能は必ず有効にしておきましょう。予期しない変換結果が出た場合に復元できます
  • Standard Shaderからのテクスチャマッピングはほぼ自動で行われます（_MainTex、_BumpMap、_MetallicGlossMap など）
  • 変換後は必ずSceneビューで見た目を確認し、必要に応じて影の色やリムライトなどのトゥーンシェーダー固有の設定を追加してください
  • 大量のマテリアルを一度に変換する場合は、フォルダ単位で段階的に進めると管理しやすくなります
  • 変換レポートに「スキップ」と表示されたマテリアルは、プロパティの互換性がなかった可能性があるため、手動で確認してください
