ステンシルプリセット

覗き窓・隠し模様などのステンシル演出をワンクリック適用 (v1.6.0)

場所: マテリアルインスペクタ > Advanced タブ > レンダリング設定 > Stencil > プリセット カテゴリ: シェーダー

概要

ステンシルプリセットは、ステンシルバッファを使った「マスク越しにだけ見える」演出に必要な設定を、マテリアルインスペクタからワンクリックで適用する機能です。Ref / Comp / Pass の組み合わせを覚えなくても、覗き窓・隠し模様・消える体といったステンシル演出を組めます。

アクセス方法

マテリアルインスペクタ: Advanced タブ > レンダリング設定 > Stencil > プリセット

プリセット一覧

  • 標準 — Ref=0, Comp=Always, Pass=Keep。ステンシル不使用（既定）
  • 書き込み — Ref=1, Comp=Always, Pass=Replace。マスク領域を書き込む側（レンズ・窓・魔法陣など）
  • 一致で表示 — Ref=1, Comp=Equal, Pass=Keep。マスク越しにだけ見える側
  • 不一致で表示 — Ref=1, Comp=NotEqual, Pass=Keep。マスク領域では消える側

使い方

  1. マスクにするマテリアル（例: 眼鏡のレンズ、窓、魔法陣）に「書き込み」プリセットを適用します
  2. 書き込み側の Render Queue を表示側より小さくして、先に描画されるようにします
  3. マスク越しに見せたいマテリアルに「一致で表示」を適用します（マスク領域で消したい場合は「不一致で表示」）
  4. 複数系統のマスクを使う場合は、参照値（1〜255）を系統ごとに変えます

演出例

  • 覗き窓: レンズ=書き込み、レンズ越しにだけ見える「本当の姿」=一致で表示
  • 隠し模様: 特定のアイテムをかざしたときだけ見えるタトゥー・紋章
  • 消える体: 魔法陣の上では体の一部が消える（不一致で表示）

Tips

  • VRChatでは他人のシェーダーもステンシルバッファを共有します。Ref値は控えめにユニークな値を選ぶと事故が減ります
  • プリセット適用後も Ref / Comp / Pass は手動で微調整できます
  • 鏡・カメラを使った不思議演出には鏡・カメラ写り分けテクスチャとの組み合わせも有効です
