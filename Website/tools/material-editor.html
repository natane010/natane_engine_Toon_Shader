複数マテリアルの一括処理

メニュー: Tools > Natane > Batch Material Processor カテゴリ: マテリアル

概要

一括マテリアル処理ツールは、複数のマテリアルに対してパラメータ調整、色の変更、テクスチャ置換、機能の切り替えなどを一度に実行できる強力なバッチ処理ツールです。大量のマテリアルを扱うプロジェクトでの作業効率を大幅に向上させます。

主な機能

  • パラメータの一括調整（Set/Multiply/Add モード対応）
  • カラーの一括変更
  • テクスチャの一括置換
  • シェーダー機能の一括切り替え（ON/OFF）
  • シェーダーバリアントの一括変換（Opaque/Cutout/Transparent）

使い方

  1. マテリアルリストから処理対象のマテリアルを追加します
  2. 操作タブを選択します: パラメータ / 色 / テクスチャ / 機能 / バリアント
  3. 選択した操作の値を設定します
  4. 「プレビュー」で適用前に変更内容を確認します
  5. 「すべてに適用」ですべてのマテリアルを一括処理します

操作モード

パラメータ調整

  • Set - 指定した値に直接設定します
  • Multiply - 現在の値に係数を乗算します（相対的な調整に便利）
  • Add - 現在の値に値を加算します

テクスチャ置換

  • 特定のプロパティスロットのテクスチャを一括で差し替え
  • テクスチャのタイリングとオフセットも一括設定可能

Tips

  • 「Set」モードで正確な値を設定できます
  • 「Multiply」で相対的な調整が可能です（例: 全マテリアルのアウトライン幅を1.5倍に）
  • 一括操作前に必ずバックアップをとりましょう（Undo対応済みですが、念のため）
  • プレビュー機能を活用して意図しない変更を防ぎましょう
