シェーダープリウォーミング

シェーダーバリアントを事前コンパイルしてゲームプレイ中のスタッターを防止

メニュー: Tools > Natane > シェーダー Shader > シェーダープリウォーミング Shader Prewarming カテゴリ: シェーダー

概要

シェーダープリウォーミングは、シェーダーバリアントを事前にコンパイル（ウォームアップ）し、ゲームプレイ中のシェーダーコンパイルによるスタッター（カクつき）を防止するツールです。VRChat対応のエディタ専用プリウォーミングと、非VRChatプロジェクト向けのランタイムプリウォーミングの2つのモードを備えています。

Unityでは、シェーダーバリアントが初めて描画される際にコンパイルが発生し、一時的なフレームレートの低下（スタッター）が起こることがあります。このツールは、ビルド前またはエディタ上でシェーダーを事前コンパイルすることで、この問題を解消します。

このツールはUnityのビルドパイプラインAPI（IPreprocessBuildWithReport）を実装しており、ビルド前に自動的にプリウォーミングを実行できます。また、ShaderVariantCollectionが空の場合は、プロジェクト内のマテリアルからバリアントを自動収集する機能も備えています。

主な機能

  • ビルド前自動プリウォーミング — IPreprocessBuildWithReportを実装し、ビルド前に自動的にシェーダーをプリウォーム。ShaderVariantCollectionが空の場合はマテリアルから自動収集も実行します
  • ShaderVariantCollectionウォームアップ — 既存のShaderVariantCollectionを検出し、含まれるすべてのバリアントをウォームアップ。Assets配置とUPMパッケージ配置の両方をサポートします
  • マテリアル自動検索・ウォームアップ — プロジェクト内のすべてのNatane Toonマテリアルを自動検索し、一時的なShaderVariantCollectionを作成してターゲット指定でウォームアップします
  • マテリアルからの自動バリアント収集 — ShaderVariantCollectionが空の場合、プロジェクト内のマテリアルからキーワードの組み合わせを収集し、ForwardBase/ForwardAdd/ShadowCaster/Metaの各パスタイプに対応するバリアントを自動登録します
  • 12種類のシェーダー対応 — Natane Toon Shaderの全バリアント（Toon Shader、Cutout、Transparent、Lite系、Fur系、Background、Wirelight、Eye、Screen FX Overlay）を対象
  • プログレスバー表示 — ウォームアップの進捗状況をプログレスバーで表示。処理時間と処理数も最終レポートで確認できます
  • ランタイムプリウォーミングスクリプト生成 — 非VRChatプロジェクト向けに、ランタイムでシェーダーをウォームアップするMonoBehaviourスクリプトを自動生成・管理できます
  • VRChat完全対応 — エディタ専用モードはランタイムスクリプトを使用しないため、VRChatのスクリプト制限に完全対応しています

アクセス方法

以下のメニューからアクセスできます：

  • Tools > Natane > シェーダー Shader > シェーダープリウォーミング Shader Prewarming > すべてウォームアップ Prewarm All Shaders — 手動でシェーダーをウォームアップ
  • Tools > Natane > シェーダー Shader > シェーダープリウォーミング Shader Prewarming > バリアントコレクションをウォームアップ Prewarm Shader Variant Collection — ShaderVariantCollectionのみをウォームアップ
  • Tools > Natane > シェーダー Shader > シェーダープリウォーミング Shader Prewarming > 設定 Settings — 設定ウィンドウを開く

使い方

  1. 設定ウィンドウを開く

    Tools > Natane > シェーダー Shader > シェーダープリウォーミング Shader Prewarming > 設定 Settings を選択して設定ウィンドウを開きます。

  2. エディタ専用プリウォーミングの設定（VRChat対応）

    以下の設定を調整します：

    • ビルド時にプリウォーム — ビルド前に自動的にシェーダーをプリウォームするかどうか。デフォルトは有効です。
    • マテリアルを自動検索 — プロジェクト内のすべてのNatane Toonマテリアルを自動的に検索してプリウォームするかどうか。デフォルトは有効です。
  3. 手動プリウォーミングの実行

    「今すぐシェーダーをプリウォーム」ボタンをクリックすると、即座にプリウォーミングが実行されます。処理時間とウォームアップされたバリアント/マテリアル数がダイアログに表示されます。

  4. ランタイムプリウォーミング（非VRChatのみ）

    VRChat以外のプロジェクトでランタイムプリウォーミングが必要な場合は、「ランタイムプリウォーミングスクリプトを生成」ボタンでMonoBehaviourスクリプトを生成できます。生成されたスクリプトをシーン内のGameObjectにアタッチし、ShaderVariantCollectionを割り当ててください。

ランタイムプリウォーミングスクリプト

非VRChatプロジェクト向けに自動生成されるランタイムスクリプトの機能：

  • Awakeでプリウォーム — ゲーム開始直後にシェーダーをウォームアップ（デフォルト有効）
  • Startでプリウォーム — Awakeの後にウォームアップを遅延実行
  • デバッグログ — 処理時間やバリアント数のログ出力を切り替え可能
  • 手動呼び出し — PrewarmShaders()メソッドを任意のタイミングで呼び出し可能

Tips

  • VRChatプロジェクトでは、必ずエディタ専用モードを使用してください。ランタイムスクリプトはVRChatでは動作しません
  • シェーダーバリアント収集ツール（Shader Variant Collector）で事前にShaderVariantCollectionを生成しておくと、プリウォーミングがより効率的になります
  • ビルド前プリウォーミングはShaderVariantCollectionが空の場合、マテリアルから自動収集してウォームアップします
  • プリウォーミングの処理時間はプロジェクトのマテリアル数とバリアント数に依存します。大規模プロジェクトではビルド時間が若干長くなる場合があります
  • バリアントストリッピングと併用することで、必要なバリアントのみをプリウォームし、不要なバリアントをビルドから除去する最適な構成が実現できます
