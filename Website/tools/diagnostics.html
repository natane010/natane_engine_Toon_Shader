ツール診断

クロスアセンブリ ツール健全性バリデータと診断ウィンドウ

メニュー: Tools > Natane > 診断 Diagnostics カテゴリ: コア

概要

ツール診断（NataneToolHealthValidator）は、Natane Toon Shaderパッケージに含まれる全エディタツールの健全性を検証する診断ウィンドウです。複数のアセンブリに分散するツール群が正しくロードされ、メニューから起動可能かどうかを自動チェックします。アセンブリのロード状態、型の存在、MenuItem属性の有無などを包括的に検証し、問題がある場合は原因と対処法を表示します。

アクセス方法

メニュー: Tools > Natane > 診断 Diagnostics

表示言語は Natane Toon の言語設定に追従します。日本語設定では「再チェック」「問題のみ表示」「対処法」などの主要 UI が日本語表示になります。

機能

包括的ツールチェック

  • アセンブリロード確認 - NataneToon.Editor、NataneToon.Editor.Tools、NataneToon.Editor.Migration の3つの必須アセンブリがロードされているか確認
  • 型存在チェック - 各ツールのクラスが対応するアセンブリ内に存在するか検証
  • MenuItem属性チェック - ツールクラスに [MenuItem] 属性が正しく設定されているか検証
  • メニューパス検証 - ツールレジストリに登録されたメニューパスの正当性を確認

検証対象ツール

以下のカテゴリに分類される30以上のツールを検証します：

  • マテリアルツール - Material Validator、Material Editor、Material Preview、Material Comparison、Makeup Layer Manager
  • プリセットツール - Material Preset Browser、Color Palette Manager、Default Preset Generator
  • エフェクトツール - Shadow Wizard、MatCap Composer、Dissolve Generator、Rim Light Visualizer、Screen FX Setup
  • 最適化ツール - Performance Budget、Texture Optimizer、Outline Optimizer、Refraction Balancer、Shader Variant Collector/Stripper、Asset Reference Checker
  • 移行ツール - lilToon Migration、Batch Material Converter、Prefab Variant Converter
  • メッシュツール - Smooth Normal Baker
  • その他 - Dashboard、Help、Particle Effect Editor、VTuber Preset Generator

診断結果表示

  • サマリー表示 - エラー/警告/正常の件数をカラーコード付きで表示
  • 問題のみ表示フィルター - 「問題のみ表示」トグルで正常なツールを非表示に
  • 詳細情報 - 問題のあるツールには原因メッセージと対処法を表示
  • 再チェック - 「再チェック」ボタンで診断を再実行

バリデーション&ランチAPI

  • ValidateTool() - メニューパスで単一ツールを事前チェック
  • ValidateAndLaunch() - チェック後にツールを起動。失敗時はダイアログで原因と対処法を表示し、診断ウィンドウへの遷移を提案
  • GetOverallHealth() - Dashboard向けの軽量ヘルスチェック（日本語設定では「正常/警告/異常」表示）
  • RunFullDiagnostics() - 全登録ツールの包括的チェックを実行

使い方

  1. メニューから「Tools > Natane > 診断 Diagnostics」を開きます
  2. ウィンドウが開くと自動的に全ツールの診断が実行されます
  3. サマリーでエラー・警告・正常の件数を確認します
  4. 「問題のみ表示」を有効にして、問題のあるツールだけを表示します
  5. 各問題の「対処法」に従って修正します
  6. 修正後、「再チェック」ボタンで診断を再実行して修正を確認します

重要度レベル

  • エラー（Error） - ツールが起動できない致命的な問題。アセンブリが未ロード、または型が見つからない
  • 警告（Warning） - ツールは存在するが、一部に問題がある。MenuItem属性が見つからない、レジストリ未登録など
  • 正常（Healthy） - ツールが正常に検証されたことを示す

トラブルシューティング

アセンブリがロードされていない場合

対応する .asmdef ファイルが存在し、参照が正しく設定されているか確認してください。Unity エディタのコンソールにコンパイルエラーがないかも確認しましょう。

型が見つからない場合

クラス名または名前空間が変更されていないか確認してください。ToolRegistry のエントリと実際のクラスの完全修飾名が一致している必要があります。

MenuItem属性が見つからない場合

ツールクラスに [MenuItem] 属性を持つ static メソッドが存在するか確認してください。メニューパスからの起動ができない可能性があります。

Tips

  • パッケージのインストール直後に診断を実行して、全ツールが正常にロードされていることを確認しましょう
  • Dashboardのツールバーインジケータは GetOverallHealth() を使用した軽量チェックの結果です
  • ツールが起動できない場合、ValidateAndLaunch() が自動的に原因を表示します
  • 新しいツールを追加する際は、ToolRegistry にエントリを追加することを忘れずに
