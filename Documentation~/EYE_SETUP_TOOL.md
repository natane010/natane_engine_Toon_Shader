# Eye Setup Tool（目のセットアップツール）

## 日本語

`Tools > Natane > メッシュ Mesh > 目のセットアップ Eye Setup Tool`

目のポリゴンを専用マテリアルへ分離し（マテリアル分け）、目のUVをテクスチャ全体へ再配置する（UV再配置）ためのツールです。分離した目には専用シェーダー **"Natane/Eye"**（視差・瞳孔サイズ・目の状態など）をそのまま使えます。

メッシュは必ず**新規アセット**として保存され、インポート元のFBXメッシュは一切変更されません。レンダラーとマテリアルの変更はすべてUndo可能です。

### 1. マテリアル分け

1. 対象の SkinnedMeshRenderer / MeshRenderer をウィンドウ上部にセットします（「選択から取得」でHierarchyの選択からも取得できます）。
2. 「1. マテリアル分け」タブで目の選択方法を選びます。
   - **既存マテリアルスロット** — 目が既に専用スロットになっている場合。メッシュは変更せず、そのスロットへ新規 "Natane/Eye" マテリアルを割り当てます。
   - **UV範囲** — UVプレビュー上をドラッグ（または数値入力）して範囲を指定。UV重心が範囲内の三角形が目として選択されます。
   - **マスクテクスチャ** — 白=目のマスクテクスチャを指定。UV重心位置の輝度がしきい値以上の三角形が選択されます。
3. プレビューで選択（緑）を確認し、概要欄で変更内容をチェックします。
4. 「マテリアル分けを実行」を押し、新規メッシュアセットの保存先を選びます（初期値は元メッシュの隣）。
   - 選択した三角形が新しい最終サブメッシュとして分離されます。
   - "Natane/Eye" シェーダーの新規マテリアルが作成され（メインテクスチャ・ベースカラーを元マテリアルから引き継ぎ）、新しいスロットへ割り当てられます。

### 2. UV再配置

1. 「2. UV再配置」タブで対象サブメッシュ（分離直後は自動で目のサブメッシュが選択されます）を選びます。
2. 配置方法を選択します。
   - **全体を1ブロック** — サブメッシュ全体のUVをターゲット矩形へ拡大。
   - **左右を重ねる** — 左右の目のアイランドを検出し、同じ領域に重ねます（左右で1枚のテクスチャを共有する、VRChatで一般的な構成）。「片側の目をU方向に反転」でミラーも可能です。
   - **左右を並べる** — 左右の目を横に並べて配置します。
3. ターゲット矩形（既定は 0..1 全面）、パディング、書き込み先UVチャンネル（uv0 / uv1）を設定します。
4. プレビューで変更前（グレー）/変更後（緑）を確認し、「UV再配置を実行」を押します。
   - 対象が本ツールで生成した `.asset` メッシュの場合は直接更新します。
   - インポート品メッシュの場合は自動で新規アセットへ複製してから書き込みます。

### 注意事項

- UV範囲/マスク選択には uv0 が必要です。
- 左右のグループ分けはメッシュ空間のX座標（顔の左右）で行うため、UVが既に重なっている目でも正しく動作します。
- 他のサブメッシュと頂点を共有している場合は警告が表示されます（共有頂点のUVも移動します）。

## English

`Tools > Natane > Mesh > Eye Setup Tool`

A tool to separate eye polygons into their own material slot (material separation) and to remap the eye UVs to fill the texture (UV relayout). The separated eyes can directly use the dedicated **"Natane/Eye"** shader (parallax, pupil size, eye states, etc.).

Meshes are always saved as **new assets**; the imported FBX mesh is never modified. All renderer and material changes are undoable.

### 1. Material Separation

1. Set the target SkinnedMeshRenderer / MeshRenderer at the top of the window ("From Selection" picks it from the Hierarchy selection).
2. In the "1. Material Separation" tab, choose how eye geometry is identified:
   - **Existing Material Slot** — when the eyes already have their own slot. The mesh is untouched; a new "Natane/Eye" material is assigned to that slot.
   - **UV Rect** — drag a rectangle on the UV preview (or type min/max values). Triangles whose UV centroid is inside the rect are selected.
   - **Mask Texture** — provide a mask texture (white = eye). Triangles whose UV-centroid luminance exceeds the threshold are selected.
3. Check the selection (green) in the preview and review the summary of changes.
4. Press "Apply Material Separation" and choose where to save the new mesh asset (defaults next to the original).
   - The selected triangles are extracted into a new last submesh.
   - A new material using the "Natane/Eye" shader is created (main texture / base color copied from the source material) and assigned to the new slot.

### 2. UV Relayout

1. In the "2. UV Relayout" tab, pick the target submesh (the eye submesh is preselected right after separation).
2. Choose the layout:
   - **Single block** — scale the whole submesh's UVs into the target rect.
   - **Overlap left/right** — detect the left/right eye islands and overlap them on the same area (both eyes share one texture region — the common VRChat pattern). "Mirror one eye horizontally" flips one side in U.
   - **Side by side** — place the left and right eyes next to each other.
3. Set the target rect (default 0..1 full texture), padding, and the target UV channel (uv0 / uv1).
4. Check before (gray) / after (green) in the preview and press "Apply UV Relayout".
   - A `.asset` mesh generated by this tool is updated in place.
   - An imported mesh is automatically duplicated into a new asset before writing.

### Notes

- UV rect / mask selection requires uv0.
- Left/right grouping uses mesh-space X (the sides of the face), so it also works when the eye UVs already overlap.
- A warning is shown when vertices are shared with other submeshes (their UVs move as well).
