# ファー（毛皮） — シェル法 / フィン法

`Natane/Toon Shader (Fur)` および `Natane/Toon Shader (Fur Lite)` の毛皮表現。
**シェル法**と**フィン法**を `_FurMethod` で使い分けられる。

インスペクターの「ファー」セクション、または `Tools > Natane` のマテリアル関連ツールから設定する。

---

## どちらを使うか

| | シェル法 (Shell) | フィン法 (Fin) |
|---|---|---|
| 作り | 法線方向にずらした殻を 16 枚重ねる | ポリゴンの辺に毛の板を立てる |
| 得意 | 面を**正面から**見たときの毛並み | **輪郭**（シルエット）の毛 |
| 苦手 | 輪郭。殻を横から見るので薄くなる | 面を真上から見たとき。板が見える |
| 負荷 | 16 パス固定（メッシュの粗さに依らない） | ジオメトリシェーダー。ポリゴン数に比例 |
| 対応環境 | すべて | **PC 専用**（ジオメトリシェーダー必須） |

- **シェル＋フィン (ShellAndFin)** は互いの苦手を打ち消す組み合わせ。負荷は最大になる。
- どちらの方式も**同じ毛の分布**（`NataneToonFurCommon.hlsl`）を参照している。
  フィンはシェルが埋める体積の垂直断面そのものなので、併用しても毛並みがずれない。

### 環境による差

フィンのパスには `#pragma require geometry` が付いている。
ジオメトリシェーダーを持たない環境（Quest など）では**そのパスごと省かれ**、
シェル法だけの見た目になる。マテリアルの設定を変える必要はないが、
PC と Quest で見た目が変わる点は把握しておくこと。

「フィンのみ」を選んでもシェル 16 パスの**描画コール自体は残る**。
ビルトイン RP はマテリアルの値でパスを止められないため、
シェル側は頂点を潰して 1 ピクセルも出さないようにしている（塗りの負荷は消える）。

## パラメータ

### 共通（方式によらず効く）

| プロパティ | 意味 |
|---|---|
| `_FurLength` | 毛の長さ。**オブジェクト空間**なので、スケールを掛けたオブジェクトでは見た目も比例して伸びる |
| `_FurDensity` | 毛の密度。**1 セルに 1 本**生え、セル数は UV 1 あたり `_FurDensity × 4`。毛が太く尖って見える（サボテン状）ときは、まずこれを上げる |
| `_FurAlphaCutoff` | 毛の細さ。大きいほど 1 本が細く、隙間が広い |
| `_FurFluff` | モフモフ感。毛が上へ向かって散らばる量（最大 0.6 セル）。**0 だと毛が真っ直ぐ立ち、ビロードや刷毛のように見える**。毛同士が交差することで初めて毛の量感が出る |
| `_FurUseNoiseTex` / `_FurNoiseTex` | ON にすると、テクスチャの明るさが**そのまま毛の長さ**になる（明るいほど長い）。lilToon の `_FurNoiseMask` と同じ。タイリング（ST）で毛の大きさが決まる。OFF なら同等の模様をシェーダー内で生成 |
| `_FurRootOffset` | 根元の詰まり（-1〜0）。負に振るほど根元側が隙間なく埋まり、0 に近づくほど根元から毛が分かれる。lilToon の同名プロパティと同じ式 |
| `_FurMask` | 毛の伸び量そのものを殺すマスク |
| `_FurRootColor` / `_FurTipColor` / `_FurColorBlend` | 根元→毛先の色。混合比はメインテクスチャとの比率 |
| `_FurGravity` | 毛先の垂れ。**毛の長さに対する比**で、毛丈を超えて垂れることはない |
| `_FurWindStrength` / `_FurWindSpeed` / `_FurWindDirection` | 揺れ。位置で位相をずらすので、隣の毛と同時に揺れない |
| `_FurAO` / `_FurShadowStrength` / `_FurSpecular` / `_FurRimLight` | 陰影 |

### シェル法のみ

| プロパティ | 意味 |
|---|---|
| `_FurLODDistance` | この距離から殻を間引き始める |
| `_FurLODMinLayers` | 遠距離での最低枚数 |

> 全体を俯瞰する距離で「毛が消える」ときは、まず `_FurLODDistance` を疑うこと。
> 既定の 10 は近距離のアバター向けで、遠景では 4 枚まで落ちて球に戻る。

### フィン法のみ

| プロパティ | 意味 |
|---|---|
| `_FurFinViewThreshold` | 面を正面から見ているとき（板が見えてしまうとき）フィンを作らないしきい値。下げるほど輪郭付近に絞られ、負荷も下がる |
| `_FurFinJoints` | 毛のしなりの関節数。1 だと真っ直ぐな板、増やすほど重力・風でしなる |
| `_FurFinNormalBlend` | ライティングに使う法線を「元の面の法線」と「フィン板の法線」でどう混ぜるか |
| `_FurFinRandomDir` | 生える向きのランダム性。0 だと毛が櫛で梳いたように揃う |

フィンは**ポリゴンの辺 1 本につき 1 枚**立つ。毛が足りないときは
メッシュのポリゴン数を増やす（サブディバイド）のが正攻法。

## 実装メモ

- `Include/Rendering/NataneToonFurCommon.hlsl` — 毛の分布・変位・シェーディング（両方式で共有）
- `Include/Rendering/NataneToonFurShell.hlsl` — シェル 16 パスの頂点/フラグメント
- `Include/Rendering/NataneToonFurFin.hlsl` — フィンの頂点/ジオメトリ/フラグメント

### 毛は「長さの場」を層で切り出して作る

lilToon（`_FurNoiseMask`）も hecomi 氏の実装（毛テクスチャのアルファ）も、
**毛そのものを描くのではなく、「毛の長さの場」を作って層の高さでしきい値処理する**。
本実装もこの順序に揃えた。

```
shift = layer - layer * _FurRootOffset + _FurRootOffset
alpha = saturate(場 - shift * |shift|^3 + 0.25)
```

この順序が重要で、根元では場の全体がしきい値を超えるので**コートが隙間なく埋まり**、
上へ行くほど場の山だけが残って**1 本ずつに分かれ**、頂上では最も長い毛だけが残る。
毛の断面を幾何的に計算する方式（以前の実装）は、この振る舞いを手で再現する必要があり、
禿げ・棘・チューブの融合はすべてその再現に失敗した結果だった。

セルフオクルージョンも lilToon と同じく場の値を使う
（`saturate(1 - 場 + 場 * layer)`）。層の高さだけで暗くするとコート全体が均一に暗くなるが、
場を使うと「長い毛は明るく、周りの短い毛は影に沈む」ため奥行きが出る。

### 毛の分布を「1 セル 1 本」で決めている理由

滑らかなノイズを閾値で切って毛の有無を決めると、ノイズの窪地が**セル数個ぶんの塊**で
閾値を下回り、そこはどの層にも毛が立たない。毛の間の隙間ではなく**穴**になり、
禿げて見える。セルごとに 1 本を配置すれば分布は構造的に一様になる。

ただし 1 セル 1 本にすると、**セルの大きさがそのまま毛の太さと本数**になる。
`_FurDensity` は元々「ノイズテクスチャのタイリング」の値（1 テクセルに何本でも入る前提）
だったため、そのままセル数に使うと毛が太く尖り、サボテンのようになる。
そこでセル数は `_FurDensity × 4` としている（`NATANE_FUR_CELLS_PER_DENSITY`）。

毛の形は、根元から 2/3 までは太さを保ち、残りで先細りさせている。
先端まで一定の割合で細くすると円錐＝棘になるため。
根元のごく薄い層だけは全面を埋めて地肌を隠す。

### 毛を散らして交差させている理由（`_FurFluff`）

毛が全部まっすぐ立っていると、どの角度から見ても**同じ円が重なるだけ**で
体積が埋まらない。ビロードや刷毛のような、平らで硬い見た目になる。
毛ごとに違う向きへ散らすと毛同士が交差し、層をまたいで隙間が埋まって
初めて「モフモフ」に見える。

散った毛は隣のセルへはみ出すため、被覆率の計算では**3×3 セルを探索**している。
自分のセルだけを見ると、はみ出した毛がセル境界で切れて格子模様になる。
毛の縁も、硬い円ではなく外へ向かって薄くなるようにしている
（硬い円はプラスチックの刷毛に見える）。

### 毛を太らせて密度を稼いではいけない

毛の間隔は 1 セルなので、半径が 0.5 に近づくと**隣の毛と接触し、
被覆率の合成（max）で 1 つのなめらかな面に融合する**。
毛ではなく、太いチューブが並んだ肉塊のような見た目になる。
縁のぼかし幅も同じで、広すぎると隣の毛と溶接される。

覆う量は毛の**本数**（`_FurDensity`）で稼ぐこと。
半径は 0.24 セル（`_FurAlphaCutoff` 0 のとき）を上限にしている。

### 重力と風が毛の長さに比例する理由

どちらも「毛の変位」であって絶対量ではない。以前は絶対量で加算していたため、
既定値（重力 0.1 / 毛丈 0.02）では毛丈の 5 倍だけ真下へ引きずられ、
毛束ではなく「メッシュの複製が下にずれたもの」になっていた。
