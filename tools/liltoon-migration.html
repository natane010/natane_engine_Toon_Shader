lilToon移行ツール

lilToonシェーダーからNatane Toon Shaderへの自動マイグレーション

メニュー: Tools > Natane > Migration > lilToon Migration カテゴリ: 移行

概要

lilToon移行ツールは、lilToonシェーダーで設定されたマテリアルをNatane Toon Shaderに自動変換するためのマイグレーションツールです。lilToonのプロパティ名とNatane Toonのプロパティ名の対応関係（マッピング）を内蔵しており、テクスチャ、色、数値パラメータを自動的に引き継ぎます。

lilToonはVRChat向けトゥーンシェーダーとして広く使われていますが、Natane Toon Shaderに乗り換える際に手動でパラメータを一つ一つ設定し直すのは非常に手間がかかります。このツールを使えば、基本的なプロパティ（メインテクスチャ、影色、影の境界、リムライト、マットキャップなど）の大部分を自動的にマッピングし、変換してくれます。

lilToonのバリアント（Opaque、Cutout、Transparent、Outline付きなど）も自動検出し、Natane Toon Shaderの対応するバリアントに変換します。変換前にプレビューで確認でき、Undo対応なので安心して使えます。一括変換にも対応しているため、アバター全体のマテリアルを一度に移行することも可能です。

主な機能

  • 自動プロパティマッピング — lilToonの各プロパティ（_MainTex、_ShadowColor、_RimColor など）をNatane Toon Shaderの対応プロパティに自動変換
  • バリアント検出 — lilToon Opaque / Cutout / Transparent / TwoPass など、使用中のバリアントを自動検出して適切なNatane Toonバリアントを選択
  • 一括変換 — フォルダ内やシーン内のlilToonマテリアルを一度に変換。大規模なアバタープロジェクトの移行に最適
  • プレビュー — 変換前にマッピング結果をプレビュー表示。どのプロパティがどのように変換されるかを事前に確認
  • Undo対応 — すべての変換操作はUndo可能。問題があればCtrl+Zで即座に元に戻せます
  • カスタムマッピング — 自動マッピングで対応できないプロパティは、手動でマッピングを追加・修正可能

使い方

  1. lilToonマテリアルを選択

    Projectビューで変換したいlilToonマテリアルを選択します。フォルダを指定すると、フォルダ内のlilToonマテリアルが自動検出されます。

  2. プロパティマッピングを確認

    自動検出されたプロパティマッピングの一覧が表示されます。各プロパティの変換先を確認し、必要に応じて修正してください。

  3. プレビュー

    「プレビュー」ボタンで変換後のマテリアルの見た目を確認します。Sceneビューでリアルタイムにプレビューされます。

  4. 変換を実行

    「変換実行」ボタンでマテリアルを変換します。元のマテリアルのシェーダーがNatane Toon Shaderに切り替わり、マッピングされたプロパティが自動設定されます。

Tips

  • 変換前に元のマテリアルのバックアップを取ることをおすすめします。プレハブバリアント変換ツールを使えば、元のプレハブを保持したまま変換できます
  • lilToonの2nd/3rd Shadow はNatane Toonの多階調シャドウにマッピングされます。変換後に色味の微調整が必要な場合があります
  • マットキャップやリムライトの強度は、シェーダー間で計算方法が異なるため、変換後に微調整が必要になることがあります
  • lilToonのアウトライン設定も自動的に変換されますが、太さのスケールが異なる場合があるため確認してください
  • 一括変換の際は、最初に1つのマテリアルで試してから残りを変換するのが安全です
