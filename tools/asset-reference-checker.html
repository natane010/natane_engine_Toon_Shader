アセット参照チェック

シーン・プレハブ・マテリアルの参照エラーを自動検出

メニュー: Tools > Natane > 最適化 Optimization > Asset Reference Checker カテゴリ: 最適化

概要

アセット参照チェッカーは、シーン・プレハブ・マテリアル内の欠損・破損した参照を自動的に検出するツールです。Missing Script、欠損マテリアル、未設定テクスチャ、シェーダーエラー、null参照などをスキャンし、問題を重要度別（Error/Warning/Info）に一覧表示します。

主な機能

  • 3つのスキャンモード（シーン / プレハブ / マテリアル）
  • 5種類の参照エラー検出（Missing Script, Material, Texture, Shader, Null Reference）
  • 重要度別フィルタリングと色分け表示（Error: 赤 / Warning: 黄 / Info: 青）
  • クリックで対象オブジェクトを選択・ハイライト
  • プロジェクト全体のプレハブ一括スキャン
  • 結果のコンソール出力（エクスポート）

使い方

  1. スキャンモードを選択します（シーン / プレハブ / マテリアル）
  2. 必要に応じてオプションを設定します（非アクティブ含む、Natane Toon限定など）
  3. スキャンボタンをクリックして検査を開始します
  4. 検出された問題を重要度別に確認します
  5. 「Select」ボタンで問題のあるオブジェクトに直接移動できます

スキャンモード詳細

シーンモード

  • 現在開いているシーンのすべてのGameObjectをスキャン
  • 非アクティブオブジェクトの包含/除外を切替可能

プレハブモード

  • 個別プレハブを指定してスキャン
  • プロジェクト内の全プレハブを一括スキャン（プログレスバー付き）

マテリアルモード

  • プロジェクト内のすべてのマテリアルをスキャン
  • Natane Toon Shaderのみにフィルタリング可能
  • ShaderUtilによるテクスチャプロパティの自動走査

検出される問題

  • Missing Script (Error): 欠損したスクリプトコンポーネント。パッケージの削除や名前変更が原因です
  • Missing Material (Error): Rendererのnullマテリアルスロット。マテリアルの削除や移動が原因です
  • Missing Shader (Error): シェーダーがnullまたはエラー状態（Hidden/InternalErrorShader）
  • Null Reference (Warning): コンポーネントの欠損したオブジェクト参照。SerializedObjectの走査で検出します
  • Missing Texture (Warning/Info): 未設定のテクスチャプロパティ。_MainTexは Warning、その他は Info

Tips

  • VRChatアバターをアップロードする前にシーンモードでスキャンしましょう
  • Missing Scriptはパッケージの欠如やスクリプト名変更が原因であることが多いです
  • エラー（赤）から優先的に対処してください
  • プロジェクト全体スキャンは大規模プロジェクトでは時間がかかる場合があります
  • Detailsの折りたたみを開くとコンポーネント名やプロパティ名などの詳細を確認できます
