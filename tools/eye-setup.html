目のセットアップ

目のマテリアル分離とUV再配置を非破壊で行うツール (v1.6.0)

メニュー: Tools > Natane > メッシュ Mesh > 目のセットアップ Eye Setup Tool カテゴリ: メッシュ

概要

目のセットアップツールは、目のポリゴンを専用マテリアルへ分離し（マテリアル分け）、目のUVをテクスチャ全体へ再配置する（UV再配置）ためのエディタウィンドウです。分離した目には専用シェーダー "Natane/Eye"（視差・瞳孔サイズ・目の状態など）をそのまま使えます。

メッシュは必ず新規アセットとして保存され、インポート元のFBXメッシュは一切変更されません。レンダラーとマテリアルの変更はすべてUndo可能です。

アクセス方法

メニュー: Tools > Natane > メッシュ Mesh > 目のセットアップ Eye Setup Tool

機能

  • 3つの目の選択方法
    • 既存マテリアルスロット — 目が既に専用スロットになっている場合。メッシュは変更せず、そのスロットへ新規 "Natane/Eye" マテリアルを割り当てます
    • UV範囲 — UVプレビュー上をドラッグ（または数値入力）して範囲を指定。UV重心が範囲内の三角形が目として選択されます
    • マスクテクスチャ — 白=目のマスクテクスチャを指定。UV重心位置の輝度がしきい値以上の三角形が選択されます
  • 3つのUV配置方法
    • 全体を1ブロック — サブメッシュ全体のUVをターゲット矩形へ拡大
    • 左右を重ねる — 左右の目のアイランドを検出し、同じ領域に重ねます（VRChatで一般的な構成）。片側の目のU方向反転も可能
    • 左右を並べる — 左右の目を横に並べて配置
  • UVプレビュー — 選択（緑）や変更前（グレー）/変更後（緑）を確認できます
  • 非破壊ワークフロー — 新規メッシュを .asset として保存。インポート品メッシュへの書き込み時は自動で複製します
  • マテリアル引き継ぎ — 新規 "Natane/Eye" マテリアルにメインテクスチャ・ベースカラーを元マテリアルから引き継ぎます
  • 書き込み先UVチャンネル選択 — uv0 / uv1 を選択可能。ターゲット矩形とパディングも設定できます

使い方

  1. 対象の SkinnedMeshRenderer / MeshRenderer をウィンドウ上部にセットします（「選択から取得」でHierarchyの選択からも取得できます）
  2. 「1. マテリアル分け」タブで目の選択方法（既存スロット / UV範囲 / マスク）を選びます
  3. プレビューで選択（緑）を確認し、概要欄で変更内容をチェックします
  4. 「マテリアル分けを実行」を押し、新規メッシュアセットの保存先を選びます（選択した三角形が新しい最終サブメッシュとして分離され、"Natane/Eye" マテリアルが割り当てられます）
  5. 「2. UV再配置」タブで対象サブメッシュを選びます（分離直後は自動で目のサブメッシュが選択されます）
  6. 配置方法・ターゲット矩形・パディング・UVチャンネルを設定します
  7. プレビューで変更前後を確認し、「UV再配置を実行」を押します

Tips

  • UV範囲/マスク選択には uv0 が必要です
  • 左右のグループ分けはメッシュ空間のX座標（顔の左右）で行うため、UVが既に重なっている目でも正しく動作します
  • 他のサブメッシュと頂点を共有している場合は警告が表示されます（共有頂点のUVも移動します）
  • 「左右を重ねる」は左右で1枚のテクスチャを共有する、VRChatで一般的な構成に最適です
  • 分離後は "Natane/Eye" シェーダーのアイパララックスなどの目専用機能がそのまま使えます
