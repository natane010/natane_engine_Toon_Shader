メイクアップレイヤー管理

ビジュアルレイヤー管理でメイクアップテクスチャを制御

メニュー: Tools > Natane > Makeup Layer Manager カテゴリ: マテリアル

概要

メイクアップレイヤー管理ツールは、Natane Toon Shaderのメイクアップ機能で使用するテクスチャレイヤーを視覚的に管理するためのエディタウィンドウです。チーク、アイシャドウ、リップなどのメイクアップレイヤーをPhotoshopのようなレイヤーパネルで直感的に操作できます。

主な機能

  • ビジュアルなレイヤー管理インターフェース
  • 各レイヤーの不透明度とブレンドモード制御
  • レイヤーの表示/非表示切り替え
  • レイヤーの順序変更（ドラッグ&ドロップ）
  • プレビュー付きのレイヤー編集
  • レイヤーカラーの調整

使い方

  1. 対象のマテリアルを選択してツールを開きます
  2. メイクアップレイヤー（チーク、アイシャドウ、リップなど）が一覧表示されます
  3. 各レイヤーのテクスチャ、カラー、不透明度を調整します
  4. ドラッグ&ドロップでレイヤーの重なり順を変更します
  5. プレビューで結果を確認しながら調整を進めます

Tips

  • レイヤーの不透明度を下げると自然な仕上がりになります
  • ブレンドモードを変更することで、異なる質感のメイクアップが表現できます
  • VRChatアバターのキャラクター表現を豊かにするために、複数レイヤーを組み合わせてみてください
  • 不要なレイヤーは非表示にすることで、マテリアルの処理負荷を確認できます
