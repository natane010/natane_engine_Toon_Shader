スムース法線ベイク

ハードエッジモデルのアウトライン表示を改善するスムース法線ベイクツール

メニュー: Tools > Natane > メッシュ Mesh > スムース法線ベイク Smooth Normal Baker カテゴリ: メッシュ

概要

スムース法線ベイクツールは、ハードエッジを持つモデルのアウトライン描画を改善するために、スムース法線を頂点カラーのRGBチャンネルにベイクするツールです。同一位置の頂点の法線を平均化してスムース法線を計算し、頂点カラーにエンコードして保存します。元のメッシュは変更されない非破壊ワークフローを採用しています。

アクセス方法

メニュー: Tools > Natane > メッシュ Mesh > スムース法線ベイク Smooth Normal Baker

機能

  • 2つのベイクモード
    • Tangent Space（推奨） - スムース法線をタンジェント空間でエンコード。スキニングやブレンドシェイプの変形に追従します
    • Object Space - スムース法線をオブジェクト空間でエンコード。シンプルで安定しますが、メッシュの変形には追従しません
  • メッシュ情報表示 - メッシュ名、頂点数、サブメッシュ数、既存の頂点カラー有無を表示
  • 自動アサイン - ベイク後に自動的にメッシュを差し替えるオプション（Undo対応）
  • 非破壊ワークフロー - 元のメッシュは変更されず、新しいメッシュが .asset ファイルとして保存されます
  • タンジェント自動検出 - タンジェント情報がないメッシュの場合、Object Spaceへの自動切り替えを提案
  • 位置ベースの頂点グルーピング - 浮動小数点の誤差を考慮した量子化（精度: 1/10000）で同一位置の頂点をグループ化
  • SkinnedMeshRenderer / MeshFilter 両対応 - スキンメッシュと静的メッシュの両方に対応

使い方

  1. SkinnedMeshRenderer または MeshFilter を持つGameObjectを「ターゲットオブジェクト」フィールドにドラッグします
  2. メッシュ情報（頂点数、サブメッシュ数など）を確認します
  3. ベイクモードを選択します（通常は Tangent Space を推奨）
  4. 「自動アサイン」を有効にすると、ベイク後にメッシュが自動で差し替えられます
  5. 「ベイク実行」ボタンを押します
  6. 保存先を選択すると、ベイクされたメッシュが .asset ファイルとして保存されます
  7. シェーダーの「スムース法線アウトライン」機能を有効にして結果を確認します

技術詳細

スムース法線の計算

同一位置の頂点（量子化精度 1/10000）をグループ化し、グループ内の法線ベクトルの平均を取ります。この平均化された法線がスムース法線となります。

エンコード方式

  • Tangent Space: TBN行列の逆行列を使用してスムース法線をタンジェント空間に変換し、[-1,1]を[0,1]にリマップして頂点カラーRGBに格納
  • Object Space: オブジェクト空間のスムース法線を直接[-1,1]から[0,1]にリマップして頂点カラーRGBに格納

Tips

  • アバターのアウトラインがハードエッジで途切れる場合に特に効果的です
  • 既存の頂点カラーがある場合はベイクで上書きされるため注意してください
  • Tangent Spaceモードはスキニングアニメーション中もスムースなアウトラインを維持します
  • ベイク後のメッシュは元のメッシュ名に「_SmoothNormal」サフィックスが付きます
  • 同一パスに既存のアセットがある場合は上書き更新されます
