メインテクスチャアニメーション

UVスクロールと回転でテクスチャを動かす

概要

メインテクスチャアニメーションは、メインテクスチャのUV座標にスクロールと回転のアニメーションを適用する機能です。時間ベースのUV変換により、流れる水面、回転するエネルギーフィールド、スクロールするパターンなどの動的な表現を実現します。

キーワード _MAIN_TEX_ANIMATION で制御され、無効時はシェーダー命令が生成されません。ローカルキーワード（shader_feature_local）として実装されています。

パラメータ

テクスチャアニメーションを有効化 _MainTexAnimation toggle

メインテクスチャアニメーション機能の有効/無効を切り替えます。キーワード _MAIN_TEX_ANIMATION でコンパイル時に分岐します。

デフォルト: OFF

スクロール速度 XY _MainTexScrollSpeed vector

メインテクスチャのUVスクロール速度をXY方向で指定します。各成分は1秒あたりのUVオフセット量に相当します。X成分が水平方向、Y成分が垂直方向のスクロールを制御します。両方のスクロール速度が0に近い場合（二乗和がイプシロン以下）、スクロール処理は自動的にスキップされます。

デフォルト: (0, 0, 0, 0)

水の流れなら (0.1, 0) 、斜め方向のスクロールなら (0.05, 0.05) のように設定します。
回転速度 _MainTexRotateSpeed float

メインテクスチャの回転速度を指定します。UV中心 (0.5, 0.5) を回転中心として、時間に応じたsin/cos変換でUVを回転させます。正の値で反時計回り、負の値で時計回りに回転します。回転速度が0に近い場合（絶対値がイプシロン以下）、回転処理は自動的にスキップされます。

デフォルト: 0

ゆっくりとした回転には0.1〜0.3程度の値がおすすめです。

使い方のヒント

  • スクロールと回転は同時に使用できます。組み合わせることで複雑な動きの表現が可能です
  • フラグメントシェーダーの最初期段階でUV変換が適用されるため、メインテクスチャのサンプリング以降すべての処理に影響します
  • エフェクト系のマテリアル（エネルギー、魔法陣、水面など）に特に適しています
  • VRChatのアニメーションパラメータと連携して、スクロール速度を動的に制御することも可能です
  • 速度の値が0の場合は計算がスキップされるため、不要な方向を0に設定しておけばパフォーマンスに影響しません
