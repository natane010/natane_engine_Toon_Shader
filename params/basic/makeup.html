メイクアップ

最大4レイヤーのメイクアップテクスチャ（HSVカラー調整対応）

透過PNG対応のメイクアップテクスチャを最大4レイヤー重ねることができます。各レイヤーはHSVカラー調整、強度制御、ブレンドモード選択、追加マスクに対応しています。アルファチャンネルで適用範囲を制御し、複数のブレンドモードで自然なメイクアップ表現が可能です。

2nd Texture レイヤー

用途: ハイライト、アイシャドウ

2nd Textureを有効化 _Use2ndTexture toggle

2番目のメイクアップテクスチャレイヤーを有効にします。キーワード: _2ND_TEXTURE

デフォルト: OFF

2nd Texture _2ndTex texture

2番目のメイクアップテクスチャです。透過PNGに対応しており、アルファチャンネルが適用強度として使用されます。

デフォルト: なし

Hue Shift _2ndTexHueShift range

テクスチャの色相をシフトします。0で変化なし、正負の値で色相環に沿って色を変更します。

デフォルト: 0

範囲: -0.5 〜 0.5

Saturation _2ndTexSaturation range

テクスチャの彩度を調整します。1で元の彩度、0でグレースケール、2で非常に鮮やかになります。

デフォルト: 1

範囲: 0 〜 2

Brightness _2ndTexValue range

テクスチャの明度を調整します。1で元の明度、0で完全に暗く、2で非常に明るくなります。

デフォルト: 1

範囲: 0 〜 2

強度 _2ndTexIntensity range

メイクアップテクスチャの適用強度です。0で効果なし、1で最大適用になります。

デフォルト: 1

範囲: 0 〜 1

ブレンドモード _2ndTexBlendMode enum

テクスチャの合成方法を選択します。

  • Add: 加算（ハイライトに最適）
  • Multiply: 乗算（アイシャドウに最適）
  • Overlay: オーバーレイ（自然なメイク）
  • Screen: スクリーン（柔らかいハイライト）

デフォルト: Add (0)

2nd Texマスク _2ndTexMask texture

追加のマスクテクスチャです。白 = テクスチャ適用、黒 = 適用なし。マスクはアルファチャンネルと乗算されます。キーワード: _2ND_TEX_MASK

デフォルト: なし（トグルで有効化）

3rd Texture レイヤー

用途: チーク

3rd Textureを有効化 _Use3rdTexture toggle

3番目のメイクアップテクスチャレイヤーを有効にします。キーワード: _3RD_TEXTURE

デフォルト: OFF

3rd Texture _3rdTex texture

3番目のメイクアップテクスチャです。透過PNGに対応しており、チーク表現に最適です。

デフォルト: なし

Hue Shift _3rdTexHueShift range

テクスチャの色相をシフトします。

デフォルト: 0

範囲: -0.5 〜 0.5

Saturation _3rdTexSaturation range

テクスチャの彩度を調整します。1で元の彩度。

デフォルト: 1

範囲: 0 〜 2

Brightness _3rdTexValue range

テクスチャの明度を調整します。1で元の明度。

デフォルト: 1

範囲: 0 〜 2

強度 _3rdTexIntensity range

メイクアップテクスチャの適用強度です。

デフォルト: 1

範囲: 0 〜 1

ブレンドモード _3rdTexBlendMode enum

テクスチャの合成方法を選択します。Add / Multiply / Overlay / Screen から選択可能です。チークにはMultiplyが最適です。

デフォルト: Add (0)

3rd Texマスク _3rdTexMask texture

追加のマスクテクスチャです。白 = テクスチャ適用、黒 = 適用なし。キーワード: _3RD_TEX_MASK

デフォルト: なし（トグルで有効化）
