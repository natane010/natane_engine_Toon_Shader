環境リム

環境マップを使ったリムライト効果

キューブマップを使用して、環境に基づいたリムライト効果を作成します。通常のリムライトが単色であるのに対し、環境リムはキューブマップの色情報を使用するため、周囲の環境色を反映した自然なリムライトを表現できます。

キーワード: _ENV_RIM

環境リム設定

環境キューブマップ _EnvRimCube texture

環境リムに使用するキューブマップテクスチャです。リムライトの色が環境に基づいて変化します。

デフォルト: "black"（反射なし）

リフレクション用と同じキューブマップを使用すると、統一感のある環境表現になります。
環境リムの色 _EnvRimColor color

環境リムの色味を調整します。キューブマップの色に乗算されます。

デフォルト: (1, 1, 1, 1)（白・変更なし）

環境リムのパワー _EnvRimPower range

環境リムのフレネル効果の強さを設定します。値が大きいほどリムがエッジに集中し、小さいほど広がります。

デフォルト: 3（範囲: 0.1 - 10）

環境リムの強さ _EnvRimIntensity range

環境リムの全体的な明るさを設定します。

デフォルト: 1（範囲: 0 - 5）

マスク

環境リムマスク _EnvRimMask texture

環境リムの適用範囲をテクスチャで制御します。キーワード _ENV_RIM_MASK で有効化します。

デフォルト: "white"（全体に適用）

白 = 環境リムあり、黒 = 環境リムなし。顔など環境リムを見せたくない部分をマスクできます。

ブレンド設定

ブレンドモード _EnvRimBlendMode enum

環境リムとベースカラーの合成方法を選択します。

  • Normal (0) - 通常合成
  • Soft (1) - ソフトライト
  • Screen (2) - スクリーン
  • Overlay (3) - オーバーレイ

デフォルト: 0（Normal）

ブレンド _EnvRimBlend range

環境リムエフェクトの全体的な適用度を設定します。

デフォルト: 1（範囲: 0 - 1）

ブラー _EnvRimBlur range

環境リムエフェクトの境界をぼかします。

デフォルト: 0（範囲: 0 - 1）
