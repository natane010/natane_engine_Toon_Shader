ハイトフォグ

マテリアルベースの高さフォグで大気の奥行き表現

概要

ハイトフォグは、マテリアルシェーダー内で直接高さベースのフォグ効果を適用する機能です。ポストプロセッシングのフォグとは異なり、マテリアル単位で動作するため、シーンレベルのポストプロセッシングが不要です。これにより、ポストプロセッシングが使用できない・制限されるVRChat環境に最適です。

フラグメントのワールド空間Y座標に基づいてフォグカラーがマテリアル出力にブレンドされ、地表の霧、地下洞窟の霞、高所の雲層といった大気の奥行き効果を作成できます。

キーワード _HEIGHT_FOG で制御されます。この機能はBackgroundシェーダーバリアントで使用可能です。

パラメータ

フォグカラー _HeightFogColor color

ハイトフォグの色です。フォグゾーン内のフラグメントに対して、この色がマテリアル出力にブレンドされます。

デフォルト: (0.7, 0.8, 0.9, 1.0)（薄い青灰色）

神秘的な洞窟にはダークブルー、朝霧には白/ライトグレー、夕暮れの雰囲気には暖かいオレンジがおすすめです。
フォグ開始高度 _HeightFogStart float

フォグが出現し始めるワールド空間のY座標です。この高さより上のフラグメントはフォグの影響を受けません。

デフォルト: 10.0

フォグ終了高度 _HeightFogEnd float

フォグが最大密度に達するワールド空間のY座標です。この高さ以下のフラグメントは完全にフォグに覆われます。

デフォルト: 0.0

フォグは開始高度と終了高度の間でリニア（または指数関数的に）遷移します。下から上へのフォグを作るには、EndをStartより低く設定してください。
フォグ密度 _HeightFogDensity float

フォグ全体の密度を制御するマルチプライヤーです。値を大きくすると濃く不透明なフォグに、小さくすると控えめな霞になります。

デフォルト: 1.0

フォグ減衰モード _HeightFogMode enum

開始高度と終了高度の間でフォグ密度がどのように遷移するかを選択します。

  • 0 = リニア — 開始から終了まで均一な減衰
  • 1 = 指数関数 — 底部付近にフォグ密度が集中し、上方で急速に減衰

デフォルト: 0（リニア）

リニアモードは汎用的なフォグに適しています。指数関数モードは地面に張り付くような霧の表現に効果的です。

使い方のヒント

  • 神秘的な地下洞窟には、ダークブルーのフォグカラーと低い開始高度を組み合わせて奥行き感を演出しましょう。
  • 屋外の朝霧には、白やライトグレーのフォグカラーと適度な密度を設定します。
  • リニアモードは高さ範囲全体で均一な減衰を与え、指数関数モードは地面付近にフォグを集中させてよりリアルな地表霧を表現します。
  • Unityの標準ポストプロセッシングフォグが使用できないVRChatワールドで特に有効な機能です。
  • 共有マテリアルを通じて複数のオブジェクトに同じフォグ設定を適用でき、環境全体で一貫した大気効果を確保できます。
