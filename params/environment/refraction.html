屈折

GrabPass による屈折・歪みエフェクト

GrabPass を使用して、ガラスや水などの透明素材で光が曲がる屈折効果をシミュレートします。背景が歪んで見えるリアルな屈折表現が可能です。透明マテリアルに最適なエフェクトです。

キーワード: _REFRACTION

屈折設定

屈折率（IOR） _RefractionIndex range

素材の屈折率（Index of Refraction）を設定します。実際の素材の物理的な屈折率を参考に設定できます。

  • 1.0 = 空気（屈折なし）
  • 1.33 = 水
  • 1.5 = ガラス（デフォルト）
  • 2.42 = ダイヤモンド

デフォルト: 1.5（範囲: 1 - 3）

値が大きいほど背景の歪みが強くなります。ガラスなら 1.5、宝石なら 1.8-2.4 が適切です。
屈折の強さ _RefractionIntensity range

屈折による歪みの全体的な強度を設定します。

デフォルト: 1（範囲: 0 - 1）

屈折のぼかし _RefractionBlur range

屈折で歪んだ背景にぼかしを加えます。すりガラスのような効果を作成できます。

デフォルト: 0（範囲: 0 - 1）

すりガラス表現には 0.3-0.5 程度のぼかしがおすすめです。VRChat Quest では負荷軽減のため 5 サンプルに削減されています。

マスク

屈折マスク _RefractionMask texture

屈折の適用範囲をテクスチャで制御します。キーワード _REFRACTION_MASK で有効化します。

デフォルト: "white"（全体に適用）

白 = 屈折あり、黒 = 屈折なし。ガラス窓の枠部分を屈折させないといった使い方ができます。

ブレンド設定

ブレンドモード _RefractionBlendMode enum

屈折エフェクトの合成方法を選択します。

  • Normal (0) - 通常合成
  • Soft (1) - ソフトライト
  • Screen (2) - スクリーン
  • Overlay (3) - オーバーレイ

デフォルト: 0（Normal）

ブレンド _RefractionBlend range

屈折エフェクトの全体的な適用度を設定します。

デフォルト: 1（範囲: 0 - 1）
