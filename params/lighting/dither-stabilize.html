ディザ安定化

オブジェクト移動時のディザパターンのスライドを抑制

概要

ディザ安定化（Dither Stabilize）は、ディザリングパターンをオブジェクトのピボット位置に相対的に固定することで、キャラクターやオブジェクトがワールド空間で移動した際にディザパターンがスクリーン上をスライドする不快な視覚現象を抑制する機能です。

通常、ディザリングはスクリーンピクセル座標に基づいて計算されるため、オブジェクトが移動するとディザパターンがオブジェクト表面を滑るように見えます。この機能は、オブジェクトのピボットをスクリーン投影し、そのオフセットを差し引くことでパターンをオブジェクトに固定します。

このパラメータはキーワードではなく、float値で制御されます。0で従来のスクリーン固定ディザ、1で完全なオブジェクト相対ディザになります。

パラメータ

ディザ安定化 _DitherStabilize range

ディザパターンのオブジェクト相対固定の強さです。0でスクリーン座標ベース（従来動作）、1でオブジェクトピボット相対（完全安定化）になります。中間値でブレンドが可能です。

内部的には StabilizeDitherCoord() 関数で、オブジェクトのワールドピボット位置をスクリーン空間に投影し、そのスクリーン座標をディザ座標から差し引くことで実現しています。

デフォルト: 0

範囲: 0 〜 1

VRChatでキャラクターが歩き回る場合は 1.0 に設定するのがおすすめです。静止オブジェクトでは 0 のままで問題ありません。

技術的詳細

StabilizeDitherCoord() 関数は以下のように動作します:

  1. オブジェクトのワールドピボット位置（unity_ObjectToWorld._m03_m13_m23）をクリップ空間に変換
  2. NDC（正規化デバイス座標）に変換し、スクリーンピクセル座標を算出
  3. 元のスクリーンピクセル座標からピボットのスクリーン座標を差し引く
  4. 大きな正のオフセット（100000.0）を加えて、fmod()による負のインデックスを防止
  5. _DitherStabilize の値で元の座標と安定化座標をブレンド

使い方のヒント

  • 影響を受ける機能: この安定化はシェーダー内のすべてのディザリング処理に適用されます。量子化ディザリング、スペキュラーディザリング、ヘアハイライトディザリング、ハッシュドアルファ、ディザリングアルファのすべてが対象です。
  • VRChatキャラクター: アバターが移動するとディザパターンが「泳ぐ」のは目立ちやすいため、キャラクター用マテリアルでは 1.0 に設定することを強く推奨します。
  • パフォーマンス: 追加のマトリックス乗算が1回発生しますが、テクスチャサンプリングは不要で、パフォーマンスへの影響は極めて小さいです。
  • カメラ移動時: カメラが移動する場合は、どちらの設定でもディザパターンは動きます。この機能はあくまでオブジェクトの移動に対する安定化です。
