VRC Light Volumes

VRChat のボクセルベース照明システムとの統合

VRC Light Volumesはボクセルベースの次世代ライティングシステムです。対応ワールドで自動的に高品質な部分照明が適用されます。ワールドとアバター両方が対応している必要があり、非対応環境では自動的にUnityのライトプローブにフォールバックします。

Light Volumeの強さ _LightVolumeIntensity range

Light Volumeライティングの強度を制御します。1で完全強度、0で無効です。

デフォルト: 1

範囲: 0 〜 1

ブレンドモード _LightVolumeBlendMode enum

Light Volumeのブレンド方法を選択します。

  • Add (0): 直接光をアンビエントに、間接光をリムライトとして統合（デフォルト、最も自然）。Light Volumeの直接光と間接光を分離し、間接光は自然なリム効果として統合されて立体的な表現に。
  • Multiply (1): 既存のライティングと乗算（暗くなる効果）
  • Replace (2): Light Volumeで置き換え（完全に制御）

デフォルト: Add (0)

Addモードでは Shadow Receive Mask で間接光の影響を制御できます。
ブレンド _LightVolumeBlend range

Light Volume効果のブレンド強度です。

デフォルト: 1

範囲: 0 〜 1

スペキュラー関連

Light Volumeスペキュラーを有効にすると、Light Volumeからカラースペキュラーを生成します。キーワード: _LIGHT_VOLUME_SPECULAR。以下のパラメータはリフレクションと共有されます。

Smoothness _Smoothness range

表面の滑らかさ（光沢度）を制御します。リフレクション、Light Volumeスペキュラーの両方で共有されるパラメータです。高い値でより鋭い反射、低い値でぼやけた反射になります。

デフォルト: 0.5

範囲: 0 〜 1

Metallic _Metallic range

金属度を制御します。リフレクション、Light Volumeスペキュラーの両方で共有されるパラメータです。高い値で金属的な反射、低い値で非金属的な反射になります。

デフォルト: 0

範囲: 0 〜 1
