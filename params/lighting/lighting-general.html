ライティング全般

光源の強度、間接光、ライトカラーの影響を制御

グローバルライト制御

ライト強度（グローバル） _LightIntensity range

全体的なライティングの強さを制御します。0でライトなし、1で標準、2で明るくなります。

デフォルト: 1

範囲: 0 〜 2

間接光の強度 _IndirectLightIntensity range

環境光やライトプローブからの間接照明の強さを制御します。

デフォルト: 1

範囲: 0 〜 2

GI強度（環境反射） _GIIntensity range

環境反射（Light Probes/GI）の影響度を制御します。0で環境反射を完全に無効化（環境光の影響を受けない）、0.5で環境反射を50%に軽減、1で通常通り環境反射を適用します。

デフォルト: 0

範囲: 0 〜 1

VRChatで暗いワールドやライティングが強すぎるワールドで、見た目を安定させるために使用します。
ライトカラー影響度 _LightColorInfluence range

ライトの色がマテリアルに与える影響を制御します。0でライトの色を無視（白色光として処理）、0.5で中間（推奨）、1でライトの色を完全に反映します。

デフォルト: 1

範囲: 0 〜 1

色の強いライトを使うワールドでマテリアルの色味を安定させたい場合に下げてください。

シャドウ設定

影の受け取り _ShadowReceive range

他のオブジェクトからの影がこのマテリアルに与える影響を制御します。1で完全な影、0で影なしです。

デフォルト: 1

範囲: 0 〜 1

影の最大暗さ _ShadowMaxDarkness range

影の最小明るさを制御します。0で完全に暗い、1で暗くならない。影が真っ黒になりすぎるのを防ぎます。

デフォルト: 0

範囲: 0 〜 1

影が極端に暗くなるワールドでは0.2〜0.4に設定すると見栄えが改善します。
シャドー受け取りマスク _ShadowReceiveMask texture

影の受け取りを部分的に制御するマスクテクスチャです。白 = 影を受けない（明るく保つ、シェーディングも無効化）、黒 = 影を完全に受ける（通常の影とシェーディング）、グレー = 影を部分的に受けます。キーワード: _SHADOW_RECEIVE_MASK

デフォルト: "white"（トグルで有効化）

顔が髪の影で暗くなる場合、顔部分を白く塗ったマスクを使用することで顔に影がかからないようにできます。VRChatアバターでよく使われるテクニックです。Light Volumeの間接光（リム効果）も制御します。

ライト影響範囲

ライトの最小影響 _LightMinInfluence range

ライティングの最小値を設定します。暗くなりすぎを防ぎます。

デフォルト: 0

範囲: 0 〜 1

ライトの最大影響 _LightMaxInfluence range

ライティングの最大値を設定します。露出オーバーを防ぎます。

デフォルト: 2

範囲: 1 〜 5

ライトの柔らかさ

ライトのなじませ（柔らかさ） _LightBlend range

ライティングの変化を周囲となじませて、より滑らかにします。0でシャープな変化（デフォルト）、0.3〜0.5で適度な柔らかさ（推奨）、0.7〜1.0で非常に柔らかい変化です。

デフォルト: 0

範囲: 0 〜 1

ライトの強弱が急激すぎる場合に調整してください。
ハイライトの柔らかさ _HighlightSoftness range

明るい部分（ハイライト）を周囲となじませます。0でシャープなハイライト（デフォルト）、0.3〜0.5で適度な柔らかさ（推奨）、0.7〜1.0で非常に柔らかいハイライトです。

デフォルト: 0

範囲: 0 〜 1

ハイライトが強すぎる場合や、より柔らかい印象が欲しい場合に調整してください。影のなじませ・ライトのなじませ・ハイライトの柔らかさの3つ全てを0.5以上にすると、シェーディングが非常にぼやける可能性があります。メインパラメータ1〜2個を選び、他は0.3以下に抑えることを推奨します。

追加ライト

追加ライトの強さ _AdditionalLightIntensity range

追加ライト（ForwardAddパス）の強度を制御します。低い値は複数のライトを使用する際の明るくなりすぎを防ぎます。0で追加ライトなし、1で最大強度です。

デフォルト: 0.5

範囲: 0 〜 1

VRChatのクラブワールドなど、多数のライトが使われる環境では低めの値が安定します。
