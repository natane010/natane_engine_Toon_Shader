スクリーントーン

漫画風の網点オーバーレイ

影部分やマスクされた領域にスクリーントーン（網点パターン）をオーバーレイするエフェクトです。漫画やコミック風の表現に活用できます。

キーワード: _SCREEN_TONE

基本設定

スクリーントーンカラー _ScreenToneColor color

スクリーントーンのドットの色を設定します。

デフォルト: (0, 0, 0, 1)（黒）

スクリーントーンマスク _ScreenToneMask texture

スクリーントーンが表示される領域を制御するマスクテクスチャです。

  • 白 (1.0): トーンを表示
  • 黒 (0.0): トーンを非表示

デフォルト: "white"（全面に表示）

パターンスケール _ScreenToneScale range

ドットパターンの大きさを設定します。値が大きいほどドットが細かくなります。

デフォルト: 10（範囲: 1 - 200）

ドット密度 _ScreenToneThreshold range

ドットの密度（カバー率）を設定します。0 で全面、1 で最小限のドットになります。

デフォルト: 0.5（範囲: 0 - 1）

ブレンド設定

ブレンドモード _ScreenToneBlendMode enum

トーンの合成方法を選択します。

  • Normal (0) - 通常合成
  • Soft (1) - ソフト合成
  • Screen (2) - スクリーン合成
  • Overlay (3) - オーバーレイ合成

デフォルト: 0（Normal）

ブレンド _ScreenToneBlend range

トーンエフェクトの適用強度を設定します。

デフォルト: 1（範囲: 0 - 1）

マスクブラー _ScreenToneBlur range

マスクの境界をぼかします。トーンと非トーン領域の遷移を滑らかにできます。

デフォルト: 0（範囲: 0 - 1）
