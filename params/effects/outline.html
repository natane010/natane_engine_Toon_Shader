アウトライン

オブジェクトの輪郭線を描画

オブジェクトの輪郭に線を描画するアウトラインエフェクトです。トゥーンシェーダーの基本機能として、キャラクターや小物にアニメ風の輪郭線を追加できます。カメラ距離に応じた自動補正機能を搭載しています。

キーワード: _OUTLINE

アウトライン設定

描画方法 _OutlineMode enum

アウトラインの描画方法を選択します。

  • 反転ハル方式 (0) - 法線方向に頂点を押し出してアウトラインを描画。一般的に安定した結果が得られ、カメラ距離による自動調整機能を搭載。ローポリモデルやハードエッジで乱れる場合があります。
  • 背面法 (1) - メッシュを拡大して背面を描画。スムーズなアウトラインで、ハイポリモデルに適しています。内部構造が見える場合があります。

デフォルト: 0（反転ハル方式）

アウトラインの幅 _OutlineWidth range

アウトラインの太さを設定します。カメラ距離による自動補正が適用されるため、遠近で一貫した太さが維持されます。

デフォルト: 0.1（範囲: 0 - 1）

アウトラインの色 _OutlineColor color

アウトラインの色を設定します。

デフォルト: (0, 0, 0, 1)（黒）

キャラクターの場合、完全な黒よりもやや茶色や紺色にするとアニメ風に馴染みます。

アウトラインマスク

アウトラインマスク (R) _OutlineMask texture

R（赤）チャンネルを使用してアウトラインの表示を制御します。キーワード _OUTLINE_MASK で有効化します。

  • 白 (1.0): アウトラインを完全に表示
  • 黒 (0.0): アウトラインを非表示
  • グレー: 部分的に表示

デフォルト: "white"（全体に表示）

顔の目や口の周辺でアウトラインを消したい場合に活用できます。

アウトライン幅マップ

アウトライン幅マップ (R) _OutlineWidthMap texture

R（赤）チャンネルを使用してアウトラインの幅を部位ごとに制御します。キーワード _OUTLINE_WIDTH_MAP で有効化します。

  • 白 (1.0): 通常の幅
  • 黒 (0.0): 幅ゼロ（アウトライン非表示）
  • グレー: 部分的な幅

デフォルト: "white"（均一な幅）

顔は細く、体は太くなど、部位ごとにアウトラインの太さを調整できます。

マルチカラーアウトライン

アウトラインの色 2 _OutlineColor2 color

2色グラデーションアウトラインの2番目の色です。キーワード _OUTLINE_MULTI_COLOR で有効化します。

デフォルト: (0.5, 0, 0, 1)（暗い赤）

カラーミックス _OutlineColorMix range

アウトラインの色1と色2の混合度を設定します。0 で色1のみ、1 で色2のみになります。

デフォルト: 0.5（範囲: 0 - 1）

アウトラインにグラデーションやアニメーション効果を追加したい場合に使用します。

コーナーギャップ修正

ハードエッジのメッシュで反転ハル方式を使用する際、角（コーナー）に隙間が発生することがあります。最善の解決策は「スムース法線」機能（SmoothNormalBaker）の使用ですが、以下のパラメータで簡易的な改善も可能です。

コーナースムージング _OutlineCornerSmooth range

スムース法線が無効な場合のフォールバック処理です。頂点法線をオブジェクト中心からの方向にブレンドし、コーナーの隙間を軽減します。スムース法線が有効な場合は使用されません。

デフォルト: 0（範囲: 0 - 1）

0.3〜0.5 程度の値で多くのハードエッジモデルのギャップが改善されます。
エッジ幅補正 _OutlineEdgeCompensation range

シャープなエッジ部分でアウトライン幅を自動的に縮小し、コーナーの飛び出しを抑制します。法線の不一致度を検出して幅を調整するため、スムース法線の ON/OFF に関わらず使用できます。

デフォルト: 0（範囲: 0 - 1）

スムース法線と併用しても効果があります。角張ったモデルでアウトラインが不自然に太くなる部分を改善します。
