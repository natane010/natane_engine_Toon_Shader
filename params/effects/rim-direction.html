リムライト方向制御

リムライトの方向を制限して演出効果を高める

概要

リムライト方向制御は、通常すべての縁に均等にかかるリムライトを特定の方向に制限する機能です。上からの光、横からの光など、方向を指定することでよりリアルで演出的なリムライト表現が可能になります。

キーワード _RIM_DIRECTION_CONTROL で制御されます。この設定はリムライト1・リムライト2の両方に共通で適用されます。

この設定の影響範囲

リムライト方向制御を有効にすると、リムライト1とリムライト2の両方に同じ方向制限がかかります。個別の方向制御はできません。

パラメータ

リムライト方向 _RimLightDirection vector

リムライトを適用する方向をワールド空間のベクトルで指定します。指定した方向に面している法線にのみリムライトが適用されます。

デフォルト: (0, 1, 0, 0)（上方向）

ベクトルは自動的に正規化されます。(0,1,0) = 上から、(1,0,0) = 右から、(0,0,1) = 前方から。
方向の範囲 _RimDirectionRange range

方向制限の緩さを制御します。値が大きいほど指定方向から離れた部分にもリムライトが適用され、値が小さいほど厳密に方向に沿った部分のみに制限されます。

デフォルト: 0.5

範囲: 0 〜 1

0に近い値は非常に狭い範囲にのみリムが出ます。0.5前後がバランスの良い設定です。

方向プリセット

Tools > Natane > エフェクト Effects > リムライト方向ビジュアライザー を使用すると、視覚的に方向を調整できます。以下のプリセット方向がワンクリックで設定可能です:

  • 上 (Top): (0, 1, 0) - 上方向からのリム。逆光演出に最適
  • 下 (Bottom): (0, -1, 0) - 下方向からのリム。不気味な演出に
  • 左 (Left): (-1, 0, 0) - 左方向からのリム
  • 右 (Right): (1, 0, 0) - 右方向からのリム
  • 前 (Front): (0, 0, 1) - 前方からのリム
  • 後 (Back): (0, 0, -1) - 後方からのリム

方位角（Azimuth）と仰角（Elevation）スライダーで細かい角度調整も可能です。
