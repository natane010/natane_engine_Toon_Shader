雫エフェクト（ウォータードリップ）

水滴が流れ落ちるアニメーションエフェクト

概要

雫エフェクト（ウォータードリップ）は、水滴が表面を滴り落ちるような表現を追加するアニメーションエフェクトです。雨に濡れた衣装やガラス表面の表現に適しています。

キーワード _WATER_DRIP で制御され、無効時はシェーダー命令が生成されません。

パラメータ

雫の色 _DripColor color

水滴の色を設定します。透明感のある色が自然な仕上がりになります。

デフォルト: (0.7, 0.85, 1.0, 1)（薄い青白）

リアルな水滴には (0.7, 0.85, 1.0) の薄い青白、血の表現には (0.8, 0.1, 0.1) の赤系も使えます。
雫の速度 _DripSpeed range

雫が落ちる速度を制御します。値が大きいほど速く落下します。

デフォルト: 1

範囲: 0.1 〜 5

ゆっくりとした雨の表現には0.3〜0.5、激しい雨には2〜3がおすすめです。
雫の密度 _DripDensity range

雫の出現頻度を制御します。値が大きいほど多くの雫が表示されます。

デフォルト: 0.5

範囲: 0 〜 1

0 = 少ない、1 = 多い。少量の汗や結露には低密度（0.1〜0.3）、大雨には高密度（0.7〜1.0）が効果的です。
雫のサイズ _DripSize range

個々の雫の大きさを制御します。

デフォルト: 0.15

範囲: 0.01 〜 0.5

雫の尾の長さ _DripTrailLength range

雫が残す水跡（尾）の長さを制御します。値が大きいほど長い水跡が残ります。

デフォルト: 1.0

範囲: 0 〜 3

0に設定すると尾がなくなり、丸い水滴のみが表示されます。長い尾は窓ガラスを流れる雨のような表現に最適です。
雫の強度 _DripIntensity range

エフェクトの明るさ（強度）を制御します。

デフォルト: 1

範囲: 0 〜 2

雫のシャープさ _DripSharpness range

雫の輪郭の鮮明さを制御します。値が大きいほどくっきりとした輪郭、小さいほどぼやけた輪郭になります。

デフォルト: 2

範囲: 0.5 〜 5

マスク

雫マスク _DripMask texture

雫の表示領域を制御するマスクテクスチャです。キーワード _DRIP_MASK で有効化します。Rチャンネル（赤）を使用して雫の表示領域を制御します。

デフォルト: "white"（全面表示）

白 (1.0) = 雫を完全に表示、黒 (0.0) = 雫を非表示、グレー = 部分的に表示。マスクテクスチャで雫が流れる領域を制限できます。

ブレンド＆ブラー

ブレンドモード _DripBlendMode enum

雫エフェクトのブレンド方法を選択します。

  • Normal (0) - 通常の加算合成
  • Soft (1) - ソフトな加算。明るくなりすぎを防ぐ
  • Screen (2) - スクリーン合成。自然な明るさ加算
  • Overlay (3) - オーバーレイ合成。コントラスト強調

デフォルト: Normal (0)

ブレンド _DripBlend range

雫エフェクトの強度（不透明度）を制御します。

デフォルト: 1

範囲: 0 〜 1

ブラー _DripBlur range

雫エフェクトのぼかし量を調整します。

デフォルト: 0

範囲: 0 〜 1

使い方のヒント

雨に濡れた衣装やガラス表面の表現

  • 速度: 雫が落ちる速度
  • 密度: 雫の出現頻度（0=少ない、1=多い）
  • サイズ: 雫の大きさ
  • 尾の長さ: 雫が残す水跡の長さ
  • 強度: エフェクトの明るさ
  • シャープさ: 雫の輪郭の鮮明さ

マスクテクスチャで雫が流れる領域を制限することで、肩から流れ落ちる雨や、窓の一部だけに結露がつくような自然な表現が可能です。
