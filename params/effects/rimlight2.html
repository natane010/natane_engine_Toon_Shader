リムライト2

2番目のリムライトレイヤーで異なる色・強度の縁光

概要

リムライト2は、リムライト1と独立した2番目のリムライトレイヤーです。2つのリムライトレイヤーを重ねることで、より複雑で立体的なリムライト表現が可能になります。

キーワード _RIM_LIGHT_2 で制御され、無効時はシェーダー命令が生成されません。

多段階リムライトのおすすめ設定

2つのリムライトレイヤーを効果的に使い分けるコツ:

  • リムライト1: 明るい色、低いパワー（内側の輪郭）
  • リムライト2: 淡い色、高いパワー（外側の輪郭）

異なるブレンドモードや色を組み合わせることで、虹色の輪郭やグラデーション効果を演出できます。

パラメータ

リムライト2の色 _RimColor2 color

2番目のリムライトの色を設定します。リムライト1とは異なる色を設定することで、グラデーション効果を演出できます。

デフォルト: (0.5, 0.8, 1, 1)（薄い青）

リムライト1と補色関係の色を使うと、幻想的な印象になります。
リムライト2のパワー _RimPower2 range

2番目のリムライトの鋭さを制御します。リムライト1と異なるパワー値を設定すると、内側と外側で異なる輪郭効果が得られます。

デフォルト: 5

範囲: 0.1 〜 10

リムライト2の強さ _RimIntensity2 range

2番目のリムライトの明るさ（強度）を制御します。

デフォルト: 0.5

範囲: 0 〜 5

リムの広がり2（グロー） _RimSpread2 range

リムライト2を滲ませて広げます。

デフォルト: 0

範囲: 0 〜 1

マスク

リムマスク2 _RimMask2 texture

リムライト2の表示領域を制御するマスクテクスチャです。キーワード _RIM_MASK_2 で有効化します。リムライト1のマスクとは独立しています。

デフォルト: "white"（全面表示）

白 = リムライトあり、黒 = リムライトなし。リムライト1とは別のマスクが使えるため、パーツごとに異なるリムライト設定が可能です。

ブレンド＆ブラー

ブレンドモード _RimBlendMode2 enum

リムライト2のブレンド方法を選択します。

  • Normal (0) - 通常の加算合成
  • Soft (1) - ソフトな加算。明るくなりすぎを防ぐ
  • Screen (2) - スクリーン合成。自然な明るさ加算
  • Overlay (3) - オーバーレイ合成。コントラスト強調

デフォルト: Normal (0)

ブレンド _RimBlend2 range

リムライト2エフェクトの強度（不透明度）を制御します。

デフォルト: 1

範囲: 0 〜 1

ブラー _Rim2Blur range

リムライト2エフェクトのぼかし量を調整します。

デフォルト: 0

範囲: 0 〜 1
