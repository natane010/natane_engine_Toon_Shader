FXモジュレーター

時間・音・距離・視線角度で、他の機能を自動的に動かす制御装置です。心拍のように Emission が脈動したり、カメラが近づくと覚醒したり、Bass に合わせて等高線が流れる、といった演出を作れます。(v1.6.0)

PREVIEW FX Modulator

概要

この機能自体は色や模様を描きません。Source (入力信号) から取得した値を Target (適用先) のパラメータへ乗算 / 加算し、他の機能を「動かす」制御システムです。2 つのスロット (0 / 1) を持ち、複数の変化を組み合わせられます。

スロット値はフラグメント冒頭で一度だけ計算され、各ターゲット地点で適用されます。キーワード _FX_MODULATOR で切り替わり、OFF 時はゼロコストです。AudioLink 系ソースは _AUDIOLINK 併用時のみ有効になります。

作れる表現

  • 音に合わせて模様が切り替わる、Bass に合わせて等高線が上へ流れる
  • 心拍のように Emission が脈動する
  • カメラが近づくと覚醒する (CameraDistance)
  • 横から見たときだけグリッチする (ViewAngle)

信号ソース (Source)

値ソース内容
0〜4Sine / Saw / Triangle / Pulse / RandomStep時間ベースの波形
5〜8AudioLink Bass / LowMid / HighMid / Treble音の帯域 (_AUDIOLINK 必須、非対応時は中立 0)
9ChronotensityAudioLink の累積時間
10CameraDistanceカメラからの距離 (_FXModDistMin/Max で正規化)
11ViewAngle視線角度
12Manual手動値 (_FXModManual)

適用先 (Target)

値ターゲット適用
0Noneなし
1EmissionIntensity乗算
2HueShift加算
3RimIntensity乗算
4OutlineWidth乗算 (OUTLINE パスでも動作)
5LineBoilStrength乗算
6TopographicOffset加算

スロットごとのパラメータ

{n} はスロット番号 (0 または 1) です。2 スロットとも同じ構成のプロパティを持ちます。

プロパティ型 / 既定説明
_FXModulatorToggle / 0有効化 (_FX_MODULATOR)
_FXModSource{n}Enum(0-12) / 0信号ソース
_FXModTarget{n}Enum(0-6) / 0適用先
_FXModAmount{n}Float / 0変調量 (0 で中立)
_FXModOffset{n}Float / 0位相オフセット
_FXModSpeed{n}Float / 1速度
_FXModMin{n} / _FXModMax{n}Float / 0, 1出力レンジ最小 / 最大
_FXModInvert{n}Toggle / 0反転
_FXModCurve{n}Range(0.1,5) / 1カーブ (pow)
_FXModManual{n}Range(0,1) / 0.5Manual ソース値
_FXModDistMin{n} / _FXModDistMax{n}Float / 0, 10CameraDistance 正規化範囲
_FXModMaskTex2D / white共有マスク (R=スロット0, G=スロット1)

使い方のヒント

  • まずは 1 スロット: Source を選び、Target を決め、Amount を 0 から少しずつ上げると変化が見えます。Amount が 0 のときは何も起きません (中立)。
  • 音に反応させる: Source に AudioLink 系を選ぶにはAudioLink (_AUDIOLINK) が必要です。非対応環境では中立値になり破綻しません。
  • 出力を整える: Min/Max で出力範囲、Curve で反応カーブ、Invert で反転を調整します。
  • マスク: _FXModMaskTex の R チャンネルがスロット0、G チャンネルがスロット1 に対応します。
