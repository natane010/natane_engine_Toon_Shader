AudioLink

VRChat AudioLink で音楽に反応するエフェクト

VRChat の AudioLink 対応ワールドで、音楽のビートやリズムに連動してシェーダーエフェクトがリアルタイムに変化します。エミッション、リムライト、色相シフト、ディゾルブ、アウトラインの各エフェクトを個別に音楽連動させることが可能です。クラブやライブイベント向けに最適なエフェクトです。

キーワード: _AUDIOLINK

周波数帯域について

AudioLink 周波数帯域

各エフェクトで使用する周波数帯域を選択できます。

  • Bass (0) - ベース音域。キックドラムやベースラインに反応します。
  • Low Mid (1) - 中低音域。スネアドラムやギターの低音に反応します。
  • High Mid (2) - 中高音域。ボーカルやメロディに反応します。
  • Treble (3) - 高音域。ハイハットやシンバルに反応します。

エミッション連動

周波数帯域 _AudioLinkEmissionBand enum

エミッション（発光）が反応する周波数帯域を選択します。キーワード _AUDIOLINK_EMISSION で有効化します。

デフォルト: 0（Bass）

エミッション強度 _AudioLinkEmissionIntensity range

音楽に連動したエミッションの発光強度を設定します。

デフォルト: 1（範囲: 0 - 5）

リムライト連動

周波数帯域 _AudioLinkRimBand enum

リムライトが反応する周波数帯域を選択します。キーワード _AUDIOLINK_RIM で有効化します。

デフォルト: 0（Bass）

リムライト強度 _AudioLinkRimIntensity range

音楽に連動したリムライトの強度を設定します。

デフォルト: 1（範囲: 0 - 5）

色相シフト連動

周波数帯域 _AudioLinkHueBand enum

色相シフトが反応する周波数帯域を選択します。キーワード _AUDIOLINK_HUE_SHIFT で有効化します。

デフォルト: 0（Bass）

色相シフト強度 _AudioLinkHueShiftIntensity range

音楽に連動した色相シフトの強度を設定します。

デフォルト: 0.5（範囲: 0 - 1）

ディゾルブ連動

周波数帯域 _AudioLinkDissolveBand enum

ディゾルブが反応する周波数帯域を選択します。キーワード _AUDIOLINK_DISSOLVE で有効化します。

デフォルト: 0（Bass）

ディゾルブ強度 _AudioLinkDissolveIntensity range

音楽に連動したディゾルブの強度を設定します。

デフォルト: 0.5（範囲: 0 - 1）

アウトライン連動

周波数帯域 _AudioLinkOutlineBand enum

アウトラインが反応する周波数帯域を選択します。キーワード _AUDIOLINK_OUTLINE で有効化します。

デフォルト: 0（Bass）

アウトライン強度 _AudioLinkOutlineIntensity range

音楽に連動したアウトラインの強度を設定します。

デフォルト: 0.5（範囲: 0 - 1）

ブレンド設定

ブレンドモード _AudioLinkBlendMode enum

AudioLink エフェクト全体の合成方法を選択します。

  • Normal (0) - 通常合成
  • Soft (1) - ソフトライト
  • Screen (2) - スクリーン
  • Overlay (3) - オーバーレイ

デフォルト: 0（Normal）

ブレンド _AudioLinkBlend range

AudioLink エフェクトの全体的な適用度を設定します。

デフォルト: 1（範囲: 0 - 1）
