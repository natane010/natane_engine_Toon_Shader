ファー（シェルベース毛皮）

16シェルパスによる高品質なファーレンダリング

シェルベース方式でメッシュ表面に毛皮を表現するエフェクトです。メッシュを法線方向に16層押し出し、プロシージャルノイズによるアルファカットオフで毛の隙間を生成します。重力・風アニメーション・距離ベースLODなど、リアルタイム向けの最適化機能を搭載しています。

キーワード: _FUR | シェーダー: Natane/Toon Shader (Fur)

使用上の注意

  • 描画タイプを「ファー」に切り替えると、専用の Fur シェーダーバリアントが適用されます。
  • 16シェルパスにより描画コールが大幅に増加します。GPU負荷が非常に高い機能です。
  • VRChat Quest では使用しないでください。
  • ファーをOFFにすると自動で不透明シェーダーに戻り、GPUコストはゼロになります。

基本設定

ファーの長さ _FurLength range

毛の長さを設定します。値が大きいほどメッシュから離れた位置まで毛が伸びます。

デフォルト: 0.02（範囲: 0 - 0.1）

0.01〜0.05 が自然な見た目の推奨範囲です。大きすぎるとシェル間の隙間が目立ちます。
ファー密度 _FurDensity range

プロシージャルノイズの密度（スケール）を設定します。値が大きいほど細かい毛のパターンになります。

デフォルト: 30（範囲: 1 - 100）

低い値 (5〜15) で太い毛束、高い値 (30〜60) で細かい毛の表現になります。
アルファカットオフ _FurAlphaCutoff range

ノイズ値がこの閾値以下のピクセルをカットします。低い値で密な毛、高い値でまばらな毛になります。

デフォルト: 0.5（範囲: 0 - 1）

ノイズテクスチャ _FurNoiseTex texture

カスタムノイズテクスチャでプロシージャルノイズをマスクします。テクスチャ未設定（白）でもプロシージャルノイズが自動生成されるため、設定は任意です。

デフォルト: "white"（プロシージャルノイズのみ使用）

カスタムテクスチャを設定すると、プロシージャルノイズに追加のパターンを乗算できます。
ファーマスク _FurMask texture

毛が生える領域を制御するマスクテクスチャです。R チャンネルを使用します。

  • 白 (1.0): 毛が生える
  • 黒 (0.0): 毛が生えない

デフォルト: "white"（全面に毛が生える）

顔や手など毛が不要な部分を黒く塗ることで、部分的にファーを適用できます。

カラー

根元カラー _FurRootColor color

毛の根元（メッシュ表面に近い部分）の色です。

デフォルト: (0.3, 0.2, 0.15, 1)（暗い茶色）

根元を暗くすると、自然なファーの陰影感が出ます。
先端カラー _FurTipColor color

毛の先端（外側のシェル）の色です。根元から先端にかけてグラデーションがかかります。

デフォルト: (0.8, 0.7, 0.5, 1)（明るいベージュ）

メインカラー混合比 _FurColorBlend range

メインテクスチャの色とファーカラーの混合度を設定します。0 でメインテクスチャの色のみ、1 でファーカラーのみになります。

デフォルト: 0.5（範囲: 0 - 1）

物理

重力 _FurGravity range

毛が下方向に垂れる強さです。二次関数のフォールオフにより、先端ほど大きく垂れ下がります。

デフォルト: 0.02（範囲: 0 - 0.1）

風の強さ _FurWindStrength range

風による毛の揺れの振幅を設定します。

デフォルト: 0（範囲: 0 - 0.05）

風の速度 _FurWindSpeed range

風アニメーションの速度（周波数）を設定します。

デフォルト: 1（範囲: 0 - 10）

風の方向 _FurWindDirection vector

風が吹く方向を XYZ ベクトルで指定します。

デフォルト: (1, 0, 0, 0)（X方向）

シェーディング

セルフオクルージョン _FurAO range

毛の根元が暗くなるアンビエントオクルージョン効果の強さです。根元は暗く、先端は明るくなります。

デフォルト: 0.3（範囲: 0 - 1）

セルフシャドウ強度 _FurShadowStrength range

内側のシェルが受ける光の減衰の強さです。毛の内部に自然な影が生まれます。

デフォルト: 0.5（範囲: 0 - 1）

スペキュラ _FurSpecular range

毛先のハイライト（スペキュラ反射）の強さです。先端のシェルほど強く反射します。

デフォルト: 0（範囲: 0 - 1）

リムライト _FurRimLight range

毛の輪郭に沿ったリムライト効果の強さです。逆光時にファーのシルエットが強調されます。

デフォルト: 0（範囲: 0 - 1）

パフォーマンス

LOD開始距離 _FurLODDistance range

この距離からシェルの数を自動的に減らし始めます。遠くのオブジェクトでGPU負荷を軽減します。

デフォルト: 10（範囲: 1 - 50）

最小レイヤー数 _FurLODMinLayers range

遠距離でも最低限維持するシェルの数です。0 にすると遠距離で完全に非表示になります。

デフォルト: 4（範囲: 0 - 16）
