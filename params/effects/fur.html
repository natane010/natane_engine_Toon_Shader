ファーレンダリング

シェルベースのファー・毛皮レンダリングシステム

概要

16シェルパスを使用した高品質なシェルベースファーレンダリングです。リアルな毛皮、ウール、毛髪のエフェクトを作成します。この機能は「Fur」レンダリングタイプバリアントでのみ使用可能です。高いGPUコストのためデフォルトOFF — 手動でのアクティベーションが必要です。

キーワード _FUR（Furシェーダーバリアント専用）で制御されます。_FUR キーワードがOFFの場合、すべてのファーパスが破棄されGPUコストはゼロになります。

基本設定

ファーの長さ _FurLength float

ファーストランドの長さを制御します。値が高いほど長いファーになります。

小さい値（0.01〜0.05）から始めて徐々に増やしてください。非常に長いファーは極端な角度でビジュアルアーティファクトが発生する場合があります。
ファーの密度 _FurDensity float

ファーストランドの密度を制御します。値が高いほど太く密集したファーになります。

アルファカットオフ _FurAlphaCutoff float

ファーストランド先端のアルファカットオフ閾値を設定します。ストランドの先端がどれほどシャープまたはテーパーに見えるかを制御します。

重力 _FurGravity float

二次関数の減衰を使ったファーストランドへの重力垂れ下がりエフェクトを適用します。値が高いほどファーが地面方向に垂れ下がります。

カラー設定

根元の色 _FurRootColor color

ファーストランドの根元（ルート）の色を設定します。

暗い根元色と明るい先端色の組み合わせで自然なファーグラデーションが生まれます。サーフェスでのシームレスなブレンドのため、ベースマテリアルの色に合わせてください。
先端の色 _FurTipColor color

ファーストランドの先端の色を設定します。

カラーブレンド _FurColorBlend float

ファーストランドの長さに沿った根元色と先端色のブレンド係数を制御します。

シェーディング

アンビエントオクルージョン _FurAO float

自己遮蔽によるアンビエント暗化エフェクトを制御します。根元近くのファーが暗く表示され、ファーボリューム内での光の吸収をシミュレートします。

シャドウ強度 _FurShadowStrength float

ファーサーフェスに投影される影の強度を制御します。

スペキュラー _FurSpecular float

ファーストランドのスペキュラーハイライト強度を制御します。

リムライト _FurRimLight float

ファーのリムライティング強度を制御します。ファーのシルエット周りにバックライトのハロー効果を生み出します。

風アニメーション

風の方向 _FurWindDirection vector

ファーストランドに適用される風力の方向を設定します。

風の速度 _FurWindSpeed float

ファーへの風エフェクトのアニメーション速度を制御します。

風の強さ _FurWindStrength float

風アニメーションの力の強さを設定します。

LOD＆パフォーマンス

LOD距離 _FurLODDistance float

LOD（Level of Detail）がシェルレイヤーの削減を開始する距離を設定します。この距離を超えると、GPUパフォーマンスを節約するためにシェルパス数が減少します。

VRChat最適化のためにLODを有効にしてください。妥当な距離（5〜10m）に設定することで、近距離での品質を維持しつつ遠距離でのパフォーマンスを節約できます。
LOD最小レイヤー数 _FurLODMinLayers float

LOD距離で使用されるシェルレイヤーの最小数を設定します。レイヤー数はカメラ距離に基づいて16（フル品質）からこの最小値の間で補間されます。

テクスチャ

ノイズテクスチャ _FurNoiseTex texture

ファーストランドのパターンを定義するノイズテクスチャです。シェル間の個々のファーストランドの形状と分布を制御します。

ハイコントラストなノイズで個別のファーストランドを際立たせ、ソフトなノイズでウールやぬいぐるみのような外観にできます。
ファーマスク _FurMask texture

ファーがレンダリングされる場所を制御するマスクテクスチャです。白い領域にファーが生成され、黒い領域はファーなしになります。

パフォーマンス警告 — 16シェルパスがドローコールを大幅に増加させます。_FurMaskを使用して特定の領域（襟、尻尾、耳）にファーを制限し、レンダリングコストを削減してください。
