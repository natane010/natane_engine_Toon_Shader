エミッション

自己発光による光り輝くエフェクト

マテリアルの一部または全体を自己発光させるエフェクトです。光るサイン、ネオン表現、魔法効果、発光するアクセサリーなどの表現に使用します。スクロールやパルスのアニメーションも可能です。

キーワード: _EMISSION、_EMISSION_SCROLL、_EMISSION_PULSE

基本設定

エミッションの色 _EmissionColor color

エミッション（発光）の色を設定します。HDRカラーに対応しており、強度1以上の明るい色を設定することでブルーム効果と組み合わせた強い発光が可能です。

デフォルト: (0, 0, 0, 1)（黒・発光なし）

HDRカラーで強度を上げると、ポストプロセスのブルームと組み合わせて輝く効果が得られます。
エミッションマップ _EmissionMap texture

エミッションの発光パターンを定義するテクスチャです。白い部分が発光し、黒い部分は発光しません。

デフォルト: "white"（全体が発光）

スクロールアニメーション

スクロール速度 _EmissionScrollSpeed float

エミッションテクスチャがスクロールする速度を設定します。キーワード _EMISSION_SCROLL で有効化します。

デフォルト: 1

流れる光や回路のような動きのあるエフェクトを作成できます。

パルスアニメーション

パルス速度 _EmissionPulseSpeed float

エミッションが明滅（パルス）する速度を設定します。キーワード _EMISSION_PULSE で有効化します。

デフォルト: 1

パルスの振幅 _EmissionPulseAmplitude range

パルスの明暗の振幅を設定します。値が大きいほど明暗の差が大きくなります。

デフォルト: 0.5（範囲: 0 - 1）

マスク

エミッションマスク _EmissionMask texture

エミッションの適用範囲をテクスチャで制御します。キーワード _EMISSION_MASK で有効化します。

デフォルト: "white"（全体に適用）

白 = エミッションあり、黒 = エミッションなし。エミッションマップとは別に、追加のマスク制御が可能です。

グロー（ブルーム）

エミッショングロー（ブルーム） _EmissionGlow range

発光部分を滲ませて明るく広げ、柔らかく輝いているような効果を追加します。

  • 0 = グローなし（シャープな発光）
  • 0.3 - 0.5 = 適度なグロー（推奨）
  • 0.7 - 1.0 = 強いグロー（強烈な輝き）

デフォルト: 0（範囲: 0 - 1）

HDRカラーと組み合わせると、より鮮やかな発光効果が得られます。

ブレンド設定

ブレンドモード _EmissionBlendMode enum

エミッションとベースカラーの合成方法を選択します。

  • Normal (0) - 通常合成
  • Soft (1) - ソフトライト
  • Screen (2) - スクリーン
  • Overlay (3) - オーバーレイ

デフォルト: 0（Normal）

ブレンド _EmissionBlend range

エミッションエフェクトの全体的な適用度を設定します。

デフォルト: 1（範囲: 0 - 1）

ブラー _EmissionBlur range

エミッションの境界をぼかします。

デフォルト: 0（範囲: 0 - 1）
