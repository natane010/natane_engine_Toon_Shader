色相シフト

色相をリアルタイムで変化させるカラーエフェクト

マテリアル全体の色相をリアルタイムで変更するエフェクトです。VRChatでの色変更エフェクトに最適で、アニメーションコントローラーからパラメータを制御することで、衣装やアクセサリーの色をリアルタイムで切り替えることができます。

キーワード: _HUE_SHIFT

色相シフト設定

色相シフト _HueShift range

マテリアル全体の色相を変更します。色相環に沿って色が回転します。

  • 0 = 変更なし（元の色）
  • 0.25 = 90度回転
  • 0.5 = 補色（180度回転）
  • 0.75 = 270度回転
  • 1 = 完全な回転（元の色に戻る）

デフォルト: 0（範囲: 0 - 1）

VRChatのExpression Menuと連動させて、プレイ中に衣装の色をリアルタイムで変更するのに最適です。
ブレンド _HueShiftBlend range

色相シフトエフェクトの全体的な適用度を設定します。0 で元の色のまま、1 で完全に色相シフトが適用されます。

デフォルト: 1（範囲: 0 - 1）

ブラー _HueShiftBlur range

色相シフトの境界をぼかします。

デフォルト: 0（範囲: 0 - 1）
