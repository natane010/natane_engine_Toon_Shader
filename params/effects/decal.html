デカル

UV空間にステッカーやマークを貼り付け

メッシュの表面にテクスチャを貼り付けるデカルシステムです。ロゴ、マーク、タトゥー、ワッペンなどの装飾表現に最適です。UV空間での位置・回転・スケールを自由に調整できます。

キーワード: _DECAL

デカルテクスチャ

デカールテクスチャ _DecalTex texture

貼り付けるデカルのテクスチャです。アルファチャンネルを使用することで、不規則な形状のデカルも作成できます。

デフォルト: "white"

透過PNGを使えば、丸いステッカーや複雑な形状のロゴも綺麗に貼れます。
デカールカラー _DecalColor color

デカルテクスチャに乗算されるカラーです。テクスチャの色味を調整したり、単色デカルを作成する際に使用します。

デフォルト: (1, 1, 1, 1)（白・変更なし）

位置・変形

デカール位置 (XY) _DecalPosition vector

UV空間でのデカルの位置を設定します。X と Y でデカルの配置場所を調整します。

デフォルト: (0, 0, 0, 0)

UV空間の座標系なので、メッシュのUV展開を確認しながら位置を調整してください。
回転 _DecalRotation range

デカルの回転角度を度数法で設定します。

デフォルト: 0（範囲: 0 - 360）

スケール _DecalScale float

デカルの大きさを設定します。1.0 が基準サイズで、値を大きくするとデカルが拡大されます。

デフォルト: 1

ブレンド設定

合成モード _DecalBlendMode enum

デカルとベースカラーの合成方法を選択します。

  • Add (0) - 加算合成（明るく追加）
  • Multiply (1) - 乗算（暗くなる）
  • Overlay (2) - オーバーレイ
  • Replace (3) - 置き換え（デカルで上書き）

デフォルト: 0（Add）

ロゴやワッペンには Replace、光る模様には Add がおすすめです。
ブレンド _DecalBlend range

デカルエフェクトの全体的な適用度を設定します。

デフォルト: 1（範囲: 0 - 1）

ブラー _DecalBlur range

デカルの境界をぼかします。

デフォルト: 0（範囲: 0 - 1）
