スミアエフェクト

モーションブラー風の残像・引き伸ばし効果

頂点を指定方向に引き伸ばして残像風の効果を生み出すエフェクトです。高速移動の表現やスタイライズドなモーションブラーに活用できます。VATの速度データとの連携も可能です。

キーワード: _SMEAR

基本設定

ストレッチ量 _SmearStretch range

頂点の引き伸ばし量を設定します。

デフォルト: 0（範囲: 0 - 3）

スミア方向 _SmearDirection vector

引き伸ばしの方向を XYZ ベクトルで指定します。

デフォルト: (0, 0, 0, 0)

ノイズスケール _SmearNoiseScale range

引き伸ばしに適用するノイズの周波数です。不規則な変形を加えます。

デフォルト: 1（範囲: 0 - 5）

ノイズ強度 _SmearNoiseStrength range

ノイズ変形の強さを設定します。

デフォルト: 0.3（範囲: 0 - 1）

モーション連携

自動マグニチュード _SmearAutoMagnitude toggle

移動量に応じて自動的にスミア量を調整します。

デフォルト: OFF

モーション感度 _SmearMotionSensitivity range

自動マグニチュード有効時の移動量に対する感度です。

デフォルト: 1（範囲: 0.1 - 10）

VAT速度連携 _SmearVATVelocity toggle

VAT（Vertex Animation Texture）の速度データとスミア方向を連携します。

デフォルト: OFF

トレイル効果

トレイル長さ _SmearTrailLength range

残像の尾の長さを設定します。

デフォルト: 0.1（範囲: 0 - 0.5）

トレイルフェード _SmearTrailFade range

残像の尾が消えていく減衰率です。

デフォルト: 0.5（範囲: 0 - 1）

グロー・エミッション

グローカラー _SmearGlowColor color

スミア部分のグロー色を設定します。

デフォルト: (1, 1, 1, 1)（白）

グロー強度 _SmearGlowIntensity range

グローの明るさを設定します。

デフォルト: 1（範囲: 0 - 3）

エミッション強度 _SmearEmission range

スミア部分のエミッション（自発光）強度です。

デフォルト: 0（範囲: 0 - 3）

エミッションカラー _SmearEmissionColor color

エミッションの色を設定します。

デフォルト: (1, 0.5, 0, 1)（オレンジ）

マスク・ブレンド

スミアマスク _SmearMask texture

スミアエフェクトが適用される領域を制御するマスクテクスチャです。

デフォルト: "white"（全面に適用）

距離フェード _SmearDistFade range

カメラからの距離に応じてスミアを減衰させます。遠距離でエフェクトを弱めます。

デフォルト: 0（範囲: 0 - 1）
