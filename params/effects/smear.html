スメアエフェクト

モーションスメア・残像トレイルエフェクト

概要

スメアエフェクトは、動的な動きの表現のためにモーションブラー/スメアトレイルを作成します。手動の方向制御と自動モーション検出に対応しており、アニメ風のスピードエフェクトやダンスアニメーションに最適です。

キーワード _SMEAR で制御され、無効時はシェーダー命令が生成されません。

ストレッチ設定

スメアストレッチ _SmearStretch range

スメアエフェクトのストレッチ量を制御します。値が高いほど顕著な引き伸ばしになります。

デフォルト: 0

範囲: 0 〜 3

控えめな動きの示唆には低い値（0.3〜0.5）から始めてください。1.5以上でドラマチックなアニメ風スピード線になります。
スメア方向 _SmearDirection vector

スメアの方向ベクトルを手動で設定します。スメアの向きを正確に制御したい場合に使用します。

デフォルト: (0, 0, 0, 0)

水平方向のモーションには(1, 0, 0, 0)、垂直方向には(0, 1, 0, 0)を使用します。VRChatパラメータ経由でアニメーションさせて方向制御が可能です。

ノイズ設定

ノイズスケール _SmearNoiseScale range

スメアに適用されるノイズパターンのスケールを制御します。エフェクトに変化とオーガニックな質感を加えます。

デフォルト: 1

範囲: 0 〜 5

ノイズ強度 _SmearNoiseStrength range

スメアトレイルに適用されるノイズの歪み強度を設定します。

デフォルト: 0.3

範囲: 0 〜 1

モーション検出

自動マグニチュード _SmearAutoMagnitude toggle

自動モーション検出を有効にします。有効時、スメアがオブジェクトの動きに自動で反応します。

デフォルト: 0（オフ）

VRChatのダンスアニメーションでこれを有効にすると、手動のアニメーション設定なしで自動的にモーション反応型スメアが得られます。
モーション感度 _SmearMotionSensitivity range

自動モーション検出の感度を調整します。値が高いほど小さな動きにも反応します。

デフォルト: 1

範囲: 0.1 〜 10

VATベロシティ _SmearVATVelocity toggle

頂点アニメーションテクスチャ（VAT）のベロシティデータをスメアソースとして使用します。VATベースのアニメーション使用時に有効にします。

デフォルト: 0（オフ）

トレイル設定

トレイル長さ _SmearTrailLength range

スメアの後ろに続く残像トレイルの長さを設定します。

デフォルト: 0.1

範囲: 0 〜 0.5

トレイルフェード _SmearTrailFade range

トレイルのフェードアウト速度を制御します。値が高いほどトレイルが素早く消えます。

デフォルト: 0.5

範囲: 0 〜 1

グロー＆エミッション

グロー色 _SmearGlowColor color

スメアトレイルに適用されるグローの色を設定します。

デフォルト: (1, 1, 1, 1)（白）

グロー強度 _SmearGlowIntensity range

スメアのグローエフェクトの強度を制御します。

デフォルト: 1

範囲: 0 〜 3

グローパワー _SmearGlowPower range

グローの減衰パワーを制御します。値が高いほどグローがよりタイトに集中します。

デフォルト: 3

範囲: 0.5 〜 10

エミッション _SmearEmission range

スメアエフェクトのエミッション強度を設定します。自己発光する外観を作り出します。

デフォルト: 0

範囲: 0 〜 3

エミッション色 _SmearEmissionColor color

スメアトレイルのエミッション色を設定します。

デフォルト: (1, 0.5, 0, 1)（オレンジ）

オレンジで炎のようなトレイル、青でエネルギー/魔法エフェクト、白でクリーンなスピードラインの外観になります。

マスク

スメアマスク _SmearMask texture

スメアエフェクトの表示領域を制御するマスクテクスチャです。

デフォルト: "white"（全面表示）

白 = スメアあり、黒 = スメアなし。特定の手足や部位にスメアを制限する場合に使用します。

ブレンド＆ブラー

ブレンドモード _SmearBlendMode enum

スメアエフェクトのブレンド方法を選択します。

  • Normal (0) - 通常の合成
  • Soft (1) - ソフト合成。明るくなりすぎを防ぐ
  • Screen (2) - スクリーン合成。自然な明るさ加算
  • Overlay (3) - オーバーレイ合成。コントラスト強調

デフォルト: Normal (0)

ブレンド _SmearBlend range

スメアエフェクトの強度（不透明度）を制御します。

デフォルト: 1

範囲: 0 〜 1

ブラー _SmearBlur range

スメアエフェクトのぼかし量を調整します。

デフォルト: 0

範囲: 0 〜 1

距離フェード _SmearDistFade range

カメラ距離に基づいてスメアエフェクトをフェードさせます。値が高いほど近い距離でエフェクトがフェードアウトします。

デフォルト: 0

範囲: 0 〜 1

VRChatの最適化のために距離フェードを使用すると、アバターがカメラから遠い時の視覚的ノイズを軽減できます。
