オフセットリムライト

XYオフセットとライト方向連動で自由に位置を制御できるリムライト

概要

オフセットリムライトは、通常のリムライトとは異なり、リムの発光位置をXY方向に手動でオフセットできるエフェクトです。ビュー空間の法線にオフセットを加えてからフレネル計算を行うため、光の当たる位置を自由にコントロールできます。さらに、シーンのライト方向に連動させることも可能で、動的なライティング環境に柔軟に対応します。

キーワード _OFFSET_RIM_LIGHT で制御され、無効時はシェーダー命令が生成されません。

パラメータ

オフセットリムの色 _OffsetRimColor color

オフセットリムライトの発光色を設定します。シーンの雰囲気やキャラクターのデザインに合わせて調整できます。

デフォルト: (0.8, 0.9, 1, 1)（淡い青白）

逆光表現には暖色系、クールな印象には青系がおすすめです。
パワー _OffsetRimPower range

リムの鋭さ（減衰カーブ）を制御します。値が大きいほど縁の細い部分にのみ集中し、小さいほど広範囲に広がります。

デフォルト: 3

範囲: 0.01 〜 10

強度 _OffsetRimIntensity range

リムライトの明るさを制御します。1.0を超える値でHDR的な発光効果が得られます。

デフォルト: 1

範囲: 0 〜 10

オフセット X _OffsetRimOffsetX range

ビュー空間でのリム位置の水平方向オフセットです。正の値で右方向、負の値で左方向にリムが移動します。

デフォルト: 0.3

範囲: -5 〜 5

オフセット Y _OffsetRimOffsetY range

ビュー空間でのリム位置の垂直方向オフセットです。正の値で上方向、負の値で下方向にリムが移動します。

デフォルト: 0.1

範囲: -5 〜 5

ライト方向を使用 _OffsetRimUseLightDir toggle

有効にすると、シーンのディレクショナルライト方向に連動してリム位置が動的に変化します。手動オフセットにライト方向のオフセットが加算されます。

デフォルト: 0（無効）

動的なライティング環境（VRChatのワールドライト等）ではこれを有効にすると自然な見た目になります。
ライト方向の強さ _OffsetRimLightDirStrength range

ライト方向連動時の影響度を制御します。値が大きいほどライト方向に強く追従します。

デフォルト: 0.5

範囲: 0 〜 1

シャープネス _OffsetRimSharpness range

リムのトゥーン（セル調）境界のシャープさを制御します。smoothstepによるトゥーン境界が適用され、値が高いほどパキッとしたセルシェーディング風になります。

デフォルト: 0.5

範囲: 0 〜 1

アニメ調のくっきりしたリムには0.7〜0.9、柔らかい印象には0.2〜0.4がおすすめです。
シャドウマスク _OffsetRimShadowMask range

影になっている部分でリムライトをどの程度抑制するかを制御します。値が高いほど影部分でリムが弱くなり、より自然なライティング結果になります。

デフォルト: 0.5

範囲: 0 〜 1

マスク

オフセットリムマスク _OffsetRimMask texture

オフセットリムライトの表示領域を制御するマスクテクスチャです。Rチャンネルが参照されます。

デフォルト: "white"（全面表示）

白 = リムライトあり、黒 = リムライトなし。髪や衣装の特定部分にだけリムを適用したい場合に便利です。

ブレンド設定

ブレンドモード _OffsetRimBlendMode enum

オフセットリムライトのブレンド方法を選択します。

  • Normal (0) - 通常の加算合成
  • Soft (1) - ソフトな加算。明るくなりすぎを防ぐ
  • Screen (2) - スクリーン合成。自然な明るさ加算
  • Overlay (3) - オーバーレイ合成。コントラスト強調

デフォルト: Normal (0)

ブレンド _OffsetRimBlend range

オフセットリムライトの全体的な不透明度を制御します。

デフォルト: 1

範囲: 0 〜 1

ブラー _OffsetRimBlur range

リムのぼかし量を調整します。内部的にパワー値を減衰させることでソフトなリムを実現します。

デフォルト: 0

範囲: 0 〜 1

距離フェード _OffsetRimDistFade range

距離フェード機能（_DISTANCE_FADE）有効時に、カメラ距離に応じてオフセットリムの強度を減衰させる度合いを制御します。

デフォルト: 0

範囲: 0 〜 1

使い方のヒント

逆光表現

オフセットXを0に、オフセットYを正の値（例: 0.5）に設定すると、上方向からの逆光リムが表現できます。「ライト方向を使用」を有効にすると、ワールドのライト位置に追従して自動的に調整されます。

アニメ風の天使の輪

シャープネスを高め（0.7〜0.9）にして、オフセットYを正の値にすると、髪の天使の輪のような表現が可能です。マスクテクスチャを使って髪のメッシュだけに適用すると効果的です。

パフォーマンスについて

通常のリムライト（_RIM_LIGHT）と同時に使用可能ですが、両方を有効にするとシェーダーバリアント数が増加します。VRChat Quest環境ではどちらか一方の使用を推奨します。
