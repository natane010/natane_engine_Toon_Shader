グラデーションベースカラー

軸方向のグラデーションをベースカラーに適用

メッシュの特定の軸方向に沿ってグラデーションカラーを適用するエフェクトです。キャラクターの衣装に上下の色変化をつけたり、環境オブジェクトに高度に応じた色変化を加えるのに活用できます。

キーワード: _GRADIENT_BASE_COLOR

カラー設定

上部カラー _GradientTopColor color

グラデーションの終端（上側）の色です。

デフォルト: (1, 1, 1, 1)（白）

下部カラー _GradientBottomColor color

グラデーションの始端（下側）の色です。

デフォルト: (0.5, 0.5, 0.5, 1)（グレー）

軸・空間設定

グラデーション軸 _GradientAxis enum

グラデーションを適用する軸を選択します。

  • X (0) - 左右方向
  • Y (1) - 上下方向
  • Z (2) - 前後方向

デフォルト: 1（Y軸 / 上下方向）

座標空間 _GradientSpace enum

グラデーション計算に使用する座標空間を選択します。

  • Local (0) - オブジェクトのローカル座標。移動・回転しても一緒に動きます
  • World (1) - ワールド座標。オブジェクトの位置に関係なく固定

デフォルト: 0（Local）

グラデーション開始 _GradientStart float

グラデーションの開始位置（下部カラーの位置）を設定します。

デフォルト: 0

グラデーション終了 _GradientEnd float

グラデーションの終了位置（上部カラーの位置）を設定します。

デフォルト: 1

ブレンド設定

ブレンドモード _GradientBlendMode enum

グラデーションの合成方法を選択します。

  • Normal (0) - 通常合成
  • Soft (1) - ソフト合成
  • Screen (2) - スクリーン合成
  • Overlay (3) - オーバーレイ合成

デフォルト: 0（Normal）

ブレンド _GradientBlend range

グラデーションの適用強度を設定します。0 で無効、1 で完全に適用されます。

デフォルト: 1（範囲: 0 - 1）
