レンダリング設定

レンダリングモード、カリング、ステンシルなどの描画制御

概要

レンダリング設定は、マテリアルの基本的な描画方法を制御するセクションです。不透明/切り抜き/半透明のモード選択、ポリゴンの表裏描画制御、深度バッファの書き込み、ブレンドモードなど、シェーダーの根幹となる設定が含まれます。

レンダリングモード

描画タイプ RenderingMode enum

マテリアルのレンダリングモードを選択します。モードに応じて内部的に適切なシェーダーバリアントに切り替わります。すべてのプロパティは保持されます。

  • Opaque（不透明） - 標準的な不透明オブジェクト。肌、服、硬い物体などに使用。最も高速で推奨されるモードです。
  • Cutout（切り抜き） - アルファ閾値による透過。髪の毛、葉っぱ、フェンスなどに使用。ピクセル単位で完全に透明か不透明かの2択です。
  • Transparent（半透明） - 滑らかな透過。ガラス、水、煙、エフェクトなどに使用。アルファ値に応じて段階的に透過しますが、最も負荷が高いモードです。
  • Fur（ファー） - シェルベースの毛皮描画。メッシュを法線方向に16レイヤーで押し出し、ノイズテクスチャでカットオフすることで毛皮を再現します。GPU負荷が非常に高いため、VRChat Questでは使用できません。
  • Background（背景） - 背景・環境オブジェクト向け。ライトマップとPBR（物理ベースレンダリング）に対応し、建物・地形・小道具など静的オブジェクトに最適です。トゥーンシェーディングとリアルなGIライティングをブレンドできます。

デフォルト: Opaque

パフォーマンスの観点では Opaque > Cutout > Transparent の順で効率的です。可能な限りOpaqueを使用してください。

Cutout専用設定

アルファカットオフ _Cutoff range

Cutoutモード時のアルファ閾値です。テクスチャの透明度がこの値以下のピクセルを非表示にします。

  • 値を下げると: より多くのピクセルが表示される
  • 値を上げると: より多くのピクセルが非表示になる

デフォルト: 0.5（推奨）

詳細設定

カリングモード _Cull enum

ポリゴンのどちら側を描画するかを制御します。

  • Back (2) - 裏面を非表示（デフォルト。一般的な設定です）
  • Front (1) - 表面を非表示（特殊な用途向け）
  • Off (0) - 両面描画（裏面テクスチャ機能と併用する場合に設定）

デフォルト: Back (2)

両面描画（Off）は描画コストが2倍になります。必要な場合のみ使用してください。
Z書き込み _ZWrite enum

深度バッファへの書き込みを制御します。通常はONのままにしてください。

  • On (1) - 深度バッファに書き込む（不透明オブジェクトの標準設定）
  • Off (0) - 深度バッファに書き込まない（半透明やエフェクト向け）

デフォルト: On (1)

Transparent専用設定

ソースブレンド _SrcBlend enum

半透明描画時のソース（前景）のブレンド係数です。

デフォルト: SrcAlpha (5)

宛先ブレンド _DstBlend enum

半透明描画時のデスティネーション（背景）のブレンド係数です。

デフォルト: OneMinusSrcAlpha (10)

ブレンドモードは通常変更する必要はありません。標準設定で適切なアルファブレンドが行われます。

Fur専用設定

描画タイプを「ファー」に切り替えると、以下のFur専用セクションが表示されます。

ファーの長さ _FurLength range

毛の長さを制御します。

推奨: 0.01〜0.05

ファー密度 _FurDensity range

ノイズテクスチャのタイリングを制御し、毛の密度を決定します。

アルファカットオフ _FurAlphaCutoff range

ファーのアルファカットオフ閾値です。低い値で密な毛、高い値でまばらな毛になります。

ノイズテクスチャ _FurNoiseTex texture

毛の分布パターンを定義するノイズテクスチャです。テクスチャなしの場合はプロシージャルノイズが使用されます。

ファーマスク _FurMask texture

毛が生える領域を制御するマスクテクスチャです。白い部分に毛が生え、黒い部分には生えません。

根元カラー / 先端カラー _FurRootColor / _FurTipColor color

毛の根元と先端の色を個別に設定できます。根元は暗め、先端は明るめに設定すると自然な見た目になります。

重力 / 風 _FurGravity / _FurWindStrength range

物理シミュレーション設定です。重力で毛が下に垂れ、風で揺れアニメーションが加わります。

セルフオクルージョン / セルフシャドウ強度 _FurAO / _FurShadowStrength range

毛の根元が暗くなるオクルージョン効果と、毛の内部の影の強度を設定します。

LOD開始距離 / 最小レイヤー数 _FurLODDistance / _FurLODMinLayers range

パフォーマンス最適化設定です。指定した距離からシェルレイヤー数を段階的に減らします。

ファーは16シェルパスを使用し、GPU負荷が非常に高いです。LOD設定で遠距離のコストを削減してください。VRChat Questでは使用しないでください。

Background専用設定

描画タイプを「背景」に切り替えると、以下のBackground専用セクションが表示されます。

背景ライトマップ設定

ライトマップ トゥーン影響度 _LightmapToonInfluence range

ライトマップのトゥーンシェーディングへの影響度を制御します。

  • 0 - リアルGI（ライトマップをそのまま使用）
  • 0.5 - ハイブリッド（推奨。トゥーンとGIのバランス）
  • 1 - フルトゥーン（完全にトゥーンシェーディング準拠）
ライトマップを使用するには、Mesh Renderer の「Contribute GI」を有効にしてベイクしてください。
ライトマップ明度 _LightmapIntensity range

ライトマップの明るさを調整します。

PBR マテリアル設定

PBR ライティング _EnablePBR toggle

PBR（物理ベースレンダリング）ライティングを有効にします。トゥーンシェーディングの上にCook-Torrance GGX BRDFによる物理ベースの反射を追加します。

メタリック/スムーズネスマップ _PBR_MetallicGlossMap texture

メタリックとスムーズネスの情報を格納したテクスチャです。Rチャンネルにメタリック、Aチャンネルにスムーズネスが入ります。

メタリック _PBR_Metallic range

金属感の度合いです。0で非金属（プラスチック、木材など）、1で完全な金属になります。

デフォルト: 0

スムーズネス _PBR_Smoothness range

表面の滑らかさです。0で粗い表面（マット）、1で完全に滑らかな表面（鏡面反射）になります。

デフォルト: 0.5

アンビエントオクルージョンマップ _PBR_OcclusionMap texture

アンビエントオクルージョン（環境遮蔽）テクスチャです。隙間や溝に自然な影を追加します。

AO 強度 _PBR_OcclusionStrength range

アンビエントオクルージョンの効果の強さです。

リフレクションプローブ強度 _PBR_ReflectionIntensity range

リフレクションプローブからの環境反射の強度を調整します。

PBRはトゥーンシェーディングの上に物理ベースの反射を加えます。金属/光沢テクスチャで質感を表現できます。

使い方のポイント

  • VRChatアバターの多くのパーツ（肌、服、靴）にはOpaqueが最適です
  • 髪の毛や眉毛にはCutoutモードが適しています
  • ガラスや宝石などの透過素材にはTransparentを使用します
  • 毛皮や動物のキャラクターにはFurモードを使用します（GPU負荷に注意）
  • ワールドの建物や地形など静的な背景オブジェクトにはBackgroundモードが最適です
  • カリングOffは裏面テクスチャ使用時に必要ですが、パフォーマンスコストに注意してください
  • レンダリングモードの変更はシェーダーバリアントの切り替えを伴いますが、プロパティは保持されます
