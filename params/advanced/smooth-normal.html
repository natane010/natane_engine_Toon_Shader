スムースノーマル

滑らかな法線でアウトラインとシェーディングを改善

概要

スムースノーマルは、アウトラインの押し出し方向に滑らかな法線を使用することで、ハードエッジのメッシュでもアウトラインの途切れや不自然な突出を防ぐ機能です。頂点カラーまたはベイク済みテクスチャからスムース法線を読み取り、アウトラインの法線として使用します。さらに、シェーディングブレンド機能により、ライティング計算でも滑らかな法線を適用でき、影の境界線をソフトにできます。

キーワード _SMOOTH_NORMAL で制御され、無効時はシェーダー命令が生成されません。ローカルキーワード（shader_feature_local）として実装されています。

パラメータ

スムースノーマルを有効化 _SmoothNormal toggle

スムースノーマル機能の有効/無効を切り替えます。キーワード _SMOOTH_NORMAL でコンパイル時に分岐します。

デフォルト: OFF

スムースノーマルモード _SmoothNormalMode enum

スムース法線の取得元を選択します。

  • 0 - Vertex Color ObjectSpace: 頂点カラーRGBにオブジェクト空間の法線が格納されている場合に使用。[0,1]の頂点カラーを[-1,1]にデコードします。
  • 1 - Vertex Color TangentSpace: 頂点カラーRGBにタンジェント空間の法線が格納されている場合に使用。TBN行列で変換します。lilToonと互換性があります。
  • 2 - Baked Normal Texture: テクスチャに焼き込まれた法線を使用。テクスチャからサンプリングしてタンジェント空間から変換します。

デフォルト: 0（Vertex Color ObjectSpace）

スムースノーマルテクスチャ _SmoothNormalTex texture

モード2（Baked Normal Texture）で使用するスムース法線テクスチャです。タンジェント空間の法線が格納されたテクスチャを指定します。

デフォルト: "bump"

モード0・1の場合は使用されません。
シェーディングブレンド _SmoothNormalShadingBlend range

ライティング計算に使用する法線にスムース法線をブレンドする強さです。0で元の法線のみを使用し、1でスムース法線のみをシェーディングに使用します。アウトラインだけでなく、影の境界線も滑らかにしたい場合に使用します。

デフォルト: 0

範囲: 0 〜 1

0.3〜0.5で使用すると、影のガタつきを抑えつつ元の形状感を残せます。

使い方のヒント

  • アウトラインの品質改善に最も効果的です。ハードエッジのメッシュ（ローポリモデルや結合されていないメッシュ）で顕著な改善が得られます
  • モード1（Vertex Color TangentSpace）はlilToonのスムース法線と互換性があるため、lilToonからの移行時にそのまま使用できます
  • モード2（Baked Normal Texture）は頂点カラーを他の用途に使用している場合に便利です
  • シェーディングブレンドはアウトライン以外にライティングにも影響するため、控えめな値から調整してください
  • 頂点シェーダー（アウトライン方向）とフラグメントシェーダー（シェーディングブレンド）の両方で使用されます
