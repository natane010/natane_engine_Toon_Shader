グラデーションベースカラー

ベースカラーに縦方向・横方向のグラデーションをオーバーレイ

概要

グラデーションベースカラーは、選択した軸に沿ってモデルの表面に2色のグラデーションを適用する機能です。追加テクスチャや複雑なUVペイントなしで、足元が暗く頭部が明るいといった自然な色の遷移を作成できます。

グラデーションはローカル座標空間またはワールド座標空間で動作し、既存テクスチャとの柔軟な統合のために複数のブレンドモードをサポートしています。

キーワード _GRADIENT_BASE_COLOR で制御されます。

パラメータ

上部カラー _GradientTopColor color

選択した軸に応じて、モデルの上部（Y軸）、右側（X軸）、または前面（Z軸）に適用されるグラデーション終端色です。

デフォルト: (1, 1, 1, 1) — 白

下部カラー _GradientBottomColor color

選択した軸に応じて、モデルの下部（Y軸）、左側（X軸）、または背面（Z軸）に適用されるグラデーション開始色です。

デフォルト: (0.5, 0.5, 0.5, 1) — 中間グレー

グラデーション軸 _GradientAxis enum

グラデーションの方向を決定します。Yは縦方向（下から上）、Xは横方向（左から右）、Zは前後方向のグラデーションを生成します。

デフォルト: Y（縦方向）

Y軸（縦方向）は、キャラクターの自然な着色に最もよく使われるオプションです。
座標空間 _GradientSpace enum

グラデーションをローカルオブジェクト空間で計算するか、ワールド空間で計算するかを選択します。ローカル空間はオブジェクトとともに移動し、ワールド空間はシーンに対して固定されます。

デフォルト: Local

異なる位置にある複数オブジェクトで一貫したグラデーションにはWorld空間を使用してください。個別キャラクターの着色にはLocal空間が適しています。
グラデーション開始位置 _GradientStart float

選択した軸に沿ったグラデーション開始位置（下部カラー側）です。この値を調整すると、グラデーション遷移の開始点がシフトします。

デフォルト: 0

グラデーション終了位置 _GradientEnd float

選択した軸に沿ったグラデーション終了位置（上部カラー側）です。StartとEndの距離がグラデーションのシャープさを制御します — 狭い範囲は硬い遷移を作成します。

デフォルト: 1

ブレンドモード _GradientBlendMode enum

グラデーションとベーステクスチャの合成方法を制御します。Normalは直接混合、Softはソフトライトブレンド、Screenは明るく、Overlayは乗算とスクリーンを組み合わせたコントラスト保持合成を行います。

デフォルト: Normal (0)

Overlayブレンドモードは、テクスチャのディテールを保持しながら微妙な色調変化を加えるのに最適です。
ブレンド強度 _GradientBlend range

グラデーション効果の全体的な強度を制御します。0ではグラデーションの効果がなくなり、1ではフル強度で適用されます。

デフォルト: 1

範囲: 0 - 1

使い方のヒント

  • キャラクターの自然な着色には、Y軸（縦方向）をWorld空間で使用するのがおすすめです。白からわずかに暖かいトーンへのグラデーションで、上からの自然な太陽光をシミュレートできます。
  • Overlayブレンドモードと組み合わせると、既存テクスチャを損なわない微妙な色調変化が得られます。
  • Start/Endの範囲を狭く（例: 0.4〜0.6）すると、鋭い色の遷移帯が作られ、スタイライズドな効果に有効です。
  • この機能は非常に軽量で、ピクセルあたり単純な補間とブレンドのみを実行するため、GPU負荷はほぼ追加されません。
  • 補色（例: 暖かいオレンジの下部と冷たいブルーの上部）を使用すると、大気的な環境演出が可能です。
