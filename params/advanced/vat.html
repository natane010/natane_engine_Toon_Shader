VAT（頂点アニメーションテクスチャ）

頂点アニメーションテクスチャによるメッシュアニメーション

概要

VAT（Vertex Animation Texture）は、Houdiniなどで作成した頂点アニメーションをテクスチャとしてベイクし、シェーダー上で再生する技術です。流体シミュレーション、布シミュレーション、複雑な変形アニメーションなど、リアルタイムでは重すぎる物理演算をテクスチャに焼き込んで軽量に再生できます。

キーワード _VAT で制御されます。Houdini互換のフォーマットに対応しています。

基本設定

VATアニメーションを有効化 _VAT toggle

VAT機能の有効/無効を切り替えます。キーワード _VAT でコンパイル分岐します。

デフォルト: OFF

VAT位置マップ _VATPositionMap texture

頂点の位置情報を格納したテクスチャです。HoudiniのVATエクスポートで生成されるPosition Map（.exr）を使用します。

デフォルト: "black"

テクスチャのインポート設定で圧縮を「None」、sRGBをOFFに設定してください。
フレーム数 _VATNumOfFrames float

VATアニメーションの総フレーム数です。Houdiniのエクスポート設定と一致させる必要があります。

デフォルト: 30

アニメーション速度 _VATSpeed range

アニメーションの再生速度の倍率です。1.0で通常速度、2.0で2倍速になります。

デフォルト: 1.0

アニメーション強度 _VATIntensity range

アニメーション効果の強さです。0で効果なし、1で通常、2で誇張された動きになります。

デフォルト: 1.0

範囲: 0〜2

位置パラメータ

位置最小値 _VATPositionMin float

Houdiniエクスポート時の位置範囲の最小値です。テクスチャの値をワールド座標に変換する際に使用されます。

デフォルト: -1.0

位置最大値 _VATPositionMax float

Houdiniエクスポート時の位置範囲の最大値です。

デフォルト: 1.0

VAT法線マップ（オプション）

VAT法線マップを使用 _VATNormal toggle

VAT法線マップの使用を有効化します。位置だけでなく法線もアニメーションさせたい場合に使用します。キーワード _VAT_NORMAL で制御されます。

デフォルト: OFF

VAT法線マップ _VATNormalMap texture

法線情報を格納したVATテクスチャです。HoudiniのNormal Map（.exr）を使用します。

デフォルト: "bump"

法線最小値 _VATNormalMin float

法線テクスチャの値範囲の最小値です。

デフォルト: -1.0

法線最大値 _VATNormalMax float

法線テクスチャの値範囲の最大値です。

デフォルト: 1.0

詳細設定

パッキングモード _VATPackingMode enum

VATテクスチャの位置データの解釈方法を選択します。

  • Absolute (0) - 絶対位置モード。頂点位置を直接置き換えます。
  • Offset (1) - オフセットモード。元の位置にオフセットを追加します（推奨）。

デフォルト: 0（Absolute）

通常はOffset モードが推奨です。元メッシュの形状を保持したままアニメーションを加算できます。

セットアップ方法

  1. Houdiniで VAT（ROP Output Driver）を使用してエクスポート
  2. Position Map（.exr）をUnityにインポートし、VAT位置マップとして設定
  3. 必要に応じてNormal Map（.exr）をVAT法線マップとして設定
  4. フレーム数をHoudiniの設定と一致させる
  5. 位置最小値/最大値をHoudiniのエクスポート範囲に合わせる

注意事項

  • VATテクスチャは通常のテクスチャよりメモリを多く使用します
  • VRChatでは適切な解像度とフレーム数を選択してください
  • テクスチャの圧縮は無効（None）にしてください。圧縮するとアニメーションが乱れます
  • sRGBカラースペースをOFFに設定してください
