ハイトフェード

高さベースの透明フェードで段階的な出現・消失表現

概要

ハイトフェードは、ワールドまたはローカルの高さ位置に基づいてマテリアルを段階的にフェードさせる機能です。オブジェクトが地面から出現したり、霧の境界や空間的なしきい値に溶け込んでいくような効果を作成できます。

3つのフェードモードが利用可能です。スムーズな透明度のAlphaブレンド、硬いバイナリカットオフのClip、そして不透明シェーダーでも透過ソーティングの問題なく動作するオーダードディザリングパターンのDitheringです。

オプションのグロウエッジカラーにより、フェード境界に明るいディゾルブ風のボーダーを追加して、ドラマチックな視覚効果を得ることができます。

キーワード _HEIGHT_FADE で制御されます。

パラメータ

フェード開始位置 _HeightFadeStart float

フェードが始まる高さ位置です。この高さより下（反転時は上）では、マテリアルは完全に透明になります。

デフォルト: 0

フェード終了位置 _HeightFadeEnd float

フェードが終わる高さ位置です。この高さより上では、マテリアルは完全に不透明になります。StartとEndの間が遷移ゾーンです。

デフォルト: 1

この値を時間経過でアニメーションさせると、テレポートやスポーンエフェクトが作れます。
フェード軸 _HeightFadeAxis enum

ハイトフェードが動作する軸を選択します。Yが最も一般的（縦方向フェード）で、XとZは横方向や奥行きベースの効果に使用できます。

デフォルト: Y

座標空間 _HeightFadeSpace enum

高さをローカルオブジェクト空間で測定するか、ワールド空間で測定するかを決定します。ローカル空間はオブジェクトとともに移動し、ワールド空間はシーン内で固定されます。

デフォルト: Local

フェード反転 _HeightFadeInvert toggle

フェード方向を反転します。有効にすると、しきい値より下ではなく上でマテリアルがフェードアウトします。

デフォルト: OFF

フェードモード _HeightFadeMode enum

フェード方法を選択します。Alphaはスムーズな透明度ブレンド、Clipは硬いバイナリカットオフ（完全に表示または完全に不可視）、Ditheringは不透明シェーダーで透過をシミュレートするオーダードディザリングパターンを使用します。

デフォルト: Alpha

Ditheringモードは透過ソーティングのアーティファクトを回避し、不透明シェーダーバリアントで動作します。
フェード強度 _HeightFadeBlend range

フェード効果の全体的な強度を制御します。0ではハイトフェードの効果がなく、1ではフル強度で適用されます。

デフォルト: 1

範囲: 0 - 1

ディザスケール _HeightFadeDitherScale range

Ditheringモード使用時のディザリングパターンのスケールを制御します。低い値は粗く目立つパターン、高い値は細かく目立ちにくいパターンになります。

デフォルト: 4

範囲: 1 - 200

エッジ幅 _HeightFadeEdgeWidth range

フェード境界でのグロウエッジ効果の幅です。0に設定するとエッジグロウが完全に無効化されます。

デフォルト: 0

範囲: 0 - 0.5

エッジカラー _HeightFadeEdgeColor color

フェード境界でのグロウエッジのHDRカラーです。HDR値（強度 > 1）を使用すると、ブルーム対応のグロウ効果が得られます。

デフォルト: (1, 0.5, 0, 1) — オレンジ

明るいHDRカラー（強度2〜5）とポストプロセッシングブルームを組み合わせると、印象的なSF風ディゾルブ表現が作れます。

使い方のヒント

  • テレポートやスポーンエフェクトには、アニメーションクリップやスクリプトでHeightFadeEndの値を時間経過でアニメーションさせてください。
  • 不透明シェーダーバリアントにはDitheringモードが推奨です。VRChatワールドで視覚的な不具合を引き起こす透過ソーティングの問題を回避できます。
  • エッジグロウは、明るいHDRカラーとポストプロセッシングブルームを組み合わせることで、SF風ディゾルブの外観を作り出します。
  • シーン内のすべてのオブジェクトで一貫した地面レベルのフェードには、Y軸のWorld空間を使用してください。
  • ディゾルブエフェクトと組み合わせて、レイヤー状の消失アニメーションを作成できます — ハイトフェードで全体の方向を、ディゾルブでテクスチャベースのディテールを制御します。
