高さフェード

高さに基づいたメッシュのフェード

メッシュの特定の軸方向の高さに応じて徐々に透明にフェードさせるエフェクトです。キャラクターの足元からの消失演出や、テレポートエフェクトなどに活用できます。アウトラインパスにも適用されます。

キーワード: _HEIGHT_FADE

基本設定

フェード開始高さ _HeightFadeStart float

フェードが開始する高さを設定します。この位置から徐々に透明になります。

デフォルト: 0

フェード終了高さ _HeightFadeEnd float

フェードが完了する高さを設定します。この位置で完全に透明になります。

デフォルト: 1

フェード軸 _HeightFadeAxis enum
  • X (0) - 左右方向
  • Y (1) - 上下方向
  • Z (2) - 前後方向

デフォルト: 1（Y軸）

座標空間 _HeightFadeSpace enum
  • Local (0) - オブジェクトのローカル座標
  • World (1) - ワールド座標

デフォルト: 0（Local）

方向を反転 _HeightFadeInvert toggle

フェード方向を反転します。上から消える代わりに下から消えるようになります。

デフォルト: OFF

フェードモード

フェードモード _HeightFadeMode enum

フェードの表現方法を選択します。

  • Alpha (0) - 半透明フェード。滑らかなグラデーション
  • Clip (1) - バイナリカット。くっきりした境界線
  • Dithering (2) - ディザリング。不透明シェーダーでも使えるドットパターンフェード

デフォルト: 0（Alpha）

不透明シェーダーでは Alpha モードが効かないため、Clip か Dithering を使用してください。
ブレンド _HeightFadeBlend range

フェード効果の適用強度です。

デフォルト: 1（範囲: 0 - 1）

ディザースケール _HeightFadeDitherScale range

Ditheringモード使用時のドットパターンの大きさです。

デフォルト: 4（範囲: 1 - 200）

エッジグロー

エッジグロー幅 _HeightFadeEdgeWidth range

フェード境界に光るエッジエフェクトの幅です。0 で無効になります。

デフォルト: 0（範囲: 0 - 0.5）

エッジグローカラー _HeightFadeEdgeColor color (HDR)

エッジグローの色です。HDR対応でブルーム効果と組み合わせられます。

デフォルト: (1, 0.5, 0, 1)（オレンジ）
